# 실습 전 준비

## 0-1. 터미널 열기

Ubuntu에서 터미널을 열고 아래 명령을 먼저 입력한다.

```bash
pwd
whoami
cd ~
mkdir -p ~/linux5-lab
cd ~/linux5-lab
```

### 확인할 점

- `pwd`: 현재 위치를 보여준다.
- `whoami`: 현재 로그인한 사용자 이름을 보여준다.
- `cd ~`: 내 홈 디렉터리로 이동한다.
- `mkdir -p ~/linux5-lab`: 실습 폴더를 만든다.
- `cd ~/linux5-lab`: 이제 이 폴더 안에서 실습한다.

# 실습 1. apt 다시 연습하기

5-1에서 `apt` 가 패키지를 설치하고 삭제하는 도구라는 것을 배웠다.  
이번에는 가장 짧은 흐름으로 다시 연습한다.

## 1-1. 패키지 검색

```bash
apt search tree
```

### 설명

- `tree` 는 폴더 구조를 나무 모양으로 보여주는 명령이다.
- 검색 결과가 많이 나와도 괜찮다. 이름에 `tree` 가 들어간 패키지를 찾는 과정이다.

## 1-2. 패키지 설치

```bash
sudo apt update
sudo apt install tree
```

### 설명

- `sudo apt update`: 패키지 목록을 최신 상태로 가져온다.
- `sudo apt install tree`: `tree` 패키지를 설치한다.

## 1-3. 설치 확인

```bash
tree --version
tree .
```

### 설명

- `tree --version`: 설치가 되었는지 확인한다.
- `tree .`: 현재 폴더 구조를 보여준다.

## 1-4. 삭제

```bash
sudo apt remove tree
```

### 설명

- 실습이 끝난 뒤 패키지를 삭제한다.
- 설치와 삭제를 모두 해보는 것이 목적이다.

### 체크

- `apt search` 를 직접 실행했다.
- `sudo apt update` 와 `sudo apt install` 을 실행했다.
- `tree .` 결과를 확인했다.

# 실습 2. systemctl 다시 연습하기

5-1에서 `systemctl` 이 서비스를 관리하는 명령이라는 것을 배웠다.  
이번에는 **서비스 상태를 보고 다시 시작하는 것**만 연습한다.

## 2-1. 서비스 목록 보기

```bash
systemctl list-units --type=service
```

### 설명

- 현재 실행 중이거나 systemd가 관리 중인 서비스들을 볼 수 있다.
- 목록이 길면 방향키 또는 마우스로 올려서 보면 된다.

## 2-2. 서비스 상태 보기

```bash
systemctl status systemd-timesyncd
```

### 설명

- `systemd-timesyncd` 는 시간 동기화 관련 서비스다.
- 환경에 따라 서비스 이름이 다를 수 있다.
- 만약 없으면 목록에서 다른 서비스 이름을 하나 골라서 같은 방식으로 확인하면 된다.

## 2-3. 서비스 다시 시작하기

```bash
sudo systemctl restart systemd-timesyncd
systemctl status systemd-timesyncd
```

### 설명

- `restart` 는 서비스를 다시 시작하는 명령이다.
- 재시작 후 `status` 를 다시 확인해 정상 상태인지 본다.

## 2-4. 유닛 파일 보기

```bash
systemctl cat systemd-timesyncd
```

### 설명

- 이 서비스가 어떤 설정으로 동작하는지 간단히 볼 수 있다.
- 지금은 내용을 모두 이해하지 못해도 괜찮다.

### 체크

- `systemctl status` 를 직접 실행했다.
- `restart` 후 다시 `status` 를 확인했다.
- `systemctl cat` 으로 유닛 파일을 한 번 봤다.

# 실습 3. .bashrc 다시 연습하기

5-1에서 `.bashrc` 는 터미널이 시작될 때 읽는 설정 파일이라고 배웠다.  
이번에는 **alias 한 개 추가하기**만 다시 해본다.

## 3-1. 백업 만들기

```bash
cp ~/.bashrc ~/.bashrc.backup
```

### 설명

- 설정 파일을 잘못 수정했을 때 복구할 수 있도록 백업한다.

## 3-2. 편집하기

```bash
nano ~/.bashrc
```

파일 맨 아래에 아래 한 줄을 추가한다.

```bash
alias ll='ls -alF'
```

## 3-3. 적용하기

```bash
source ~/.bashrc
ll
```

### 설명

- `source ~/.bashrc`: 수정 내용을 즉시 적용한다.
- `ll`: 이제 `ls -alF` 대신 짧게 입력할 수 있다.

### 체크

- `.bashrc` 백업 파일을 만들었다.
- `alias ll='ls -alF'` 를 추가했다.
- `source ~/.bashrc` 후 `ll` 이 동작했다.

# 실습 4. find 다시 연습하기

이번 실습은 시스템 폴더가 아니라 **내 실습 폴더 안에서만** 진행한다.

## 4-1. 연습용 파일 만들기

```bash
cd ~/linux5-lab
mkdir -p find-practice/docs
touch a.txt
touch b.log
touch empty.txt
touch find-practice/docs/c.txt
```

### 설명

- `mkdir -p`: 폴더를 만든다.
- `touch`: 빈 파일을 만든다.

## 4-2. txt 파일 찾기

```bash
find . -name "*.txt"
```

## 4-3. 빈 파일 찾기

```bash
find . -type f -empty
```

## 4-4. 디렉터리만 찾기

```bash
find . -type d
```

### 설명

- `-name "*.txt"`: 이름이 `.txt` 로 끝나는 파일 찾기
- `-type f`: 일반 파일만 찾기
- `-empty`: 비어 있는 파일 찾기
- `-type d`: 디렉터리만 찾기

### 체크

- `.txt` 파일을 찾았다.
- 빈 파일을 찾았다.
- 디렉터리만 따로 찾았다.

# 실습 5. stat, df, du 다시 연습하기

이 세 명령어는 함께 비교하며 익히면 헷갈리지 않는다.

## 5-1. stat

```bash
stat a.txt
```

### 설명

- `a.txt` 파일의 크기, 권한, 수정 시간 등을 본다.
- 즉, **파일 1개의 자세한 정보**를 보는 명령이다.

## 5-2. du

```bash
du -sh .
du -sh ~/linux5-lab
```

### 설명

- 현재 폴더가 얼마나 용량을 쓰는지 확인한다.
- 즉, **폴더의 크기**를 보는 명령이다.

## 5-3. df

```bash
df -h
```

### 설명

- 컴퓨터 저장공간 전체가 얼마나 차 있는지 본다.
- 즉, **디스크 전체 현황**을 보는 명령이다.

### 한 줄 정리

- `stat`: 파일 1개 정보
- `du`: 폴더 용량
- `df`: 디스크 전체 용량

# 실습 6. tar 다시 연습하기

이번에는 파일을 몇 개 만든 뒤 하나의 압축 파일로 묶어 본다.

## 6-1. 압축할 폴더 준비

```bash
cd ~/linux5-lab
mkdir -p tar-practice
echo "hello" > tar-practice/file1.txt
echo "linux" > tar-practice/file2.txt
```

## 6-2. 압축 파일 만들기

```bash
tar -czvf tar-practice.tar.gz tar-practice
```

### 설명

- `-c`: 새로 만들기
- `-z`: gzip 압축
- `-v`: 화면에 진행 내용 표시
- `-f`: 파일 이름 지정

## 6-3. 내용 확인하기

```bash
tar -tvf tar-practice.tar.gz
```

### 설명

- 압축을 풀지 않고 안에 무엇이 들어 있는지 본다.

## 6-4. 압축 풀기

```bash
mkdir -p restore
tar -xzvf tar-practice.tar.gz -C restore
```

### 설명

- `-x`: 압축 해제
- `-C restore`: `restore` 폴더 안에 풀기

### 체크

- `.tar.gz` 파일을 만들었다.
- `tar -tvf` 로 내용 목록을 봤다.
- `restore` 폴더에 압축을 풀었다.

# 실습 7. read 다시 연습하기

이번에는 사용자의 입력을 받아 출력하는 아주 짧은 스크립트를 만들어 본다.

## 7-1. 스크립트 만들기

```bash
nano ~/linux5-lab/hello.sh
```

아래 내용을 입력한다.

```bash
#!/bin/bash
read -p "이름을 입력하세요: " name
echo "안녕하세요, ${name}님."
```

## 7-2. 실행 권한 주기

```bash
chmod +x ~/linux5-lab/hello.sh
```

## 7-3. 실행하기

```bash
~/linux5-lab/hello.sh
```

### 설명

- `read -p`: 입력 안내 문장을 보여주고 값을 입력받는다.
- `chmod +x`: 스크립트를 실행 가능하게 만든다.

### 추가 연습

아래처럼 한 줄 더 넣어서 학번도 입력받아 볼 수 있다.

```bash
read -p "학번을 입력하세요: " student_id
```

# 실습 8. 아주 쉬운 종합 연습

지금까지 배운 명령을 짧게 이어서 사용해 본다.

## 8-1. 종합 미션

아래 순서대로 해 본다.

1. `~/linux5-lab/final` 폴더를 만든다.
2. `note.txt` 파일을 만든다.
3. `find` 로 `note.txt` 를 찾는다.
4. `stat` 으로 `note.txt` 정보를 본다.
5. `tar` 로 `final` 폴더를 압축한다.
6. `du` 로 현재 실습 폴더 용량을 본다.
7. `df -h` 로 디스크 전체 사용량을 본다.

예시 명령:

```bash
cd ~/linux5-lab
mkdir -p final
echo "마지막 실습" > final/note.txt
find ~/linux5-lab -name "note.txt"
stat final/note.txt
tar -czvf final.tar.gz final
du -sh ~/linux5-lab
df -h
```
