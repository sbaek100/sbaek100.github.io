# 시스템 관리 필수 커맨드 라인 시나리오 실습

이번 자료는 명령어를 따로따로 연습하지 않고, **하나의 작업 시나리오를 따라가면서 필요한 명령어를 모두 써 보는 방식**으로 구성했다.

상황은 다음과 같다.

> "새로운 실습 디렉터리를 만들고, 필요한 패키지를 설치하고, 서비스 상태를 점검하고, 파일을 찾고, 사용량을 확인하고, 결과를 압축해서 보관한 뒤, 쉘 설정과 실행 권한까지 마무리한다."

이번 실습에서 반드시 써 볼 명령어는 아래와 같다.

- 파일/이동: `pwd`, `cd`, `mkdir -p`, `cp`
- 패키지 관리: `sudo apt update`, `sudo apt install`, `sudo apt remove`
- 서비스 관리: `systemctl status`, `sudo systemctl restart`
- 검색/확인: `find`, `stat`
- 디스크 확인: `df -h`, `du -sh`
- 압축: `tar -czvf`, `tar -xzvf`
- 쉘 설정: `source ~/.bashrc`
- 실행 권한: `chmod +x`

# 실습 시나리오

## 상황

여러분은 지금 막 Ubuntu 서버에 접속했다.  
실습용 작업 폴더를 만들고, 간단한 도구를 설치해 확인한 뒤, 서비스 상태를 점검하고, 파일을 정리해서 압축 보관해야 한다.  
마지막에는 자주 쓰는 셸 설정도 반영하고, 간단한 스크립트를 실행 가능하게 만들어야 한다.

---

# 1. 현재 위치 확인하고 작업 폴더 만들기

먼저 내가 어디에 있는지 확인하고, 홈 디렉터리 아래에 오늘 사용할 작업 폴더를 만든다.

```bash
pwd
cd ~
mkdir -p ~/linux5-scenario/docs
cd ~/linux5-scenario
pwd
```

확인 포인트:

- `pwd`는 현재 위치를 보여준다.
- `cd ~`는 홈 디렉터리로 이동한다.
- `mkdir -p`는 필요한 하위 디렉터리까지 한 번에 만든다.

---

# 2. 기존 설정 파일을 백업하기

실습 중 설정 파일을 건드리기 전에 백업하는 습관을 들인다.

```bash
cp ~/.bashrc ~/linux5-scenario/bashrc.backup
```

확인 포인트:

- `cp`는 파일 복사 명령이다.
- 실제 운영 환경에서는 설정 파일을 수정하기 전에 백업하는 것이 기본이다.

---

# 3. 패키지 목록을 갱신하고 도구 설치하기

실습용으로 `tree`를 설치해서 디렉터리 구조를 쉽게 확인해 본다.

```bash
sudo apt update
sudo apt install tree
tree .
```

확인 포인트:

- `sudo apt update`는 설치 가능한 목록을 최신화한다.
- `sudo apt install tree`는 `tree` 패키지를 설치한다.
- `tree .`로 현재 작업 폴더 구조를 확인할 수 있다.

---

# 4. 서비스 상태를 점검하고 다시 시작하기

서버 관리자는 서비스가 정상인지 먼저 확인해야 한다.  
예시로 `systemd-timesyncd` 서비스를 확인하고 다시 시작해 본다.

```bash
systemctl status systemd-timesyncd
sudo systemctl restart systemd-timesyncd
systemctl status systemd-timesyncd
```

확인 포인트:

- `systemctl status`는 현재 서비스 상태 확인의 시작점이다.
- `restart` 후에는 다시 `status`로 결과를 점검한다.

> 환경에 따라 `systemd-timesyncd`가 없으면 `ssh`, `cron`, `NetworkManager` 등 실제 존재하는 서비스로 바꾸어 실습한다.
{: .prompt-tip }

---

# 5. 실습용 파일 만들고 검색하기

이제 작업 폴더 안에 파일을 만들고, 원하는 파일을 찾아 본다.

```bash
cd ~/linux5-scenario
touch docs/note.txt
touch docs/system.log
find ~/linux5-scenario -name "*.txt"
```

확인 포인트:

- `find`는 원하는 조건에 맞는 파일을 찾을 때 사용한다.
- `.txt` 파일만 찾는 식으로 범위를 줄여 검색할 수 있다.

---

# 6. 파일 상세 정보 확인하기

찾은 파일의 상태를 확인한다.

```bash
stat ~/linux5-scenario/docs/note.txt
```

확인 포인트:

- `stat`는 파일 크기, 권한, 수정 시각 등을 확인할 수 있다.
- 파일이 존재하는지만 보는 것이 아니라, 상태까지 확인하는 습관이 중요하다.

---

# 7. 디스크 사용량 점검하기

시스템 전체 사용량과, 내가 만든 작업 폴더의 사용량을 각각 확인한다.

```bash
df -h
du -sh ~/linux5-scenario
```

확인 포인트:

- `df -h`는 시스템 전체 디스크 상태를 본다.
- `du -sh`는 특정 디렉터리의 실제 사용량을 본다.

---

# 8. 결과물을 압축해서 보관하기

작업 폴더를 압축 파일로 만들고, 다시 복원해 본다.

```bash
cd ~
tar -czvf linux5-scenario.tar.gz linux5-scenario
mkdir -p ~/linux5-restore
tar -xzvf linux5-scenario.tar.gz -C ~/linux5-restore
```

확인 포인트:

- `tar -czvf`는 압축 파일 생성
- `tar -xzvf`는 압축 해제
- `-C`는 해제할 위치 지정

압축 해제 후 다시 확인해 보자.

```bash
find ~/linux5-restore -name "note.txt"
```

---

# 9. 쉘 설정 추가하고 즉시 반영하기

자주 쓰는 명령을 편하게 쓰기 위해 `ll` 별칭을 추가한다.

```bash
nano ~/.bashrc
```

파일 끝에 아래 한 줄을 추가한다.

```bash
alias ll='ls -alF'
```

이제 변경 사항을 현재 셸에 바로 반영한다.

```bash
source ~/.bashrc
ll
```

확인 포인트:

- `.bashrc`를 수정한 뒤 `source ~/.bashrc`를 실행하면 새 터미널을 열지 않아도 된다.

---

# 10. 실행 가능한 스크립트 만들기

간단한 스크립트를 만들고 실행 권한을 부여해 본다.

```bash
nano ~/linux5-scenario/hello.sh
```

아래 내용을 입력한다.

```bash
#!/bin/bash
echo "hello linux"
```

저장 후 실행 권한을 부여하고 실행한다.

```bash
chmod +x ~/linux5-scenario/hello.sh
~/linux5-scenario/hello.sh
```

확인 포인트:

- `chmod +x`는 파일에 실행 권한을 준다.
- 스크립트는 내용 작성만으로 끝나지 않고, 실행 권한까지 있어야 바로 실행할 수 있다.

---

# 11. 패키지 정리하기

실습이 끝났으면 설치한 패키지를 정리한다.

```bash
sudo apt remove tree
```

확인 포인트:

- 실습 환경에서는 설치와 제거를 둘 다 경험해 보는 것이 좋다.

---

# 12. 최종 미션

아래 명령어 흐름을 도움 없이 다시 수행해 보자.

```bash
pwd
cd ~
mkdir -p ~/linux5-scenario/docs
cp ~/.bashrc ~/linux5-scenario/bashrc.backup
sudo apt update
sudo apt install tree
systemctl status systemd-timesyncd
sudo systemctl restart systemd-timesyncd
touch ~/linux5-scenario/docs/note.txt
find ~/linux5-scenario -name "*.txt"
stat ~/linux5-scenario/docs/note.txt
df -h
du -sh ~/linux5-scenario
tar -czvf linux5-scenario.tar.gz ~/linux5-scenario
mkdir -p ~/linux5-restore
tar -xzvf linux5-scenario.tar.gz -C ~/linux5-restore
source ~/.bashrc
chmod +x ~/linux5-scenario/hello.sh
sudo apt remove tree
```

이 흐름을 직접 따라갈 수 있으면, 초보 단계에서 필요한 시스템 관리 명령어는 충분히 잘 잡힌 것이다.
