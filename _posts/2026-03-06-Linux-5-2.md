# 실습 2. systemctl 서비스 관리

## 2-1. 서비스 목록 확인

```bash
systemctl list-units --type=service --state=running
```

**출력 예시:**
```
  UNIT                        LOAD   ACTIVE SUB     DESCRIPTION
  cron.service                loaded active running Regular background program processing daemon
  dbus.service                loaded active running D-Bus System Message Bus
  ssh.service                 loaded active running OpenBSD Secure Shell server
  ...

LOAD   = Reflects whether the unit definition was properly loaded.
ACTIVE = The high-level unit activation state, i.e. generalization of SUB.
SUB    = The low-level unit activation state, values depend on unit type.
```

---

## 2-2. SSH 서비스 상태 확인

```bash
systemctl status ssh
```

**출력 예시:**
```
● ssh.service - OpenBSD Secure Shell server
     Loaded: loaded (/usr/lib/systemd/system/ssh.service; enabled; preset: enabled)
     Active: active (running) since Tue 2026-03-11 09:00:00 KST; 1h 23min ago
       Docs: man:sshd(8)
             man:sshd_config(5)
```


**출력 예시 (Active 부분):**
```
Active: active (running) since Tue 2026-03-11 10:30:00 KST; 3s ago
```

---

## 2-4. 직접 서비스 등록 실습

```bash
# 1. 실행할 스크립트 작성
sudo bash -c 'cat > /usr/local/bin/heartbeat.sh << "EOF"
#!/bin/bash
while true; do
    echo "$(date): heartbeat" >> /tmp/heartbeat.log
    sleep 10
done
EOF'

sudo chmod +x /usr/local/bin/heartbeat.sh

# 2. 유닛 파일 작성
sudo bash -c 'cat > /etc/systemd/system/heartbeat.service << "EOF"
[Unit]
Description=Heartbeat Logger Service
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/heartbeat.sh
Restart=on-failure
User=nobody

[Install]
WantedBy=multi-user.target
EOF'

# 3. systemd 설정 재로드
sudo systemctl daemon-reload

# 4. 서비스 시작 및 확인
sudo systemctl start heartbeat
systemctl status heartbeat
```

**출력 예시:**
```
● heartbeat.service - Heartbeat Logger Service
     Loaded: loaded (/etc/systemd/system/heartbeat.service; disabled; preset: enabled)
     Active: active (running) since Tue 2026-03-11 10:35:00 KST; 2s ago
   Main PID: 5678 (heartbeat.sh)
```

```bash
# 5. 로그 확인
sleep 15 && cat /tmp/heartbeat.log
```

**출력 예시:**
```
Tue Mar 11 10:35:01 KST 2026: heartbeat
Tue Mar 11 10:35:11 KST 2026: heartbeat
```

```bash
# 6. 서비스 중지 및 정리
sudo systemctl stop heartbeat
sudo systemctl disable heartbeat
sudo rm /etc/systemd/system/heartbeat.service
sudo systemctl daemon-reload
```

# 실습 4. find — 파일 검색

## 4-1. 기본 검색

```bash
# /etc 에서 .conf 파일 검색 (상위 5개)
find /etc -name "*.conf" 2>/dev/null | head -5
```

**출력 예시:**
```
/etc/adduser.conf
/etc/deluser.conf
/etc/ca-certificates.conf
/etc/hdparm.conf
/etc/host.conf
```

---

## 4-2. 타입별 검색

```bash
# /tmp 에서 디렉터리만
find /tmp -type d

# 홈 디렉터리에서 심볼릭 링크
find ~ -type l 2>/dev/null
```

---

## 4-3. 크기 조건 검색

```bash
# 1MB 이상 파일 (/ 에서, 에러 무시)
find / -type f -size +1M 2>/dev/null | head -10
```

**출력 예시:**
```
/usr/lib/x86_64-linux-gnu/libicudata.so.74.2
/usr/lib/x86_64-linux-gnu/libLLVM-18.so.1
/var/cache/apt/pkgcache.bin
...
```

```bash
# 빈 파일 찾기
find ~/textlab -type f -empty
```

---

## 4-4. 시간 조건 검색

```bash
# 1일 이내 수정된 파일
find /var/log -type f -mtime -1 2>/dev/null
```

**출력 예시:**
```
/var/log/auth.log
/var/log/syslog
/var/log/kern.log
```

---

## 4-5. -exec 액션 실습

```bash
# 실습용 파일 생성
mkdir -p ~/findlab
touch ~/findlab/a.txt ~/findlab/b.txt ~/findlab/run.sh

# .sh 파일에 실행 권한 부여
find ~/findlab -name "*.sh" -exec chmod +x {} \;

# 권한 확인
ls -l ~/findlab/
```

**출력:**
```
-rw-r--r-- 1 user user 0 Mar 11 10:50 a.txt
-rw-r--r-- 1 user user 0 Mar 11 10:50 b.txt
-rwxr-xr-x 1 user user 0 Mar 11 10:50 run.sh
```

## 5-3. du 실습

# 실습 6. tar — 아카이브와 압축

## 6-1. 실습 디렉터리 준비

```bash
mkdir -p ~/tarlab/source
echo "파일1 내용" > ~/tarlab/source/file1.txt
echo "파일2 내용" > ~/tarlab/source/file2.txt
echo "파일3 내용" > ~/tarlab/source/file3.txt
mkdir ~/tarlab/source/subdir
echo "서브파일" > ~/tarlab/source/subdir/sub.txt

cd ~/tarlab
```

---

## 6-2. 아카이브 생성

```bash
# gzip 압축 아카이브 생성
tar -czvf source_backup.tar.gz source/
```

**출력:**
```
source/
source/file1.txt
source/file2.txt
source/file3.txt
source/subdir/
source/subdir/sub.txt
```

```bash
# 파일 크기 비교
ls -lh source_backup.tar.gz
du -sh source/
```

**출력 예시:**
```
-rw-r--r-- 1 user user 312 Mar 11 11:00 source_backup.tar.gz
4.0K    source/
```

---

## 6-3. 아카이브 내용 확인 (해제 없이)

```bash
tar -tzvf source_backup.tar.gz
```

**출력:**
```
drwxr-xr-x user/user         0 2026-03-11 11:00 source/
-rw-r--r-- user/user        16 2026-03-11 11:00 source/file1.txt
-rw-r--r-- user/user        16 2026-03-11 11:00 source/file2.txt
-rw-r--r-- user/user        16 2026-03-11 11:00 source/file3.txt
drwxr-xr-x user/user         0 2026-03-11 11:00 source/subdir/
-rw-r--r-- user/user        13 2026-03-11 11:00 source/subdir/sub.txt
```

---

## 6-4. 아카이브 해제

```bash
# 별도 디렉터리에 해제
mkdir -p ~/tarlab/restore
tar -xzvf source_backup.tar.gz -C ~/tarlab/restore/

# 해제 결과 확인
ls -R ~/tarlab/restore/
```

**출력:**
```
/home/user/tarlab/restore/:
source

/home/user/tarlab/restore/source:
file1.txt  file2.txt  file3.txt  subdir

/home/user/tarlab/restore/source/subdir:
sub.txt
```

## 6-5. /etc 백업 (실무 패턴)


# 실습 7. 종합 실습 — 시스템 점검 스크립트

```bash
cat > ~/system_check.sh << 'EOF'
#!/bin/bash
echo "=============================="
echo " 시스템 점검 리포트"
echo " $(date)"
echo "=============================="

echo ""
echo "[1] 디스크 사용량"
df -h | grep -v tmpfs

echo ""
echo "[2] 큰 디렉터리 TOP 5 (/var)"
du -h --max-depth=1 /var 2>/dev/null | sort -rh | head -5

echo ""
echo "[3] 30일 이상 된 /tmp 파일"
find /tmp -type f -mtime +30 2>/dev/null | wc -l
echo "개"

echo ""
echo "[4] 실행 중인 서비스 수"
systemctl list-units --type=service --state=running --no-legend | wc -l
echo "개"

echo ""
echo "[5] SUID 파일 목록"
find / -perm /u+s -type f 2>/dev/null

echo ""
echo "=============================="
echo " 점검 완료"
echo "=============================="
EOF

chmod +x ~/system_check.sh
~/system_check.sh
```
