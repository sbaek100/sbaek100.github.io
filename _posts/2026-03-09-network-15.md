# 최종 평가 — 내가 만든 네트워크, 내가 증명한다

---

# 오늘은 시험보다 실전 미션에 가깝다

---

오늘 해야 할 일은 복잡해 보이지만 사실 3가지뿐임.

1. 네트워크를 직접 완성하기
2. PC0에서 Server0 웹 페이지 열기
3. 성공한 장면을 캡처해서 제출하기

> 즉, **통신이 실제로 되게 만들고 그 증거를 남기면 됨**.

---

# 1장. 미션 목표

---

| 미션 | 성공 기준 |
|---|---|
| 네트워크 구성 | 장비 배치와 케이블 연결 완료 |
| 기본 통신 확인 | `ping 192.168.1.1` 성공 |
| 원격 통신 확인 | `ping 192.168.2.100` 에서 `Reply from` 확인 |
| 웹 접속 확인 | `http://192.168.2.100` 페이지 표시 |
| 패킷 추적 확인 | Simulation Mode에서 `ARP`, `TCP`, `HTTP` 흐름 확인 |

> 오늘은 `TTL=126` 같은 세부 숫자보다 **최종 성공 화면**이 더 중요함.

---

# 2장. 설계표

---

| 장비 | 설정 |
|---|---|
| PC0 | `192.168.1.10 / 255.255.255.0 / GW 192.168.1.1` |
| PC1 | `192.168.1.20 / 255.255.255.0 / GW 192.168.1.1` |
| Router0 LAN | `192.168.1.1 / 255.255.255.0` |
| Router0 WAN | `10.0.0.1 / 255.255.255.252` |
| Router1 WAN | `10.0.0.2 / 255.255.255.252` |
| Router1 LAN | `192.168.2.1 / 255.255.255.0` |
| Server0 | `192.168.2.100 / 255.255.255.0 / GW 192.168.2.1` |

---

# 3장. 따라 하기 체크리스트

---

## STEP 1 — 장비 놓기

```
□ PC 2대
□ Switch 2대
□ Router 2대
□ Server 1대
```

## STEP 2 — 케이블 연결

```
□ PC0 ↔ Switch0
□ PC1 ↔ Switch0
□ Switch0 ↔ Router0 LAN 포트
□ Router0 ↔ Router1 시리얼 포트
□ Router1 LAN 포트 ↔ Switch1
□ Switch1 ↔ Server0
```

> 라우터에서 시리얼 포트가 안 보이면 `Physical` 탭에서 `HWIC-2T` 모듈을 추가함.

## STEP 3 — PC와 Server IP 넣기

```
□ PC0 설정
□ PC1 설정
□ Server0 설정
□ Server0 HTTP 서비스 On 확인
```

## STEP 4 — Router0 설정

```
enable
configure terminal
hostname Router0
interface g0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit
interface s0/0/0
ip address 10.0.0.1 255.255.255.252
clock rate 64000
no shutdown
exit
ip route 192.168.2.0 255.255.255.0 10.0.0.2
end
```

## STEP 5 — Router1 설정

```
enable
configure terminal
hostname Router1
interface s0/0/0
ip address 10.0.0.2 255.255.255.252
no shutdown
exit
interface g0/0
ip address 192.168.2.1 255.255.255.0
no shutdown
exit
ip route 192.168.1.0 255.255.255.0 10.0.0.1
end
```

> `g0/0` 가 안 보이면 `fa0/0` 으로 바꿔서 사용함.

---

# 4장. 검증도 쉬운 순서로

---

## STEP 6 — Ping 확인

PC0에서 아래 순서대로 실행:

```
ping 192.168.1.1
ping 10.0.0.2
ping 192.168.2.100
```

마지막에 `Reply from 192.168.2.100` 이 보이면 성공.

## STEP 7 — 웹 접속 확인

PC0 → `Desktop` → `Web Browser`

```
http://192.168.2.100
```

페이지가 뜨면 성공.

## STEP 8 — Simulation Mode 확인

1. `Simulation` 탭 클릭
2. 필터는 `ARP`, `TCP`, `HTTP` 만 선택
3. 브라우저에서 다시 한 번 `Go`
4. `Capture/Forward` 로 천천히 관찰

### 여기서 꼭 볼 것

1. ARP가 먼저 나오는지
2. TCP SYN 이 보이는지
3. HTTP GET 이 보이는지
4. HTTP 200 OK 응답이 오는지

---

# 5장. 제출 캡처는 5장만

---

초보자 기준으로 제출도 간단하게 가져감.

1. 전체 토폴로지 화면
2. Router0 `show ip route`
3. Router1 `show ip route`
4. PC0에서 `ping 192.168.2.100` 성공 화면
5. PC0 웹 브라우저 접속 성공 화면

> 여유가 있으면 Simulation Mode에서 `HTTP GET` 장면을 추가 캡처해도 좋음.

---

# 6장. 점검표

---

| 증상 | 확인할 것 |
|---|---|
| 빨간 불이 계속 보임 | `no shutdown` |
| WAN이 안 됨 | `clock rate 64000`, 시리얼 IP |
| Ping은 안 되는데 설정은 맞아 보임 | `show ip route` 에 `S` 경로 있는지 |
| 웹만 안 열림 | Server0 HTTP On |
| 시리얼 포트가 안 보임 | `HWIC-2T` 모듈 추가 |

---

# 7장. 마지막 한 줄 정리

---

직접 네트워크를 만들고, 다른 네트워크의 서버에 접속하고, 그 흐름을 Simulation Mode로 확인했다면 이 과정의 목표는 충분히 달성한 것임.
