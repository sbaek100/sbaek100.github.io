# 제1절. 사전 준비와 VirtualBox 설치

---

## 1.1 준비물 점검

작업을 시작하기 전에 다음 항목을 확인한다.

| 항목 | 요구 사항 | 비고 |
|---|---|---|
| 운영체제 | 윈도우 10 또는 11 | 호스트 |
| 메모리(RAM) | **8GB 이상** | Ubuntu만 설치할 경우 4GB로도 가능 |
| 여유 디스크 공간 | **40GB 이상** | Ubuntu만 설치할 경우 25GB |
| 인터넷 연결 | 필수 | 설치 파일의 용량이 수 GB에 이른다 |

> **네트워크 환경에 관한 권고**
> 설치 파일의 용량이 크므로 유선 연결 또는 안정적인 무선 환경에서 진행할 것을 권장한다.
{: .prompt-tip }

---

## 1.2 VirtualBox 설치

VirtualBox는 가상 머신을 생성하고 구동하는 무료 하이퍼바이저이다.

**1단계.** [VirtualBox 공식 사이트](https://www.virtualbox.org/)에 접속하여 **[Download VirtualBox]** 를 선택한다.

**2단계.** **Windows hosts** 항목의 설치 파일(`.exe`)을 내려받는다.

**3단계.** 내려받은 파일을 실행하고 모든 항목을 기본값으로 두어 설치를 진행한다.

> 설치 도중 "네트워크 연결이 일시적으로 중단된다"는 안내가 표시되면 **Yes**를 선택하여 계속 진행한다. 가상 네트워크 드라이버를 설치하는 과정이다.

**4단계.** 설치가 완료되면 **VirtualBox 관리자(Manager)** 창이 실행된다. 이후 모든 가상 머신은 이 화면에서 관리한다.

> **가상화 기능이 비활성화된 경우**
> 일부 시스템은 CPU의 가상화 기능이 꺼져 있어 64비트 가상 머신을 실행하지 못한다.
>
> 이 경우 시스템 부팅 시 **BIOS 또는 UEFI 설정 화면**에 진입하여 **VT-x**(인텔) 또는 **SVM**(AMD) 항목을 **Enable**로 변경하여야 한다. 대부분의 시스템에서는 기본적으로 활성화되어 있다.
{: .prompt-warning }

# 제2절. Ubuntu Server 24.04 설치

---

Ubuntu Server는 본 과정의 **주 실습 대상**이다. 제1강부터 제6강까지의 모든 명령은 이 시스템에서 실행한다.

---

## 2.1 설치 이미지(ISO) 내려받기

**1단계.** [Ubuntu Server 다운로드 페이지](https://ubuntu.com/download/server)에 접속한다.

**2단계.** **Ubuntu Server 24.04 LTS** 항목의 ISO 파일을 내려받는다.

> **LTS 판본을 사용하는 이유**
> LTS는 **L**ong **T**erm **S**upport(장기 지원)의 약어로, 5년간 표준 보안 갱신을 제공한다. 학습 도중 지원이 종료되어 환경을 재구축하는 상황을 방지하기 위하여 LTS 판본을 사용한다. 이 내용은 제1강 1.6절에서 다시 다룬다.
{: .prompt-tip }

---

## 2.2 가상 머신 생성

**1단계.** VirtualBox 관리자에서 **[새로 만들기(New)]** 를 선택한다.

**2단계.** 다음과 같이 설정한다.

| 항목          | 설정값             | 비고                       |
| ----------- | --------------- | ------------------------ |
| 이름          | `ubuntu-lab`    | 제1강 이후 예시의 호스트 이름과 일치시킨다 |
| 종류(Type)    | Linux           |                          |
| 버전(Version) | Ubuntu (64-bit) |                          |
| 메모리(RAM)    | `2048` MB       | 여유가 있으면 4096 MB 권장       |
| 프로세서        | `2` CPU         |                          |
| 디스크         | 새로 생성 → `25` GB | 동적 할당                    |

**3단계.** 생성된 가상 머신을 선택한 뒤 **[설정] → [저장소(Storage)]** 로 이동한다.

**4단계.** 비어 있는 광학 드라이브(CD 아이콘)를 선택하고, 오른쪽의 디스크 아이콘을 눌러 **앞서 내려받은 ISO 파일**을 지정한다.

**5단계.** **[시작(Start)]** 을 눌러 설치를 시작한다.

---

## 2.3 설치 진행

설치 마법사가 단계별로 항목을 질의한다. 주요 항목과 선택값은 다음과 같다.

| 설치 단계 | 선택값 | 근거 |
|---|---|---|
| 언어 | English 또는 한국어 | 오류 메시지 검색이 용이하도록 English를 권장한다 |
| 키보드 배열 | Korean 또는 기본값 | |
| 설치 유형 | Ubuntu Server (기본) | |
| 네트워크 | **기본값 유지** | 0-3에서 다시 설정한다 |
| 프록시 | 공란 | |
| 저장소 미러 | 기본값 | |
| 디스크 구성 | **Use an entire disk** | 가상 디스크 전체를 사용한다 |
| **사용자 이름** | **`student`** | **제1강 이후 예시와 일치시킨다** |
| **서버 이름** | **`ubuntu-lab`** | **프롬프트에 표시되는 이름이다** |
| 비밀번호 | 기억 가능한 값 | 실습용으로 `Linux#2026` 등 |
| **OpenSSH server 설치** | **체크함** | 제6강 원격 접속 실습에 필요하다 |
| 추가 스냅 패키지 | 선택하지 않음 | |

**설치 완료 후 재부팅한다.**

> **재부팅 시 설치 화면이 반복되는 경우**
> "설치 미디어를 제거하라"는 안내가 표시되면 VirtualBox 메뉴의 **[장치] → [광학 드라이브] → [가상 드라이브에서 디스크 꺼내기]** 를 선택한 뒤 `Enter`를 누른다.
>
> 또는 가상 머신을 종료하고 **[설정] → [저장소]** 에서 광학 드라이브를 비운 뒤 다시 시작하여도 된다.
{: .prompt-warning }

---

## 2.4 설치 결과 확인

설치가 완료되면 로그인 프롬프트가 표시된다. 앞서 생성한 `student` 계정으로 로그인한다.

로그인 후 다음 명령으로 설치 결과를 확인한다.

```bash
whoami
```

> `student`가 출력되어야 한다.

```bash
hostname
```

> `ubuntu-lab`이 출력되어야 한다.

```bash
cat /etc/os-release | head -3
```

> `Ubuntu 24.04 LTS` 항목을 확인한다.

프롬프트가 다음과 같이 표시되면 제1강의 예시와 동일한 환경이 구성된 것이다.

```
student@ubuntu-lab:~$
```

> **확인 사항** 위 세 명령의 결과가 각각 `student`, `ubuntu-lab`, `Ubuntu 24.04 LTS`로 출력되면 설치가 정상적으로 완료된 것이다.
{: .prompt-tip }

# 제3절. Kali Linux 설치(선택)

---

> **본 절은 선택 사항이다**
> 리눅스 기초 과정(제1강 ~ 제6강)은 Ubuntu 한 대만으로 모두 수행할 수 있다.
>
> 다만 이후 애플리케이션 보안 등 보안 관련 과정을 수강할 예정이라면, 해당 과정에서 점검 측 시스템으로 Kali Linux를 사용하므로 지금 함께 구성해 두는 것이 효율적이다.
{: .prompt-warning }

---

## 3.1 사전 구성 이미지를 이용한 설치

Kali Linux는 운영체제를 직접 설치하는 대신, **배포처가 제공하는 VirtualBox용 이미지**를 등록하는 방식이 간편하다. 보안 점검 도구가 사전 설치된 상태로 시작할 수 있다.

**1단계.** [Kali 다운로드 페이지](https://www.kali.org/get-kali/)에서 **[Virtual Machines]** 를 선택한다.

**2단계.** **VirtualBox** 항목의 `.7z` 파일을 내려받는다.

**3단계.** [7-Zip](https://www.7-zip.org/)을 설치한 뒤 내려받은 파일의 압축을 해제한다. `.vbox` 파일과 `.vdi`(가상 디스크) 파일이 생성된다.

**4단계.** VirtualBox 관리자의 **[추가(Add)]** 를 선택하고 **`.vbox` 파일**을 지정한다.

**5단계.** 목록에 Kali Linux 가상 머신이 등록된다. 선택한 뒤 **[시작]** 을 누른다.

**6단계.** 기본 계정으로 로그인한다.

| 항목 | 값 |
|---|---|
| 사용자 이름 | `kali` |
| 비밀번호 | `kali` |

> 최초 부팅에는 1~2분이 소요될 수 있다. 검은 화면이 일시적으로 지속되는 것은 정상적인 동작이다.
{: .prompt-tip }

# 제4절. 스냅샷 생성과 점검

---

## 4.1 스냅샷 생성

**설치가 완료된 직후의 상태를 스냅샷으로 저장해 두어야 한다.** 이후 실습 과정에서 시스템 설정을 손상시키더라도 재설치 없이 이 시점으로 복원할 수 있다.

**1단계.** 가상 머신을 **종료**한다.

```bash
sudo poweroff
```

> `poweroff`는 시스템을 안전하게 종료하는 명령이다. 자세한 내용은 제1강 3.4절에서 다룬다.

**2단계.** VirtualBox 관리자에서 해당 가상 머신을 선택한다.

**3단계.** 오른쪽 상단의 메뉴에서 **[스냅샷] → [찍기(Take)]** 를 선택한다.

**4단계.** 이름을 `설치 직후`로 지정하고 확인한다.

**5단계.** Kali Linux를 설치한 경우 동일한 절차를 반복한다.

---

## 4.2 점검 항목

다음 항목을 모두 확인한다.

```
 [ ] VirtualBox 관리자에 가상 머신이 등록되어 있다.
 [ ] Ubuntu에 student 계정으로 로그인된다.
 [ ] 프롬프트가 student@ubuntu-lab:~$ 형태로 표시된다.
 [ ] cat /etc/os-release 결과에 24.04 LTS가 포함된다.
 [ ] 설치 직후 스냅샷이 생성되어 있다.
 [ ] (선택) Kali에 kali / kali 로 로그인된다.
```

---

## 4.3 진행 흐름

```
 ① VirtualBox 설치
        ↓
 ② Ubuntu Server 24.04 가상 머신 생성·설치
        ↓
 ③ (선택) Kali Linux 이미지 등록
        ↓
 ④ 스냅샷 생성
        ↓
 ⑤ 다음 글 0-3 : 네트워크 연결
```

# 제5절. 자주 발생하는 오류와 대응 방법

---

| 증상 | 원인 | 대응 방법 |
|---|---|---|
| 64비트 버전이 목록에 없음 | CPU 가상화 기능 비활성화 | BIOS/UEFI에서 VT-x 또는 SVM을 활성화한다. |
| 가상 머신이 시작되지 않음 | 다른 가상화 소프트웨어와 충돌 | 윈도우 기능에서 Hyper-V를 비활성화한다. |
| 설치 화면이 반복해서 나타남 | ISO가 제거되지 않음 | 저장소 설정에서 광학 드라이브를 비운다. |
| 화면이 지나치게 작음 | 게스트 확장 미설치 | 서버 환경에서는 문제되지 않는다. 필요 시 `[보기] → [화면 배율]` 을 조정한다. |
| 마우스 커서가 가상 머신에 갇힘 | 마우스 통합 미설정 | 오른쪽 `Ctrl` 키를 누르면 호스트로 복귀한다. |
| 설치 속도가 매우 느림 | 메모리 또는 CPU 할당 부족 | 설정에서 메모리를 4096 MB, 프로세서를 2개 이상으로 조정한다. |
| 비밀번호 입력 시 화면에 표시되지 않음 | **정상 동작** | 보안상 입력 내용을 표시하지 않는다. 그대로 입력하고 `Enter`를 누른다. |

# 제6절. 요약 및 다음 글

---

## 6.1 요약

| 구분 | 요점 |
|---|---|
| VirtualBox | 무료 하이퍼바이저이며, 기본값으로 설치하면 된다. 가상화 기능이 꺼져 있으면 BIOS에서 활성화한다. |
| Ubuntu Server 24.04 | 본 과정의 주 실습 대상이다. 사용자 `student`, 서버 이름 `ubuntu-lab`으로 설정한다. |
| OpenSSH 설치 | 설치 과정에서 반드시 선택한다. 제6강 원격 접속 실습에 필요하다. |
| Kali Linux | 선택 사항이며, 후속 보안 과정에서 사용한다. 사전 구성 이미지를 등록하는 방식이 간편하다. |
| 스냅샷 | 설치 직후 반드시 생성한다. 실습 중 문제가 발생하면 즉시 복원할 수 있다. |

---

## 6.2 다음 글 예고

가상 머신은 생성되었으나 아직 네트워크 설정이 완료되지 않은 상태이다.

다음 글 **0-3. 네트워크 연결과 통신 확인**에서는 어댑터 두 개를 구성하고 고정 IP 주소를 지정한 뒤, `ping` 명령으로 통신 상태를 점검한다. 이 작업까지 완료하면 제1강을 시작할 수 있다.
