> 2. FHS 표준에 따른 `/home`·`/etc`·`/bin` 등 주요 디렉터리의 용도를 설명할 수 있다.
> 3. 절대 경로와 상대 경로를 구분하고 원하는 위치로 이동할 수 있다.

앞선 강의에서 터미널을 열고 명령어의 기본 구조를 익혔다. 본 강의에서는 그 터미널 위에서 리눅스의 파일이 저장되는 공간, 곧 **파일 시스템(File System)** 의 구조를 이해하고 그 안을 자유롭게 이동하는 방법을 학습한다.

윈도우 사용자는 파일 관리자에서 마우스로 폴더를 하나씩 열어 원하는 위치를 찾아간다. 리눅스의 그래픽 데스크톱에도 파일 관리자(Files)가 있으나, 터미널에서 명령어로 이동하면 **위치를 정확히 지정할 수 있고, 그 경로를 명령에 그대로 사용할 수 있다는** 결정적 이점이 있다.

실습 계정은 `student`, 호스트 이름은 `ubuntu-y1`이며, 실습 디렉터리로 `~/lab02`를 사용한다.

# 제1절. 파일 시스템의 계층 구조

---

## 1.1 단일 트리 구조

윈도우는 저장 장치마다 `C:`, `D:`와 같은 드라이브 문자를 부여한다. 반면 리눅스에는 드라이브 문자가 존재하지 않으며, 모든 파일과 저장 장치가 **`/`(루트)를 정점으로 하는 하나의 트리**에 연결된다.

```
 [윈도우 방식]              [리눅스 방식]

 C:\                        /            ← 루트. 모든 것의 시작점
 ├─ Windows                 ├─ home      ← 사용자 공간
 ├─ Users                   │   └─ student
 │                          ├─ etc       ← 설정 파일
 D:\  (두 번째 디스크)        ├─ bin       ← 명령 프로그램
 E:\  (USB)                 └─ var       ← 로그 등 가변 데이터
```

리눅스에서는 두 번째 디스크나 USB 저장 장치도 별도의 드라이브 문자를 갖지 않고, 트리의 특정 디렉터리에 연결되어 하나의 트리 안에서 함께 다루어진다. 이처럼 저장 장치를 트리의 특정 디렉터리에 연결하는 행위를 **마운트(mount)** 라 한다.

> **용어 정리 — 디렉터리와 폴더**
> 윈도우에서 '폴더(folder)'라 부르는 것을 리눅스에서는 **디렉터리(directory)** 라 한다. 두 용어는 같은 대상을 가리키며, 본 강의에서는 리눅스 관례에 따라 '디렉터리'로 통일한다.
{: .prompt-info }

---

## 1.2 FHS와 주요 디렉터리

![](/assets/img/posts/2026-09-08-linuxintro-week2-2-directory-files-1787465809258.png)

리눅스의 디렉터리 구조는 **FHS(Filesystem Hierarchy Standard, 파일 시스템 계층 표준)** 라는 규약으로 규정되어 있다. 어느 배포판을 사용하더라도 동일한 위치에 동일한 성격의 파일이 존재하므로, 한 번 익혀 두면 계속 활용할 수 있다.

```
 /                        루트. 모든 것의 시작점
 ├── bin  → usr/bin       일반 사용자 명령(ls, cp 등)
 ├── boot                 커널 이미지, GRUB 설정
 ├── dev                  장치 파일
 ├── etc                  ★ 시스템 전역 설정 파일
 ├── home                 ★ 일반 사용자의 홈 디렉터리
 │    └── student              사용자의 개인 작업 공간(~)
 ├── lib  → usr/lib       공유 라이브러리
 ├── media                USB 등 이동식 매체 자동 마운트 지점
 ├── mnt                  임시 마운트 지점
 ├── opt                  서드파티 응용 프로그램
 ├── proc                 커널·프로세스 정보(가상)
 ├── root                 ※ 관리자의 홈 디렉터리
 ├── sbin → usr/sbin      관리자용 명령
 ├── tmp                  임시 파일
 ├── usr                  설치된 프로그램과 문서
 └── var                  ★ 로그·스풀 등 가변 데이터
      └── log                  시스템 로그
```

비전공 학습자가 우선 기억해야 할 디렉터리는 다음과 같다.

| 디렉터리 | 읽는 뜻 | 용도 |
|---|---|---|
| **`/`** | 루트(root) | 파일 트리의 최상위. 모든 경로의 출발점 |
| **`/home`** | 홈 | 일반 사용자의 개인 작업 공간(`/home/student`) |
| **`/etc`** | 엣시(et cetera) | 시스템 전역 **설정 파일** 보관소 |
| **`/bin`** | 바이너리(**bin**ary) | `ls`, `cp` 등 기본 명령 프로그램 |
| `/var` | 배리어블(**var**iable) | 로그 등 크기가 변동하는 데이터 |
| `/tmp` | 템프(**t**e**mp**orary) | 임시 파일. 재부팅 시 삭제 |
| `/usr` | 유저(**us**e**r**) | 설치된 프로그램과 라이브러리 |

> **혼동하기 쉬운 개념**
> `/`(루트 디렉터리)와 `/root`(관리자 홈 디렉터리)는 명칭이 유사하나 전혀 다른 대상이다. 전자는 파일 트리의 최상위이고, 후자는 관리자 계정의 개인 디렉터리이다. 시험에서 이를 바꾸어 묻는 문항이 자주 출제된다.
{: .prompt-warning }

> **[그림 2-3] 필요**
> 리눅스 파일 시스템의 트리 구조를 나타낸 그림. 최상위 `/` 아래에 `home`, `etc`, `bin`, `var` 등이 가지처럼 뻗어 있고, `home` 아래에 `student`가 표시된 도식.
{: .prompt-tip }

---

> ### 따라 하기 2-1. 루트 디렉터리 둘러보기
>
> **목적** 파일 트리의 최상위를 확인하고 주요 디렉터리가 실재함을 눈으로 확인한다.
{: .prompt-tip }

**1단계.** 루트 디렉터리의 내용을 확인한다.

```bash
ls /
```

> `home`, `etc`, `bin`, `var` 등 FHS가 규정한 디렉터리들이 출력된다. `/`는 절대 경로의 출발점인 최상위 디렉터리이다.

**2단계.** 홈 디렉터리 안을 확인한다.

```bash
ls /home
```

> `student` 디렉터리가 출력된다. 이곳이 실습 계정의 개인 작업 공간이다.

**3단계.** 설정 파일 디렉터리를 살펴본다.

```bash
ls /etc | head -10
```

> 여러 설정 파일과 디렉터리가 출력된다. `| head -10`은 결과가 길어 앞의 10줄만 보이도록 제한한 것이다. `/etc`에는 시스템 전역 설정 파일이 모여 있다.

> **확인 사항** `/`, `/home`, `/etc`의 내용을 각각 확인하였고, `/home` 아래에 `student`가 존재함을 확인하였다면 성공이다.
{: .prompt-tip }

# 제2절. 절대 경로와 상대 경로

---

## 2.1 두 가지 경로 표기

파일이나 디렉터리의 위치를 지정하는 방법은 두 가지이다.

| 구분 | 정의 | 예시 |
|---|---|---|
| **절대 경로** | 루트(`/`)에서 시작하는 완전한 경로 | `/home/student/docs/report.txt` |
| **상대 경로** | **현재 작업 디렉터리**를 기준으로 하는 경로 | `docs/report.txt` |

일상적인 표현에 비유하면 절대 경로는 "서울특별시 강남구 테헤란로 123"과 같이 어디서 출발하든 찾아갈 수 있는 주소이고, 상대 경로는 "여기서 오른쪽으로 두 블록"과 같이 현재 위치를 알아야 의미가 성립하는 안내이다.

**구분 방법은 간단하다. 맨 앞에 `/`가 있으면 절대 경로, 없으면 상대 경로이다.**

---

## 2.2 경로에 쓰이는 특수 기호

경로 표기에는 다음과 같은 특수 기호가 사용된다.

| 기호 | 의미 | 사용 예 |
|---|---|---|
| `.` (점 하나) | **현재** 디렉터리 | `./run.sh` |
| `..` (점 두 개) | **상위(부모)** 디렉터리 | `cd ..` |
| `~` (물결) | **현재 사용자의 홈** 디렉터리 | `cd ~` |
| `-` (하이픈) | **직전에 있던** 디렉터리 | `cd -` |
| `/` | 루트 디렉터리 또는 경로 구분자 | `/etc/ssh` |

`~`는 매우 자주 사용된다. `student` 계정으로 로그인한 경우 `~`는 `/home/student`를 가리키므로, `cd ~/lab02`는 `cd /home/student/lab02`와 동일하다.

---

> ### 따라 하기 2-2. 절대 경로와 상대 경로로 이동하기
>
> **목적** 두 가지 경로 방식으로 이동하며 차이를 체득한다.
{: .prompt-tip }

**1단계.** 현재 위치를 확인한다.

```bash
pwd
```

> `pwd`는 **p**rint **w**orking **d**irectory(현재 작업 디렉터리를 출력하라)의 약어이다. 로그인 직후에는 `/home/student`가 출력된다.

**2단계.** 절대 경로로 이동한다.

```bash
cd /etc
```

```bash
pwd
```

> 맨 앞에 `/`가 있으므로 절대 경로이다. 프롬프트도 `:/etc$`로 변경된 것을 확인한다. `cd`는 **c**hange **d**irectory(디렉터리를 변경하라)의 약어이다.

**3단계.** 상위 디렉터리로 이동한 뒤 상대 경로로 다시 내려간다.

```bash
cd ..
```

```bash
pwd
```

> `..`는 상위 디렉터리를 뜻한다. `/etc`의 상위는 루트이므로 `/`가 출력된다.

```bash
cd etc/ssh
```

```bash
pwd
```

> 맨 앞에 `/`가 없으므로 상대 경로이다. 현재 위치인 `/`에서 출발하여 `etc` → `ssh`로 이동하였다.

**4단계.** 홈 디렉터리로 복귀한다.

```bash
cd
```

```bash
pwd
```

> `cd`를 인자 없이 실행하면 항상 홈 디렉터리(`/home/student`)로 이동한다. **경로를 잃었을 때 사용하는 방법이다.**

**5단계.** 직전 디렉터리를 왕복한다.

```bash
cd -
```

```bash
cd -
```

> `cd -`는 직전에 있던 디렉터리로 되돌아간다. 두 위치를 번갈아 오갈 때 편리하다.

> **확인 사항** 절대 경로(`/etc`)와 상대 경로(`etc/ssh`)로 각각 이동할 수 있고, `cd`와 `cd -`의 동작 차이를 설명할 수 있다면 성공이다.
{: .prompt-tip }

# 제3절. 디렉터리 탐색 명령

---

## 3.1 이동과 목록 조회 명령

| 명령어 | 약어 풀이 | 기능 |
|---|---|---|
| `pwd` | **p**rint **w**orking **d**irectory | 현재 디렉터리 출력 |
| `cd` | **c**hange **d**irectory | 디렉터리 이동 |
| `ls` | **l**i**s**t | 디렉터리 내용 목록 출력 |
| `tree` | — | 디렉터리 구조를 나무 형태로 출력 |

`ls`는 가장 빈번하게 사용하는 명령이므로 주요 옵션을 숙지하여야 한다.

| 옵션 | 약어 풀이 | 기능 |
|---|---|---|
| `-l` | **l**ong | 상세 정보 표시 |
| `-a` | **a**ll | 숨김 파일 포함 |
| `-h` | **h**uman-readable | 크기를 KB/MB/GB 단위로 |
| `-t` | **t**ime | 수정 시각순 정렬 |
| `-r` | **r**everse | 역순 정렬 |
| `-R` | **R**ecursive | 하위 디렉터리까지 재귀 출력 |

---

## 3.2 `ls -l` 출력의 해석

`ls -l`의 출력은 여러 항목으로 구성되며, 각 항목이 무엇을 의미하는지 익혀 두어야 한다.

```
 -rw-r--r--   1  student  student   1024  Mar 16 10:24  report.txt
 └───┬────┘   │  └──┬──┘  └──┬──┘  └─┬─┘  └────┬─────┘  └────┬───┘
     │        │     │        │       │         │             │
     │        │     │        │       │         │             └ 파일명
     │        │     │        │       │         └─────────────── 최종 수정 시각
     │        │     │        │       └───────────────────────── 크기(바이트)
     │        │     │        └───────────────────────────────── 소유 그룹
     │        │     └────────────────────────────────────────── 소유자
     │        └──────────────────────────────────────────────── 링크 수
     └───────────────────────────────────────────────────────── 파일 종류 + 권한
```

맨 앞 한 글자는 파일의 종류를 나타낸다.

| 기호 | 종류 |
|---|---|
| `-` | 일반 파일 |
| **`d`** | **d**irectory(디렉터리) |
| `l` | **l**ink(심볼릭 링크) |

> 파일 종류와 권한, 소유자에 관한 상세한 내용은 이후 계정·권한 강의에서 다룬다. 본 강의에서는 첫 글자로 파일과 디렉터리를 구분할 수 있으면 충분하다.

---

## 3.3 `tree`로 구조 한눈에 보기

`tree`는 디렉터리와 그 하위 내용을 나무 형태로 한눈에 보여 주는 명령이다. Ubuntu Desktop에 기본으로 설치되어 있지 않은 경우 다음과 같이 설치한다.

```bash
sudo apt install tree
```

> `apt`는 우분투의 소프트웨어 설치 도구이며, `install`은 설치를 의미한다. 설치 시 비밀번호를 물으면 자신의 비밀번호를 입력한다.

---

> ### 따라 하기 2-3. 디렉터리 탐색
>
> **목적** `ls`의 여러 옵션과 `tree`를 사용하여 디렉터리 구조를 확인한다.
{: .prompt-tip }

**1단계.** 이름만 간단히 조회한다.

```bash
ls /etc | head -10
```

> 이름만 출력된다.

**2단계.** 상세 정보와 함께 조회한다.

```bash
ls -l /etc | head -10
```

> 권한·소유자·크기·시각이 함께 출력된다. 맨 앞 글자가 `d`이면 디렉터리, `-`이면 일반 파일이다.

**3단계.** 크기를 읽기 쉬운 단위로 조회한다.

```bash
ls -lh /etc | head -10
```

> `-h`(**h**uman-readable)를 붙이면 크기가 `4.0K`, `1.2M`처럼 사람이 읽기 쉬운 단위로 표시된다.

**4단계.** 하위 디렉터리까지 재귀적으로 조회한다.

```bash
ls -R /etc/apt
```

> `-R`(**R**ecursive)은 지정한 디렉터리뿐 아니라 그 안의 하위 디렉터리 내용까지 차례로 출력한다.

**5단계.** 나무 형태로 구조를 확인한다.

```bash
tree /etc/apt
```

> `tree`가 설치되어 있으면 디렉터리와 파일이 나뭇가지 형태로 정리되어 출력되므로 구조를 한눈에 파악할 수 있다.

> **확인 사항** `ls`와 `ls -l`의 출력 차이를 설명할 수 있고, `-R` 옵션 또는 `tree`로 하위 구조까지 확인하였다면 성공이다.
{: .prompt-tip }

# 제4절. 숨김 파일과 와일드카드

---

## 4.1 숨김 파일

윈도우는 파일 속성으로 숨김 여부를 설정하지만, 리눅스는 **파일명 앞에 마침표(`.`)를 붙이면 숨김 파일이 된다.** 사용자의 홈 디렉터리에는 개인 설정을 담은 숨김 파일이 여럿 존재한다.

| 숨김 파일 | 용도 |
|---|---|
| `.bashrc` | 셸을 열 때 자동으로 적용되는 개인 설정 |
| `.profile` | 로그인 시 적용되는 환경 설정 |

이러한 숨김 파일은 일반적인 `ls`로는 보이지 않으며, `-a`(**a**ll) 옵션을 붙여야 나타난다.

> **리눅스의 숨김 파일**
> 숨김 파일은 감추어야 할 비밀 파일이라는 뜻이 아니라, 평소에 목록을 어지럽히지 않도록 가려 두는 설정 파일이라는 의미이다. 마침표로 시작하는 이름을 붙이는 것만으로 숨김 상태가 된다.
{: .prompt-tip }

---

## 4.2 와일드카드(파일명 대치)

여러 파일을 한 번에 지정할 때 사용하는 기호를 **와일드카드(wildcard)** 또는 **globbing**이라 한다. 명령을 실행하기 **전에 셸이 먼저** 해당 기호를 실제 파일명 목록으로 확장한다.

| 기호 | 의미 | 사용 예 |
|---|---|---|
| `*` | 임의의 문자 **0개 이상** | `*.txt` → 모든 txt 파일 |
| `?` | 임의의 문자 **정확히 1개** | `file?.txt` → file1.txt, fileA.txt |
| `[abc]` | 나열된 문자 중 하나 | `file[12].txt` |
| `[a-z]` | 범위 내 문자 하나 | `[a-c]*.conf` |

> **안전한 작업 습관**
> 여러 파일을 한꺼번에 처리하기 전에, 동일한 와일드카드를 `ls`에 먼저 적용하여 대상이 무엇인지 눈으로 확인하는 습관을 들여야 한다. 예를 들어 `ls *.txt`로 대상을 확인한 뒤 실제 작업을 수행하면 실수를 크게 줄일 수 있다.
{: .prompt-warning }

---

> ### 따라 하기 2-4. 숨김 파일과 와일드카드
>
> **목적** 숨김 파일을 확인하고, 와일드카드로 여러 파일을 한 번에 지정한다.
{: .prompt-tip }

**1단계.** 홈 디렉터리를 일반 방식으로 조회한다.

```bash
cd ~
```

```bash
ls
```

> `Desktop`, `Documents` 등 데스크톱 기본 디렉터리가 보이며, 마침표로 시작하는 파일은 보이지 않는다.

**2단계.** 숨김 파일까지 포함하여 조회한다.

```bash
ls -a
```

> `-a`를 붙이면 `.bashrc`, `.profile` 등 마침표로 시작하는 숨김 파일이 나타난다. 앞선 결과와 비교한다.

**3단계.** 실습 디렉터리를 만들고 여러 파일을 생성한다.

```bash
mkdir -p ~/lab02
```

```bash
cd ~/lab02
```

```bash
touch file1.txt file2.txt file3.txt data1.log data2.log note.md
```

> `touch`는 빈 파일을 생성하는 명령이다. 여섯 개의 파일이 한 번에 만들어진다.

**4단계.** 와일드카드로 대상을 확인한다.

```bash
ls
```

```bash
ls *.txt
```

> `*.txt`는 확장자가 `txt`인 파일만 골라 보여 준다. `file1.txt`, `file2.txt`, `file3.txt` 세 개가 출력된다.

**5단계.** 다른 와일드카드를 비교한다.

```bash
ls *.log
```

> 확장자가 `log`인 `data1.log`, `data2.log`가 출력된다.

```bash
ls file?.txt
```

> `?`는 정확히 한 글자를 의미하므로, `file1.txt`처럼 `file` 뒤에 한 글자가 오는 파일이 선택된다.

> **확인 사항** `ls`와 `ls -a`의 차이로 숨김 파일을 확인하였고, `*`와 `?` 와일드카드로 원하는 파일만 골라낼 수 있다면 성공이다.
{: .prompt-tip }

# 제5절. 종합 실습 — 디렉터리 구조 탐사

---

> **실습 시나리오**
>
> 학습자는 처음 접하는 리눅스 시스템의 구조를 파악하는 임무를 맡았다. 파일 트리의 주요 디렉터리를 둘러보고, 자신의 홈 디렉터리 구조를 조사하여 한 개의 파일로 정리한다.
>
> 본 실습에서는 제1절부터 제4절까지 학습한 명령어만을 사용한다.
{: .prompt-info }

---

## 단계 1. 작업 공간 준비

```bash
mkdir -p ~/lab02/survey
```

> `mkdir`은 **m**a**k**e **dir**ectory의 약어이며, `-p`는 상위 디렉터리까지 함께 생성한다.

```bash
cd ~/lab02/survey
```

```bash
pwd
```

> 현재 위치가 `/home/student/lab02/survey`인지 확인한다.

---

## 단계 2. 루트의 주요 디렉터리 기록

```bash
echo "===== 루트 주요 디렉터리 =====" > structure.txt
```

> `>` 기호는 명령의 출력을 화면이 아닌 파일로 보내는 리다이렉션이다.

```bash
ls / >> structure.txt
```

> `>>`는 기존 내용 뒤에 이어서 기록한다.

---

## 단계 3. 홈 디렉터리 구조 기록

```bash
echo "" >> structure.txt
```

```bash
echo "===== 홈 디렉터리(숨김 포함) =====" >> structure.txt
```

```bash
ls -a ~ >> structure.txt
```

> 숨김 파일까지 포함하여 홈 디렉터리의 전체 내용을 기록한다.

---

## 단계 4. 실습 파일 목록 기록

```bash
echo "" >> structure.txt
```

```bash
echo "===== lab02 안의 txt 파일 =====" >> structure.txt
```

```bash
cd ~/lab02
```

```bash
ls *.txt >> ~/lab02/survey/structure.txt
```

> 앞선 실습에서 만든 txt 파일 목록을 와일드카드로 골라 기록한다. 파일이 없으면 먼저 `touch file1.txt file2.txt`로 생성한다.

---

## 단계 5. 보고서 확인

```bash
cd ~/lab02/survey
```

```bash
cat structure.txt
```

> `cat`은 con**cat**enate의 약어로, 파일 내용을 화면에 출력한다.

```bash
wc -l structure.txt
```

> `wc -l`은 기록된 행 수를 계산한다.

> **종합 실습 완료 기준**
> `structure.txt` 하나에 루트의 주요 디렉터리, 홈 디렉터리(숨김 포함), 실습 txt 파일 목록의 세 항목이 순서대로 정리되어 있으면 성공이다. 본 실습에서 사용한 명령은 `mkdir`, `cd`, `pwd`, `echo`, `ls`, `cat`, `wc`의 7개이다.
{: .prompt-tip }

# 제6절. 자주 발생하는 오류와 대응 방법

---

| 화면에 출력된 메시지 | 원인 | 대응 방법 |
|---|---|---|
| `No such file or directory` | 경로가 존재하지 않음 | `ls`로 이름을 확인한다. **대소문자**를 확인한다. |
| `Permission denied` | 접근 권한 부족 | 명령 앞에 `sudo`를 붙인다. 상세 원리는 이후 권한 강의에서 다룬다. |
| 대문자 명령이 동작하지 않음 | 리눅스는 대소문자를 구분함 | `LS`가 아니라 `ls`로 입력한다. |
| `cd`로 파일에 들어가려 하면 `Not a directory` | 디렉터리가 아닌 파일을 지정 | 대상이 디렉터리인지 `ls -l`로 확인한다. |
| `tree: command not found` | `tree`가 설치되지 않음 | `sudo apt install tree`로 설치한다. |
| 경로를 잃어 위치를 모를 때 | 여러 번 이동한 뒤 방향 상실 | `cd`(인자 없이)로 홈으로 복귀한 뒤 `pwd`로 확인한다. |

# 제7절. 요약

---

## 7.1 핵심 개념 정리

| 구분 | 요점 |
|---|---|
| 단일 트리 | 모든 파일과 저장 장치는 `/`(루트)를 정점으로 하는 하나의 트리에 연결된다. |
| 주요 디렉터리 | `/home`(사용자), `/etc`(설정), `/bin`(명령)을 우선 기억한다. `/`와 `/root`는 서로 다르다. |
| 경로 구분 | 맨 앞에 `/`가 있으면 절대 경로, 없으면 상대 경로이다. |
| 특수 기호 | `.`(현재), `..`(상위), `~`(홈), `-`(직전) 디렉터리를 뜻한다. |
| 탐색 명령 | `pwd`(위치 확인), `cd`(이동), `ls`(목록), `tree`(구조)를 사용한다. |
| 숨김 파일 | 파일명이 마침표로 시작하면 숨김 파일이며 `ls -a`로 확인한다. |
| 와일드카드 | `*`는 임의의 문자열, `?`는 한 글자를 뜻한다. 처리 전 `ls`로 대상을 확인한다. |

---

## 7.2 본 강의에서 학습한 명령어

| 명령어 | 약어 풀이 | 기능 |
|---|---|---|
| `pwd` | print working directory | 현재 디렉터리 출력 |
| `cd` | change directory | 디렉터리 이동 |
| `ls` | list | 목록 조회 |
| `tree` | — | 디렉터리 구조를 나무 형태로 출력 |
| `mkdir` | make directory | 디렉터리 생성 |
| `touch` | — | 빈 파일 생성 |
| `echo` | — | 문자열 출력 |
| `cat` | concatenate | 파일 내용 출력 |
| `wc` | word count | 행·단어 수 계산 |
| `apt` | — | 소프트웨어 설치 도구 |
