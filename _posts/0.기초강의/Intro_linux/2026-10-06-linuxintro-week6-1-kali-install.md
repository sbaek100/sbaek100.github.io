# 제1절. Kali Linux의 이해

---

## 1.1 Kali Linux란

**Kali Linux(칼리 리눅스)** 는 정보 보안 점검을 목적으로 만들어진 리눅스 배포판이다. 시스템의 취약점을 진단하고 보안 상태를 점검하는 데 필요한 여러 도구가 **사전에 설치된 상태**로 배포된다는 점이 일반 배포판과 다르다.

| 항목 | 내용 |
|---|---|
| 개발 주체 | Offensive Security |
| 기반 계열 | **데비안(Debian) 계열** |
| 패키지 관리 | `apt`(Ubuntu와 동일) |
| 기본 계정 | `kali` / `kali` |
| 주된 용도 | 취약점 진단, 보안 점검, 보안 교육 |

Kali Linux는 1주차-1에서 학습한 배포판 계열 중 **데비안 계열**에 속한다. 따라서 Ubuntu에서 익힌 명령어(`ls`, `cd`, `apt`, `chmod` 등)를 Kali에서도 그대로 사용할 수 있다. **새로운 운영체제를 다시 배우는 것이 아니라, 익숙한 리눅스에 보안 도구가 더해진 형태**로 이해하면 된다.

## 1.2 왜 별도의 배포판을 사용하는가

보안 점검 도구를 Ubuntu에 하나씩 설치할 수도 있으나, 그 수가 많고 상호 의존 관계가 복잡하다. Kali Linux는 이러한 도구를 검증된 조합으로 미리 묶어 배포하므로, 학습자가 도구 설치에 시간을 들이지 않고 점검 자체에 집중할 수 있다.

> **본 과정에서 Kali의 위치**
> 리눅스 기초 과정에서는 Kali의 보안 도구를 본격적으로 사용하지 않는다. 이번 주차의 목적은 **보안 실습을 위한 환경을 갖추는 것**이며, Kali의 도구는 이후 보안 관련 후속 과정에서 다룬다. 다만 Kali 역시 하나의 리눅스이므로, 지금까지 배운 명령이 그대로 통용됨을 확인하는 것이 이번 시간의 학습 내용이다.
{: .prompt-tip }

# 제2절. 사전 구성 이미지 내려받기

---

Kali Linux는 운영체제를 직접 설치하는 대신, 배포처가 제공하는 **VirtualBox용 사전 구성 이미지**를 등록하는 방식이 간편하다. 보안 도구가 설치된 상태로 즉시 시작할 수 있다.

> ### 따라 하기 2-1. Kali 이미지 내려받기
>
> **목적** VirtualBox에 등록할 Kali 가상 머신 이미지를 준비한다.
{: .prompt-tip }

**1단계.** [Kali 다운로드 페이지](https://www.kali.org/get-kali/)에서 **[Virtual Machines]** 를 선택한다.

**2단계.** **VirtualBox** 항목의 파일을 내려받는다. 파일 이름은 `kali-linux-2026.x-virtualbox-amd64.7z` 형태이며, `.7z`로 압축되어 있다.

**3단계.** [7-Zip](https://www.7-zip.org/)을 설치한 뒤 내려받은 파일의 압축을 해제한다. 압축을 풀면 `.vbox` 파일과 `.vdi`(가상 디스크) 파일이 생성된다.

| 파일 | 성격 |
|---|---|
| `.vbox` | 가상 머신의 설정 정보 파일 |
| `.vdi` | 가상 디스크 이미지(실제 운영체제가 담긴 파일) |

> 파일 이름의 판 번호(`2026.x`)는 내려받는 시점에 따라 다를 수 있다. `.7z` 압축 파일이며 압축 해제 후 `.vbox` 파일이 존재하면 올바른 파일이다.
{: .prompt-warning }

# 제3절. 가상 머신 등록과 실행

---

> ### 따라 하기 3-1. Kali 가상 머신 등록
>
> **목적** 내려받은 이미지를 VirtualBox에 등록하고 실행한다.
{: .prompt-tip }

**1단계.** VirtualBox 관리자에서 **[추가(Add)]** 를 선택한다. (새로 만들기가 아니라 **추가**임에 유의한다. 이미 만들어진 가상 머신을 등록하는 것이다.)

**2단계.** 압축을 해제한 폴더에서 **`.vbox` 파일**을 지정한다.

**3단계.** 목록에 Kali 가상 머신이 등록된다. 이름을 1학년 표시가 포함된 **`kali-y1`** 으로 변경한다. 가상 머신을 선택하고 **[설정] → [일반] → [기본]** 에서 이름을 수정한다.

> **가상 머신 이름 규약**
> 1주차에 만든 Ubuntu는 `ubuntu-y1`, 이번에 등록한 Kali는 `kali-y1`이다. 모든 가상 머신 이름에 1학년을 뜻하는 `-y1`을 붙여 구분한다.
{: .prompt-tip }

**4단계.** `kali-y1`을 선택하고 **[시작(Start)]** 을 누른다. 최초 부팅에는 1~2분이 소요될 수 있으며, 검은 화면이 일시적으로 지속되는 것은 정상적인 동작이다.

**5단계.** 로그인 화면에서 기본 계정으로 로그인한다.

| 항목 | 값 |
|---|---|
| 사용자 이름 | `kali` |
| 비밀번호 | `kali` |

> **[그림 6-1] 필요**
> Kali Linux의 로그인 화면 또는 로그인 직후의 바탕화면(용 문양 배경) 스크린샷.
{: .prompt-tip }

**6단계.** 로그인 후 터미널을 연다. 상단 작업 표시줄의 터미널 아이콘을 누르거나 `Ctrl` + `Alt` + `T`를 사용한다. 프롬프트는 다음과 같이 표시된다.

```
┌──(kali㉿kali-y1)-[~]
└─$
```

> Kali의 프롬프트는 Ubuntu와 형태가 다르지만, 의미는 동일하다. `kali`는 사용자, `kali-y1`은 호스트 이름이며, `$`는 명령 입력을 기다린다는 표시이다.
{: .prompt-tip }

# 제4절. 종합 실습 — Kali가 데비안 계열임을 확인

---

Kali Linux 역시 하나의 리눅스이며, Ubuntu와 같은 데비안 계열이다. 지금까지 Ubuntu에서 배운 명령이 Kali에서도 동일하게 동작함을 직접 확인한다. Kali 터미널에서 아래 단계를 순서대로 수행한다.

**1단계.** 현재 사용자와 호스트 이름을 확인한다.

```bash
whoami
hostname
```

> `kali`와 `kali-y1`이 각각 출력된다. 명령의 사용법은 Ubuntu에서와 완전히 동일하다.

**2단계.** 커널과 배포판 정보를 확인한다.

```bash
uname -r
cat /etc/os-release
```

> `uname -r`은 커널 버전을, `cat /etc/os-release`는 배포판 정보를 출력한다. 출력의 `ID=kali`, `ID_LIKE=debian` 항목에서 Kali가 **데비안 계열**임을 확인할 수 있다.

**3단계.** 패키지 관리 도구를 확인한다.

```bash
which apt dpkg
```

> 두 명령의 경로가 출력된다. Kali가 Ubuntu와 동일하게 `apt`와 `dpkg`를 사용하는 데비안 계열임을 확인한 것이다. `rpm`이나 `dnf`는 존재하지 않는다.

**4단계.** 디렉터리 구조를 확인한다.

```bash
ls /
```

> `/`(루트)를 정점으로 하는 단일 트리 구조와 `bin`, `etc`, `home`, `usr` 등의 디렉터리가 Ubuntu와 동일하게 존재함을 확인한다.

## 4.1 완료 기준

```
 [ ] kali / kali 로 로그인된다.
 [ ] 프롬프트가 kali㉿kali-y1 형태로 표시된다.
 [ ] cat /etc/os-release 결과에 ID_LIKE=debian 이 포함된다.
 [ ] which apt dpkg 로 두 명령의 경로가 확인된다.
```

> 이 실습을 통해, Kali가 특별한 별개의 운영체제가 아니라 **보안 도구가 더해진 데비안 계열 리눅스**임을 확인하였다. 지금까지 배운 모든 명령을 Kali에서도 그대로 사용할 수 있다.
{: .prompt-tip }

# 제5절. 스냅샷 생성

---

Ubuntu와 마찬가지로, 설치 직후의 상태를 스냅샷으로 저장한다.

> ### 따라 하기 5-1. Kali 스냅샷 생성
{: .prompt-tip }

**1단계.** Kali 터미널에서 시스템을 종료한다.

```bash
sudo poweroff
```

> 비밀번호를 물으면 `kali`를 입력한다.

**2단계.** VirtualBox 관리자에서 `kali-y1`을 선택하고, **[스냅샷] → [찍기(Take)]** 를 선택한다.

**3단계.** 이름을 `설치 직후`로 지정하고 확인한다.

> **확인 사항** `kali-y1`의 스냅샷 목록에 `설치 직후` 항목이 생성되면 성공이다.
{: .prompt-tip }

# 제6절. 자주 발생하는 오류와 대응 방법

---

| 증상 | 원인 | 대응 방법 |
|---|---|---|
| 이미지 등록 시 오류 발생 | `.7z` 압축이 완전히 해제되지 않음 | 7-Zip으로 다시 압축을 해제하고 `.vbox`와 `.vdi`가 같은 폴더에 있는지 확인한다. |
| 부팅이 매우 느리거나 멈춤 | 메모리 할당 부족 | 설정에서 메모리를 2048 MB 이상으로 상향한다. |
| 로그인 실패 | 대소문자 오입력 | 사용자·비밀번호 모두 소문자 `kali`이다. |
| 화면이 지나치게 작음 | 게스트 확장 미포함 | 사전 구성 이미지에는 대부분 포함되어 있다. 창 크기를 조절하거나 `[보기] → [게스트 확장]` 을 확인한다. |
| 마우스 커서가 갇힘 | 마우스 통합 미설정 | 오른쪽 `Ctrl` 키를 눌러 호스트로 복귀한다. |
