# 9-2 Python으로 VIEW 다루기

> 이번 시간 학습 목표
> - Python에서 MySQL에 **접속**할 수 있다.
> - Python 코드로 **VIEW를 생성/조회/삭제** 할 수 있다.
> - "SQL은 DB 관리자가 짜고, 프로그램은 파이썬으로 쓴다" 라는 실무 구조를 체험한다.

## 1. 왜 Python으로 DB를 다루는가?

- 실무에서는 SQL을 **Workbench로 직접 치는 경우는 드물다.**
- 대부분 Python, Java, JavaScript 같은 언어에서 DB에 연결해 쿼리를 실행한다.
- 이렇게 하면 **자동화**(매일 밤 백업, 매시간 리포트 생성)가 가능하다.

## 5. VIEW 생성 코드

같은 파일을 아래처럼 바꾼다.

```python
# view_practice.py
import mysql.connector

conn = mysql.connector.connect(
    host="localhost", user="root",
    password="본인_비밀번호", database="view_db"
)
cursor = conn.cursor()

create_view_sql = """
CREATE OR REPLACE VIEW v_student_contact AS
SELECT id, student_no, name, phone
FROM students
"""

cursor.execute(create_view_sql)
conn.commit()   # DDL도 안전하게 commit

print("VIEW 생성 완료")

cursor.close()
conn.close()
```

실행 후 MySQL Workbench로 돌아가서 확인하면:

```sql
USE view_db;
SHOW FULL TABLES WHERE Table_type = 'VIEW';
```

방금 만든 `v_student_contact` 가 보인다.

## 6. VIEW 조회 코드

```python
# view_select.py
import mysql.connector

conn = mysql.connector.connect(
    host="localhost", user="root",
    password="본인_비밀번호", database="view_db"
)
cursor = conn.cursor()

cursor.execute("SELECT * FROM v_student_contact")

rows = cursor.fetchall()
for row in rows:
    print(row)

cursor.close()
conn.close()
```

**예상 출력:**

```
(1, '2026001', '김민준', '010-0000-0000')
(2, '2026002', '이서연', '010-3333-4444')
(3, '2026003', '박지호', '010-5555-6666')
...
```

### 결과를 더 보기 좋게

`dictionary=True` 옵션을 쓰면 딕셔너리 형태로 받을 수 있다.

```python
cursor = conn.cursor(dictionary=True)
cursor.execute("SELECT * FROM v_student_contact")

for row in cursor.fetchall():
    print(f"{row['student_no']} {row['name']} ({row['phone']})")
```

**예상 출력:**

```
2026001 김민준 (010-0000-0000)
2026002 이서연 (010-3333-4444)
...
```

## 7. 마스킹 VIEW 자동 생성 스크립트

9-1의 마스킹 뷰를 **Python 한 번 실행으로** 만들어 보자.

```python
# make_masked_view.py
import mysql.connector

conn = mysql.connector.connect(
    host="localhost", user="root",
    password="본인_비밀번호", database="view_db"
)
cursor = conn.cursor()

sql_list = [
    """
    CREATE OR REPLACE VIEW v_student_masked AS
    SELECT student_no,
           name,
           CONCAT('010-****-', SUBSTRING(phone, -4)) AS phone_masked,
           CONCAT(SUBSTRING(resident_no, 1, 7), '*******') AS rrn_masked
    FROM students
    """,
]

for sql in sql_list:
    cursor.execute(sql)
conn.commit()

print("마스킹 뷰 생성 완료")

# 바로 조회 테스트
cursor.execute("SELECT * FROM v_student_masked")
for row in cursor.fetchall():
    print(row)

cursor.close()
conn.close()
```

**예상 출력:**

```
마스킹 뷰 생성 완료
('2026001', '김민준', '010-****-0000', '080312-*******')
('2026002', '이서연', '010-****-4444', '080715-*******')
...
```

## 8. 조건 검색 — 안전한 방법 (파라미터 바인딩)

이름으로 검색하는 기능을 Python에서 만들어 보자.

```python
# search_by_name.py
import mysql.connector

conn = mysql.connector.connect(
    host="localhost", user="root",
    password="본인_비밀번호", database="view_db"
)
cursor = conn.cursor(dictionary=True)

name_input = input("찾을 학생 이름: ")

# ⚠️ 아래처럼 %s 를 쓰는 것이 '안전한 방법' 이다.
sql = "SELECT * FROM v_student_masked WHERE name = %s"
cursor.execute(sql, (name_input,))

for row in cursor.fetchall():
    print(row)

cursor.close()
conn.close()
```

> ⚠️ **`sql = "... WHERE name = '" + name_input + "'"` 는 절대 쓰지 말 것.**  
> SQL Injection 공격에 그대로 뚫린다. 10-3 강의에서 자세히 다룬다.
{: .prompt-warning }

## 9. VIEW 목록 조회 & 삭제

```python
# manage_views.py
import mysql.connector

conn = mysql.connector.connect(
    host="localhost", user="root",
    password="본인_비밀번호", database="view_db"
)
cursor = conn.cursor()

# 현재 존재하는 VIEW 목록
cursor.execute("""
    SELECT table_name
    FROM information_schema.views
    WHERE table_schema = 'view_db'
""")

print("=== 현재 VIEW 목록 ===")
views = [v[0] for v in cursor.fetchall()]
for v in views:
    print("-", v)

# 첫 번째 VIEW 삭제 예시 (주석 처리, 실행 시 주석 해제)

# conn.commit()
# print(f"{views[0]} 삭제 완료")

cursor.close()
conn.close()
```

## 10. 실습 과제

### 과제 1
`view_db` 에 접속해 **평균 점수가 80점 이상인 학생**만 보여 주는 뷰 `v_top_students` 를 **Python 스크립트로** 생성하고 조회하시오.

<details>
<summary>힌트 코드</summary>

```python
sql = """
CREATE OR REPLACE VIEW v_top_students AS
SELECT s.student_no, s.name, ROUND(AVG(sc.score), 1) AS avg_score
FROM students s
JOIN scores sc ON s.id = sc.student_id
GROUP BY s.id, s.student_no, s.name
HAVING AVG(sc.score) >= 80
"""
cursor.execute(sql)
conn.commit()
```
</details>

### 과제 2
위 뷰를 조회하는 Python 스크립트를 만들되, **평균점수 내림차순으로 출력**하도록 하시오.

### 과제 3 (도전)
사용자가 콘솔에 학생 이름을 입력하면 그 학생의 과목별 점수를 출력하는 스크립트를 만드시오.  
(단, 파라미터 바인딩 `%s` 를 반드시 사용할 것.)

## 11. 정리

- Python은 `mysql-connector-python` 으로 MySQL에 접속한다.
- `cursor.execute(sql)` → `conn.commit()` 이 DDL(뷰 생성 등)의 기본 흐름이다.
- 조회 결과는 `fetchall()` 로 받고, `dictionary=True` 옵션이 편하다.
- 검색 조건은 **반드시 `%s` 파라미터 바인딩**을 사용한다. (10-3 예고)

다음 주([10-1](/posts/database-10-1))에는 SQL 명령어를 **DDL / DML / DCL** 로 분류하고, 이어서 권한 관리와 SQL Injection 방어까지 배운다.
