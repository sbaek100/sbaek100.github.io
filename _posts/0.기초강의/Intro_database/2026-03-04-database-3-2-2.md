# 데이터 필터링 심화 반복 실습 (3-2-2)

> 이번 실습은 **3-1, 3-2에서 배운 `WHERE`, `AND`, `OR`, 괄호 조건**을 조금 더 복잡한 문장으로 다시 연습하는 보충 자료이다.  
> 이번에는 조건이 2개에서 끝나지 않고, **3개 이상 섞인 조건식**도 직접 작성해 보는 것이 목표다.

## 1. 실습 준비

이번에는 동아리 학생 명단을 기준으로 조건 검색을 연습해 보자.

```sql
DROP DATABASE IF EXISTS filter_db3;
CREATE DATABASE filter_db3;
USE filter_db3;

CREATE TABLE club_members (
  id INT,
  name VARCHAR(20),
  grade INT,
  class_no INT,
  club VARCHAR(20),
  city VARCHAR(20),
  attendance INT
);
```

```sql
INSERT INTO club_members VALUES (1, '민준', 1, 2, '축구', '서울', 95);
INSERT INTO club_members VALUES (2, '서연', 1, 1, '농구', '부산', 88);
INSERT INTO club_members VALUES (3, '지호', 2, 3, '축구', '서울', 72);
INSERT INTO club_members VALUES (4, '하은', 2, 2, '밴드', '대전', 81);
INSERT INTO club_members VALUES (5, '도윤', 3, 1, '농구', '부산', 67);
INSERT INTO club_members VALUES (6, '지우', 3, 2, '축구', '대구', 91);
INSERT INTO club_members VALUES (7, '예준', 2, 1, '밴드', '서울', 86);
```

데이터가 잘 들어갔는지 먼저 확인해 보자.

```sql
SELECT * FROM club_members;
```

## 2. AND 다시 연습

두 조건을 모두 만족해야 할 때 `AND`를 사용한다.

```sql
SELECT id, name, club, city
FROM club_members
WHERE club = '축구' AND city = '서울';

SELECT id, name, grade, attendance
FROM club_members
WHERE grade = 2 AND attendance >= 80;
```

확인 포인트:

- 첫 번째 쿼리는 `축구부`이면서 `서울`인 학생만 조회한다.
- 두 번째 쿼리는 `2학년`이면서 `출석률 80 이상`인 학생만 조회한다.

---

## 3. OR 다시 연습

여러 조건 중 하나만 만족해도 될 때 `OR`를 사용한다.

```sql
SELECT id, name, city
FROM club_members
WHERE city = '부산' OR city = '대전';

SELECT id, name, club, attendance
FROM club_members
WHERE club = '농구' OR attendance >= 90;
```

확인 포인트:

- 첫 번째 쿼리는 `부산`, `대전` 중 하나에 해당하면 조회된다.
- 두 번째 쿼리는 `농구부`이거나 출석률이 `90 이상`이면 조회된다.

---

## 4. AND + OR + 괄호 심화 연습

조건이 섞이면 **괄호로 먼저 묶어서 의미를 분명하게** 만드는 습관이 중요하다.

```sql
SELECT id, name, grade, class_no, city
FROM club_members
WHERE (grade = 1 OR grade = 2) AND (city = '서울' OR city = '부산');

SELECT id, name, club, city, attendance
FROM club_members
WHERE (club = '축구' OR club = '밴드') AND (city = '서울' OR attendance >= 85);

SELECT id, name, grade, class_no, city, attendance
FROM club_members
WHERE (class_no = 1 AND city = '부산')
   OR (class_no = 2 AND attendance >= 90)
   OR (grade = 2 AND club = '밴드');
```

확인 포인트:

- 괄호가 없으면 SQL이 우리가 생각한 순서와 다르게 해석될 수 있다.
- `OR`가 들어갈 때는 먼저 묶고, 그 뒤에 `AND`와 조합한다고 생각하면 실수가 줄어든다.

## 5. 문제와 예상 답안

아래 문제는 **앞쪽은 비교적 쉽게**, 뒤로 갈수록 **괄호와 조건 수가 늘어나도록** 구성했다.  
먼저 스스로 작성한 뒤, 바로 아래 `예상 답안`과 비교해 보자.

### 문제 1

도시가 `서울` 또는 `부산`인 학생을 조회해 보자.

### 예상 답안

```sql
SELECT id, name, city
FROM club_members
WHERE city = '서울' OR city = '부산';
```

### 문제 2

`2학년`이면서 출석률이 `80 이상`인 학생을 조회해 보자.

### 예상 답안

```sql
SELECT id, name, grade, attendance
FROM club_members
WHERE grade = 2 AND attendance >= 80;
```

### 문제 3

동아리가 `축구` 또는 `밴드`이면서, 도시가 `서울`인 학생을 조회해 보자.

### 예상 답안

```sql
SELECT id, name, club, city
FROM club_members
WHERE (club = '축구' OR club = '밴드')
  AND city = '서울';
```

### 문제 4

`1학년` 또는 `2학년`이면서, 도시가 `서울` 또는 `부산`인 학생을 조회해 보자.

### 예상 답안

```sql
SELECT id, name, grade, city
FROM club_members
WHERE (grade = 1 OR grade = 2)
  AND (city = '서울' OR city = '부산');
```

### 문제 5

반 번호가 `1반`이면서 도시가 `부산`이거나, 반 번호가 `2반`이면서 도시가 `서울`인 학생을 조회해 보자.

### 예상 답안

```sql
SELECT id, name, class_no, city
FROM club_members
WHERE (class_no = 1 AND city = '부산')
   OR (class_no = 2 AND city = '서울');
```

### 문제 6

`2학년`이면서, 동아리가 `축구` 또는 `밴드`이고, 출석률이 `80 이상`인 학생을 조회해 보자.

### 예상 답안

```sql
SELECT id, name, grade, club, attendance
FROM club_members
WHERE grade = 2
  AND (club = '축구' OR club = '밴드')
  AND attendance >= 80;
```

### 문제 7

도시가 `서울`이면서 동아리가 `축구`이거나, 도시가 `부산`이면서 출석률이 `80 이상`인 학생을 조회해 보자.

### 예상 답안

```sql
SELECT id, name, city, club
FROM club_members
WHERE (city = '서울' AND club = '축구')
   OR (city = '부산' AND attendance >= 80);
```

### 문제 8

동아리가 `축구` 또는 `농구`이면서, 출석률이 `85 이상`이고, 학년이 `3학년`은 아닌 학생을 조회해 보자.

### 예상 답안

```sql
SELECT id, name, grade, club, attendance
FROM club_members
WHERE (club = '축구' OR club = '농구')
  AND attendance >= 85
  AND grade <> 3;
```

### 문제 9

출석률이 `70 미만`이거나, `3학년`이면서 동아리가 `축구`이고 도시가 `대구`인 학생을 조회해 보자.

### 예상 답안

```sql
SELECT id, name, grade, city, attendance
FROM club_members
WHERE attendance < 70
   OR (grade = 3 AND club = '축구' AND city = '대구');
```

### 문제 10

동아리가 `밴드`이면서, 도시가 `서울` 또는 `대전`이고, `(출석률이 85 이상이거나 학년이 2학년인)` 학생을 조회해 보자.

### 예상 답안

```sql
SELECT id, name, grade, club, city, attendance
FROM club_members
WHERE club = '밴드'
  AND (city = '서울' OR city = '대전')
  AND (attendance >= 85 OR grade = 2);
```

## 6. 특별 예제: NOT, IN, BETWEEN

지금까지는 `AND`, `OR`, 괄호에 집중했다면, 이번에는 실무와 시험에서 자주 나오는 `NOT`, `IN`, `BETWEEN`도 함께 익혀 보자.

### 1) NOT 예제

```sql
SELECT id, name, grade, city
FROM club_members
WHERE NOT city = '서울';

SELECT id, name, club, attendance
FROM club_members
WHERE NOT attendance >= 90;
```

설명:

- `NOT city = '서울'`은 `서울이 아닌 학생`을 뜻한다.
- `NOT attendance >= 90`은 `출석률이 90 이상이 아닌 학생`, 즉 `90 미만` 학생을 뜻한다.

### 2) IN 예제

```sql
SELECT id, name, city
FROM club_members
WHERE city IN ('서울', '부산', '대전');

SELECT id, name, club
FROM club_members
WHERE club IN ('축구', '밴드');
```

설명:

- `IN`은 여러 값을 한꺼번에 비교할 때 편리하다.
- `city = '서울' OR city = '부산' OR city = '대전'`을 더 짧게 쓸 수 있다.

### 3) BETWEEN 예제

```sql
SELECT id, name, attendance
FROM club_members
WHERE attendance BETWEEN 80 AND 90;

SELECT id, name, grade
FROM club_members
WHERE grade BETWEEN 1 AND 2;
```

설명:

- `BETWEEN 80 AND 90`은 `80 이상 90 이하`를 뜻한다.
- 범위를 찾을 때 `>=`와 `<=`를 함께 쓰는 대신 더 읽기 쉽게 표현할 수 있다.

### 4) 함께 섞어 보기

```sql
SELECT id, name, grade, city, attendance
FROM club_members
WHERE city IN ('서울', '부산')
  AND attendance BETWEEN 80 AND 95;

SELECT id, name, club, city
FROM club_members
WHERE club IN ('축구', '농구')
  AND NOT city = '대구';
```

## 7. 한 번 더 점검하기

아래 문장을 보고 바로 SQL로 바꿀 수 있으면 잘 익힌 것이다.

- "`그리고`"가 나오면 `AND`
- "`또는`"이 나오면 `OR`
- "`아닌`"이 나오면 `NOT`도 떠올리기
- "`여러 값 중 하나`"라면 `IN`도 떠올리기
- "`사이`", "`범위`"가 나오면 `BETWEEN`도 떠올리기
- `A이거나 B이면서 C`처럼 섞이면, 먼저 어느 부분을 묶을지 판단하기
- 조건이 3개 이상이면 문장을 짧게 끊어서 괄호 단위로 옮기기
- 먼저 `SELECT ... FROM ...`을 쓰고, 그 다음 `WHERE` 조건을 천천히 붙이기

헷갈리는 문제일수록 바로 타이핑하지 말고, 문장을 `조건 1 / 조건 2 / 조건 3`으로 잘라 본 뒤 SQL로 옮기면 훨씬 정확해진다.
