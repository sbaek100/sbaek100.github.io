# 5-2 집계 함수 응용 실습 — 조건 결합


---

## 0. 5-1과의 차이

5-1에서는 **조건을 하나씩** 사용해서 집계했다.  
5-2에서는 그 위에 **조건을 1~2개 더 얹어서** 집계해 본다.  
새로운 함수는 없다. **조건 결합 능력**을 늘리는 것이 목표다.

| 단계 | 5-1 (거래 DB) | 5-2 (성적 DB) |
|---|---|---|
| 데이터 | `transactions` | `scores` |
| 조건 개수 | 보통 0~1개, AND 결합은 2개 | 기본 2개, 응용 3개 이상 |
| 새 문법 | (없음) — 5-1에서 배운 5가지 패턴 그대로 | (없음) — 5-1 패턴 + `OR` 추가 |

> 핵심: **5-1의 5가지 패턴(=, 비교, BETWEEN, IN, AND)은 그대로 사용**하고, 거기에 조건을 더 얹는 연습.
{: .prompt-tip }

## STEP 1. 데이터베이스와 테이블 만들기

> MySQL 워크벤치에서 아래를 순서대로 실행한다.
{: .prompt-tip }

```sql
CREATE DATABASE score_db;
USE score_db;
```

```sql
CREATE TABLE scores (
  id      INT,
  name    VARCHAR(20),
  subject VARCHAR(20),
  score   INT,
  grade   INT
);
```

칼럼 설명:

| 칼럼명 | 의미 | 예시 값 |
|---|---|---|
| `id` | 번호 | 1, 2, 3 … |
| `name` | 학생 이름 | 민준, 서연 … |
| `subject` | 과목 이름 | 국어, 수학, 영어 |
| `score` | 점수 | 0 ~ 100 |
| `grade` | 학년 | 1, 2, 3 |

## STEP 3. COUNT — 응시 건수 세기 (조건 결합)

> 5-1의 각 패턴에 **조건을 1~2개 더 결합**해서 사용한다.
{: .prompt-tip }

---

### 패턴 ① `=` 두 개 결합 — AND

**민준이가 본 수학 시험 건수**를 센다. (이름 `=` + 과목 `=`)

```sql
SELECT COUNT(*) AS 민준수학수
FROM scores
WHERE name = '민준' AND subject = '수학';
```

---

**1학년 학생의 영어 응시 건수**를 센다. (학년 `=` + 과목 `=`)

```sql
SELECT COUNT(*) AS 일학년영어수
FROM scores
WHERE grade = 1 AND subject = '영어';
```

---

**민준이가 1학년 때 본 시험 건수**를 센다. (이름 `=` + 학년 `=`)

```sql
SELECT COUNT(*) AS 민준일학년수
FROM scores
WHERE name = '민준' AND grade = 1;
```

---

### 패턴 ② 비교 연산자 + 다른 조건

**수학에서 80점 이상 응시 건수**를 센다. (`=` + `>=`)

```sql
SELECT COUNT(*) AS 수학고득점수
FROM scores
WHERE subject = '수학' AND score >= 80;
```

---

**1학년에서 70점 미만 응시 건수**를 센다. (`=` + `<`)

```sql
SELECT COUNT(*) AS 일학년저득점수
FROM scores
WHERE grade = 1 AND score < 70;
```

---

**70점 이상 90점 미만 응시 건수**를 센다. (비교 연산자 두 개를 `AND`로 결합)

```sql
SELECT COUNT(*) AS 중상위수
FROM scores
WHERE score >= 70 AND score < 90;
```

---

### 패턴 ③ `BETWEEN` + 다른 조건

**수학 점수 중 70~89점 사이 건수**를 센다. (`=` + `BETWEEN`)

```sql
SELECT COUNT(*) AS 수학중상위수
FROM scores
WHERE subject = '수학' AND score BETWEEN 70 AND 89;
```

---

**1~2학년 중 80점 이상 건수**를 센다. (`BETWEEN` + `>=`)

```sql
SELECT COUNT(*) AS 일이학년고득점수
FROM scores
WHERE grade BETWEEN 1 AND 2 AND score >= 80;
```

---

**민준이의 70~89점 사이 응시 건수**를 센다. (`=` + `BETWEEN`)

```sql
SELECT COUNT(*) AS 민준중상위수
FROM scores
WHERE name = '민준' AND score BETWEEN 70 AND 89;
```

---

### 패턴 ④ `IN` + 다른 조건

**국어 또는 수학에서 80점 이상 응시 건수**를 센다. (`IN` + `>=`)

```sql
SELECT COUNT(*) AS 국수고득점수
FROM scores
WHERE subject IN ('국어', '수학') AND score >= 80;
```

---

**민준 또는 지호의 2학년 시험 건수**를 센다. (`IN` + `=`)

```sql
SELECT COUNT(*) AS 두학생이학년수
FROM scores
WHERE name IN ('민준', '지호') AND grade = 2;
```

---

**1학년 또는 3학년의 영어 응시 건수**를 센다. (`IN` + `=`)

```sql
SELECT COUNT(*) AS 일삼학년영어수
FROM scores
WHERE grade IN (1, 3) AND subject = '영어';
```

---

### 패턴 ⑤ 조건 3개 결합 + `OR` 도입

`OR`은 **둘 중 하나만 참이어도** 결과에 포함된다.  
`AND`와 `OR`이 같이 있으면 `AND`가 먼저 계산되므로, 우선순위를 바꾸려면 **괄호**를 쓴다.

**1학년 수학에서 80점 이상 응시 건수**를 센다. (조건 3개)

```sql
SELECT COUNT(*) AS 일학년수학고득점수
FROM scores
WHERE grade = 1 AND subject = '수학' AND score >= 80;
```

---

**민준 또는 지호 중 수학에서 80점 이상 건수**를 센다. (`IN` + `=` + `>=`)

```sql
SELECT COUNT(*) AS 두학생수학고득점수
FROM scores
WHERE name IN ('민준', '지호')
  AND subject = '수학'
  AND score >= 80;
```

---

**국어 또는 수학에서 80점 이상 받은 응시 건수**를 센다. (`OR` + 괄호)

```sql
SELECT COUNT(*) AS 합격수
FROM scores
WHERE (subject = '국어' OR subject = '수학')
  AND score >= 80;
```

> 괄호가 없으면 `subject = '수학' AND score >= 80`만 묶이고, 국어는 점수에 상관없이 모두 포함된다.  
> **조건 우선순위가 헷갈리면 괄호로 묶어준다.**
{: .prompt-warning }

## STEP 4. SUM — 점수 합계 (조건 결합)

> 같은 5가지 패턴 + 조건 결합을 `SUM`에도 적용한다.
{: .prompt-tip }

---

### 패턴 ① `=` 두 개 결합

**1학년 영어 점수 합계**를 구한다.

```sql
SELECT SUM(score) AS 일학년영어합계
FROM scores
WHERE grade = 1 AND subject = '영어';
```

---

**민준이의 수학 + 영어 점수 합계**를 구한다. (`=` + `IN`)

```sql
SELECT SUM(score) AS 민준수영합계
FROM scores
WHERE name = '민준' AND subject IN ('수학', '영어');
```

---

### 패턴 ② 비교 + 다른 조건

**수학 80점 이상의 합계**를 구한다.

```sql
SELECT SUM(score) AS 수학고득점합계
FROM scores
WHERE subject = '수학' AND score >= 80;
```

---

**1학년의 70점 이상 점수 합계**를 구한다.

```sql
SELECT SUM(score) AS 일학년양호합계
FROM scores
WHERE grade = 1 AND score >= 70;
```

---

### 패턴 ③ `BETWEEN` + 다른 조건

**1~2학년에서 70~89점 사이 점수 합계**를 구한다.

```sql
SELECT SUM(score) AS 일이학년중상위합계
FROM scores
WHERE grade BETWEEN 1 AND 2
  AND score BETWEEN 70 AND 89;
```

---

**영어 과목의 80~100점 점수 합계**를 구한다.

```sql
SELECT SUM(score) AS 영어고득점합계
FROM scores
WHERE subject = '영어'
  AND score BETWEEN 80 AND 100;
```

---

### 패턴 ④ `IN` + 다른 조건

**국어 또는 수학의 80점 이상 합계**를 구한다.

```sql
SELECT SUM(score) AS 국수고득점합계
FROM scores
WHERE subject IN ('국어', '수학')
  AND score >= 80;
```

---

**민준 또는 준서의 1~3학년 점수 합계**를 구한다.

```sql
SELECT SUM(score) AS 합계
FROM scores
WHERE name IN ('민준', '준서')
  AND grade BETWEEN 1 AND 3;
```

---

### 패턴 ⑤ 조건 3개 + `OR`

**1학년 수학에서 80점 이상 합계**를 구한다.

```sql
SELECT SUM(score) AS 일학년수학고득점합계
FROM scores
WHERE grade = 1
  AND subject = '수학'
  AND score >= 80;
```

---

**1학년 또는 2학년 학생이 받은 80점 이상 점수의 합계**를 구한다. (`OR` + 괄호 + `>=`)

```sql
SELECT SUM(score) AS 합계
FROM scores
WHERE (grade = 1 OR grade = 2)
  AND score >= 80;
```

## STEP 6. MAX / MIN — 최고점·최저점 (조건 결합)

---

### 패턴 ① `=` 두 개 결합

**1학년 수학의 최고점과 최저점**을 구한다.

```sql
SELECT MAX(score) AS 최고,

FROM scores

```

---

**민준이가 1학년 때 받은 최고점과 최저점**을 구한다.

```sql
SELECT MAX(score) AS 최고,
       MIN(score) AS 최저
FROM scores
WHERE name = '민준' AND grade = 1;
```

---

### 패턴 ② 비교 + 다른 조건

**수학에서 80점 이상 점수 중 최고와 최저**를 구한다.

```sql
SELECT MAX(score) AS 최고,
       MIN(score) AS 최저
```

**1학년의 70점 이상 점수 중 최고와 최저**를 구한다.

```sql
SELECT MAX(score) AS 최고,
```

```sql
SELECT MAX(score) AS 최고,
```

```sql
SELECT MAX(score) AS 최고,
```

```sql
SELECT MAX(score) AS 최고,
```

## STEP 7. 여러 함수 한꺼번에 + 조건 결합

5-1의 마지막 단계와 같지만, **조건을 2~3개 결합한 통계**를 한 번에 구한다.

---

### 1학년 수학 통계 (조건 2개)

```sql
SELECT
    COUNT(*)      AS 응시수,
    SUM(score)    AS 합계,
    AVG(score)    AS 평균,
    MAX(score)    AS 최고,
    MIN(score)    AS 최저
FROM scores
WHERE grade = 1 AND subject = '수학';
```

---

### 1학년 80점 이상 통계 (조건 2개: `=` + `>=`)

```sql
SELECT
    COUNT(*)      AS 응시수,
    SUM(score)    AS 합계,
    AVG(score)    AS 평균,
    MAX(score)    AS 최고,
    MIN(score)    AS 최저
FROM scores
WHERE grade = 1 AND score >= 80;
```

---

### 수학 70~89점 구간 통계 (조건 2개: `=` + `BETWEEN`)

```sql
SELECT
    COUNT(*)      AS 응시수,
    SUM(score)    AS 합계,
    AVG(score)    AS 평균,
    MAX(score)    AS 최고,
    MIN(score)    AS 최저
FROM scores
WHERE subject = '수학'
  AND score BETWEEN 70 AND 89;
```

---

### 국어·수학에서 80점 이상 통계 (조건 2개: `IN` + `>=`)

```sql
SELECT
    COUNT(*)      AS 응시수,
    SUM(score)    AS 합계,
    AVG(score)    AS 평균,
    MAX(score)    AS 최고,
    MIN(score)    AS 최저
FROM scores
WHERE subject IN ('국어', '수학')
  AND score >= 80;
```

---

### 1학년 수학 80점 이상 통계 (조건 3개)

```sql
SELECT
    COUNT(*)      AS 응시수,
    SUM(score)    AS 합계,
    AVG(score)    AS 평균,
    MAX(score)    AS 최고,
    MIN(score)    AS 최저
FROM scores
WHERE grade = 1
  AND subject = '수학'
  AND score >= 80;
```

---

### 1·2학년 + 국어·수학 + 80점 이상 통계 (조건 3개, `BETWEEN` + `IN` + `>=`)

```sql
SELECT
    COUNT(*)      AS 응시수,
    SUM(score)    AS 합계,
    AVG(score)    AS 평균,
    MAX(score)    AS 최고,
    MIN(score)    AS 최저
FROM scores
WHERE grade BETWEEN 1 AND 2
  AND subject IN ('국어', '수학')
  AND score >= 80;
```

---

### 국어 또는 수학에서 80점 이상 통계 (`OR` + 괄호 + `>=`)

```sql
SELECT
    COUNT(*)      AS 응시수,
    SUM(score)    AS 합계,
    AVG(score)    AS 평균,
    MAX(score)    AS 최고,
    MIN(score)    AS 최저
FROM scores
WHERE (subject = '국어' OR subject = '수학')
  AND score >= 80;
```

## STEP 8. DISTINCT — 중복 없이 + 조건 결합

**80점 이상 받은 학생 수** (조건 1개 + DISTINCT)

```sql
SELECT COUNT(DISTINCT name) AS 학생수
FROM scores
WHERE score >= 80;
```

---

**수학에서 80점 이상 받은 학생 수** (조건 2개 + DISTINCT)

```sql
SELECT COUNT(DISTINCT name) AS 학생수
FROM scores
WHERE subject = '수학' AND score >= 80;
```

---

**1~2학년에서 80점 이상 받은 학생 수** (조건 2개 + DISTINCT)

```sql
SELECT COUNT(DISTINCT name) AS 학생수
FROM scores
WHERE grade BETWEEN 1 AND 2
  AND score >= 80;
```

---

**국어 또는 수학에서 80점 이상 받은 학생 수** (`IN` + `>=` + DISTINCT)

```sql
SELECT COUNT(DISTINCT name) AS 학생수
FROM scores
WHERE subject IN ('국어', '수학')
  AND score >= 80;
```

## 정리 — 5-1과 5-2 비교표

| 패턴 | 5-1 (조건 1개) | 5-2 (조건 2~3개 결합) |
|---|---|---|
| ① 기본 | `WHERE subject = '수학'` | `WHERE grade = 1 AND subject = '수학'` |
| ② 비교 | `WHERE score >= 80` | `WHERE subject = '수학' AND score >= 80` |
| ③ BETWEEN | `WHERE score BETWEEN 70 AND 89` | `WHERE subject = '수학' AND score BETWEEN 70 AND 89` |
| ④ IN | `WHERE subject IN ('국어','수학')` | `WHERE subject IN ('국어','수학') AND score >= 80` |
| ⑤ 결합 | `WHERE A = 'x' AND B = 'y'` | `WHERE A = 'x' AND B = 'y' AND C >= 80`<br>또는 `WHERE (A = 'x' OR A = 'y') AND C >= 80` |

> 5-1에서 익힌 5가지 패턴을 그대로 쓰면서 **조건을 한두 개 더 얹기**만 하면 된다.  
> 헷갈릴 때는 **`OR`이 섞이면 괄호로 묶기**를 잊지 않는다.
