# 실습 준비 — company DB 및 employees 테이블 생성

## 칼럼 설명

| 칼럼명 | 설명 |
|--------|------|
| id | 각 직원의 아이디. 기본키(Primary Key), 정수형 |
| name | 직원 이름. 최대 50자 문자형 |
| department | 소속 부서. 최대 50자 문자형 |
| salary | 연봉. 단위는 '천만 원', 정수형 |

## 문제 1. company DB를 생성 및 진입한 후 employees 테이블을 만드세요.

```sql
-- company DB 생성 및 진입
CREATE DATABASE IF NOT EXISTS company;
USE company;

-- employees 테이블 생성
CREATE TABLE employees (
    id         INTEGER,        -- 아이디(정수형, 기본키)
    name       VARCHAR(50),    -- 직원명(문자형: 최대 50자)
    department VARCHAR(50),    -- 소속 부서(문자형: 최대 50자)
    salary     INTEGER,        -- 연봉(정수형, 단위: 천만 원)
    PRIMARY KEY (id)
);
```

> 💡 `mapdonalds`(3주차 버거 실습)와 다른 DB이므로 반드시 `USE company;` 실행 후 진행할 것.

# 셀프체크 풀이 (p.129)

## 문제 3. 모든 직원의 연봉 합계를 계산하세요.

```sql
SELECT SUM(salary) AS 연봉합계
FROM employees;
```

**결과:**

| 연봉합계 |
|---------|
| 65200 |

> `SUM(salary)` = 7000+5500+8000+6500+7200+6500+5900+6300+5500+6800 = 65200.
> 집계함수(Aggregate Function)는 `WHERE` 없이 쓰면 전체 행을 대상으로 함.

---

## 문제 4. Sales 부서의 평균 연봉을 구하세요.

```sql
SELECT AVG(salary) AS Sales평균연봉
FROM employees
WHERE department = 'Sales';
```

**결과:**

| Sales평균연봉 |
|-------------|
| 6750.0000 |

> Sales 부서 직원: John(7000), Mike(8000), Emma(6500), Lucas(5500) → 합계 27000 / 4명 = 6750.
> `AVG()`는 NULL 값을 제외하고 계산함 — 데이터가 없는 행은 분모에 포함되지 않음.

---

## 문제 5. 부서가 모두 몇 개 있는지 조회하세요.

```sql
SELECT COUNT(DISTINCT department) AS 부서수
FROM employees;
```

**결과:**

| 부서수 |
|-------|
| 3 |

> `COUNT(department)`만 쓰면 행 수(10)가 나옴 — 중복 제거가 필요하므로 `DISTINCT` 필수.
> 부서는 Sales, IT, HR 3개.

---

## 문제 6. Sales 부서의 최대 연봉과 최소 연봉 차이를 구하세요.

```sql
SELECT MAX(salary) - MIN(salary) AS 연봉차이
FROM employees
WHERE department = 'Sales';
```

**결과:**

| 연봉차이 |
|---------|
| 2500 |

> Sales 부서 최대: Mike(8000), 최소: Lucas(5500) → 8000 - 5500 = 2500.
> `MAX()`와 `MIN()`은 같은 `SELECT` 절에서 동시에 사용 가능하며 산술 연산도 바로 적용 가능.

---

## 문제 7. 가장 높은 연봉을 받는 직원은 전체 평균 연봉 대비 얼마나 더 받는지 구하세요.

```sql
SELECT MAX(salary) - AVG(salary) AS 평균초과금액
FROM employees;
```

**결과:**

| 평균초과금액 |
|------------|
| 1480.0000 |

> 전체 평균 연봉: 65200 / 10 = 6520.
> 최고 연봉: Mike 8000 → 8000 - 6520 = **1480**.
> `MAX()`와 `AVG()`를 하나의 `SELECT` 절에서 빼는 방식으로 처리 가능.

## 전체 쿼리 통합본

```sql
-- DB 생성 및 테이블 준비
CREATE DATABASE IF NOT EXISTS company;
USE company;

CREATE TABLE employees (
    id         INTEGER,
    name       VARCHAR(50),
    department VARCHAR(50),
    salary     INTEGER,
    PRIMARY KEY (id)
);

INSERT INTO employees (id, name, department, salary) VALUES
    (101, 'John',      'Sales', 7000),
    (102, 'Aria',      'IT',    5500),
    (103, 'Mike',      'Sales', 8000),
    (104, 'Lily',      'HR',    6500),
    (105, 'David',     'IT',    7200),
    (106, 'Emma',      'Sales', 6500),
    (107, 'Oliver',    'IT',    5900),
    (108, 'Sophia',    'HR',    6300),
    (109, 'Lucas',     'Sales', 5500),
    (110, 'Charlotte', 'HR',    6800);

-- 문제 3: 연봉 합계
SELECT SUM(salary) AS 연봉합계 FROM employees;

-- 문제 4: Sales 평균 연봉
SELECT AVG(salary) AS Sales평균연봉
FROM employees WHERE department = 'Sales';

-- 문제 5: 부서 수
SELECT COUNT(DISTINCT department) AS 부서수 FROM employees;

-- 문제 6: Sales 최대-최소 차이
SELECT MAX(salary) - MIN(salary) AS 연봉차이
FROM employees WHERE department = 'Sales';

-- 문제 7: 최고 연봉 - 전체 평균
SELECT MAX(salary) - AVG(salary) AS 평균초과금액 FROM employees;
```
