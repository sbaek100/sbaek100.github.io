# 4-2 LIKE, BETWEEN

이번 4-2는 4-1의 `datatype_db.products` 테이블을 그대로 이어서 사용한다.

---

## 1부. 이론

### 1-1. LIKE

문자열 패턴 검색에 사용한다.

- `%` : 글자 0개 이상
- `_` : 글자 1개

예시:

```sql
WHERE name LIKE '갤럭시%'
WHERE name LIKE '%프로%'
WHERE name LIKE '__'
```

### 1-2. BETWEEN

범위 검색에 사용한다.

```sql
WHERE price BETWEEN 10000 AND 30000
```

위 문장은 아래와 같다.

```sql
WHERE price >= 10000 AND price <= 30000
```

---

## 2부. 4-1 연장 실습

```sql
USE datatype_db;
```

```sql
INSERT INTO products VALUES (4, '갤럭시 버즈', '무선 이어폰', 180000.00, 25, '2026-03-05', '2026-03-05 09:10:00');
INSERT INTO products VALUES (5, '에어팟 프로', '노이즈 캔슬링 이어폰', 320000.00, 18, '2026-03-06', '2026-03-06 14:20:00');
INSERT INTO products VALUES (6, '갤럭시 워치', '스마트 워치', 350000.00, 10, '2026-03-07', '2026-03-07 11:00:00');
```

LIKE 실습:

```sql
SELECT id, name, price FROM products WHERE name LIKE '갤럭시%';
SELECT id, name, price FROM products WHERE name LIKE '%프로%';
SELECT id, name, description FROM products WHERE description LIKE '%이어폰%';
```

BETWEEN 실습:

```sql
SELECT id, name, price FROM products WHERE price BETWEEN 10000 AND 200000;
SELECT id, name, release_date FROM products WHERE release_date BETWEEN '2026-03-02' AND '2026-03-06';
```

조합 실습:

```sql
SELECT id, name, price
FROM products
WHERE name LIKE '갤럭시%'
  AND price BETWEEN 100000 AND 400000;
```

---

## 정리

- 문자열 패턴: `LIKE`
- 숫자/날짜 범위: `BETWEEN`
- 정확한 검색: `AND` 조합
