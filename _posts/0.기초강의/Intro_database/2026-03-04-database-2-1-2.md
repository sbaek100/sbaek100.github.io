# MySQL 기초 복습 2-1-2: 테이블 실습

이번 복습에서는 **정수(INT)**와 **문자(VARCHAR/CHAR)**만 사용해서
칼럼 5개짜리 테이블을 만들고 CRUD를 다시 연습한다.

---

## 1. 데이터베이스 생성 및 선택

```sql
CREATE DATABASE school_review;
USE school_review;
```

---

## 2. 5개 칼럼 테이블 만들기

테이블 이름: `student_info`

- `student_id` : 학생 번호 (정수)
- `name` : 이름 (문자)
- `grade` : 학년 (정수)
- `class_no` : 반 (정수)
- `memo` : 메모 (문자)

```sql
CREATE TABLE student_info (
  student_id INT,
  name VARCHAR(20),
  grade INT,
  class_no INT,
  memo VARCHAR(50)
);
```

---

## 3. 데이터 추가 (INSERT)

```sql
INSERT INTO student_info (student_id, name, grade, class_no, memo)
VALUES (1, '철수', 1, 3, '전학 예정 없음');

INSERT INTO student_info (student_id, name, grade, class_no, memo)
VALUES (2, '영희', 2, 1, '독서 동아리');

INSERT INTO student_info (student_id, name, grade, class_no, memo)
VALUES (3, '민수', 1, 2, '축구부');
```

---

## 4. 데이터 조회 (SELECT)

```sql
SELECT * FROM student_info;
```

예상 결과

```
student_id | name | grade | class_no | memo
---------------------------------------------------
1          | 철수 | 1     | 3        | 전학 예정 없음
2          | 영희 | 2     | 1        | 독서 동아리
3          | 민수 | 1     | 2        | 축구부
```

---

## 5. 데이터 수정 (UPDATE)

`student_id = 3`인 학생의 메모를 수정해보자.

```sql
UPDATE student_info
SET memo = '축구부 주장'
WHERE student_id = 3;
```

수정 확인:

```sql
SELECT * FROM student_info WHERE student_id = 3;
```

---

## 6. 데이터 삭제 (DELETE)

`student_id = 1`인 학생 데이터를 삭제해보자.

```sql
DELETE FROM student_info
WHERE student_id = 1;
```

삭제 확인:

```sql
SELECT * FROM student_info;
```

예상 결과

```
student_id | name | grade | class_no | memo
--------------------------------------------------
2          | 영희 | 2     | 1        | 독서 동아리
3          | 민수 | 1     | 2        | 축구부 주장
```
