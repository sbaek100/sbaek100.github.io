# 데이터 필터링 (3-1)

## 자료형 요약표

|자료형|저장 내용|예시 데이터|언제 사용하면 좋은가|
|---|---|---|---|
|`INT`|정수|1, 100, -5|학생 번호, 점수, 재고 수량처럼 소수점이 없는 값을 저장할 때 사용한다.|
|`VARCHAR(n)`|가변 문자열|'김철수', 'abc@gmail.com'|이름, 이메일, 도시처럼 길이가 일정하지 않은 짧은 문자를 저장할 때 적합하다.|
|`TEXT`|긴 문자열|'오늘 수업은...(긴 글)'|게시글 본문, 긴 설명, 후기처럼 길이가 긴 문장을 저장할 때 사용한다.|
|`DECIMAL(p,s)`|정확한 소수|29900.00, 0.30|가격, 할인율, 정산 금액처럼 소수점 계산이 정확해야 하는 값을 저장할 때 사용한다.|
|`DATE`|날짜|2025-03-16|생년월일, 시험일, 만료일처럼 날짜만 필요할 때 사용한다.|
|`DATETIME`|날짜+시간|2025-03-16 09:30:00|가입 시각, 주문 시각, 로그 기록처럼 날짜와 시간이 모두 필요할 때 사용한다.|

소수점 데이터는 아무 자료형에나 넣는 것이 아니라 목적에 맞게 골라야 한다.

- `DECIMAL(p,s)`는 소수점을 정확하게 저장하므로 돈, 세금, 할인율처럼 계산 오차가 나면 안 되는 값에 적합하다.
- 반대로 `FLOAT`나 `DOUBLE`은 아주 큰 수나 대략적인 실수 계산에는 편하지만, 저장 과정에서 미세한 오차가 생길 수 있다. 예를 들어 `0.1 + 0.2`를 계산했을 때 우리가 기대하는 값은 `0.3`이지만, 어떤 환경에서는 `0.30000000000000004`처럼 아주 조금 다르게 보일 수 있다.
- 그래서 **가격처럼 정확도가 중요하면 `DECIMAL`**, **대략적인 실수 계산이면 `FLOAT`/`DOUBLE`**을 고려한다.

다음은 **실습(테이블 생성 → 데이터 삽입 → 조회)** 으로 넘어갈까요?

---

## 1. 준비

```sql
DROP DATABASE IF EXISTS filter_db;
CREATE DATABASE filter_db;
USE filter_db;

CREATE TABLE students (
  id INT,
  name VARCHAR(20),
  grade INT,
  city VARCHAR(20),
  score INT
);
```

```sql
INSERT INTO students VALUES (1, '철수', 1, '서울', 85);
INSERT INTO students VALUES (2, '영희', 2, '부산', 92);
INSERT INTO students VALUES (3, '민수', 1, '서울', 74);
INSERT INTO students VALUES (4, '지은', 3, '대전', 88);
INSERT INTO students VALUES (5, '준호', 2, '부산', 67);
```

---

## 2. WHERE 기본 실습

```sql
SELECT * FROM students WHERE score >= 80;
SELECT * FROM students WHERE city = '서울';
SELECT * FROM students WHERE grade = 2;
```

---

## 3. AND / OR 실습

```sql
SELECT * FROM students
WHERE city = '부산' AND score >= 70;

SELECT * FROM students
WHERE city = '서울' OR city = '대전';
```

## 4. 추가 연습 문제

아래 문제는 위에서 입력한 `students` 데이터를 기준으로 풀어보면 된다.

1. 점수가 90점 이상인 학생만 조회해 보자.
2. 도시가 `부산`이면서 학년이 2학년인 학생만 조회해 보자.
3. 도시가 `서울`이거나 점수가 70점 미만인 학생을 조회해 보자.
4. 1학년이면서 점수가 80점 이상인 학생을 조회해 보자.
5. 도시가 `대전`이거나 3학년인 학생을 조회해 보자.

직접 작성해 보고 싶다면 먼저 스스로 쿼리를 만들어 본 뒤, 아래 예시와 비교해 보자.

```sql
SELECT * FROM students
WHERE score >= 90;

SELECT * FROM students
WHERE city = '부산' AND grade = 2;

SELECT * FROM students
WHERE city = '서울' OR score < 70;

SELECT * FROM students
WHERE grade = 1 AND score >= 80;

SELECT * FROM students
WHERE city = '대전' OR grade = 3;
```
