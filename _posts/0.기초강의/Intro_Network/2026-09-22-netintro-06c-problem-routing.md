> 대회 문제지와 비슷한 형식의 과제입니다. 요구사항만 보고 직접 구성한 뒤 ‘완성 기준’으로 스스로 채점하세요. 명령어는 6강 따라하기 실습을 참고하되, 답은 제공하지 않습니다.

## 1. 과제 개요

당신은 세 지점(본사·지사A·지사B)을 잇는 네트워크의 담당자입니다. 라우터 세 대를 연결하고, 각 지점의 내부망이 서로 통신할 수 있도록 동적 라우팅을 구성해야 합니다.

## 2. 지급재료

- 패킷 트레이서 9.0
- 제출 파일명: `학번_이름_실습06.pkt`

## 3. 네트워크 구성

```
 [PC-본사]—[R-HQ]======[R-A]======[R-B]—[PC-지사B]
             |            (라우터 3대 직렬 연결)
```

| 구간 | 네트워크 | 비고 |
|---|---|---|
| 본사 LAN | 172.16.1.0/24 | R-HQ g0/0 = 사용 가능한 마지막 주소 |
| 지사B LAN | 172.16.2.0/24 | R-B g0/0 = 사용 가능한 마지막 주소 |
| R-HQ ↔ R-A | 10.0.12.0/30 | R-HQ .1, R-A .2 |
| R-A ↔ R-B | 10.0.23.0/30 | R-A .1, R-B .2 |

_표 6-4. 네트워크 구성_

## 4. 요구사항

### 4-1. 기본 설정

① 라우터 3대의 이름을 `R-HQ`, `R-A`, `R-B`로 변경하시오.
② 표 6-4에 따라 각 인터페이스에 IP를 설정하시오. LAN 쪽 라우터 인터페이스는 **“사용 가능한 마지막 주소”** 를 사용한다(2강 계산법 활용).
③ 본사·지사B의 PC에 IP를 배정하고, 게이트웨이를 각 라우터 LAN 주소로 지정하시오.

### 4-2. 동적 라우팅

세 라우터에 **OSPF(프로세스 1, area 0)** 를 구성하여, 모든 네트워크가 서로 통신되도록 하시오.

### 4-3. 동작 확인

① `R-HQ`에서 `show ip ospf neighbor`로 이웃 관계가 맺어져야 한다.
② `show ip route`에 다른 지점의 네트워크가 `O`(OSPF)로 학습되어야 한다.
③ 본사 PC에서 지사B PC로 ping이 성공해야 한다.

## 5. 선수 유의사항

1. 라우터 이름의 대소문자·하이픈을 정확히 구별하여 작성하시오.
2. OSPF의 network 명령에는 마스크가 아니라 와일드카드 마스크를 사용한다.
3. 모든 라우터가 같은 area 0에 속해야 이웃 관계가 맺어진다.
4. 반드시 설정을 저장한 뒤 제출하시오.

## 6. 완성 기준 (스스로 채점)

| 확인 항목 | 완성 여부 |
|---|---|
| 세 라우터 이름이 조건과 일치하는가 | ☐ |
| LAN 인터페이스가 “사용 가능한 마지막 주소”로 설정되었는가 | ☐ |
| 세 라우터에 OSPF(area 0)가 구성되어 이웃 관계가 맺어졌는가 | ☐ |
| 라우팅 테이블에 원격 네트워크가 `O`로 학습되었는가 | ☐ |
| 본사 PC ↔ 지사B PC ping이 성공하는가 | ☐ |

> **생각해 보기 — 가운데 라우터(R-A)에는 왜 PC가 없어도 될까?**
> R-A에는 연결된 PC(LAN)가 없지만, R-A가 없으면 본사와 지사B는 통신할 수 없습니다. R-A가 하는 일은 무엇일까요? 그리고 R-A의 OSPF 설정에서 LAN 네트워크는 없고 두 연결 구간(10.0.12.0, 10.0.23.0)만 선언하게 되는데, 그 이유를 생각해 보세요. (라우터는 자기 LAN이 없어도 ‘경유지’ 역할을 합니다.)
{: .prompt-info }

---

이 과제를 완성했다면, 대회의 라우팅 구간(RIPv2·OSPF)을 다룰 기초를 갖춘 것입니다. 다음 7강에서는 멀리 떨어진 지점을 잇는 WAN 기술(프레임릴레이)과, 라우터가 고장 나도 통신이 끊기지 않게 하는 게이트웨이 이중화(HSRP)를 배웁니다.
