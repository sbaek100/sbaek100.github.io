> **실습 문제 사용법**
> 대회 문제지와 비슷한 형식의 과제입니다. 이번 과제는 실제 대회 도면의 본사 스위치 구성(VLAN·VTP·트렁크)을 단순화한 것입니다. 요구사항만 보고 직접 구성한 뒤 ‘완성 기준’으로 스스로 채점하세요.
{: .prompt-info }

---

## 1. 과제 개요

당신은 본사의 네트워크 담당자입니다. 사무실은 1층·2층으로 나뉘고, IP 전화를 위한 음성 네트워크도 별도로 둡니다. 세 스위치를 VTP로 묶어 VLAN 정보를 한 곳에서 관리하고, 스위치 간은 트렁크로 연결해야 합니다.

## 2. 지급재료

- 패킷 트레이서 9.0
- 제출 파일명: `학번_이름_실습05.pkt`

## 3. 요구사항

### 3-1. VTP 구성

- VTP 도메인: **`secu.com`**
- **`SW-2`** 를 VTP **서버**, **`SW-1`·`SW-3`** 을 VTP **클라이언트**로 동작시키시오.

### 3-2. VLAN 구성

서버에서 아래 VLAN을 생성하시오(클라이언트로 자동 전파되어야 함).

| VLAN ID | 이름 | 용도 |
|---|---|---|
| 10 | HO-1F | 1층 사무실 |
| 20 | HO-2F | 2층 사무실 |
| 150 | VOICE | 음성 |

_표 5-4. 생성할 VLAN_

### 3-3. 포트 배정과 트렁크

| 스위치 | 액세스 포트 배정 | 트렁크 포트 |
|---|---|---|
| SW-1 | 연결된 PC 포트 → VLAN 10 | SW 간 연결 포트 |
| SW-3 | 연결된 PC 포트 → VLAN 20 | SW 간 연결 포트 |

_표 5-5. 포트 구성_

① 각 스위치에 PC를 1대씩 연결하고, 표대로 액세스 VLAN을 배정하시오.
② 스위치 간 연결 포트는 모두 트렁크로 설정하시오.
③ 모든 액세스 포트가 up 되는 즉시 포워딩 상태가 되도록 설정하시오(PortFast).

### 3-4. 동작 확인

① 클라이언트 스위치(SW-1·SW-3)에서 `show vlan brief`로 VLAN 10·20·150이 전파되어 보여야 한다.
② VLAN 10의 PC와 VLAN 20의 PC는 서로 통신되지 않아야 한다(격리 확인).

## 4. 선수 유의사항

1. VLAN 이름의 대소문자를 정확히 구별하여 작성하시오(예: `HO-1F`, `VOICE`).
2. VLAN은 반드시 VTP 서버에서만 생성하고, 클라이언트로 전파되는지 확인하시오.
3. 반드시 설정을 저장한 뒤 제출하시오.

## 5. 완성 기준 (스스로 채점)

| 확인 항목 | 완성 여부 |
|---|---|
| VTP 도메인이 `secu.com`이고 SW-2=서버, SW-1·SW-3=클라이언트인가 | ☐ |
| 서버에서 만든 VLAN 10·20·150이 클라이언트로 전파되었는가 | ☐ |
| 스위치 간 포트가 모두 트렁크인가 | ☐ |
| PC 포트에 올바른 VLAN이 배정되고 PortFast가 적용되었는가 | ☐ |
| 서로 다른 VLAN의 PC가 통신되지 않는가(격리) | ☐ |

> **생각해 보기 — 음성 VLAN(150)은 왜 따로 둘까?**
> 이 과제에서 데이터(VLAN 10·20)와 별개로 음성 전용 VLAN 150을 만들었습니다. IP 전화 트래픽을 굳이 별도 VLAN으로 분리하는 이유는 무엇일까요? 통화가 끊기지 않으려면 음성 데이터가 어떤 대우를 받아야 할지, 그리고 데이터와 섞여 있을 때 생길 문제를 생각해 보세요. (음성 VLAN을 실제 전화 서비스와 연결하는 것은 9강에서 합니다.)
{: .prompt-info }
