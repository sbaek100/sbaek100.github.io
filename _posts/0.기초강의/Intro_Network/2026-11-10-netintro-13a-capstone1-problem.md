## 1. 과제 개요

당신은 회사의 네트워크 보안 담당자입니다. 본사 내부망(VLAN·전화·서버)을 구축하고, 방화벽(ASA)으로 경계를 지키며, 외부 공인망(라우팅·이중화·프레임릴레이·서버)을 구성해야 합니다.

- 지급재료: 패킷 트레이서 9.0
- 제출 파일명: `학번_이름_종합1.pkt`
- 모든 장비의 hostname은 도면(구성표)과 동일하게 지정한다.
- 과제에 제시되지 않은 설정에 필요한 암호는 `secu2024`로 한다.

## 2. 본사(A) 구축

### 2-1. 네트워크 구성 (5강·6강·2강)

| 네트워크 | 호스트 | IP 주소 |
|---|---|---|
| 172.16.8.0/23 | A-PC1 / A-PC2 | 172.16.8.1 / 172.16.8.2 |
| | A-Call-R | 사용 가능한 마지막 주소 |
| 172.16.10.0/23 | A-PC3 | 172.16.10.1 |
| | A-Call-R | 사용 가능한 마지막 주소 |
| 172.16.1.0/24 | A-Phone1 / A-Phone2 | DHCP |
| | A-Call-R | 172.16.1.1 |
| 172.16.0.0/24 | A-Call-R / A-ASA | 172.16.0.1 / 172.16.0.2 |
| 192.168.10.0/24 | A-Main / A-DNS | 192.168.10.1 / 192.168.10.2 |
| | A-ASA(DMZ) | 사용 가능한 마지막 주소 |
| 100.0.0.0/24 | A-ASA(OUTSIDE) | 100.0.0.10 |

_표 13-1. 본사 네트워크 구성_

- 모든 호스트의 DNS 주소는 A-DNS(192.168.10.2)를 사용한다.

### 2-2. VLAN·VTP (5강)

- A-S2 = VTP **서버**, A-S1·A-S3 = VTP **클라이언트**, 도메인 `secu.com`
- VLAN: 10(HO-1F), 20(HO-2F), 150(VOICE)

| 스위치 | 액세스(VLAN) | 트렁크 포트 |
|---|---|---|
| A-S1 | g0/1 제외 모든 포트 → 10, 150 | g0/1 |
| A-S2 | — | g0/1, g0/2, fa0/24 |
| A-S3 | g0/1 제외 모든 포트 → 20, 150 | g0/1 |

_표 13-2. VLAN 포트 구성_

### 2-3. Inter-VLAN·라우팅 (5강·6강·11강)

- A-Call-R와 A-ASA는 **사설 네트워크에 대해 RIPv2** 라우팅을 실시한다.
- A-ASA는 OUTSIDE 방향으로 **디폴트 라우팅**을 실시한다.
- VLAN 간 라우팅은 A-Call-R에서 서브인터페이스로 구성한다.

### 2-4. 방화벽 ASA (11강)

| 인터페이스 | Zone | security-level | IP |
|---|---|---|---|
| Gig1/1 | INSIDE | 100 | 172.16.0.2/24 |
| Gig1/2 | DMZ | 50 | 192.168.10.254/24 |
| Gig1/3 | OUTSIDE | 0 | 100.0.0.10/24 |

_표 13-3. ASA 구성_

- 각 존에서 필요한 서비스가 이루어지도록 설정한다.
- 외부에서 `100.0.0.8`로 웹 접속 시 A-ASA가 **A-Main 서버가 응답** 하도록 정적 NAT(포트 포워딩)를 설정한다.

### 2-5. 서비스 (3강·8강)

- **DNS**: A-DNS에서 `intra.secu.com`에 대해 A-Main의 IP가 응답하도록 한다.
- **전화(VoIP, 9강)**: A-Call-R가 A-Phone1·A-Phone2에 전화번호를 할당하도록 하고, DHCP 이름은 `VOICE`를 사용하며, 내·외부 간 전화 통화가 가능하도록 한다.

## 3. 외부 공인망 구축

### 3-1. 네트워크 구성 (2강)

| 네트워크 | 호스트 | IP |
|---|---|---|
| 100.0.0.0/24 | A-ASA / A-GRE / A-R1 / A-R2 | .10 / .9 / .11 / .12 |
| 100.0.1.0/24 | A-R1 / A-R2 / B-R1 | .1 / .2 / .3 |
| 100.0.2.0/24 | B-R1 / B-R2 / B-R3 | .1 / .3 / .2 |
| 100.0.3.0/24 | B-SRV / B-R2 | .1 / 마지막 주소 |
| 100.0.4.0/26 | B-R3 / Home-RT | .1 / DHCP |
| 100.0.4.64/26 | B-R2 / A2-RT | .65 / .66 |

_표 13-4. 외부망 구성_

### 3-2. OSPF 라우팅 (6강)

- 모든 공인 네트워크와 연결된 라우터는 **공인 네트워크에 한하여 OSPF 10 (area 0)** 라우팅을 실시한다.
- 라우팅 설정 시 네트워크 주소를 선언한다.

> ⚠ **감점 조건**: 사설 네트워크에 대해 라우팅 시 수동 채점 항목을 0점 처리한다.

### 3-3. 게이트웨이 이중화 (7강)

- 본사를 위해 A-R1·A-R2에서 게이트웨이 이중화를 실시한다.
- A-R1이 기본 동작(액티브), A-R2는 대기, 게이트웨이 주소는 `100.0.0.1`.
- A-R1 복구 시 다시 A-R1을 통해 통신되도록 한다(선점).

### 3-4. 프레임릴레이 (7강)

- Cloud0를 프레임릴레이 스위치로 사용하고, B-R1·B-R2·B-R3를 프레임릴레이 모드로 동작시킨다(서브인터페이스 생성 불가).

| DLCI | 라우터 | 릴레이 방향 |
|---|---|---|
| 103 | B-R1 | B-R1 → B-R3 |
| 203 | B-R2 | B-R2 → B-R3 |
| 301 | B-R3 | B-R3 → B-R1 |
| 302 | B-R3 | B-R3 → B-R2 |

_표 13-5. 프레임릴레이 DLCI_

### 3-5. B-SRV 서비스 (3강·8강)

- **DNS**: `www.secu.com` → A-ASA의 포트 포워딩 주소, `www/smtp/pop3/mail.skills.com` → B-SRV의 주소
- **DHCP**: 내부 pool 100.0.3.100~150 / 외부 pool(EX-DHCP) 100.0.4.10~20, DNS 100.0.3.1
- **메일**: 메일 서비스를 구성한다(홈 사용자가 이용).

### 3-6. B-R3 보안 (11강)

- Home-RT의 호스트들이 외부와 통신에 필요한 서비스만(DHCP, 메일 송·수신) 허용한다.
- 그 외 모든 트래픽은 통제하며, **Extended ACL**을 사용하고 Home-RT와 연결된 인터페이스의 **들어오는 방향(in)** 에서 동작하도록 한다. 보안 설정 이름은 `IN->PERMIT`을 사용한다.

### 3-7. 스위치 즉시 포워딩 (5강)

- A-S4, B-SW의 모든 인터페이스가 up 될 때 즉시 포워딩 상태가 되도록 설정한다(PortFast).
