## 1. 과제 개요

당신은 한 사무실의 서버 담당자입니다. 직원 PC들이 IP를 자동으로 배정받고, 사내 웹 사이트에 이름으로 접속할 수 있도록 서버를 구성해야 합니다. 서버 한 대가 DHCP·DNS·HTTP 세 가지 서비스를 함께 제공합니다.

## 2. 지급재료

- 패킷 트레이서 9.0
- 제출 파일명: `학번_이름_실습03.pkt`

## 3. 네트워크 구성

| 장치 | 이름 | IP 주소 |
|---|---|---|
| 서버 | `SRV-CENTER` | 172.16.30.10 / 255.255.255.0 (고정) |
| PC 2대 | `PC-1`, `PC-2` | DHCP로 자동 배정 |
| 스위치 | `SW-OFFICE` | — |

_표 3-7. 장치 구성_

## 4. 요구사항

### 4-1. 기본 구성

① 스위치 1대, 서버 1대, PC 2대를 배치하고 표 3-7의 이름으로 변경하시오.
② 서버 `SRV-CENTER`에 고정 IP `172.16.30.10`을 설정하시오.

### 4-2. DHCP 서비스

서버에 DHCP를 구성하여 PC들이 아래 조건으로 주소를 자동 배정받도록 하시오.

- 배정 시작 주소: `172.16.30.101`
- 기본 게이트웨이: `172.16.30.1`
- DNS 서버: `172.16.30.10`

### 4-3. DNS 서비스

서버에 DNS를 구성하여, 이름 **`intra.class.com`** 에 대해 **서버 자신의 IP(172.16.30.10)** 가 응답하도록 A 레코드를 등록하시오.

### 4-4. 통신·서비스 확인

① 두 PC가 DHCP로 `172.16.30.101`, `172.16.30.102`를 자동 배정받아야 한다.
② PC에서 웹 브라우저로 `http://intra.class.com`에 접속하면 서버의 웹 페이지가 열려야 한다.
③ PC의 명령 프롬프트에서 `nslookup intra.class.com`을 실행하면 `172.16.30.10`이 응답해야 한다.

## 5. 선수 유의사항

1. 서버는 반드시 고정 IP여야 하며, DHCP로 주소를 받으면 안 된다.
2. 이름(hostname·도메인)의 대소문자와 점(.)을 정확히 구별하여 작성하시오.
3. 주어지지 않은 설정 중 반드시 필요한 설정은 응시자가 임의로 설정할 수 있다.
4. 작업을 마친 뒤 반드시 파일을 저장하여 제출하시오.

## 6. 완성 기준 (스스로 채점)

| 확인 항목 | 완성 여부 |
|---|---|
| 장치 이름이 표 3-7과 일치하는가 | ☐ |
| 서버가 고정 IP `172.16.30.10`을 사용하는가 | ☐ |
| 두 PC가 DHCP로 `172.16.30.101`, `.102`를 받는가 | ☐ |
| A 레코드 `intra.class.com → 172.16.30.10`이 등록되었는가 | ☐ |
| PC에서 `http://intra.class.com` 접속이 되는가 | ☐ |
| `nslookup intra.class.com`이 `172.16.30.10`을 응답하는가 | ☐ |

> **생각해 보기 — 게이트웨이 172.16.30.1은 지금 존재하지 않는데 왜 넣을까?**
> DHCP 설정에 기본 게이트웨이 `172.16.30.1`을 넣으라고 했지만, 이 구성에는 아직 라우터가 없어 그 주소를 쓰는 장치가 없습니다. 그런데도 왜 미리 넣어 둘까요? 이 사무실이 나중에 인터넷이나 다른 부서와 연결될 때 무엇이 필요할지, 그리고 게이트웨이가 하는 일이 무엇인지 떠올려 보세요. (라우터로 서로 다른 네트워크를 잇는 것은 6강에서 배웁니다.)
{: .prompt-info }
