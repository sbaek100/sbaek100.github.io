> **실습 문제 사용법**
> 대회 문제지와 비슷한 형식의 과제입니다. 이번 과제는 대회 도면의 본사 전화 서비스를 단순화한 것입니다. 요구사항만 보고 직접 구성한 뒤 ‘완성 기준’으로 스스로 채점하세요.
{: .prompt-info }

---

## 1. 과제 개요

당신은 본사의 전화망 담당자입니다. 라우터를 통화 관리자(CME)로 구성하여, 두 대의 IP 전화기가 전화번호를 자동으로 배정받고 서로 통화할 수 있도록 해야 합니다.

## 2. 지급재료

- 패킷 트레이서 9.0
- 제출 파일명: `학번_이름_실습09.pkt`

## 3. 네트워크 구성

| 항목 | 값 |
|---|---|
| 음성 네트워크 | 172.16.1.0/24 |
| 라우터(CME) 음성 IP | 172.16.1.1 |
| 음성 VLAN | 150 (이름 VOICE) |
| 전화번호 | Phone1 = `2001`, Phone2 = `2002` |

_표 9-2. 구성_

## 4. 요구사항

### 4-1. 스위치·VLAN

① 스위치에 음성 VLAN **150(VOICE)** 을 만들고, 전화기가 연결된 포트를 음성 VLAN으로 설정하시오.
② 라우터로 가는 포트를 트렁크로 설정하시오.

### 4-2. 라우터(CME)

① 라우터에 음성 VLAN용 서브인터페이스(`172.16.1.1`)를 구성하시오.
② 전화기가 DHCP로 주소와 설정 서버 정보(**option 150**)를 받도록 DHCP를 구성하시오.
③ 통화 서비스(telephony-service)를 구성하고, 두 전화기에 번호 **`2001`, `2002`** 를 배정하시오.

### 4-3. 동작 확인

① 두 전화기 화면에 각각 `2001`, `2002`가 표시되어야 한다.
② Phone1(2001)에서 Phone2(2002)로 전화를 걸면 통화가 연결되어야 한다.

## 5. 선수 유의사항

1. VLAN 이름(`VOICE`)의 대소문자를 정확히 구별하여 작성하시오.
2. DHCP에는 반드시 option 150을 포함해야 전화기가 번호를 받는다.
3. IP 전화기에 전원이 공급되는지 확인하시오.
4. 반드시 설정을 저장한 뒤 제출하시오.

## 6. 완성 기준 (스스로 채점)

| 확인 항목 | 완성 여부 |
|---|---|
| 음성 VLAN 150(VOICE)이 만들어지고 포트에 배정되었는가 | ☐ |
| 라우터 음성 서브인터페이스(172.16.1.1)가 구성되었는가 | ☐ |
| DHCP에 option 150이 포함되어 전화기가 번호를 받는가 | ☐ |
| 두 전화기에 2001·2002가 표시되는가 | ☐ |
| Phone1 ↔ Phone2 통화가 연결되는가 | ☐ |

> **생각해 보기 — 전화기 뒤에 PC를 달면?**
> 실제 사무실에서는 IP 전화기 뒤에 PC를 연결해, 케이블 하나로 전화와 PC를 함께 씁니다. 이때 한 포트로 음성(VLAN 150)과 데이터(예: VLAN 10)가 함께 흐릅니다. 스위치는 이 둘을 어떻게 구별할까요? 5강에서 배운 ‘태그(802.1Q)’와 음성 VLAN이 어떻게 협력하는지 생각해 보세요.
