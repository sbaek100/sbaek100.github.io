> **실습 문제 사용법**
> 대회 문제지와 비슷한 형식의 과제입니다. 이번 과제는 대회 본사 방화벽(ASA) 구성을 단순화한 것입니다. 요구사항만 보고 직접 구성한 뒤 ‘완성 기준’으로 스스로 채점하세요.
{: .prompt-info }

---

## 1. 과제 개요

당신은 본사의 방화벽 담당자입니다. 방화벽(ASA)에 내부·DMZ·외부 세 구역을 구성하고, 내부는 자유롭게 외부로 나가되 외부에서는 함부로 들어올 수 없도록 해야 합니다. 다만 외부 사용자가 DMZ의 웹 서버에는 접속할 수 있어야 합니다.

## 2. 지급재료

- 패킷 트레이서 9.0
- 제출 파일명: `학번_이름_실습11.pkt`

## 3. 네트워크 구성

| 인터페이스 | 존 이름 | 보안 레벨 | IP |
|---|---|---|---|
| G1/1 | INSIDE | 100 | 172.16.0.2 / 24 |
| G1/2 | DMZ | 50 | 192.168.10.254 / 24 |
| G1/3 | OUTSIDE | 0 | 100.0.0.10 / 24 |

_표 11-3. ASA 인터페이스 구성_

- DMZ 웹 서버: `192.168.10.1`
- 외부 게이트웨이: `100.0.0.1`

## 4. 요구사항

### 4-1. 존 구성

① ASA의 세 인터페이스에 표 11-3대로 존 이름·보안 레벨·IP를 설정하시오.
② OUTSIDE 방향으로 디폴트 라우팅을 설정하시오.

### 4-2. 기본 방화벽 동작

① 내부(INSIDE)에서 외부(OUTSIDE)로 나가는 통신은 허용되어야 한다.
② 외부에서 내부로 먼저 들어오는 통신은 기본 차단되어야 한다.

### 4-3. 웹 서버 공개

외부에서 ASA 공인 주소(`100.0.0.10`)의 **웹(80)** 으로 접속하면, DMZ의 웹 서버(`192.168.10.1`)가 응답하도록 정적 NAT와 ACL을 설정하시오.

### 4-4. 동작 확인

① 내부 PC에서 외부로 ping/웹이 나가야 한다.
② 외부 PC에서 `http://100.0.0.10` 접속 시 DMZ 웹 서버 페이지가 열려야 한다.

## 5. 선수 유의사항

1. 존 이름(INSIDE·DMZ·OUTSIDE)과 보안 레벨을 정확히 설정하시오.
2. NAT·ACL 문법은 패킷 트레이서에 내장된 ASA 버전에 맞춰 적용하시오.
3. 반드시 설정을 저장한 뒤 제출하시오.

## 6. 완성 기준 (스스로 채점)

| 확인 항목 | 완성 여부 |
|---|---|
| 세 인터페이스에 존·보안레벨·IP가 올바르게 설정되었는가 | ☐ |
| OUTSIDE 디폴트 라우팅이 설정되었는가 | ☐ |
| 내부→외부는 허용, 외부→내부는 기본 차단되는가 | ☐ |
| 정적 NAT로 웹(80)만 서버로 넘어가는가 | ☐ |
| 외부에서 `http://100.0.0.10` 접속이 되는가 | ☐ |

> **생각해 보기 — 보안 레벨 숫자의 의미**
> ASA에서 INSIDE=100, DMZ=50, OUTSIDE=0으로 숫자를 매겼습니다. 이 숫자의 크기 자체가 규칙을 만듭니다(높은 곳→낮은 곳은 허용). 그렇다면 DMZ(50)에서 INSIDE(100)로 가는 통신은 기본적으로 될까요, 안 될까요? 만약 DMZ의 웹 서버가 뚫렸을 때, 이 규칙이 내부망을 어떻게 지켜 주는지 생각해 보세요. (DMZ를 중간 레벨에 둔 이유가 여기에 있습니다.)
{: .prompt-info }
