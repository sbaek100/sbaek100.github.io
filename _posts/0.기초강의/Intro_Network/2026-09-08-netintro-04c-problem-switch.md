## 1. 과제 개요

당신은 한 부서의 네트워크 관리자입니다. 부서 PC들을 스위치에 연결하되, 각 포트에는 지정된 PC 한 대만 연결할 수 있도록 포트 보안을 적용해야 합니다. 허가되지 않은 장비가 연결되면 해당 포트가 자동으로 차단되어야 합니다.

## 2. 지급재료

- 패킷 트레이서 9.0
- 제출 파일명: `학번_이름_실습04.pkt`

## 3. 요구사항

### 3-1. 기본 설정

① 스위치 1대(모델 2960)를 배치하고 이름(hostname)을 **`SW-SEC`** 로 변경하시오.
② 업무용 PC 2대(`PC-1`, `PC-2`)를 각각 스위치의 `Fa0/1`, `Fa0/2`에 연결하고, IP를 `192.168.50.11`, `192.168.50.12`(마스크 255.255.255.0)로 설정하시오.
③ 변경한 설정이 재부팅 후에도 유지되도록 저장하시오.

### 3-2. 포트 보안

`Fa0/1`, `Fa0/2` 두 포트에 아래 조건으로 포트 보안을 적용하시오.

- 각 포트에는 MAC 주소를 **1개만** 허용한다.
- 위반이 발생하면 해당 포트를 **차단(shutdown)** 한다.
- 현재 연결된 PC의 MAC을 **자동으로 학습(sticky)** 하도록 한다.

### 3-3. 동작 확인

① 정상 상태에서 `PC-1` ↔ `PC-2` 통신(ping)이 성공해야 한다.
② `PC-1`을 떼어 내고 다른 PC(임의의 MAC)를 `Fa0/1`에 연결하면, 해당 포트가 차단되어야 한다.
③ 차단된 포트를 확인하는 명령과, 다시 정상으로 복구하는 방법을 설명할 수 있어야 한다.

## 4. 선수 유의사항

1. 이름(hostname)의 대소문자와 하이픈을 정확히 구별하여 작성하시오.
2. 포트 보안은 각 포트를 액세스 모드로 설정한 뒤 적용해야 한다.
3. 반드시 설정을 저장한 뒤 제출하시오.

## 5. 완성 기준 (스스로 채점)

| 확인 항목 | 완성 여부 |
|---|---|
| 스위치 이름이 `SW-SEC`로 표시되고 설정이 저장되었는가 | ☐ |
| 두 PC의 IP가 조건과 일치하고 정상 통신되는가 | ☐ |
| 두 포트에 포트 보안(최대 1, shutdown, sticky)이 적용되었는가 | ☐ |
| 비인가 장비 연결 시 포트가 `Secure-shutdown`으로 차단되는가 | ☐ |
| 차단 확인 명령(`show port-security interface ...`)과 복구 방법을 설명할 수 있는가 | ☐ |

> **생각해 보기 — 위반 정책 세 가지**
> 포트 보안의 위반 정책에는 `shutdown`(포트 차단) 외에도 `protect`(위반 프레임만 조용히 버림)와 `restrict`(버리고 로그·카운터 기록)가 있습니다. 세 정책은 각각 어떤 상황에 어울릴까요? 관리자에게 즉시 알려야 하는 보안 사고라면, 그리고 잠깐의 오연결까지 일일이 포트를 잠그면 곤란한 환경이라면 각각 어떤 정책이 나을지 생각해 보세요.
