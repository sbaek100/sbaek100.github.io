## 1. 과제 개요

당신은 작은 사무실의 네트워크 담당자입니다. 사무실에는 업무용 PC 세 대가 있으며, 이 PC들이 하나의 스위치에 연결되어 서로 자유롭게 통신할 수 있도록 네트워크를 구성해야 합니다. 아직 인터넷 연결이나 다른 사무실과의 통신은 고려하지 않으며, **사무실 내부의 세 PC가 서로 ping이 되는 것**까지가 이번 과제의 범위입니다.

## 2. 지급재료

- 패킷 트레이서 9.0
- 제출 파일명: `학번_이름_실습01.pkt`

## 3. 네트워크 구성도

```
      [PC-A]        [PC-B]        [PC-C]
         \            |            /
          \           |           /
           +----- [ SW-Office ] -----+
                  (2960 스위치)
```

_그림 1-17. 사무실 네트워크 구성도_

## 4. 요구사항

### 4-1. 기본 설정

① 스위치 한 대(모델 2960)를 배치하고, 장치 이름(hostname)을 도면과 같이 **`SW-Office`** 로 변경하시오.
② 업무용 PC 세 대를 배치하고, 각각 `PC-A`, `PC-B`, `PC-C`로 이름을 표시하시오.

### 4-2. 케이블 연결

① PC 세 대를 스위치 `SW-Office`에 연결하시오.
② PC와 스위치를 잇는 케이블은 상황에 맞는 올바른 종류를 선택하시오.

### 4-3. IP 주소 설정

아래 표에 따라 각 PC에 IP 주소와 서브넷 마스크를 설정하시오. 세 PC는 모두 같은 네트워크에 속해야 한다.

| 호스트 | IP 주소 | 서브넷 마스크 |
|---|---|---|
| PC-A | 192.168.10.11 | 255.255.255.0 |
| PC-B | 192.168.10.12 | 255.255.255.0 |
| PC-C | 192.168.10.13 | 255.255.255.0 |

_표 1-10. IP 주소 배정표_

### 4-4. 통신 확인

① `PC-A`에서 `PC-B`와 `PC-C`로 각각 ping이 성공해야 한다.
② `PC-B`에서 `PC-C`로 ping이 성공해야 한다.

## 5. 선수 유의사항

1. 이름(hostname·표시 이름)의 대소문자와 하이픈(-)을 정확히 구별하여 작성하시오.
2. 주어지지 않은 설정 중 반드시 필요한 설정은 응시자가 임의로 설정할 수 있다.
3. 모든 PC는 표에 제시된 IP 주소를 정확히 사용해야 하며, 오타가 없어야 한다.
4. 작업을 마친 뒤 반드시 파일을 저장하여 제출하시오.

## 6. 완성 기준 (스스로 채점)

아래 항목을 모두 만족하면 과제를 완성한 것입니다.

| 확인 항목 | 완성 여부 |
|---|---|
| 스위치 이름이 `SW-Office`로 표시되는가 | ☐ |
| PC 세 대가 스위치에 올바른 케이블로 연결되어 링크가 초록색인가 | ☐ |
| 세 PC의 IP·서브넷 마스크가 표와 정확히 일치하는가 | ☐ |
| PC-A → PC-B, PC-A → PC-C ping이 모두 성공하는가 | ☐ |
| PC-B → PC-C ping이 성공하는가 | ☐ |

> **한 걸음 더 (선택 과제)** 여유가 있다면, PC-C의 IP만 `192.168.20.13`(마스크는 그대로 255.255.255.0)으로 바꾼 뒤 PC-A에서 PC-C로 ping을 해 보시오. 통신이 실패할 것입니다. **왜 실패하는지** 한 문장으로 설명해 보세요. (힌트: 세 PC가 ‘같은 네트워크’에 속한다는 조건이 왜 필요했을까요? 이 질문의 답은 2강에서 확인합니다.)
{: .prompt-tip }

---

이 과제를 스스로 완성했다면, 네트워크의 가장 기본인 ‘같은 네트워크 안에서의 통신’을 이해하고 손으로 구현할 수 있게 된 것입니다. 다음 2강에서는 방금 사용한 IP 주소와 서브넷 마스크가 정확히 무슨 의미인지, 그리고 “사용 가능한 마지막 주소” 같은 조건을 어떻게 계산하는지를 배웁니다.
