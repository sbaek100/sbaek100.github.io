> **종합실습 안내**
> 13강에서 본사·외부망을 세웠습니다. 이 마지막 과제에서는 **지사(A2)와 홈(Home)** 을 구축하고, 본사와 지사를 **GRE/IPSec 터널** 로 이어 전체를 하나로 완성합니다. 이 과제를 마치면 실제 기능경기대회 제2과제 전체를 완주한 것과 같습니다.
{: .prompt-info }

---

## 1. 과제 개요

- 지급재료: 패킷 트레이서 9.0
- 제출 파일명: `학번_이름_종합2.pkt`
- 이 과제는 13강의 본사·외부망 구성 위에 이어서 구축한다.
- 모든 hostname은 도면과 동일하게, 미제시 암호는 `secu2024`로 지정한다.

---

## 2. 지사(A2) 구축

### 2-1. IOS 복구 (10강)

- A2-RT의 운영체제(IOS)가 삭제되어 있다. **A2-SRV(TFTP)로부터 IOS를 복구** 하여 설정하시오.

### 2-2. 네트워크 구성 (2강)

| 네트워크 | 호스트 | IP |
|---|---|---|
| 172.16.14.0/25 | A2-PC / A2-RT | DHCP / 사용 가능한 마지막 주소 |
| 172.16.14.128/25 | A2-Laptop / A2-SRV | 172.16.14.129 / 172.16.14.130 |
| | A2-RT | 사용 가능한 마지막 주소 |
| 172.16.2.0/24 (VoIP 전용) | A2-Phone1 / A2-Laptop | DHCP |
| | A2-RT | 172.16.2.1 |

_표 14-1. 지사 네트워크 구성_

- A2-RT에 연결된 모든 호스트의 DNS는 본사 A-DNS 주소를 사용한다.

### 2-3. VLAN (5강)

- native vlan은 **10**, VLAN: 10(BO-1F), 20(BO-2F), 150(VOICE)

| 스위치 | 인터페이스 | VLAN | 트렁크 |
|---|---|---|---|
| A2-SW1 | fa0/1~10 | 20, 150 | g0/1, g0/2 |
| A2-SW1 | fa0/11~20 | 10, 150 | |
| A2-SW2 | g0/1 제외 전 포트 | 10, 150 | g0/1 |

_표 14-2. 지사 VLAN 구성_

### 2-4. 전화(VoIP) (9강)

- A2-RT가 A2-Phone1·A2-Laptop(CIPC)에 전화번호를 할당하고, DHCP 이름 `VOICE`를 사용한다.
- A2-Phone1·A2-Laptop 간 전화 통화가 가능하도록 한다.

### 2-5. 보안 정책 A2-RT (10강)

- 플래시 메모리에서 IOS 파일을 확인할 수 없어야 한다.
- 최소 암호 길이 **10자 이상**.
- SSHv2 접속 시 **AAA 인증(A2-SRV)** 을 받아야 하고, **A2-Laptop에서만** 접속 가능. 계정 `cyber`(암호 `secu2024$$`).
- SSH 도메인 `cyber.com`, 키 길이 **2048**.

### 2-6. GRE 터널링(IPSec) (12강)

- 본사 A-GRE 설정을 참고하여 A2-RT에 터널링을 구성한다(터널 10, 200.0.0.0/30, A-GRE 200.0.0.1 · A2-RT 200.0.0.2).
- 터널을 통해 본사와 지사의 사설 네트워크가 원활히 통신되도록 하고, IPSec(crypto map `MAP`, 정책 10, aes 256, sha)으로 보호한다.
- **200X 번을 사용하는 지사와의 전화 통화가 GRE 터널을 이용해 가능** 하도록 한다.

---

## 3. 홈(Home) 구축

### 3-1. 외부 연결 (8강)

- 외부 인터넷 주소를 B-SRV의 DHCP를 통해 받아오도록 설정한다.

### 3-2. 무선 (8강)

- Home-RT의 두 호스트에 무선 서비스를 제공한다. 내부 DHCP 대역 192.168.0.100~150, DNS 100.0.3.1.

| 대역 | 사용 | SSID | 암호 방식 | 암호키 |
|---|---|---|---|---|
| 2.4GHz | 사용 | `secu2.4` | WPA2 Personal / AES | `secu2024` |
| 5GHz | 사용 | `secu5` | WPA2 Personal / AES | `secu2024` |

_표 14-3. 홈 무선 설정_

- H-Laptop은 5GHz, H-PC는 2.4GHz에 연결한다.

### 3-3. 이메일 (8강)

- B-SRV를 활용한 메일 서비스를 이용한다. 보내는 서버 `smtp.skills.com`, 받는 서버 `pop3.skills.com`.
- 계정: H-Laptop(`user01@skills.com`), H-PC(`user02@skills.com`).

## 4. 완성 기준 (스스로 채점)

| 구분 | 확인 항목 | 완성 |
|---|---|---|
| 지사 | A2-SRV TFTP로 IOS 복구 | ☐ |
| 지사 | native vlan 10 · VLAN 10·20·150 | ☐ |
| 지사 | A2-Phone1·A2-Laptop 전화번호·통화 | ☐ |
| 지사 | SSHv2·AAA(A2-SRV)·A2-Laptop만·계정 cyber·키 2048 | ☐ |
| 지사 | IOS 플래시 확인 불가·최소 암호 10자 | ☐ |
| 통합 | GRE 터널(10)·IPSec(MAP)로 본사↔지사 사설망 통신 | ☐ |
| 통합 | 200X 지사 전화 ↔ 본사 전화 통화(GRE 경유) | ☐ |
| 홈 | 외부 주소 B-SRV DHCP 수신 | ☐ |
| 홈 | 무선 2.4/5GHz WPA2 · H-PC=2.4 · H-Laptop=5 | ☐ |
| 홈 | 메일 user01↔user02 송수신 | ☐ |

> **감점 조건 재확인**: 공인 네트워크 구간에 터널 구간·사설 IP가 라우팅되면 수동 채점 항목을 모두 0점 처리한다(12강 유의사항).

> **생각해 보기 — 왜 지사 전화는 GRE 터널을 거쳐야 할까?**
> 본사 전화(1001·1002)와 지사 전화(2001·2002)가 통화하려면, 두 지점의 사설망이 이어져 있어야 합니다. 그런데 두 지점 사이에는 인터넷(공인망)이 있고, 사설 IP는 인터넷에서 라우팅되지 않습니다(2강). 그래서 전화 신호가 GRE 터널을 통해야만 상대 지점에 닿습니다. 데이터 통신과 전화 통신이 ‘같은 터널’을 함께 쓴다는 점에서, 앞서 배운 VoIP(9강)와 VPN(12강)이 어떻게 하나로 만나는지 생각해 보세요.
