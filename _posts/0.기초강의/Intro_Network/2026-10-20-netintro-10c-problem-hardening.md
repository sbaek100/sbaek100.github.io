> **실습 문제 사용법**
> 대회 문제지와 비슷한 형식의 과제입니다. 이번 과제는 대회 지사 라우터의 보안 정책을 단순화한 것입니다. 요구사항만 보고 직접 구성한 뒤 ‘완성 기준’으로 스스로 채점하세요.
{: .prompt-info }

---

## 1. 과제 개요

당신은 지사의 네트워크 보안 담당자입니다. 지사 라우터를 안전하게 잠가야 합니다. 원격 관리는 암호화된 SSH로만, 그것도 지정된 계정으로만 허용하고, 암호 정책과 배너를 적용합니다.

## 2. 지급재료

- 패킷 트레이서 9.0
- 제출 파일명: `학번_이름_실습10.pkt`

## 3. 네트워크 구성

라우터 `R-BRANCH` 1대, 관리용 PC 1대, 스위치 1대. 라우터 관리 IP `172.16.14.1/24`, PC `172.16.14.10`.

## 4. 요구사항

### 4-1. 암호 정책

① 특권 모드 암호를 되돌릴 수 없는 방식(`enable secret`)으로 설정하시오.
② 설정 파일의 평문 암호가 보이지 않도록 하시오.
③ 최소 암호 길이를 **10자 이상**으로 강제하시오.

### 4-2. 원격 접속(SSH)

① SSH **버전 2** 만 허용하고, Telnet 접속은 거부되도록 하시오.
② SSH용 도메인은 `cyber.com`, 암호화 키 길이는 **2048** 로 설정하시오.
③ 접속 계정은 `cyber`(암호는 10자 이상)로 하고, 로컬 인증(AAA)을 적용하시오.

### 4-3. 기타 하드닝

① 접속 시 ‘허가되지 않은 접속 금지’ 경고 배너를 표시하시오.
② 사용하지 않는 HTTP 서버 서비스를 끄시오.

### 4-4. 동작 확인

① 관리 PC에서 `ssh -l cyber 172.16.14.1`로 접속되어야 한다.
② 같은 PC에서 `telnet 172.16.14.1`은 거부되어야 한다.

## 5. 선수 유의사항

1. 계정·도메인 이름의 대소문자를 정확히 구별하여 작성하시오.
2. SSH 키 생성 전에 hostname과 도메인 이름이 설정되어 있어야 한다.
3. 반드시 설정을 저장한 뒤 제출하시오.

## 6. 완성 기준 (스스로 채점)

| 확인 항목 | 완성 여부 |
|---|---|
| enable secret과 service password-encryption이 적용되었는가 | ☐ |
| 최소 암호 길이 10자가 강제되는가 | ☐ |
| SSHv2만 허용되고 Telnet은 거부되는가 | ☐ |
| 도메인 `cyber.com`, 키 2048, 계정 `cyber`로 접속되는가 | ☐ |
| AAA 로컬 인증과 경고 배너가 적용되었는가 | ☐ |

> **생각해 보기 — 보안과 편의는 왜 자주 부딪칠까?**
> 이 과제의 조건들(긴 암호, SSH만 허용, 서비스 끄기)은 모두 관리자를 조금씩 불편하게 만듭니다. 그런데도 왜 이렇게 할까요? ‘편하게 열어 두기’와 ‘불편해도 잠그기’ 사이에서, 지사 라우터처럼 외부에 노출된 장비일수록 왜 후자를 택해야 하는지 생각해 보세요. 보안은 늘 편의와의 균형입니다.
