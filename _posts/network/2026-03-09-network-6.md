# 실제로 친구 PC에 파일 보내기

지금까지 패킷트레이서에서 연습했음.  
이번엔 **진짜 내 PC에서 옆자리 친구 PC로 파일을 보내는 실습**임.

---

## 오늘의 순서

1. 내 IP 주소 확인
2. 방화벽 잠깐 열기
3. Ping으로 연결 확인
4. 폴더 공유 설정
5. 친구 PC에서 내 폴더 접속해 파일 가져가기

---

## Step 1 — 내 IP 주소 확인하기

1. 키보드에서 `윈도우키 + R` 누름
2. 실행 창에 `cmd` 입력 후 엔터
3. 검은 창(명령 프롬프트)이 열림
4. 아래 명령어 입력 후 엔터

```
ipconfig
```

결과에서 **IPv4 주소** 를 찾음:

```
IPv4 Address. . . . . : 192.168.0.15
Subnet Mask . . . . . : 255.255.255.0
Default Gateway . . . : 192.168.0.1
```

> `IPv4 Address` 옆에 적힌 숫자가 내 IP 주소임.  
> 이 주소를 옆자리 친구에게 알려줘야 함.

친구의 IP 주소도 받아 적어 둠.

---

## Step 2 — 방화벽 열기 (Ping 허용)

> 방화벽 = 외부에서 들어오는 신호를 막는 문  
> 기본적으로 Ping을 막고 있기 때문에, 잠깐 열어줘야 함.

1. 시작 버튼 클릭 → `Windows Defender 방화벽` 검색 후 열기
2. 왼쪽 메뉴에서 **`고급 설정`** 클릭
3. 왼쪽 목록에서 **`인바운드 규칙`** 클릭
4. 오른쪽 목록을 스크롤해서 아래 항목을 찾음

```
파일 및 프린터 공유(에코 요청 - ICMPv4-In)
```

5. 해당 항목을 찾으면 **오른쪽 클릭 → `규칙 사용`** 클릭
6. 항목 왼쪽 아이콘에 초록 체크가 붙으면 완료

> **"프로필"이 `도메인`, `개인`, `공용` 3개가 있을 수 있음.**  
> 3개 모두 활성화해 주면 됨.

---

## Step 3 — 연결됐는지 확인하기 (Ping)

1. `cmd` 창에서 친구의 IP 주소로 Ping 보내기

```
ping 192.168.0.xx
```

> `xx` 자리에 친구 IP 주소의 마지막 숫자를 넣음

성공 결과:

```
Reply from 192.168.0.xx: bytes=32 time<1ms TTL=128
Reply from 192.168.0.xx: bytes=32 time<1ms TTL=128
Reply from 192.168.0.xx: bytes=32 time<1ms TTL=128
Reply from 192.168.0.xx: bytes=32 time<1ms TTL=128
```

`Reply` 가 보이면 연결된 것임.

### Ping이 안 될 때 확인할 것

| 증상 | 확인할 것 |
|---|---|
| Request timed out | 친구 PC에서 방화벽 열었는지 확인 |
| Request timed out | 같은 공유기(Wi-Fi)에 연결됐는지 확인 |
| Destination unreachable | IP 주소를 잘못 입력했는지 확인 |

---

## Step 4 — 공유 폴더 만들기

> 친구가 내 PC에서 파일을 가져갈 수 있도록 폴더 하나를 공유함.

1. 바탕화면 또는 C드라이브에 **새 폴더** 만들기
2. 폴더 이름을 `공유` 로 지정
3. 폴더 안에 친구에게 전달할 **파일을 넣어둠** (텍스트 파일, 이미지 등)
4. **공유 폴더를 오른쪽 클릭** → **속성** 클릭
5. 상단 탭에서 **`공유`** 탭 클릭
6. **`공유...`** 버튼 클릭
7. 이름 입력란에 `Everyone` 입력 후 **`추가`** 클릭
8. 권한 수준을 **`읽기`** 또는 **`읽기/쓰기`** 로 설정
9. **`공유`** 버튼 클릭
10. 공유 완료 창에서 **`완료`** 클릭

---

## Step 5 — 친구가 내 폴더에 접속하기

> 이 단계는 **친구 PC**에서 진행함.

1. **탐색기** 열기 (폴더 아이콘 또는 `윈도우키 + E`)
2. 상단 주소 입력란 클릭
3. 아래처럼 입력 후 엔터

```
\\192.168.0.xx
```

> `xx` 자리에 **내 IP 주소** 의 마지막 숫자를 넣음

4. 내 공유 폴더 목록이 보임
5. `공유` 폴더를 클릭하면 안에 있는 파일이 보임
6. 파일을 복사해서 친구 PC 바탕화면에 붙여넣기

---

## Step 6 — 반대로도 해보기

이번엔 **친구가 공유 폴더를 만들고, 내가 접속해서 파일 가져오기** 를 해봄.

---

## 오늘 실습과 패킷트레이서 연결

| 패킷트레이서에서 본 것 | 오늘 실제로 한 것 |
|---|---|
| PC에 IP 주소 설정 | ipconfig로 내 IP 확인 |
| Ping으로 연결 확인 | cmd에서 ping 명령 사용 |
| Broadcast로 상대방 찾기 | 파일 공유 접속 전에 ARP가 자동으로 동작 |
| Switch가 경로 기억 | 두 번째 접속부터 더 빠름 |

> 패킷트레이서에서 봤던 것들이 지금 실제로 내 PC에서도 똑같이 일어나고 있음.

---

## 오늘 배운 것 정리

- `ipconfig` 명령어로 내 IP 주소를 확인할 수 있음
- 방화벽을 열어줘야 Ping이 됨
- 폴더를 공유하면 같은 LAN 안에서 파일을 주고받을 수 있음
- `\\IP주소` 로 탐색기에서 상대방 PC에 접속할 수 있음
