# 네트워크 기초 실습 1 — Packet Tracer 설치 & LAN 구성

---

# 1장. Packet Tracer란?

Packet Tracer(패킷 트레이서)는 **Cisco(시스코)에서 무료로 제공하는 네트워크 시뮬레이션 프로그램**입니다.

실제 라우터, 스위치, 서버, PC 등을 가상으로 배치하고, 케이블로 연결하여 네트워크를 구성하고 테스트할 수 있습니다.

> **왜 Packet Tracer를 사용하는가?**  
> 실제 네트워크 장비(스위치, 라우터)는 가격이 매우 비쌉니다.  
> Packet Tracer를 사용하면 비용 부담 없이 비슷한 환경에서 실습할 수 있습니다.

---

# 2장. Packet Tracer 설치

---

## 2.1 Cisco NetAcad 계정 만들기

Packet Tracer는 **Cisco NetAcad(네트워킹 아카데미) 계정**이 있어야 다운로드할 수 있습니다.

### Step 1 — 계정 가입

1. 브라우저에서 아래 주소로 접속합니다.

```
https://www.netacad.com
```

2. 우측 상단 **`Sign up`** 버튼을 클릭합니다.
3. 아래 정보를 입력한 뒤 가입을 진행합니다.
   ![](/assets/img/posts/2026-03-09-network-2-1774424136701.png)

| 항목 | 입력값 |
|---|---|
| First Name | 영문 이름 |
| Last Name | 영문 성 |
| Email | 본인 이메일 주소 |
| Password | 8자 이상, 영문+숫자 조합 |
| Country | South Korea |

![](/assets/img/posts/2026-03-09-network-2-1774424245282.png)


4. 가입한 이메일로 인증 메일이 오면 **`Confirm Account`** 를 클릭합니다.

> **팁**  
> 개인 이메일을 사용해도 되지만, 자주 쓰는 구글 계정을 사용하면 로그인할 때 조금 더 편할 수 있습니다.

---

## 2.2 Packet Tracer 다운로드

### Step 2 — Packet Tracer 다운로드 페이지 접속

1. NetAcad에 로그인한 뒤 아래 주소로 이동합니다.

```
https://www.netacad.com/resources/lab-downloads?courseLang=en-US
```

2. 페이지에서 **`Cisco Packet Tracer`** 항목을 찾습니다.
3. 사용 중인 운영체제(OS)에 맞는 설치 파일을 클릭합니다.
4. 브라우저가 다운로드 위치를 물어보면, 찾기 쉬운 폴더에 저장합니다.
5. 다운로드가 끝날 때까지 기다립니다.

> **참고**  
> Packet Tracer는 Windows, macOS, Linux를 지원합니다.  
> 스마트폰이나 태블릿에서는 설치할 수 없습니다.

![](/assets/img/posts/2026-03-09-network-2-1774424489896.png)

| 운영체제 | 선택할 파일 |
|---|---|
| Windows 64비트 | `PacketTracer_x.x.x_Windows_64bit.exe` |
| Windows 32비트 | `PacketTracer_x.x.x_Windows_32bit.exe` |
| macOS | `PacketTracer_x.x.x_MacOS.dmg` |
| Linux | `PacketTracer_x.x.x_amd64.deb` |

> **내 Windows 비트 확인 방법**:  
> `윈도우키` → `설정` → `시스템` → `정보` → **시스템 종류** 확인

> **학생용 체크 포인트**  
> 파일 이름 끝이 `.exe` 이면 Windows용 설치 파일이 맞습니다.  
> 보통 학교 PC와 개인 노트북은 대부분 `Windows 64비트`를 사용합니다.

---

## 2.3 Packet Tracer 설치

### Step 3 — 설치 진행 (Windows 기준)

1. 다운로드한 폴더로 이동하여 `.exe` 설치 파일을 찾습니다.
2. 설치 파일을 **더블클릭**하여 실행합니다.
3. 설치 창이 열리면 사용권 계약 화면에서 **`I accept the agreement`** 를 선택한 뒤 `Next` 를 클릭합니다.
   ![](/assets/img/posts/2026-03-09-network-2-1774425938110.png)
   
4. 설치 경로 선택 화면이 나오면 특별한 이유가 없으면 **기본 경로 그대로** 두고 `Next` 를 클릭합니다.
   - 기본 경로 예시: `C:\Program Files\Cisco Packet Tracer x.x.x\`
     
     ![](/assets/img/posts/2026-03-09-network-2-1774425962715.png)
     
     
1. `Select Start Menu Folder` 화면이 나오면 기본값을 유지하고 `Next` 를 클릭합니다.
2. `Select Additional Tasks` 화면이 나오면 **바탕화면 바로가기(Desktop Shortcut)** 가 체크되어 있는지 확인한 뒤 `Next` 를 클릭합니다.
3. `Ready to Install` 화면에서 설정을 한 번 확인합니다.
   - 다시 수정하려면 `Back`
   - 바로 설치하려면 `Install`
8. `Install` 을 클릭하고 설치가 끝날 때까지 기다립니다.
   - 보통 2~3분 정도 걸립니다.
9. 설치 완료 화면에서 **`Launch Cisco Packet Tracer`** 체크가 되어 있는지 확인합니다.   
   ![](/assets/img/posts/2026-03-09-network-2-1774425991081.png)
   
   ![](/assets/img/posts/2026-03-09-network-2-1774426072778.png)
   
   
10. `Finish` 를 클릭하여 설치를 마칩니다.

> **헷갈리지 않기**  
> 처음 배우는 단계에서는 대부분 **기본값 유지 + Next** 로 진행하면 됩니다.  
> 설치 중간에 경로를 굳이 바꾸지 않아도 됩니다.

## 2.4 Packet Tracer 최초 실행 및 로그인

### Step 4 — 로그인

1. `Finish` 를 누른 뒤 자동 실행되면 그대로 기다리고, 자동 실행되지 않으면 바탕화면의 **Cisco Packet Tracer** 아이콘을 더블클릭합니다.
2. 처음 실행할 때 **멀티유저 모드(Multiuser Mode)** 로 실행할지 묻는 창이 나오면 **`No`** 를 클릭합니다.
   - 지금은 혼자 실습하는 단계이므로 `No` 를 선택하면 됩니다.
     
     ![](/assets/img/posts/2026-03-09-network-2-1774426127165.png)
     

3. 경우에 따라 Windows 보안 경고 창이 나타날 수 있습니다.
   - 당황하지 말고 창 내용을 확인한 뒤 닫거나 허용 여부를 선택하면 됩니다.
4. 로그인 화면에서 NetAcad 계정 정보를 입력합니다.
   ![](/assets/img/posts/2026-03-09-network-2-1774426156109.png)

```
Username: 가입한 이메일 주소
Password: 가입 시 설정한 비밀번호
```

5. 개인 컴퓨터라면 **`Keep me logged in`** 옵션을 켜 두면 다음부터 로그인 과정을 줄일 수 있습니다.
6. **`Log in`** 버튼을 클릭합니다.
7. 브라우저 탭이 자동으로 열릴 수 있습니다.
   - 이미 NetAcad 로그인 상태이면 `로그인 성공` 안내가 보일 수 있습니다.
   - 로그인 세션이 만료되었으면 NetAcad 사이트에서 한 번 더 로그인해야 할 수 있습니다.
8. 브라우저에서 성공 메시지를 확인한 뒤 탭을 닫고 Packet Tracer 화면으로 돌아옵니다.
9. Packet Tracer 메인 화면이 열리면 실행과 로그인이 완료된 것입니다.

> **오프라인 모드**  
> 인터넷이 없을 때는 `Guest Login` 버튼으로도 실행할 수 있습니다.  
> 다만 일부 기능은 제한될 수 있으므로, 가능하면 NetAcad 계정으로 로그인하는 것을 권장합니다.

> **학생용 체크 포인트**  
> 로그인까지 끝나면 빈 작업 화면이 보이고, 아래쪽에 `Routers`, `Switches`, `End Devices` 같은 장비 메뉴가 나타납니다.  
> 여기까지 보이면 정상적으로 설치가 완료된 것입니다.

# 4장. 실습 — PC 2대 + 스위치 LAN 구성

---

## 4.1 목표 토폴로지

이번 실습에서 만들 네트워크 구성도(토폴로지)입니다.

```
[PC0]                  [PC1]
192.168.1.10           192.168.1.20
    |                      |
    └──────[Switch0]───────┘
            (스위치)
```

두 PC가 스위치를 통해 연결되어 같은 네트워크에서 통신하는 가장 기본적인 LAN 구성입니다.

---

## 4.2 Step-by-Step 실습

---

### Step 1 — 새 파일 만들기

1. Packet Tracer를 실행합니다.
2. 상단 메뉴 **`File`** → **`New`** 를 클릭합니다. 또는 `Ctrl + N` 을 눌러도 됩니다.
3. 빈 작업 공간이 열리면 준비 완료입니다.

---

### Step 2 — PC 배치하기

1. 하단 장비 유형 패널에서 **`End Devices`** (끝단 장치)를 클릭합니다. 
   ![](/assets/img/posts/2026-03-09-network-2-1774426352727.png)
   
2. 장비 목록에서 **`PC`** 아이콘을 확인합니다.
3. PC 아이콘을 **작업 공간으로 드래그** 하여 `PC0` 를 배치합니다.
4. 같은 방법으로 **PC를 하나 더 드래그** 하여 `PC1` 을 배치합니다.
5. 두 PC를 적당히 좌우로 배치합니다.
   
   ![](/assets/img/posts/2026-03-09-network-2-1774426376631.png)

> **팁**  
> 이름을 바꾸고 싶다면 장비를 클릭한 뒤 `Config` 탭에서 변경할 수 있습니다.

![](/assets/img/posts/2026-03-09-network-2-1774426405257.png)


---

### Step 3 — 스위치 배치하기

1. 하단 장비 유형 패널에서 **`Switches`** 를 클릭합니다.
2. 장비 목록에서 **`2960`** 스위치를 선택합니다. 이 장비가 기본 스위치입니다.
   
   ![](/assets/img/posts/2026-03-09-network-2-1774426479937.png)
   
3. 작업 공간의 두 PC 사이 아래쪽에 드래그하여 배치합니다. 이름은 `Switch0` 으로 표시됩니다.
   
   ![](/assets/img/posts/2026-03-09-network-2-1774426555319.png)

---

### Step 4 — 케이블로 연결하기

1. 하단 패널에서 **`Connections`** (번개 모양 아이콘)을 클릭합니다.
   
   ![](/assets/img/posts/2026-03-09-network-2-1774426583329.png)
   
2. **`Copper Straight-Through`** (직선 케이블, 실선)를 선택합니다.
   
   ![](/assets/img/posts/2026-03-09-network-2-1774426620722.png)


> **케이블 종류 설명**  
> - **Straight-Through** (직선): PC ↔ 스위치, PC ↔ 허브 연결 시 사용  
> - **Crossover** (크로스): PC ↔ PC 직접 연결, 스위치 ↔ 스위치 연결 시 사용  
> - **Auto** (자동): 자동으로 케이블 종류 선택 (입문 시 편리함)

3. `PC0` 를 클릭한 뒤 포트 선택 창에서 **`FastEthernet0`** 를 클릭합니다.
   
   ![](/assets/img/posts/2026-03-09-network-2-1774426732158.png)
   
   
3. `Switch0` 를 클릭한 뒤 포트 선택 창에서 **`FastEthernet0/1`** 를 클릭합니다.
   
   ![](/assets/img/posts/2026-03-09-network-2-1774426750686.png)
   
   
3. 케이블이 연결되면 포트에 **초록색 점** 이 표시됩니다. 그러면 연결이 성공한 것입니다.
4. 같은 방법으로 `PC1` 과 `Switch0` 도 연결합니다. 이때 스위치 쪽 포트는 `FastEthernet0/2` 를 사용합니다.

> **주황색 점**: 아직 포트가 활성화되지 않은 상태 (잠시 후 초록색으로 변함)  
> **빨간색 점**: 연결 오류

> **학생용 체크 포인트**  
> 케이블을 잘못 선택하면 연결이 되지 않을 수 있습니다.  
> 이번 실습에서는 `Copper Straight-Through` 를 선택하면 됩니다.

![](/assets/img/posts/2026-03-09-network-2-1774426814078.png)

---

### Step 5 — PC0에 IP 주소 설정

1. `PC0` 아이콘을 **더블클릭**합니다.
2. 팝업 창에서 **`Desktop`** 탭을 클릭합니다.
3. **`IP Configuration`** 을 클릭합니다.
   
   ![](/assets/img/posts/2026-03-09-network-2-1774426889109.png)
   
4. 아래 정보를 입력합니다.

| 항목 | 값 |
|---|---|
| **IP Address** | `192.168.1.10` |
| **Subnet Mask** | `255.255.255.0` |
| **Default Gateway** | 비워 둠 |

![](/assets/img/posts/2026-03-09-network-2-1774426950381.png)


5. 입력이 끝나면 값이 잘 들어갔는지 확인한 뒤 창을 닫습니다.

---

### Step 6 — PC1에 IP 주소 설정

1. `PC1` 아이콘을 **더블클릭**합니다.
2. **`Desktop`** 탭 → **`IP Configuration`** 으로 이동합니다.
3. 아래 정보를 입력합니다.

| 항목 | 값 |
|---|---|
| **IP Address** | `192.168.1.20` |
| **Subnet Mask** | `255.255.255.0` |
| **Default Gateway** | 비워 둠 |
![](/assets/img/posts/2026-03-09-network-2-1774426975999.png)

4. 값이 잘 들어갔는지 확인한 뒤 창을 닫습니다.

---

### Step 7 — Ping 테스트로 통신 확인

Ping(핑)은 **목적지 IP 주소로 테스트 패킷을 보내서 통신이 되는지 확인하는 명령어**입니다.

1. `PC0` 를 더블클릭합니다.
2. **`Desktop`** 탭 → **`Command Prompt`** 를 클릭합니다.
   
   ![](/assets/img/posts/2026-03-09-network-2-1774427037620.png)
   
3. 아래 명령어를 입력합니다.

```
ping 192.168.1.20
```

4. 성공하면 아래와 같은 결과가 나타납니다.

```
Pinging 192.168.1.20 with 32 bytes of data:
Reply from 192.168.1.20: bytes=32 time<1ms TTL=128
```
