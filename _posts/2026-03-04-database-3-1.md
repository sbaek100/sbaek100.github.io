# 1장. 데이터 필터링

## 1.1 데이터 필터링(Data Filtering)이란

데이터 필터링은 테이블에 저장된 수많은 데이터 중에서 **원하는 조건에 맞는 데이터만 골라내는 작업**임.

엑셀의 "자동 필터" 기능과 같은 개념이며, SQL에서는 `WHERE` 절을 사용함.

```sql
-- WHERE 절 기본 형식
SELECT 칼럼명 FROM 테이블명 WHERE 조건;
```

> 💡 `WHERE` 절이 없으면 테이블의 **모든 행**이 조회됨.
> `WHERE` 절이 있으면 조건에 **맞는 행만** 걸러서 조회됨.

**WHERE 절을 사용하는 SQL 문:**

| SQL 문 | WHERE 절 사용 가능 여부 |
|--------|------------------------|
| SELECT | ✅ 사용 가능 |
| UPDATE | ✅ 사용 가능 |
| DELETE | ✅ 사용 가능 |
| INSERT | ❌ 사용 불가 |

---

## 1.2 비교 연산자(Comparison Operator)

두 값을 비교해서 참(TRUE) / 거짓(FALSE)을 판단하는 기호임.
`WHERE` 절 안에서 조건을 만들 때 사용함.

| 연산자 | 의미 | 예시 | 설명 |
|--------|------|------|------|
| `=` | 같다 | `WHERE score = 90` | 점수가 정확히 90인 행 |
| `!=` | 같지 않다 | `WHERE name != '김민준'` | 이름이 김민준이 아닌 행 |
| `>` | 크다 | `WHERE score > 80` | 점수가 80보다 큰 행 |
| `>=` | 크거나 같다 | `WHERE score >= 80` | 점수가 80 이상인 행 |
| `<` | 작다 | `WHERE score < 70` | 점수가 70보다 작은 행 |
| `<=` | 작거나 같다 | `WHERE score <= 70` | 점수가 70 이하인 행 |

> 💡 `=` 는 **등호 하나**임. 프로그래밍에서 같음을 비교할 때 `==` 를 쓰는 언어가 많지만, SQL에서는 `=` 하나만 사용함.

**사용 예:**

```sql
-- 프로그래밍 점수가 80점을 초과한 학생 조회
SELECT * FROM students WHERE programming > 80;

-- 네트워크 점수가 70점 미만인 학생 조회
SELECT * FROM students WHERE network < 70;

-- 이름이 '김민준'이 아닌 학생 조회
SELECT * FROM students WHERE name != '김민준';
```

---

## 1.3 논리 연산자(Logical Operator)

두 개 이상의 조건을 조합해서 새로운 조건을 만드는 연산자임.

| 연산자 | 의미 | 설명 |
|--------|------|------|
| `AND` | 그리고 | 두 조건이 **모두** 참일 때만 해당 |
| `OR` | 또는 | 두 조건 중 **하나라도** 참이면 해당 |
| `NOT` | 아닌 | 조건이 **거짓**인 것만 해당 |

> 💡 AND 는 **교집합(∩)**, OR 는 **합집합(∪)** 으로 생각하면 쉬움.

**AND 동작 원리:**

세 과목 모두 90점 이상인 학생을 찾을 때 → 조건 세 개를 AND 로 묶음.

```sql
-- 세 과목이 모두 90점 이상인 학생
SELECT * FROM students
WHERE programming >= 90
  AND db_score >= 90
  AND network >= 90;
```

**OR 동작 원리:**

한 과목이라도 60점 미만인 학생을 찾을 때 → 조건 세 개를 OR 로 묶음.

```sql
-- 한 과목이라도 60점 미만인 학생
SELECT * FROM students
WHERE programming < 60
   OR db_score < 60
   OR network < 60;
```

**세 조건의 교집합(AND) vs 합집합(OR):**

| 구분 | 의미 | SQL |
|------|------|-----|
| 교집합 (AND) | 모든 조건을 동시에 만족 | `WHERE A AND B AND C` |
| 합집합 (OR) | 조건 중 하나 이상 만족 | `WHERE A OR B OR C` |

---

## 1.4 산술 연산자(Arithmetic Operator)

칼럼 값으로 사칙연산을 수행하는 연산자임.
`SELECT` 절과 `WHERE` 절 모두에서 사용 가능함.

| 연산자 | 의미 | 예시 |
|--------|------|------|
| `+` | 더하기 | `programming + db_score` |
| `-` | 빼기 | `programming - network` |
| `*` | 곱하기 | `score * 2` |
| `/` | 나누기 | `total / 3` |
| `%` | 나머지 | `id % 2` |

**총점과 평균을 계산하는 예:**

```sql
-- 총점 계산
SELECT name, programming + db_score + network AS 총점
FROM students;

-- 평균 계산 (괄호로 더하기를 먼저 수행)
SELECT name, (programming + db_score + network) / 3 AS 평균
FROM students;
```

---

## 1.5 연산자 우선순위(Operator Precedence)

SQL 도 수학처럼 연산자마다 계산 순서가 정해져 있음.
우선순위가 높은 연산자가 먼저 계산됨.

| 우선순위 | 연산자 | 설명 |
|----------|--------|------|
| 1 (가장 먼저) | `( )` | 괄호 안을 먼저 계산 |
| 2 | `*` `/` `%` | 곱하기, 나누기, 나머지 |
| 3 | `+` `-` | 더하기, 빼기 |
| 4 | `=` `!=` `>` `>=` `<` `<=` | 비교 연산자 |
| 5 | `NOT` | 논리 부정 |
| 6 | `AND` | 논리 곱 |
| 7 (가장 나중) | `OR` | 논리 합 |

**괄호의 중요성:**

```sql
-- ❌ 잘못된 예: network / 3 을 먼저 계산한 뒤 더하기 수행
SELECT (programming + db_score + network / 3) AS 잘못된평균
FROM students;

-- ✅ 올바른 예: 괄호로 묶어 더하기를 먼저 수행
SELECT (programming + db_score + network) / 3 AS 올바른평균
FROM students;
```

> ⚠️ 나누기(`/`)가 더하기(`+`)보다 **우선순위가 높기** 때문에 괄호 없이 쓰면 의도와 다른 결과가 나옴.
> 헷갈릴 때는 **괄호로 묶으면 항상 안전**함.

## 1.6 AS — 별칭(Alias)

`AS` 키워드는 칼럼이나 계산 결과에 **임시로 이름을 붙이는** 기능임.

- 결과 화면에서만 해당 이름으로 표시됨
- 실제 테이블의 칼럼명은 바뀌지 않음
- 한글 별칭도 사용 가능함

```sql
-- AS 사용 예
SELECT name AS 이름,
       programming AS 프로그래밍점수,
       (programming + db_score + network) / 3 AS 평균점수
FROM students;
```

> ⚠️ `WHERE` 절에서는 `AS` 로 붙인 별칭을 사용할 수 없음.
> `WHERE 평균점수 >= 80` 으로 쓰면 오류 발생.
> `WHERE` 절에는 반드시 실제 계산식을 그대로 써야 함.

```sql
-- ❌ 오류: WHERE 절에 별칭 사용 불가
SELECT name, (programming + db_score + network) / 3 AS 평균
FROM students
WHERE 평균 >= 80;

-- ✅ 올바른 방법: WHERE 절에 계산식 직접 작성
SELECT name, (programming + db_score + network) / 3 AS 평균
FROM students
WHERE (programming + db_score + network) / 3 >= 80;
```

# 2장. 집계 함수

## 2.1 집계 함수(Aggregate Function)란

여러 행의 값을 **하나의 결과값으로 요약**해 주는 함수임.
개수, 합계, 평균, 최댓값, 최솟값 등 통계 계산에 사용함.

```sql
-- 집계 함수 기본 형식
SELECT 함수명(칼럼명) FROM 테이블명;
```

| 함수 | 의미 | 사용 예 | 비고 |
|------|------|---------|------|
| `COUNT()` | 행의 개수를 셈 | `COUNT(*)` | 모든 자료형 사용 가능 |
| `SUM()` | 합계를 구함 | `SUM(amount)` | 숫자 칼럼만 가능 |
| `AVG()` | 평균을 구함 | `AVG(amount)` | 숫자 칼럼만 가능 |
| `MAX()` | 최댓값을 구함 | `MAX(amount)` | 숫자 칼럼만 가능 |
| `MIN()` | 최솟값을 구함 | `MIN(amount)` | 숫자 칼럼만 가능 |

---

## 2.2 MAX / MIN — 최댓값, 최솟값

`MAX()` 함수는 지정한 칼럼에서 **가장 큰 값**을 반환함.
`MIN()` 함수는 지정한 칼럼에서 **가장 작은 값**을 반환함.

```sql
-- 기본 형식
SELECT MAX(칼럼명) FROM 테이블명;
SELECT MIN(칼럼명) FROM 테이블명;
```

**사용 예:**

```sql
-- PayPal 거래 중 가장 큰 금액과 가장 작은 금액
SELECT MAX(amount) AS 최대금액,
       MIN(amount) AS 최소금액
FROM transactions
WHERE company = 'PayPal';
```

> 💡 `MAX()` 와 `MIN()` 은 숫자뿐만 아니라 날짜, 문자열에도 사용 가능함.
> 날짜의 경우 가장 최근 날짜 / 가장 오래된 날짜를 반환함.

---

## 2.3 COUNT — 개수 세기

`COUNT()` 함수는 조건에 맞는 **행의 개수**를 반환함.

```sql
-- 기본 형식
SELECT COUNT(*) FROM 테이블명;
SELECT COUNT(칼럼명) FROM 테이블명;
```

**`COUNT(*)` 와 `COUNT(칼럼명)` 의 차이:**

| 구분 | 설명 |
|------|------|
| `COUNT(*)` | NULL 포함 전체 행 수를 셈 |
| `COUNT(칼럼명)` | 해당 칼럼에서 NULL 이 아닌 행 수만 셈 |

```sql
-- 전체 거래 건수
SELECT COUNT(*) AS 전체거래수 FROM transactions;

-- Coupang 과 Amazon 의 거래 건수
SELECT COUNT(*) AS 거래건수
FROM transactions
WHERE company = 'Coupang' OR company = 'Amazon';
```

**IN 연산자:**

`OR` 를 여러 번 쓰는 대신 `IN` 을 사용하면 코드가 간결해짐.

```sql
-- OR 대신 IN 사용 (결과 동일)
SELECT COUNT(*) AS 거래건수
FROM transactions
WHERE company IN ('Coupang', 'Amazon');
```

| 방법 | 코드 |
|------|------|
| OR 사용 | `WHERE company = 'A' OR company = 'B' OR company = 'C'` |
| IN 사용 | `WHERE company IN ('A', 'B', 'C')` |

> 💡 비교할 값이 3개 이상이면 `IN` 을 사용하는 것이 훨씬 읽기 쉬움.

---

## 2.4 SUM — 합계

`SUM()` 함수는 지정한 칼럼의 **모든 값을 더한 합계**를 반환함.
숫자형 칼럼에만 사용 가능함.

```sql
-- 기본 형식
SELECT SUM(칼럼명) FROM 테이블명;
```

**사용 예:**

```sql
-- Google 과 거래한 금액의 합계
SELECT SUM(amount) AS 합계금액
FROM transactions
WHERE company = 'Google';

-- Google 과 Amazon 에서 입금받은 금액의 합계
SELECT SUM(amount) AS 입금합계
FROM transactions
WHERE company IN ('Google', 'Amazon')
  AND ttype = '입금';
```

---

## 2.5 AVG — 평균

`AVG()` 함수는 지정한 칼럼 값들의 **평균**을 반환함.
숫자형 칼럼에만 사용 가능함.

```sql
-- 기본 형식
SELECT AVG(칼럼명) FROM 테이블명;
```

**사용 예:**

```sql
-- Google 과 Amazon 에서 입금받은 금액의 평균
SELECT AVG(amount) AS 입금평균
FROM transactions
WHERE company IN ('Google', 'Amazon')
  AND ttype = '입금';
```

> 💡 `AVG()` 는 NULL 값을 제외하고 계산함.
> NULL 이 있는 행은 분모(나누는 수)에서도 제외되므로
> `SUM() / COUNT(*)` 와 결과가 다를 수 있음.

---

## 2.6 DISTINCT — 중복 제거

`DISTINCT` 는 조회 결과에서 **중복된 값을 제거**하고 고유한 값만 반환하는 키워드임.

```sql
-- 기본 형식
SELECT DISTINCT 칼럼명 FROM 테이블명;
```

**중복이 있는 경우 vs DISTINCT 사용:**

```sql
-- 중복 포함 조회 (거래처가 여러 번 반복됨)
SELECT company FROM transactions;

-- 중복 제거 조회 (고유한 거래처 목록만)
SELECT DISTINCT company FROM transactions;
```

| DISTINCT 없이 | DISTINCT 사용 후 |
|--------------|-----------------|
| Google | Google |
| Google | PayPal |
| PayPal | Coupang |
| PayPal | Amazon |
| Coupang | (4개만 출력) |
| ... (15개 출력) | |

> 💡 `DISTINCT` 는 `SELECT` 바로 뒤에 붙여 씀.
> `COUNT(DISTINCT 칼럼명)` 처럼 집계 함수 안에 넣어 **고유한 값의 개수**를 셀 수도 있음.

```sql
-- 고유한 거래처의 수 세기
SELECT COUNT(DISTINCT company) AS 거래처수
FROM transactions;
-- 출력: 4
```

# 핵심 정리

## 1장 — 데이터 필터링 요약

| 개념 | 키워드 | 설명 |
|------|--------|------|
| 기본 필터링 | `WHERE` | 조건에 맞는 행만 조회 |
| 비교 연산자 | `=` `!=` `>` `>=` `<` `<=` | 두 값을 비교 |
| 논리 연산자 | `AND` `OR` `NOT` | 조건을 조합 |
| 목록 비교 | `IN (값1, 값2, …)` | OR 여러 개를 간결하게 대체 |
| 산술 연산자 | `+` `-` `*` `/` `%` | 칼럼 값으로 계산 |
| 별칭 | `AS` | 칼럼에 임시 이름 부여 |
| 우선순위 | `( )` | 괄호로 계산 순서 명시 |

## 2장 — 집계 함수 요약

| 함수 / 키워드 | 역할 | 주의사항 |
|--------------|------|----------|
| `COUNT(*)` | 전체 행 수 | NULL 포함 |
| `COUNT(칼럼)` | NULL 제외 행 수 | NULL 제외 |
| `SUM(칼럼)` | 합계 | 숫자형만 가능 |
| `AVG(칼럼)` | 평균 | NULL 제외하고 계산 |
| `MAX(칼럼)` | 최댓값 | 날짜, 문자열도 가능 |
| `MIN(칼럼)` | 최솟값 | 날짜, 문자열도 가능 |
| `DISTINCT` | 중복 제거 | SELECT 바로 뒤에 붙임 |
