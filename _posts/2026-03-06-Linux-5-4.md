# 시스템 관리 필수 커맨드 라인 시나리오 기반 30문제 실습

이번 실습 시나리오는 아래와 같다.

> 여러분은 Ubuntu 실습 서버에 접속한 초급 관리자이다.  
> 필요한 패키지를 설치하고, 서비스 상태를 점검하고, 실습 파일을 찾고, 디스크 사용량을 확인하고, 마지막에는 작업 폴더를 압축해 보관해야 한다.

이번 문제에서는 아래 명령어를 반복해서 익힌다.

- `sudo apt update`
- `sudo apt install`
- `sudo apt remove`
- `systemctl status`
- `sudo systemctl restart`
- `find`
- `stat`
- `df -h`
- `du -sh`
- `tar -czvf`
- `tar -xzvf`

---

# 1단계. 패키지 준비하기

## 문제 1

패키지를 설치하기 전에, 설치 가능한 패키지 목록을 최신 상태로 바꾸려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
sudo apt update
```

---

## 문제 2

디렉터리 구조를 보기 쉽게 확인하는 `tree` 패키지를 설치하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
sudo apt install tree
```

---

## 문제 3

`tree` 패키지가 설치된 뒤, 홈 디렉터리 구조를 한 번 확인해 보고 싶다. 어떤 명령을 입력해야 하는가?

### 답

```bash
tree ~
```

---

## 문제 4

설치가 잘 되었는지 다시 한 번 보기 위해, 현재 디렉터리 구조만 출력하고 싶다. 어떤 명령을 입력해야 하는가?

### 답

```bash
tree .
```

---

## 문제 5

실습이 끝난 뒤 `tree` 패키지를 제거하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
sudo apt remove tree
```

---

## 문제 6

다시 실습을 이어가기 위해 `tree` 패키지를 한 번 더 설치하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
sudo apt install tree
```

---

# 2단계. 서비스 상태 점검하기

## 문제 7

서버 시간이 자동으로 맞춰지고 있는지 확인하려고 한다. `systemd-timesyncd` 서비스 상태를 확인하는 명령을 입력하시오.

### 답

```bash
systemctl status systemd-timesyncd
```

---

## 문제 8

서비스 상태를 확인한 뒤, 해당 서비스를 다시 시작하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
sudo systemctl restart systemd-timesyncd
```

---

## 문제 9

다시 시작한 뒤 서비스가 정상 상태인지 한 번 더 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
systemctl status systemd-timesyncd
```

---

## 문제 10

만약 `systemd-timesyncd`가 없는 환경이라면, `ssh` 서비스 상태를 확인해 보고 싶다. 어떤 명령을 입력하면 되는가?

### 답

```bash
systemctl status ssh
```

---

## 문제 11

`ssh` 서비스가 응답하지 않는다고 가정하고, 다시 시작하는 명령을 입력하시오.

### 답

```bash
sudo systemctl restart ssh
```

---

## 문제 12

서비스 관리 실습을 마무리하며, 다시 한 번 `ssh` 서비스 상태를 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
systemctl status ssh
```

# 3단계. 파일 찾기와 상태 확인하기

이제 파일 검색과 확인 실습을 위해 연습용 폴더와 파일을 만든다.

먼저 아래 명령을 입력해 준비한다.

```bash
mkdir -p ~/linux5-quest/docs
touch ~/linux5-quest/docs/sample.txt
touch ~/linux5-quest/docs/report.txt
touch ~/linux5-quest/docs/error.log
```

## 문제 13

`linux5-quest` 폴더 아래에서 `.txt` 파일만 찾으려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
find ~/linux5-quest -name "*.txt"
```

---

## 문제 14

이번에는 `.log` 파일만 찾고 싶다. 어떤 명령을 입력해야 하는가?

### 답

```bash
find ~/linux5-quest -name "*.log"
```

---

## 문제 15

`sample.txt` 파일의 크기, 수정 시간, 권한을 확인하고 싶다. 어떤 명령을 입력해야 하는가?

### 답

```bash
stat ~/linux5-quest/docs/sample.txt
```

---

## 문제 16

`report.txt` 파일의 상세 정보를 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash

```

---

## 문제 17

압축을 하기 전에, `linux5-quest` 폴더 안에 있는 `.txt` 파일이 정확히 어디에 있는지 다시 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
find ~/linux5-quest -name "*.txt"
```

---

## 문제 18

`error.log` 파일이 실제로 존재하는지 상태 정보까지 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
stat ~/linux5-quest/docs/error.log
```

# 5단계. 압축하고 복원하기

## 문제 25

이제 `linux5-quest` 폴더를 `linux5-quest.tar.gz` 파일로 압축하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
tar -czvf linux5-quest.tar.gz ~/linux5-quest
```

---

## 문제 26

압축이 끝난 뒤, 압축 파일이 현재 위치에 만들어졌는지 확인하기 위해 현재 디렉터리 구조를 보고 싶다. 어떤 명령을 입력해야 하는가?

### 답

```bash
tree .
```

---

## 문제 27

복원 실습을 위해 `linux5-restore` 폴더를 만들고 싶다. 어떤 명령을 입력해야 하는가?

### 답

```bash
mkdir -p ~/linux5-restore
```

---

## 문제 28

`linux5-quest.tar.gz` 압축 파일을 `~/linux5-restore` 폴더에 풀려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
tar -xzvf linux5-quest.tar.gz -C ~/linux5-restore
```

---

## 문제 29

압축을 푼 뒤, 복원된 폴더 안에 `.txt` 파일이 잘 들어 있는지 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
find ~/linux5-restore -name "*.txt"
```

---

## 문제 30

복원된 `sample.txt` 파일의 상태 정보를 마지막으로 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
stat ~/linux5-restore/linux5-quest/docs/sample.txt
```
