# Bash 스크립팅 기초 - 쉬운 복습 문제

이 문서는 6-1 이론과 6-2 실습을 마친 뒤, 핵심 내용을 부담 없이 다시 확인하기 위한 복습 자료이다.  
처음 배우는 학생이 너무 어렵지 않게 풀 수 있도록 **짧은 문제, 쉬운 보기, 간단한 해설** 중심으로 구성했다.

---

# 1장. 변수

## 문제 1

다음 중 Bash에서 변수를 올바르게 선언한 것은?

① `name = "kim"`  
② `name="kim"`  
③ `$name="kim"`  
④ `set name="kim"`

## 문제 2

다음 코드의 출력 결과는?

```bash
student="hong"
echo "$student"
```

① `$student`  
② hong  
③ student  
④ 오류

## 문제 3

다음 중 변수 `age=20` 과 `num=3` 이 있을 때 올바른 계산은?

① `echo $(age + num)`  
② `echo $[age + num]`  
③ `echo $((age + num))`  
④ `echo ${age + num}`

# 2장. 조건문

## 문제 4

다음 중 "90 이상이면 합격"을 검사하는 조건으로 알맞은 것은?

① `[ $score -eq 90 ]`  
② `[ $score -gt 90 ]`  
③ `[ $score -ge 90 ]`  
④ `[ $score -le 90 ]`

## 문제 5

다음 코드의 실행 결과는?

```bash
score=75
if [ $score -ge 80 ]; then
    echo "합격"
else
    echo "불합격"
fi
```

① 합격  
② 불합격  
③ 75  
④ 오류

## 문제 6

다음 중 `/etc/passwd` 가 일반 파일인지 확인하는 조건은?

① `[ -d /etc/passwd ]`  
② `[ -f /etc/passwd ]`  
③ `[ -e /etc/passwd ]`  
④ `[ -x /etc/passwd ]`

# 3장. 반복문

## 문제 7

다음 코드의 출력은?

```bash
for i in 1 2 3; do
    echo "$i"
done
```

① 1 2 3  
② 1줄에 1, 2, 3이 순서대로 출력  
③ 123  
④ 오류

## 문제 8

다음 중 조건이 참인 동안 반복하는 문장은?

① `if`  
② `case`  
③ `while`  
④ `break`

## 문제 9

다음 코드의 결과로 맞는 것은?

```bash
for i in 1 2 3 4 5; do
    if [ $i -eq 3 ]; then
        continue
    fi
    echo "$i"
done
```

① 1 2 3 4 5  
② 1 2 4 5  
③ 3만 출력  
④ 1 2만 출력

## 문제 10

다음 코드의 결과로 맞는 것은?

```bash
for i in 1 2 3 4 5; do
    if [ $i -eq 4 ]; then
        break
    fi
    echo "$i"
done
```

① 1 2 3  
② 1 2 3 4  
③ 4 5  
④ 아무것도 출력되지 않음

# 4장. 함수

## 문제 11

다음 중 Bash 함수 선언으로 올바른 것은?

① `hello[] { echo "hi"; }`  
② `function hello = { echo "hi"; }`  
③ `hello() { echo "hi"; }`  
④ `hello => { echo "hi"; }`

## 문제 12

다음 코드의 출력 결과는?

```bash
greet() {
    echo "안녕하세요, $1 님"
}
greet "kim"
```

① 안녕하세요  
② 안녕하세요, kim 님  
③ kim  
④ 오류

# 쉬운 해설

## 문제 1 해설

변수는 `name="kim"` 처럼 등호 양쪽에 공백 없이 써야 한다.

## 문제 3 해설

숫자 계산은 `$(( ))` 형태를 가장 많이 사용한다.

## 문제 4 해설

`-ge` 는 "크거나 같다" 라는 뜻이다.

## 문제 6 해설

`-f` 는 일반 파일인지 확인할 때 사용한다.

## 문제 8 해설

`while` 은 조건이 맞는 동안 계속 반복한다.

## 문제 9 해설

`continue` 는 이번 한 번만 건너뛴다. 그래서 3만 빼고 출력된다.

## 문제 10 해설

`break` 는 반복문을 즉시 끝낸다. 그래서 4를 만나기 전까지만 출력된다.

## 문제 12 해설

함수 안에서 `$1` 은 첫 번째 입력값이다.

## 문제 14 해설

`$#` 는 입력값의 개수이다. `apple banana cherry` 이므로 3이다.

## 문제 16 해설

`${colors[@]}` 는 배열 전체를 의미한다.

# 마지막 체크

6주차에서 꼭 알고 넘어가면 좋은 것은 아래와 같다.

- 변수는 값을 저장한다.
- 조건문은 상황에 따라 다른 동작을 하게 한다.
- 반복문은 같은 일을 여러 번 할 때 쓴다.
- 함수는 자주 쓰는 코드를 묶어 둔다.
- `$1`, `$2`, `$#` 는 입력값과 관련 있다.
- 배열은 여러 값을 한 번에 저장한다.

한 번에 다 외우지 않아도 괜찮다.  
직접 작은 스크립트를 여러 번 만들어 보면 훨씬 빨리 익숙해진다.
