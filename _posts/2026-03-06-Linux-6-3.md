# 📖 풀이 및 해설

---

### 문제 1 해설 — 변수 선언

**정답: ② `name="홍길동"`**

Bash 변수 선언 규칙: `변수명=값` 형식이며, **등호(=) 양쪽에 공백이 없어야 함**.  
공백이 있으면 `name`을 명령어로 해석해 오류 발생.

---

### 문제 2 해설 — 거듭제곱

**정답: ③ 1000**

`**`는 거듭제곱 연산자. `$((10 ** 3))` = 10³ = 1000.

---

### 문제 3 해설 — 중괄호로 변수 구분

**정답: ② `${x}_log.txt`**

`$x_log.txt` 는 `x_log` 라는 이름의 변수를 찾음 → 빈 문자열 반환.  
`${x}` 로 변수명을 중괄호로 명확히 구분해야 함.

---

### 문제 4 해설 — expr 사용법

**정답: ③ `expr 10 + 5`**

`expr` 은 **각 토큰(숫자, 연산자) 사이에 공백** 이 있어야 함.  
`expr 10+5` 는 `10+5` 를 문자열로 인식해 그대로 출력.

---

### 문제 5 해설 — 파일 테스트 연산자

**정답: ② `[ -f /etc/passwd ]`**

| 옵션 | 의미 |
|---|---|
| `-f` | **일반 파일** 존재 |
| `-d` | **디렉터리** 존재 |
| `-r` | 읽기 권한 있음 |
| `-s` | 파일 크기 > 0 |

`/etc/passwd`는 일반 파일이므로 `-f` 가 올바름.

---

### 문제 6 해설 — 빈 문자열 테스트

**정답: ③ `[ -z "$str" ]`**

| 옵션 | 의미 |
|---|---|
| `-z` | **z**ero — 문자열 길이 = 0 (빈 문자열) |
| `-n` | **n**ot empty — 문자열 길이 > 0 |

---

### 문제 7 해설 — if-elif-else 흐름

**정답: ③ C**

`score=75`.
- `75 -ge 90`: 거짓
- `75 -ge 80`: 거짓
- `75 -ge 70`: **참** → `C` 출력

---

### 문제 8 해설 — 숫자 비교 연산자

**정답: ② `-ne`**

| 연산자 | 의미 | 수학 |
|---|---|---|
| `-eq` | **eq**ual (같다) | = |
| `-ne` | **n**ot **e**qual (같지 않다) | ≠ |
| `-lt` | **l**ess **t**han (작다) | < |
| `-ge` | **g**reater or **e**qual (크거나 같다) | ≥ |

---

### 문제 9 해설 — case 문 패턴 매칭

**정답: ② 파이썬**

`lang="python"` 이 `python)` 패턴과 일치 → `파이썬` 출력.  
`|` 는 case 문에서 OR 조건을 의미함.

---

### 문제 10 해설 — for 범위

**정답: ① `1 2 3 4 5`**

`{1..5}` 는 1부터 5까지의 시퀀스를 생성.  
`echo -n` 은 줄바꿈 없이 출력하므로 공백으로 구분되어 한 줄에 출력됨.

---

### 문제 11 해설 — while 반복 조건

**정답: ② count: 1, count: 2, count: 3**

`count=1` 시작, `count -le 3` 조건 확인:
- `1 ≤ 3`: 참 → 출력 후 count=2
- `2 ≤ 3`: 참 → 출력 후 count=3
- `3 ≤ 3`: 참 → 출력 후 count=4
- `4 ≤ 3`: 거짓 → 종료

---

### 문제 12 해설 — break/continue 흐름

**정답: ② 1 2 4 5**

- `i=1,2`: 출력
- `i=3`: `continue` → 건너뜀
- `i=4,5`: 출력
- `i=6`: `break` → 종료

출력: `1 2 4 5`

---

### 문제 13 해설 — until 문

**정답: ② 조건이 거짓인 동안 반복한다.**

- `while`: 조건이 **참**인 동안 반복
- `until`: 조건이 **거짓**인 동안 반복 (while의 반대)

---

### 문제 14 해설 — 명령어 치환으로 함수 반환값

**정답: ③ 합계: 10**

`add` 함수는 `echo $(( $1 + $2 ))` 로 결과를 출력.  
`$(add 7 3)` 명령어 치환으로 그 출력값(10)을 받아 `result`에 저장.

### 문제 15 해설 — $0

**정답: ② `$0`**

| 변수 | 의미 |
|---|---|
| `$0` | 스크립트 파일명 |
| `$1` | 첫 번째 인자 |
| `$#` | 인자 개수 |
| `$?` | 직전 명령 종료 코드 |

---

### 문제 16 해설 — $# 인자 개수

**정답: ③ 3**

`./test.sh apple banana cherry` 실행 시:
- `$0` = `./test.sh`
- `$1` = `apple`, `$2` = `banana`, `$3` = `cherry`
- `$#` = **3** (스크립트명 제외)

---

### 문제 17 해설 — $? 종료 코드

**정답: ④ `$?`**

- `$?` = 직전 명령의 **종료 코드** (0=성공, 비-0=실패)
- `$$` = 현재 셸의 PID

---

### 문제 18 해설 — local 변수 범위

**정답: ② 함수 내: 로컬 / 함수 밖: 전역**

`local outer="로컬"` 은 함수 내부에만 존재함. 함수 밖의 `outer="전역"` 은 영향받지 않음.  
이것이 `local` 키워드의 핵심 역할 — **로컬 변수는 함수 스코프에만 존재**.

---

### 문제 19 해설 — ##*/ 패턴 제거 (basename)

**정답: ② `photo.jpg`**

`${filepath##*/}`: 앞에서부터 가장 길게 `*/` 패턴 제거 → 마지막 `/` 이후만 남음.  
`basename /home/user/docs/photo.jpg` 와 동일한 결과.

`"Hello, World!"` 에서 0~4번 = `H`, `e`, `l`, `l`, `o` → `Hello`.

- `${s,,}` = 전체 소문자
- `${s,}` = 첫 글자만 소문자

### 문제 22 해설 — set -e

**정답: ③ 명령이 실패(0이 아닌 종료 코드)하면 스크립트를 즉시 종료한다.**

| 옵션 | 의미 |
|---|---|
| `set -e` (errexit) | 명령 실패 시 **즉시 종료** |
| `set -u` (nounset) | 미정의 변수 사용 시 오류 |
| `set -x` (xtrace) | 실행 명령 추적 출력 |
| `set -o pipefail` | 파이프 실패 감지 |

### 문제 23 해설 — :- vs :=

**정답: ② `${name:-'기본값'}`**

| 표현 | 의미 |
|---|---|
| `${var:-기본값}` | 비어있으면 기본값 사용 (변수 변경 **없음**) |
| `${var:=기본값}` | 비어있으면 기본값 사용 + 변수에 **저장** |
| `${var:+값}` | 비어있지 **않으면** 값 사용 |
| `${var:?메시지}` | 비어있으면 **오류 발생** |

### 문제 24 해설 — 2>&1 올바른 순서

**정답: ③ stdout과 stderr 모두 output.txt에 저장된다.**

`> output.txt 2>&1` 처리 순서:
1. `> output.txt`: stdout → output.txt
2. `2>&1`: stderr → stdout이 가리키는 곳(=output.txt)

---

### 문제 25 해설 — stderr 버리기

**정답: ② `cmd 2> /dev/null`**

- `2>`: stderr(FD 2) 리다이렉션
- `/dev/null`: 데이터를 버리는 특수 파일
- `cmd > /dev/null`: stdout을 버림 (에러는 여전히 화면에)
- `cmd &> /dev/null`: stdout + stderr 모두 버림

---

### 문제 26 해설 — 잘못된 2>&1 순서

**정답: ② stdout은 output.txt에, stderr는 화면에 출력된다.**

`2>&1 > output.txt` 처리 순서:
1. `2>&1`: stderr → 현재 stdout 방향 = **화면**
2. `> output.txt`: stdout → output.txt

stderr는 이미 화면 방향으로 복사된 상태이므로 화면에 출력됨.

---

### 문제 27 해설 — heredoc

**정답: ② 스크립트 내에서 여러 줄의 텍스트를 직접 stdin으로 전달하는 기능이다.**

| 기능 | 표기 | 설명 |
|---|---|---|
| 입력 리다이렉션 | `< file` | 파일을 stdin으로 |
| heredoc | `<< EOF` ... `EOF` | **여러 줄** 직접 입력 |
| here string | `<<< "문자열"` | 단 **한 줄** |
| 파이프 | `cmd1 \| cmd2` | stdout → stdin |

---

### 문제 28 해설 — pipefail

**정답: ② 1**

`pipefail` 켜진 상태:
- `false`: 종료 코드 1 (실패)
- `true`: 종료 코드 0 (성공)
- 파이프라인 중 하나라도 실패 → 전체 종료 코드 = **1**

`pipefail` 없으면 마지막 명령(`true`)의 종료 코드 0을 반환함.

---

### 문제 29 해설 — tee

**정답: ③ `cmd | tee output.txt`**

`tee`는 stdin을 받아 **stdout(화면) + 파일 양쪽으로 동시에 출력**함.

```
명령 → tee → 화면
              → 파일
```

---

### 문제 30 해설 — here string + read

**정답: ② apple**

`read -r first rest <<< "$data"` 에서:
- `data="apple banana cherry"`
- `read`는 첫 단어를 `first`에, 나머지를 `rest`에 할당
- `first` = `apple`
- `rest` = `banana cherry`

따라서 `echo "$first"` = `apple`.

### 문제 36 해설 — 팩토리얼

**정답: ④ `5! = 120`**

`n=5`, 1×2×3×4×5 = **120**.  
C 스타일 for 문 `((i=1; i<=5; i++))` 이 1부터 5까지 순서대로 곱함.

### 문제 37 해설 — `"$@"` 는 각 인자를 개별로

**정답: ③ `[apple pie]` / `[banana]`**

`"$@"` 는 각 인자를 **개별 문자열로 유지**함. 공백 포함 인자 `"apple pie"` 가 하나의 항목으로 처리됨.

### 문제 38 해설 — `declare -i` 정수형

**정답: ② `35`**

`declare -i x=10` 으로 정수형 선언.  
이후 `x=x*3+5` 는 **산술식으로 자동 해석** → `10×3+5 = 35`.  
일반 변수였다면 `x*3+5` 라는 문자열이 그대로 저장됨.

### 문제 39 해설 — IFS와 read

**정답: ② `beta` / `delta`**

`IFS=:` 로 구분자를 콜론으로 지정.  
`data="alpha:beta:gamma:delta"` → `a=alpha`, `b=beta`, `c=gamma`, `d=delta`.  
`echo "$b"` = `beta`, `echo "$d"` = `delta`.

---

### 문제 40 해설 — while로 passwd 파싱

**정답: ② `UID가 0인 사용자 수: 1`**

`/etc/passwd` 에서 UID(3번째 필드)가 0인 사용자는 일반적으로 **root** 하나임.  
`IFS=:` 로 콜론 구분, `uid` = 3번째 필드.  
`[ "$uid" -eq 0 ]` 조건에 맞는 것 = root = **1명**.
