# Day1~4 통합 토폴로지 완성 & 전 구간 패킷 추적 실습

---

# 1장. 오늘 할 일 한눈에 보기

---

오늘은 3단계로만 생각하면 됨.

1. 토폴로지를 완성한다
2. PC0에서 Server0 웹 페이지를 연다
3. 그다음 Simulation Mode로 패킷 흐름을 본다

> **반드시 순서를 지킴**  
> 먼저 Realtime Mode에서 성공하고,  
> 그다음 Simulation Mode로 분석함.

---

# 2장. 완성할 그림

---

```
PC0, PC1 -- Switch0 -- Router0 ==== Router1 -- Switch1 -- Server0
```

| 장비 | 값 |
|---|---|
| PC0 | `192.168.1.10 / 255.255.255.0 / GW 192.168.1.1` |
| PC1 | `192.168.1.20 / 255.255.255.0 / GW 192.168.1.1` |
| Router0 LAN | `192.168.1.1 / 255.255.255.0` |
| Router0 WAN | `10.0.0.1 / 255.255.255.252` |
| Router1 WAN | `10.0.0.2 / 255.255.255.252` |
| Router1 LAN | `192.168.2.1 / 255.255.255.0` |
| Server0 | `192.168.2.100 / 255.255.255.0 / GW 192.168.2.1` |

---

# 3장. 토폴로지 만들기

---

## Step 1 — 새 파일 열기

`File` → `New`

## Step 2 — 장비 배치

1. `PC` 2개 배치
2. `2960` 스위치 2개 배치
3. 라우터 2개 배치
4. `Server` 1개 배치

> 라우터에서 `Se0/0/0` 이 안 보이면 11강처럼 `Physical` 탭에서 `HWIC-2T` 모듈을 추가함.

## Step 3 — LAN A 연결

1. `PC0` ↔ `Switch0`
2. `PC1` ↔ `Switch0`
3. `Switch0` ↔ `Router0 g0/0`

> `g0/0` 대신 `fa0/0` 이 보이면 그 포트를 사용함.

## Step 4 — WAN 연결

1. `Serial DCE` 선택
2. `Router0 Se0/0/0` 클릭
3. `Router1 Se0/0/0` 클릭

## Step 5 — LAN B 연결

1. `Router1 g0/0` ↔ `Switch1`
2. `Switch1` ↔ `Server0`

---

# 4장. IP와 라우팅 설정

---

## Step 6 — PC0 설정

| 항목 | 값 |
|---|---|
| IP Address | `192.168.1.10` |
| Subnet Mask | `255.255.255.0` |
| Default Gateway | `192.168.1.1` |

## Step 7 — PC1 설정

| 항목 | 값 |
|---|---|
| IP Address | `192.168.1.20` |
| Subnet Mask | `255.255.255.0` |
| Default Gateway | `192.168.1.1` |

## Step 8 — Router0 설정

```
enable
configure terminal
hostname Router0
interface g0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit
interface s0/0/0
ip address 10.0.0.1 255.255.255.252
clock rate 64000
no shutdown
exit
ip route 192.168.2.0 255.255.255.0 10.0.0.2
end
```

> `g0/0` 대신 `fa0/0` 이면 그 부분만 바꿔서 입력함.

## Step 9 — Router1 설정

```
enable
configure terminal
hostname Router1
interface s0/0/0
ip address 10.0.0.2 255.255.255.252
no shutdown
exit
interface g0/0
ip address 192.168.2.1 255.255.255.0
no shutdown
exit
ip route 192.168.1.0 255.255.255.0 10.0.0.1
end
```

## Step 10 — Server0 설정

`Server0` → `Config` → `FastEthernet0`

| 항목 | 값 |
|---|---|
| IP Address | `192.168.2.100` |
| Subnet Mask | `255.255.255.0` |
| Default Gateway | `192.168.2.1` |

그리고 `Services` → `HTTP` → `On` 확인.

---

# 5장. 먼저 Realtime Mode에서 성공시키기

---

## Step 11 — Ping 순서대로 확인

PC0에서 아래 순서대로 실행.

```
ping 192.168.1.1
ping 10.0.0.2
ping 192.168.2.1
ping 192.168.2.100
```

> 마지막에 `Reply from 192.168.2.100` 이 보이면 통신 성공임.  
> TTL 숫자는 참고만 하고, 오늘의 핵심은 **웹 서버까지 도달하는 것**임.

## Step 12 — 웹 페이지 열기

`PC0` → `Desktop` → `Web Browser`

주소창에 입력:

```
http://192.168.2.100
```

페이지가 뜨면 성공.

> 여기서 안 뜨면 아직 Simulation Mode로 넘어가지 않음.  
> 먼저 IP, 케이블, `no shutdown`, `ip route`, HTTP On 여부를 다시 확인함.

---

# 6장. 그다음 Simulation Mode로 보기

---

## Step 13 — 필터 설정

1. `Simulation` 탭 클릭
2. `Edit Filters`
3. `Show All/None`
4. `ARP`, `TCP`, `HTTP` 만 선택

## Step 14 — 이벤트 만들기

1. 다시 `PC0` 브라우저 열기
2. `http://192.168.2.100` 입력
3. `Go`

이제 Event List가 생김.

## Step 15 — `Capture/Forward` 로 천천히 보기

초보자 기준으로 아래 4가지만 보면 충분함.

1. **ARP가 먼저 뜨는지**
2. **TCP SYN 이 보이는지**
3. **HTTP GET 이 보이는지**
4. **HTTP 200 OK 응답이 돌아오는지**

---

# 7장. 장비별로 무엇을 보면 좋은가

---

## 체크포인트 1 — PC0

`TCP SYN` 이나 `HTTP GET` 을 클릭했을 때:

- Source IP가 `192.168.1.10`
- Destination IP가 `192.168.2.100`

## 체크포인트 2 — Switch0

Switch는 주로 2계층 장비이므로,  
MAC 주소를 보고 전달한다고 이해하면 됨.

## 체크포인트 3 — Router0

여기서는 두 가지만 확인하면 충분함.

1. 목적지 IP는 여전히 `192.168.2.100`
2. TTL이 1 줄어듦

> 시리얼 구간은 이더넷 LAN 구간과 화면이 다르게 보일 수 있으므로,  
> 초보자는 **IP는 그대로, TTL은 감소**만 먼저 확인해도 충분함.

## 체크포인트 4 — Server0

`HTTP GET` 이 도착하고,  
다시 `HTTP 200 OK` 응답이 나가는지 확인함.

# 8장. 막히면 여기만 다시 보기

---

| 증상 | 먼저 확인할 것 |
|---|---|
| 192.168.1.1 Ping 실패 | PC0 설정, Router0 LAN 포트 IP, `no shutdown` |
| 10.0.0.2 Ping 실패 | 시리얼 케이블, 시리얼 IP, `clock rate 64000` |
| 192.168.2.100 Ping 실패 | 양쪽 `ip route` |
| Ping은 되는데 웹이 안 열림 | Server0 HTTP 서비스 `On` |
| Simulation이 너무 복잡함 | 필터를 `ARP`, `TCP`, `HTTP`만 남기기 |

---

# 정리

오늘 실습의 핵심은 이것임.  
PC0가 웹 서버에 접속할 수 있으면 네트워크 구성이 성공한 것이고,  
Simulation Mode는 그 성공한 통신을 천천히 해부해서 보는 도구임.
