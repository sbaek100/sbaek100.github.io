# 4-1 자주 쓰는 자료형

이번 글은 이론과 실습으로 나눠서 진행한다.

---

## 1부. 이론

### 1-1. 자료형이란?

자료형(Data Type)은 칼럼에 어떤 값을 저장할지 정하는 규칙이다.

### 1-2. 각 자료형 세부 설명 + 대표 사용

1. `INT`
- 정수 저장
- 대표 사용: 번호, 점수, 수량

2. `VARCHAR(n)`
- 길이가 달라지는 문자열 저장
- 대표 사용: 이름, 이메일, 도시

3. `TEXT`
- 긴 문자열 저장
- 대표 사용: 설명문, 후기, 본문

4. `DECIMAL(p, s)`
- 정확한 소수 저장
- 대표 사용: 가격, 정산 금액

5. `DATE`
- 날짜만 저장 (`YYYY-MM-DD`)
- 대표 사용: 생년월일, 출시일

6. `DATETIME`
- 날짜+시간 저장 (`YYYY-MM-DD HH:MM:SS`)
- 대표 사용: 생성시각, 주문시각

한 줄 정리:
- 정수는 `INT`, 일반 문자열은 `VARCHAR`, 긴 글은 `TEXT`, 금액은 `DECIMAL`, 날짜는 `DATE`, 날짜+시간은 `DATETIME`을 대표로 사용한다.

## 2부. 실습

```sql
CREATE DATABASE datatype_db;
USE datatype_db;

CREATE TABLE products (
  id INT,
  name VARCHAR(30),
  description TEXT,
  price DECIMAL(10,2),
  stock INT,
  release_date DATE,
  created_at DATETIME
);
```

```sql
INSERT INTO products VALUES (1, '아메리카노 원두', '산미가 적고 고소한 원두', 12900.50, 30, '2026-03-01', '2026-03-04 10:30:00');
INSERT INTO products VALUES (2, '드립백 세트', '사무실에서 간편하게 마시는 드립백', 8900.00, 50, '2026-03-02', '2026-03-04 10:35:00');
INSERT INTO products VALUES (3, '텀블러', '보온/보냉이 가능한 스테인리스 텀블러', 15900.00, 12, '2026-03-03', '2026-03-04 10:40:00');
```

```sql
SELECT * FROM products;
SELECT id, name, price FROM products WHERE price >= 10000;
SELECT id, name, release_date FROM products WHERE release_date >= '2026-03-02';
```
