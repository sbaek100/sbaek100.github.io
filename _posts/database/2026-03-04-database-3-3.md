# 실습 준비 — mapdonalds DB 및 burgers 테이블 생성

## DB 생성 및 테이블 구조

```sql
-- mapdonalds DB 생성 및 진입
CREATE DATABASE IF NOT EXISTS mapdonalds;
USE mapdonalds;

-- burgers 테이블 생성
CREATE TABLE burgers (
    id      INTEGER,         -- 아이디(정수형 숫자)
    name    VARCHAR(50),     -- 이름(문자형: 최대 50자)
    price   INTEGER,         -- 가격(정수형 숫자)
    gram    INTEGER,         -- 그램(정수형 숫자)
    kcal    INTEGER,         -- 열량(정수형 숫자)
    protein INTEGER,         -- 단백질량(정수형 숫자)
    PRIMARY KEY (id)         -- 기본키 지정: id
);
```

> 💡 교재 원본은 `AUTO_INCREMENT` 없이 `id`를 직접 지정하는 방식임.
> `burger_db`(2주차 실습)와 **다른 DB**이므로 반드시 `USE mapdonalds;` 실행 후 진행할 것.

# 셀프체크 풀이 (p.109)

## 문제 1. 가격이 6,000원 이상 7,000원 미만인 버거의 모든 칼럼을 조회하세요.

```sql
SELECT *
FROM burgers
WHERE price >= 6000
  AND price < 7000;
```

**결과:**

| id | name | price | gram | kcal | protein |
|----|------|-------|------|------|---------|
| 2 | 베이컨 토메이러 디럭스 | 6200 | 242 | 545 | 27 |
| 4 | 슈비두밥 버거 | 6200 | 269 | 563 | 21 |

> `BETWEEN 6000 AND 7000`은 7000 포함이므로 이 문제에서는 사용 불가.
> `>= 6000 AND < 7000` 조합으로 작성해야 7000원 미만 조건을 정확히 만족함.

---

## 문제 2. 열량이 500 미만이거나 단백질량이 25 이상인 버거의 모든 칼럼을 조회하세요.

```sql
SELECT *
FROM burgers
WHERE kcal < 500
   OR protein >= 25;
```

**결과:**

| id | name | price | gram | kcal | protein |
|----|------|-------|------|------|---------|
| 1 | 빅맥 | 5300 | 223 | 583 | 27 |
| 2 | 베이컨 토메이러 디럭스 | 6200 | 242 | 545 | 27 |
| 3 | 맨스파이시 상해 버거 | 5300 | 235 | 494 | 20 |
| 5 | 더블 쿼터파운드 치즈 | 7700 | 275 | 770 | 50 |

> 두 조건 중 **하나라도** 만족하면 포함이므로 `OR` 사용.
> 슈비두밥 버거(kcal 563, protein 21)는 두 조건 모두 해당 안 되므로 제외.

## 문제 3. 모든 버거의 100g당 가격을 조회하세요.

```sql
SELECT name               AS 버거이름,
       price * 100 / gram AS '100g당 가격'
FROM burgers;
```

**결과:**

| 버거이름 | 100g당 가격 |
|----------|------------|
| 빅맥 | 2376.6816 |
| 베이컨 토메이러 디럭스 | 2561.9835 |
| 맨스파이시 상해 버거 | 2255.3191 |
| 슈비두밥 버거 | 2305.5762 |
| 더블 쿼터파운드 치즈 | 2800.0000 |

> `price / gram * 100`이 아니라 `price * 100 / gram` 순서가 정수 나눗셈 오차를 줄임.
> 소수점 불필요 시 `ROUND(price * 100 / gram, 0)`으로 반올림 가능.

## 문제 4. 100g당 가격이 2,500원 미만인 버거를 조회하세요.

```sql
SELECT name               AS 버거이름,
       price              AS 가격,
       gram               AS '무게(g)',
       price * 100 / gram AS '100g당 가격'
FROM burgers
WHERE price * 100 / gram < 2500;
```

**결과:**

| 버거이름 | 가격 | 무게(g) | 100g당 가격 |
|----------|------|---------|------------|
| 빅맥 | 5300 | 223 | 2376.6816 |
| 맨스파이시 상해 버거 | 5300 | 235 | 2255.3191 |
| 슈비두밥 버거 | 6200 | 269 | 2305.5762 |

> `WHERE` 절에 `AS` 별칭을 쓰면 오류 발생.
> `WHERE` 절에는 반드시 계산식을 직접 작성해야 함.

## 문제 5. 1,000원당 들어 있는 단백질량을 계산해 조회하세요.

```sql
SELECT name                   AS 버거이름,
       protein / price * 1000 AS '1000원당 단백질량'
FROM burgers;
```

**결과:**

| 버거이름 | 1000원당 단백질량 |
|----------|-----------------|
| 빅맥 | 5.0943 |
| 베이컨 토메이러 디럭스 | 4.3548 |
| 맨스파이시 상해 버거 | 3.7736 |
| 슈비두밥 버거 | 3.3871 |
| 더블 쿼터파운드 치즈 | 6.4935 |

> 의미: 1,000원을 내면 단백질을 몇 g 섭취할 수 있는지.

## 문제 6. 1,000원당 들어 있는 단백질량이 5 이상인 버거를 조회하세요.

```sql
SELECT name                   AS 버거이름,
       protein / price * 1000 AS '1000원당 단백질량'
FROM burgers
WHERE protein / price * 1000 >= 5;
```

**결과:**

| 버거이름 | 1000원당 단백질량 |
|----------|-----------------|
| 빅맥 | 5.0943 |
| 더블 쿼터파운드 치즈 | 6.4935 |

> 문제 5 결과 기준으로 5 이상인 것은 빅맥(5.09)과 더블 쿼터파운드 치즈(6.49) 두 개.
> `WHERE` 절에 별칭 사용 불가 — 계산식을 그대로 반복해야 함.

## 전체 쿼리 통합본

```sql
-- DB 생성 및 테이블 준비
CREATE DATABASE IF NOT EXISTS mapdonalds;
USE mapdonalds;

CREATE TABLE burgers (
    id      INTEGER,
    name    VARCHAR(50),
    price   INTEGER,
    gram    INTEGER,
    kcal    INTEGER,
    protein INTEGER,
    PRIMARY KEY (id)
);

INSERT INTO burgers (id, name, price, gram, kcal, protein) VALUES
    (1, '빅맥',               5300, 223, 583, 27),
    (2, '베이컨 토메이러 디럭스', 6200, 242, 545, 27),
    (3, '맨스파이시 상해 버거',  5300, 235, 494, 20),
    (4, '슈비두밥 버거',        6200, 269, 563, 21),
    (5, '더블 쿼터파운드 치즈',  7700, 275, 770, 50);

-- 문제 1
SELECT * FROM burgers WHERE price >= 6000 AND price < 7000;

-- 문제 2
SELECT * FROM burgers WHERE kcal < 500 OR protein >= 25;

-- 문제 3
SELECT name AS 버거이름, price * 100 / gram AS '100g당 가격'
FROM burgers;

-- 문제 4
SELECT name AS 버거이름, price AS 가격, gram AS '무게(g)',
       price * 100 / gram AS '100g당 가격'
FROM burgers
WHERE price * 100 / gram < 2500;

-- 문제 5
SELECT name AS 버거이름, protein / price * 1000 AS '1000원당 단백질량'
FROM burgers;

-- 문제 6
SELECT name AS 버거이름, protein / price * 1000 AS '1000원당 단백질량'
```
