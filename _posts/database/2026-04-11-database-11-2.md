## 문제 1

**📌 문제:** 모든 학생의 이름(`name`)과 소속 학과명(`dept_name`)을 함께 출력하세요.
학과가 없는 학생과 학생이 없는 학과는 제외합니다.

**💡 힌트:** `INNER JOIN`, `ON students.dept_id = departments.dept_id`

```sql
SELECT s.name, d.dept_name
FROM students AS s
INNER JOIN departments AS d ON s.dept_id = d.dept_id;
```

## 문제 2

**📌 문제:** **전자공학과** 학생의 이름과 학년을 조회하세요. 학년 오름차순으로 정렬하세요.

**💡 힌트:** `INNER JOIN` + `WHERE d.dept_name = '전자공학과'` + `ORDER BY`

---

**✅ 답안:**

```sql
SELECT s.name, s.grade, d.dept_name
FROM students AS s
INNER JOIN departments AS d ON s.dept_id = d.dept_id
WHERE d.dept_name = '전자공학과'
ORDER BY s.grade ASC;
```

|------|-------|-----------|
| 박지호 | 1 | 전자공학과 |

| 최수아 | 3 | 전자공학과 |

## 문제 15

**📌 문제:** 소속 학생이 **2명 이상**인 학과의 이름과 학생 수를 출력하세요.

**💡 힌트:** `INNER JOIN` + `GROUP BY` + `HAVING COUNT(...) >= 2`

---

**✅ 답안:**

```sql
SELECT d.dept_name, COUNT(s.student_id) AS 학생수
FROM students AS s
INNER JOIN departments AS d ON s.dept_id = d.dept_id
GROUP BY d.dept_name
HAVING COUNT(s.student_id) >= 2;
```

**🖥️ 예상 결과:**

| dept_name | 학생수 |
|-----------|--------|
| 컴퓨터공학과 | 3 |
| 전자공학과 | 3 |
| 경영학과 | 2 |

> `WHERE`는 GROUP BY 전에 필터링하고, `HAVING`은 GROUP BY 후 집계 결과를 필터링합니다.

## 문제 17

**📌 문제:** 같은 학과에 소속된 학생끼리 **짝(쌍)**을 만들어 출력하세요. 중복 쌍은 제외합니다. (예: 김민준↔이서연 / 이서연↔김민준 중 하나만)

**💡 힌트:** SELF JOIN: `FROM students AS s1 INNER JOIN students AS s2 ON s1.dept_id = s2.dept_id AND s1.student_id < s2.student_id`

---

**✅ 답안:**

```sql
SELECT s1.name AS 학생1, s2.name AS 학생2, d.dept_name AS 학과명
FROM students AS s1
INNER JOIN students AS s2
    ON s1.dept_id = s2.dept_id
    AND s1.student_id < s2.student_id
INNER JOIN departments AS d ON s1.dept_id = d.dept_id
ORDER BY d.dept_name, s1.name;
```

**🖥️ 예상 결과:**

| 학생1 | 학생2 | 학과명 |
|-------|-------|--------|
| 정우진 | 한예린 | 경영학과 |
| 박지호 | 최수아 | 전자공학과 |
| 박지호 | 강태양 | 전자공학과 |
| 최수아 | 강태양 | 전자공학과 |
| 김민준 | 이서연 | 컴퓨터공학과 |
| 김민준 | 오시현 | 컴퓨터공학과 |
| 이서연 | 오시현 | 컴퓨터공학과 |

## 문제 18

**📌 문제:** 각 학과별 **평균 학년**을 소수점 한 자리로 출력하세요. 평균 학년이 높은 순서로 정렬하세요.

**💡 힌트:** `INNER JOIN` + `ROUND(AVG(...), 1)` + `GROUP BY` + `ORDER BY DESC`

---

**✅ 답안:**

```sql
SELECT d.dept_name, d.building, ROUND(AVG(s.grade), 1) AS 평균학년
FROM students AS s
INNER JOIN departments AS d ON s.dept_id = d.dept_id
GROUP BY d.dept_name, d.building
ORDER BY 평균학년 DESC;
```

**🖥️ 예상 결과:**

| dept_name | building | 평균학년 |
|-----------|----------|----------|
| 경영학과 | C동 | 3.0 |
| 컴퓨터공학과 | A동 | 2.0 |
| 전자공학과 | B동 | 2.0 |

## 문제 19

**📌 문제:** **3학년 이상** 학생을 학년 내림차순으로 정렬하여 **상위 3명**의 이름, 학년, 학과명을 출력하세요.

**💡 힌트:** `INNER JOIN` + `WHERE s.grade >= 3` + `ORDER BY DESC` + `LIMIT 3`

---

**✅ 답안:**

```sql
SELECT s.name, s.grade, d.dept_name
FROM students AS s
INNER JOIN departments AS d ON s.dept_id = d.dept_id
WHERE s.grade >= 3
ORDER BY s.grade DESC
LIMIT 3;
```

**🖥️ 예상 결과:**

| name | grade | dept_name |
|------|-------|-----------|
| 한예린 | 4 | 경영학과 |
| 최수아 | 3 | 전자공학과 |
| 오시현 | 3 | 컴퓨터공학과 |

## 문제 20

**📌 문제:** 모든 학과(학생이 없는 학과 포함)의 **종합 현황**을 출력하세요.
- 학과명, 건물, 학생 수, 평균 학년(소수점 1자리)을 포함합니다.
- 학생이 없는 학과는 학생 수 **0**, 평균 학년 **NULL**로 표시합니다.
- 학생 수 내림차순으로 정렬합니다.

**💡 힌트:** `RIGHT JOIN` + `COUNT()` + `ROUND(AVG(), 1)` + `GROUP BY` + `ORDER BY DESC`

---

**✅ 답안:**

```sql
SELECT
    d.dept_name              AS 학과명,
    d.building               AS 건물,
    COUNT(s.student_id)      AS 학생수,
    ROUND(AVG(s.grade), 1)   AS 평균학년
FROM students AS s
RIGHT JOIN departments AS d ON s.dept_id = d.dept_id
GROUP BY d.dept_id, d.dept_name, d.building
ORDER BY 학생수 DESC;
```

**🖥️ 예상 결과:**

| 학과명 | 건물 | 학생수 | 평균학년 |
|--------|------|--------|----------|
| 컴퓨터공학과 | A동 | 3 | 2.0 |
| 전자공학과 | B동 | 3 | 2.0 |
| 경영학과 | C동 | 2 | 3.0 |
| 수학과 | D동 | 0 | NULL |

> 💡 `COUNT(s.student_id)`는 NULL을 세지 않아 수학과가 0이 됩니다. `AVG(s.grade)`도 NULL을 제외하고 계산하므로 수학과는 NULL이 됩니다.
