# DB 만들기부터 CRUD 실습, 셀프체크까지

이번 글은 PDF 실습 파트만 먼저 흐름대로 정리한 뒤, 마지막에 p.87 셀프체크를 이어서 푸는 방식으로 정리했다.  
앞부분은 `mapdonalds` DB와 `burgers` 테이블로 CRUD를 연습하고, 뒷부분은 같은 구조를 `starbuuks` DB와 `coffees` 테이블에 옮겨 직접 풀어본 내용이다.

---

## 1. PDF 실습 발췌

### 1-1. 데이터베이스 생성하고 진입하기

실습은 새 데이터베이스를 만드는 것부터 시작한다.

```sql
CREATE DATABASE mapdonalds;
USE mapdonalds;
SELECT DATABASE();
```

- `CREATE DATABASE`: 새 DB 생성
- `USE`: 앞으로 작업할 DB 선택
- `SELECT DATABASE()`: 현재 어떤 DB를 사용 중인지 확인

---

### 1-2. burgers 테이블 만들기

실습용 버거 테이블은 다음과 같은 구조를 사용한다.

|id|name|price|gram|kcal|protein|
|---|---|---|---|---|---|
|1|빅맥|5300|223|583|27|
|2|베이컨 토마토 디럭스|6200|242|545|27|
|3|맥스파이시 상하이 버거|5300|235|494|20|
|4|슈비두밥 버거|6200|269|563|21|
|5|더블 쿼터파운드 치즈|7700|275|770|50|

```sql
CREATE TABLE burgers (
    id INTEGER,
    name VARCHAR(50),
    price INTEGER,
    gram INTEGER,
    kcal INTEGER,
    protein INTEGER,
    PRIMARY KEY (id)
);
```

테이블이 잘 만들어졌는지 구조를 확인할 때는 `DESC`를 사용한다.

```sql
DESC burgers;
```

---

### 1-3. 데이터 삽입하기

먼저 한 행만 넣어보고, 그다음 나머지 데이터를 한 번에 추가한다.

```sql
INSERT INTO burgers (id, name, price, gram, kcal, protein)
VALUES (1, '빅맥', 5300, 223, 583, 27);
```

```sql
INSERT INTO burgers (id, name, price, gram, kcal, protein)
VALUES
    (2, '베이컨 토마토 디럭스', 6200, 242, 545, 27),
    (3, '맥스파이시 상하이 버거', 5300, 235, 494, 20),
    (4, '슈비두밥 버거', 6200, 269, 563, 21),
    (5, '더블 쿼터파운드 치즈', 7700, 275, 770, 50);
```

특정 칼럼만 조회할 수도 있고, 전체를 조회할 수도 있다.

```sql
SELECT name, price
FROM burgers;
```

```sql
SELECT *
FROM burgers;
```

---

### 1-4. 데이터 수정하기

#### 모든 튜플 수정

PDF 실습에서는 모든 버거 가격을 1000원으로 바꾸는 예제를 먼저 보여준다.  
MySQL Workbench의 안전 모드 때문에 아래처럼 잠시 해제하고 수정한 뒤 다시 켠다.

```sql
SET SQL_SAFE_UPDATES = 0;

UPDATE burgers
SET price = 1000;

SET SQL_SAFE_UPDATES = 1;
```

확인은 다음과 같이 한다.

```sql
SELECT *
FROM burgers;
```

#### 특정 튜플 수정

특정 버거 하나만 수정할 때는 기본키를 기준으로 잡는 편이 안전하다.

```sql
UPDATE burgers
SET price = 500
WHERE id = 1;
```

```sql
SELECT *
FROM burgers;
```

- `WHERE name = '빅맥'`처럼도 가능하지만
- 실습과 실제 작업 모두에서 `WHERE id = 1`처럼 기본키를 기준으로 잡는 편이 더 안전하다

---

### 1-5. 데이터 삭제하기

특정 행 하나를 삭제할 때는 `DELETE`를 사용한다.

```sql
DELETE FROM burgers
WHERE id = 4;
```

```sql
SELECT *
FROM burgers;
```

테이블 자체를 삭제할 때는 `DROP TABLE`을 사용한다.

```sql
DROP TABLE burgers;
```

삭제 후 구조를 확인하면 더 이상 테이블이 없으므로 오류가 발생한다.

```sql
DESC burgers;
```

## 3. 셀프체크 p.87

이번에는 PDF 실습과 같은 흐름을 `coffees` 테이블로 직접 풀어본다.

### 문제 개요

`starbuuks` DB를 생성하고, 아래 구조의 `coffees` 테이블을 만들어 데이터를 관리하는 쿼리를 작성한다.

### 테이블 구조

|칼럼|자료형|설명|
|---|---|---|
|id|INT (기본키)|각 커피의 고유 식별자, 정수|
|name|VARCHAR(20)|커피 이름, 최대 20자|
|price|INT|커피 가격, 정수|

### 초기 데이터

|id|name|price|
|---|---|---|
|1|아메리카노|3800|
|2|카페라떼|4000|
|3|콜드브루|3500|
|4|카페모카|4500|
|5|카푸치노|5000|

---

### 3-1. starbuuks DB를 생성하고 진입하기

```sql
CREATE DATABASE starbuuks;
USE starbuuks;
```

- `starbuuks`는 문제에 적힌 이름 그대로 사용
- `USE`까지 해야 이후 작업이 해당 DB에서 실행됨

---

### 3-2. coffees 테이블 만들기

```sql
CREATE TABLE coffees (
    id INT NOT NULL AUTO_INCREMENT,
    name VARCHAR(20) NOT NULL,
    price INT NOT NULL,
    PRIMARY KEY (id)
);
```

- `id`는 기본키이면서 자동 증가
- `name`, `price`는 비워둘 수 없으므로 `NOT NULL`

---

### 3-3. 데이터 삽입하기

`id`는 `AUTO_INCREMENT`이므로 직접 넣지 않고 `name`, `price`만 삽입한다.

```sql
INSERT INTO coffees (name, price) VALUES
    ('아메리카노', 3800),
    ('카페라떼', 4000),
    ('콜드브루', 3500),
    ('카페모카', 4500),
    ('카푸치노', 5000);
```

문자열은 작은따옴표로 감싸야 하고, 각 행은 쉼표로 구분한다.

---

### 3-4. 모든 커피 이름 조회하기

```sql
SELECT name
FROM coffees;
```

이 쿼리는 `name` 칼럼만 조회한다.

예상 결과:

|name|
|---|
|아메리카노|
|카페라떼|
|콜드브루|
|카페모카|
|카푸치노|

---

### 3-5. 카푸치노 가격 200원 인상하기

```sql
UPDATE coffees
SET price = price + 200
WHERE id = 5;
```

- 기존 가격 5000원에서 200원을 더해 5200원으로 수정
- `WHERE`를 생략하면 모든 커피 가격이 함께 바뀌므로 주의
- 이름 기준보다 기본키 기준이 더 안전하므로 `id = 5`로 작성

---

### 3-6. 콜드브루 삭제하기

```sql
DELETE FROM coffees
WHERE id = 3;
```

- `DELETE FROM`은 행 단위 삭제
- `WHERE`를 빼면 테이블의 모든 데이터가 삭제됨

---

### 3-7. 최종 결과 조회하기

```sql
SELECT *
FROM coffees;
```

예상 결과:

|id|name|price|
|---|---|---|
|1|아메리카노|3800|
|2|카페라떼|4000|
|4|카페모카|4500|
|5|카푸치노|5200|

`id = 3`은 삭제되었기 때문에 보이지 않는다.  
`AUTO_INCREMENT`는 중간 번호를 자동으로 다시 채우지 않으므로 번호가 비어 있는 상태로 조회된다.

---

## 4. 셀프체크 전체 쿼리

```sql
CREATE DATABASE starbuuks;
USE starbuuks;

CREATE TABLE coffees (
    id INT NOT NULL AUTO_INCREMENT,
    name VARCHAR(20) NOT NULL,
    price INT NOT NULL,
    PRIMARY KEY (id)
);

INSERT INTO coffees (name, price) VALUES
    ('아메리카노', 3800),
    ('카페라떼', 4000),
    ('콜드브루', 3500),
    ('카페모카', 4500),
    ('카푸치노', 5000);

SELECT name
FROM coffees;

UPDATE coffees
SET price = price + 200
WHERE id = 5;

DELETE FROM coffees
WHERE id = 3;

SELECT *
FROM coffees;
```
