# 실습 1. apt 패키지 관리

---

## 1.1 패키지 목록 갱신 및 검색

```bash
# 저장소 목록 갱신 (업그레이드 아님)
sudo apt update
```

**예상 출력:**
```
Hit:1 http://archive.ubuntu.com/ubuntu noble InRelease
Get:2 http://archive.ubuntu.com/ubuntu noble-updates InRelease
...
Reading package lists... Done
```

> `Hit:`는 이미 최신, `Get:`는 새로 다운로드함을 의미함. 마지막 줄에 `Done`이 보이면 정상.
{: .prompt-info }

```bash
# 패키지 검색
apt search tree

# 패키지 상세 정보 확인
apt show tree
```

---

## 1.2 패키지 설치 및 확인

```bash
# tree 패키지 설치
sudo apt install -y tree

# 설치 확인
tree --version
which tree

# 설치된 파일 목록 확인
dpkg -L tree
```

**예상 출력:**
```
tree v2.1.1 (c) 1996 - 2023 ...
/usr/bin/tree
```

```bash
# tree로 디렉터리 구조 시각화
tree /etc/apt/
```

**예상 출력:**
```
/etc/apt/
├── apt.conf.d
│   ├── 01autoremove
│   └── ...
├── sources.list
└── sources.list.d
```

---

## 1.3 dpkg 활용

```bash
# 설치된 패키지 목록 확인
dpkg -l | head -20

# 특정 패키지 설치 여부 확인
dpkg -l | grep tree

# 파일이 어느 패키지에서 설치됐는지 확인
dpkg -S /usr/bin/ls
dpkg -S /bin/bash
```

**예상 출력:**
```
coreutils: /usr/bin/ls
bash: /bin/bash
```

**✅ 확인 포인트:**
- `dpkg -l`의 상태 코드: `ii`(정상 설치), `rc`(제거됐지만 설정 파일 남음)
- `dpkg -S` 로 파일의 출처 패키지를 역추적할 수 있음

# 실습 2. systemctl 서비스 관리

---

## 2.1 서비스 상태 확인

```bash
# 실행 중인 서비스 목록
systemctl list-units --type=service --state=running

# 특정 서비스 상태 확인 (ssh 서비스)
systemctl status ssh
```

**예상 출력 (active 상태):**
```
● ssh.service - OpenBSD Secure Shell server
     Loaded: loaded (/lib/systemd/system/ssh.service; enabled; ...)
     Active: active (running) since ...
   Main PID: 1234 (sshd)
```

> 상태 표시: `active (running)` = 정상 실행 중, `inactive (dead)` = 중지됨, `failed` = 오류로 중지됨
{: .prompt-info }

---

## 2.2 서비스 시작·중지·재시작

```bash
# cron 서비스 상태 확인
systemctl status cron

# 중지 → 확인 → 시작 → 확인
sudo systemctl stop cron
systemctl status cron

sudo systemctl start cron
systemctl status cron

# 재시작 (stop + start)
sudo systemctl restart cron
```

**중지 상태 예상 출력:**
```
● cron.service - Regular background program processing daemon
     Active: inactive (dead) since ...
```

---

## 2.3 부팅 자동 시작 설정

```bash
# 현재 enable 상태 확인
systemctl is-enabled cron
systemctl is-enabled ssh

# enable/disable 전환 확인
sudo systemctl disable cron
systemctl is-enabled cron    # → disabled

sudo systemctl enable cron
systemctl is-enabled cron    # → enabled
```

**예상 출력:**
```
enabled
disabled
enabled
```

---

## 2.4 커스텀 서비스 유닛 파일 작성

```bash
# 간단한 서비스 유닛 파일 작성
sudo tee /etc/systemd/system/hello.service << 'EOF'
[Unit]
Description=Hello World Service
After=network.target

[Service]
Type=oneshot
ExecStart=/bin/echo "Hello from systemd!"
RemainAfterExit=yes

[Install]
WantedBy=multi-user.target
EOF

# 유닛 파일 확인
systemctl cat hello.service

# systemd 재로드 (파일 수정 후 필수)
sudo systemctl daemon-reload

# 서비스 시작 및 상태 확인
sudo systemctl start hello.service
systemctl status hello.service
```

**예상 출력:**
```
● hello.service - Hello World Service
     Active: active (exited) since ...
```

> `oneshot` + `RemainAfterExit=yes` 조합은 한 번 실행하고 `active` 상태를 유지함. 초기화 스크립트에 자주 사용하는 패턴임.
{: .prompt-tip }

# 실습 3. .bashrc와 alias 설정

---

## 3.1 현재 alias 확인

```bash
# 설정된 alias 전체 확인
alias

# 특정 alias 확인
alias ls
alias grep
```

**예상 출력:**
```
alias grep='grep --color=auto'
alias ls='ls --color=auto'
```

---

## 3.2 alias 생성 및 해제

```bash
# 임시 alias 생성
alias ll='ls -alF'
alias la='ls -A'
alias ..='cd ..'
alias mydate='date "+%Y-%m-%d %H:%M:%S"'

# 생성된 alias 테스트
ll /etc | head -5
mydate

# alias 해제
unalias mydate

# alias를 우회하여 원래 명령 실행
\ls /etc | head -5
```

---

## 3.3 .bashrc에 영구 등록

```bash
# 현재 .bashrc 끝부분 확인
tail -20 ~/.bashrc

# .bashrc에 alias 추가
cat >> ~/.bashrc << 'EOF'

# === 커스텀 alias ===
alias ll='ls -alF'
alias la='ls -A'
alias ..='cd ..'
alias grep='grep --color=auto'
alias myip='ip addr show | grep "inet " | awk "{print \$2}"'
EOF

# 변경 사항 즉시 적용
source ~/.bashrc

# 적용 확인
alias ll
```

**✅ 확인 포인트:**
- `source` 없이 새 터미널을 열어도 alias가 유지되는지 확인
- `alias myip` 실행 후 현재 IP 출력 확인

# 실습 4. grep 텍스트 검색

---

## 4.1 기본 grep 사용

```bash
# /etc/passwd에서 bash 사용자 검색
grep "bash" /etc/passwd

# 줄 번호 포함
grep -n "bash" /etc/passwd

# 일치하는 줄 수
grep -c "bash" /etc/passwd

# 대소문자 무시
grep -i "ROOT" /etc/passwd
```

**예상 출력 예시:**
```
root:x:0:0:root:/root:/bin/bash
ubuntu:x:1000:1000:Ubuntu:/home/ubuntu:/bin/bash
```

---

## 4.2 역방향 grep과 재귀 검색

```bash
# nologin이 없는 줄 (bash 사용자만)
grep -v "nologin" /etc/passwd | grep -v "false"

# /etc 디렉터리에서 "ubuntu" 포함 파일 재귀 검색
grep -r "ubuntu" /etc/ 2>/dev/null | head -10

# 일치하는 파일 이름만 출력
grep -rl "ubuntu" /etc/ 2>/dev/null | head -5
```

---

## 4.3 파이프와 조합

```bash
# 실행 중인 프로세스에서 특정 프로세스 찾기
ps aux | grep ssh

# 시스템 로그에서 오류 메시지 검색
grep -i "error" /var/log/syslog 2>/dev/null | tail -5

# 여러 패턴 동시 검색 (OR)
grep -E "bash|sh$" /etc/passwd

# 파일에서 특정 행 앞뒤 맥락 포함
grep -n -A 2 -B 1 "root" /etc/passwd | head -20
```

**✅ 확인 포인트:**

| 옵션 | 동작 확인 |
|---|---|
| `-i` | ROOT, Root, root 모두 찾아지는가 |
| `-v` | 지정 패턴이 없는 줄만 나오는가 |
| `-c` | 숫자(줄 수)만 출력되는가 |
| `-r` | 디렉터리 전체 재귀 검색되는가 |

# 실습 5. find 파일 탐색

---

## 5.1 기본 find 사용

```bash
# 현재 디렉터리에서 .conf 파일 찾기
find /etc -name "*.conf" 2>/dev/null | head -10

# 디렉터리만 찾기
find /home -type d 2>/dev/null

# 일반 파일만 찾기
find /tmp -type f 2>/dev/null
```

---

## 5.2 크기와 시간 조건

```bash
# 10KB 이상 파일 찾기
find /etc -size +10k -type f 2>/dev/null | head -5

# 1시간 이내에 접근한 파일
find /var/log -atime -1 2>/dev/null | head -5

# 1일 이내에 수정된 파일
find /etc -mtime -1 2>/dev/null | head -5
```

---

## 5.3 -exec 활용

```bash
# 찾은 파일에 ls -l 적용
find /etc -name "*.conf" -type f -exec ls -lh {} \; 2>/dev/null | head -10

# /tmp에서 빈 파일 찾아서 목록 출력
find /tmp -type f -empty 2>/dev/null

# SUID 파일 찾기 (보안 점검 기법)
find /usr/bin -perm -4000 -type f 2>/dev/null
```

**예상 출력 (SUID 파일):**
```
/usr/bin/passwd
/usr/bin/sudo
/usr/bin/su
```

**✅ 확인 포인트:**
- `-exec {} \;` 에서 `{}`는 찾은 파일 경로, `\;`는 명령 종료 표시
- `2>/dev/null`로 권한 오류 메시지를 숨기는 습관을 들일 것

# 실습 6. stat과 wc

---

## 6.1 stat으로 파일 상세 정보

```bash
# /etc/passwd 상세 정보
stat /etc/passwd

# 특정 항목만 출력 (format 옵션)
stat -c "%n %s %U %G %A" /etc/passwd
# 출력: 파일명 크기 소유자 그룹 권한
```

**예상 출력:**
```
  File: /etc/passwd
  Size: 2847        Blocks: 8          IO Block: 4096   regular file
Device: ...         Inode: 131073      Links: 1
Access: (0644/-rw-r--r--)  Uid: (    0/    root)   Gid: (    0/    root)
Access: 2026-03-07 10:00:00.000000000 +0900
Modify: 2026-03-07 09:00:00.000000000 +0900
Change: 2026-03-07 09:00:00.000000000 +0900
```

```bash
# 파일 수정 후 시간 변화 확인
touch /tmp/test_stat.txt
stat /tmp/test_stat.txt

# 내용 수정 → mtime+ctime 변화
echo "hello" >> /tmp/test_stat.txt
stat /tmp/test_stat.txt

# 권한만 변경 → ctime만 변화
chmod 755 /tmp/test_stat.txt
stat /tmp/test_stat.txt
```

**✅ 확인 포인트:**

| 동작 | atime | mtime | ctime |
|---|---|---|---|
| 파일 읽기 | 갱신 | 유지 | 유지 |
| 내용 수정 | 갱신 | 갱신 | 갱신 |
| 권한/소유자 변경 | 유지 | 유지 | 갱신 |

---

## 6.2 wc로 파일 통계

```bash
# /etc/passwd 줄/단어/바이트 수
wc /etc/passwd

# 줄 수만
wc -l /etc/passwd

# 파이프와 조합
ps aux | wc -l        # 프로세스 개수 + 헤더 1줄
ls /etc | wc -l       # /etc 항목 개수

# 여러 파일 동시 통계
wc -l /etc/passwd /etc/group /etc/hosts
```

**예상 출력:**
```
  35  55 2847 /etc/passwd
 ...
```

# 실습 7. df와 du 디스크 관리

---

## 7.1 df로 파티션 공간 확인

```bash
# 전체 디스크 사용량
df -h

# 파일 시스템 타입 포함
df -hT

# inode 사용량 확인
df -i

# 특정 경로 확인
df -h /
df -h /tmp
```

**예상 출력:**
```
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1        20G  5.2G   14G  28% /
tmpfs           2.0G     0  2.0G   0% /dev/shm
```

---

## 7.2 du로 디렉터리 용량 분석

```bash
# 현재 디렉터리 총 용량
du -sh .

# /var 하위 1단계 용량 비교
du -h --max-depth=1 /var 2>/dev/null | sort -rh | head -10

# /etc 내 큰 파일/디렉터리 찾기
du -h /etc/* 2>/dev/null | sort -rh | head -10
```

**예상 출력:**
```
52M     /var/lib
12M     /var/log
4.0M    /var/cache
```

```bash
# 실전 시나리오: 디스크가 꽉 찼을 때 범인 찾기
du -sh /* 2>/dev/null | sort -rh | head -10
```

**✅ 확인 포인트:**
- `df -h`는 파티션 전체 상황, `du -sh`는 특정 경로 용량
- `-h`는 사람이 읽기 쉬운 단위, `-s`는 하위 합산 총합만

# 실습 8. tar 압축·해제

---

## 8.1 실습 파일 준비

```bash
# 실습용 디렉터리와 파일 생성
mkdir -p /tmp/tar_test/subdir
echo "파일1 내용" > /tmp/tar_test/file1.txt
echo "파일2 내용" > /tmp/tar_test/file2.txt
echo "서브 파일" > /tmp/tar_test/subdir/sub.txt
ls -R /tmp/tar_test/
```

---

## 8.2 tar 묶기와 압축

```bash
# 1) 묶기만 (압축 없음)
tar cvf /tmp/backup.tar /tmp/tar_test/

# 2) gzip 압축 (가장 일반적)
tar cvzf /tmp/backup.tar.gz /tmp/tar_test/

# 3) bzip2 압축 (더 높은 압축률)
tar cvjf /tmp/backup.tar.bz2 /tmp/tar_test/

# 파일 크기 비교
ls -lh /tmp/backup.tar /tmp/backup.tar.gz /tmp/backup.tar.bz2
```

**예상 출력:**
```
/tmp/tar_test/
/tmp/tar_test/file1.txt
/tmp/tar_test/file2.txt
/tmp/tar_test/subdir/
/tmp/tar_test/subdir/sub.txt
```

---

## 8.3 tar 내용 확인 및 압축 해제

```bash
# 내용 확인 (압축 해제 없이)
tar tvf /tmp/backup.tar.gz

# 압축 해제 (현재 위치)
mkdir /tmp/extract_test
cd /tmp/extract_test
tar xvzf /tmp/backup.tar.gz

# 특정 경로에 압축 해제 (-C 옵션)
mkdir /tmp/extract2
tar xvzf /tmp/backup.tar.gz -C /tmp/extract2/

# 결과 확인
ls -R /tmp/extract2/
```

**✅ 확인 포인트:**

| 작업 | 명령어 패턴 |
|---|---|
| 묶기+gzip 압축 | `tar cvzf 아카이브.tar.gz 경로/` |
| 내용 확인 | `tar tvf 아카이브.tar.gz` |
| 압축 해제 | `tar xvzf 아카이브.tar.gz` |
| 특정 경로에 해제 | `tar xvzf 아카이브.tar.gz -C /경로/` |

> `c`=묶기, `x`=풀기, `t`=목록, `v`=상세출력, `z`=gzip, `j`=bzip2, `f`=파일지정. `f`는 항상 마지막 옵션!
{: .prompt-danger }

# 실습 9. read와 tr 입출력 처리

---

## 9.1 read 사용

```bash
# 기본 입력
read myvar
echo "입력한 값: $myvar"

# 프롬프트 표시 입력
read -p "이름을 입력하세요: " username
echo "안녕하세요, ${username}님!"

# 비밀번호 입력 (화면 숨김)
read -s -p "비밀번호: " password
echo ""
echo "비밀번호 길이: ${#password}자"

# 타임아웃 설정 (5초)
read -t 5 -p "5초 안에 입력하세요: " input && echo "입력: $input" || echo "시간 초과"
```

---

## 9.2 tr 문자 변환

```bash
# 소문자 → 대문자
echo "hello world" | tr 'a-z' 'A-Z'
# 출력: HELLO WORLD

# 대문자 → 소문자
echo "HELLO LINUX" | tr 'A-Z' 'a-z'
# 출력: hello linux

# 숫자 제거
echo "abc 123 def 456" | tr -d '0-9'
# 출력: abc  def

# 공백을 밑줄로 변환
echo "hello world linux" | tr ' ' '_'
# 출력: hello_world_linux

# 연속 공백 압축
echo "hello     world" | tr -s ' '
# 출력: hello world

# 줄바꿈 제거 (여러 줄을 한 줄로)
printf "line1\nline2\nline3\n" | tr -d '\n'
# 출력: line1line2line3
```

**✅ 확인 포인트:**

| 패턴 | 명령어 |
|---|---|
| 소→대 | `tr 'a-z' 'A-Z'` |
| 대→소 | `tr 'A-Z' 'a-z'` |
| 숫자 제거 | `tr -d '0-9'` |
| 공백→밑줄 | `tr ' ' '_'` |

## 종합 실습: 명령어 조합

```bash
# 1. /etc/passwd에서 bash 사용자의 홈 디렉터리 용량 확인
grep "bash$" /etc/passwd | cut -d: -f6 | while read dir; do
  du -sh "$dir" 2>/dev/null
done

# 2. /var/log에서 오늘 수정된 로그 파일 목록
find /var/log -type f -mtime 0 2>/dev/null | head -10

# 3. 시스템에서 가장 큰 파일 Top 5
find / -type f -size +1M 2>/dev/null | xargs ls -lh 2>/dev/null | sort -k5 -rh | head -5

# 4. 실행 중인 프로세스 수 (헤더 제외)
ps aux | grep -v "^USER" | wc -l

# 5. /etc에서 "server" 라는 단어가 들어간 설정 파일 찾기
grep -rl "server" /etc/ 2>/dev/null | grep "\.conf$" | head -5

# 6. 로그 파일에서 ERROR 줄만 모아서 파일로 저장
grep -i "error" /var/log/syslog 2>/dev/null > /tmp/errors.txt
wc -l /tmp/errors.txt
```
