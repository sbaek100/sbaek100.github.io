# 6부. 내 PC에 AI 설치하기
---
## 1. Ollama 소개와 설치 준비

### Ollama란?

![](/assets/img/posts/2026-03-04-project-6-1774221695450.png)

> **Ollama**는 내 컴퓨터에서 LLM(대규모 언어 모델)을 쉽게 내려받고, 실행하고, API로 연결할 수 있게 도와주는 도구임.

쉽게 말하면, ChatGPT 같은 AI 모델을 인터넷 서비스에만 의존하지 않고 **내 PC 안에서 직접 실행할 수 있도록 관리해 주는 실행 환경**이라고 보면 됨.

### 왜 Ollama를 사용할까?

| 항목 | 설명 |
| --- | --- |
| **로컬 실행** | 모델을 내 PC에서 직접 실행하므로 데이터가 외부 서버로 나가지 않음 |
| **쉬운 설치** | 복잡한 환경 설정 없이 비교적 간단하게 설치 가능 |
| **다양한 모델 지원** | 여러 공개 LLM을 같은 방식으로 실행 가능 |
| **API 제공** | `http://localhost:11434` 로 API를 제공하므로 Python, 웹, 앱과 쉽게 연동 가능 |
| **학습/실습에 적합** | 작은 모델부터 시작해서 AI 실습 환경을 만들기 좋음 |

### LLM이란?

LLM(Large Language Model)은 대량의 텍스트 데이터를 학습하여 다음과 같은 작업을 수행할 수 있는 AI 모델임.

- 질문에 답하기
- 문장 요약하기
- 번역하기
- 코드 설명하기
- 문서 초안 만들기
- 아이디어 정리하기

즉, 사람이 입력한 문장을 이해하고 그에 맞는 자연어 응답을 생성하는 모델이라고 볼 수 있음.

### 내 PC에서 LLM을 돌릴 때 알아둘 점

LLM은 모델 크기에 따라 요구 자원이 크게 달라짐. 처음 실습할 때는 **4B 이하의 작은 모델**부터 시작하는 것이 좋음.

| 모델 크기 | 특징 | 권장 상황 |
| --- | --- | --- |
| **1B 이하** | 매우 가볍고 빠름, 성능은 제한적일 수 있음 | 테스트, 입문, 저사양 PC |
| **1B~4B** | 속도와 성능의 균형이 좋음 | 개인 실습, 간단한 채팅, Python 연동 |
| **7B 이상** | 답변 품질이 좋아질 수 있으나 메모리 사용량 증가 | 고사양 PC, 본격 실험 |

### Windows 기준 설치 개요

Ollama 공식 문서 기준으로 Windows에서 설치하면:

- Windows 10 22H2 이상 또는 Windows 11 환경에서 사용 가능
- 설치 후 백그라운드에서 Ollama가 실행됨
- PowerShell, CMD, 터미널에서 `ollama` 명령 사용 가능
- 기본 API 주소는 `http://localhost:11434`

### Ollama 설치 방법

#### 방법 1. 설치 파일로 설치

가장 쉬운 방법은 Ollama 공식 Windows 설치 파일을 사용하는 것임.

1. Ollama Windows 다운로드 페이지에 접속
2. 설치 파일 다운로드
3. 일반 프로그램 설치하듯 진행
4. 설치 후 PowerShell을 새로 열기
   
![](/assets/img/posts/2026-03-04-project-6-1774221727198.png)


#### 방법 2. PowerShell에서 설치

공식 다운로드 페이지에는 PowerShell 설치 명령도 안내됨.

```powershell
irm https://ollama.com/install.ps1 | iex
```

설치가 끝난 뒤에는 버전 확인으로 정상 설치 여부를 확인할 수 있음.

```powershell
ollama --version
```

![](/assets/img/posts/2026-03-04-project-6-1774221776638.png)
### 설치 후 확인할 것

```powershell
ollama
```

최근 Ollama는 `ollama` 명령만 입력해도 간단한 인터랙티브 메뉴를 열 수 있음. 여기서 모델 실행이나 여러 연동 기능 진입이 가능함.

또는 직접 서버 형태로 실행하려면 다음 명령을 사용함.

```powershell
ollama serve
```

보통 Windows에서는 설치 후 백그라운드에서 자동으로 실행되는 경우가 많으므로, 실습에서는 별도로 `serve`를 매번 실행하지 않아도 되는 경우가 많음.

### 모델 저장 위치 변경

모델 파일은 용량이 크기 때문에 저장 위치를 바꾸고 싶을 수 있음. 이때는 사용자 환경 변수 `OLLAMA_MODELS`를 설정하면 됨.

예:

```powershell
$env:OLLAMA_MODELS="D:\OllamaModels"
```

다만 위 방식은 현재 세션에만 임시 적용될 수 있으므로, 실제로는 Windows 사용자 환경 변수에 등록하는 것이 일반적임.

### 실습 전 체크리스트

| 점검 항목 | 확인 내용 |
| --- | --- |
| Ollama 설치 완료 | `ollama --version` 실행 가능 |
| 백그라운드 실행 여부 | API가 `localhost:11434` 에서 동작 |
| 디스크 여유 공간 | 최소 수 GB 이상 확보 권장 |
| PowerShell 사용 가능 | 명령 실행 및 테스트 가능 |
| Python 설치 여부 | 뒤의 Python 연동 실습 준비 |

## 2. Ollama에서 LLM 살펴보기

### "설치 가능한 모델"과 "이미 설치한 모델"은 다름

Ollama를 처음 사용할 때 많이 헷갈리는 부분이 이것임.

| 구분 | 의미 |
| --- | --- |
| **Ollama 라이브러리 모델** | Ollama 사이트에서 제공하는, 앞으로 설치할 수 있는 모델 목록 |
| **내 PC에 설치된 모델** | 내가 이미 `pull` 또는 `run` 해서 다운로드한 모델 목록 |

즉, Ollama 사이트의 라이브러리를 보는 것은 **설치 후보를 찾는 과정**이고, `ollama ls`는 **내 컴퓨터에 이미 내려받은 모델 목록**을 보는 명령임.

### 설치된 모델 목록 확인

```powershell
ollama ls
```

이 명령은 현재 내 PC에 다운로드된 모델 목록을 보여줌.

예를 들어 다음과 같은 정보를 볼 수 있음.

- 모델 이름
- 태그(tag)
- 크기(size)
- 수정 시각

### 현재 실행 중인 모델 확인

```powershell
ollama ps
```

이 명령은 메모리에 올라와 현재 실행 중인 모델을 확인할 때 사용함.

### Ollama 라이브러리에서 모델 고르기

설치 가능한 전체 모델은 Ollama 라이브러리 페이지에서 확인하는 것이 가장 좋음.

모델을 고를 때는 다음 요소를 함께 봐야 함.

| 기준 | 설명 |
| --- | --- |
| **파라미터 크기** | `1b`, `3b`, `4b`, `7b` 처럼 표시되며 대체로 숫자가 클수록 무거움 |
| **용도** | 일반 대화, 코드, 임베딩, 비전 등 |
| **언어 성능** | 한국어/영어 처리 품질 차이가 있을 수 있음 |
| **하드웨어 여건** | 메모리와 GPU 상황에 따라 선택 범위가 달라짐 |

### 입문용으로 추천할 만한 4B 이하 모델 예시

아래는 입문자가 연습하기 좋은 소형 모델 예시임.

| 모델 | 크기 | 특징 | 예시 명령 |
| --- | --- | --- | --- |
| `gemma3:270m` | 270M | 매우 가벼움, 테스트용 | `ollama run gemma3:270m` |
| `gemma3:1b` | 1B | 가볍고 빠른 입문용 | `ollama run gemma3:1b` |
| `llama3.2:1b` | 1B | 경량 대화용 | `ollama run llama3.2:1b` |
| `qwen2.5:1.5b` | 1.5B | 작은 크기 대비 성능 기대 가능 | `ollama run qwen2.5:1.5b` |
| `llama3.2` | 3B | 기본 태그가 3B 계열 | `ollama run llama3.2` |
| `gemma3:4b` | 4B | 4B 이하에서 비교적 강력한 편 | `ollama run gemma3:4b` |

### 처음에는 어떤 모델이 좋을까?

처음 학습용으로는 다음 기준을 추천함.

| 상황 | 추천 모델 |
| --- | --- |
| 아주 가볍게 테스트만 해보고 싶다 | `gemma3:270m` 또는 `gemma3:1b` |
| 채팅 품질과 속도의 균형이 필요하다 | `llama3.2` 또는 `qwen2.5:1.5b` |
| 4B 이하에서 조금 더 성능을 원한다 | `gemma3:4b` |

### 모델 이름과 태그 읽는 법

예를 들어 `gemma3:1b`는 다음처럼 읽으면 됨.

| 부분 | 의미 |
| --- | --- |
| `gemma3` | 모델 계열 이름 |
| `:1b` | 10억(1 billion) 파라미터 크기 태그 |

태그를 생략하면 기본 태그가 실행되는 경우가 있음. 예를 들어 `llama3.2`는 기본적으로 3B 계열 태그를 가리키는 방식으로 많이 사용됨.

## 3. 4B 이하 LLM 다운로드하기

### 가장 쉬운 방법: `run` 명령

다음 명령은 모델이 아직 없으면 자동으로 다운로드하고, 다운로드가 끝나면 바로 채팅 모드로 진입함.

```powershell
ollama run gemma3:1b
```

이 명령 하나로 다음 작업이 한 번에 이루어짐.

1. 모델 존재 여부 확인
2. 없으면 다운로드
3. 모델 로드
4. 대화 시작

### 다운로드만 먼저 하고 싶다면 `pull`

모델을 미리 받아두기만 하고, 나중에 실행하고 싶다면 `pull` 명령을 사용함.

```powershell
ollama pull gemma3:1b
```

또는 4B 모델을 받고 싶다면:

```powershell
ollama pull gemma3:4b
```

### 다운로드 예시 흐름

```powershell
ollama pull gemma3:1b
ollama ls
ollama run gemma3:1b
```

위 흐름은 다음 의미를 가짐.

- 먼저 모델 다운로드
- 다운로드가 완료되었는지 목록 확인
- 그 후 실제 채팅 실행

### 모델 삭제하기

실습 후 공간이 부족하면 모델을 삭제할 수도 있음.

```powershell
ollama rm gemma3:1b
```

### 어떤 모델을 실제 실습용으로 받는 것이 좋을까?

초보 실습 기준으로는 아래 조합이 무난함.

| 목적            | 추천                                         |
| ------------- | ------------------------------------------ |
| 첫 테스트         | `gemma3:1b`                                |
| 조금 더 자연스러운 대화 | `llama3.2`                                 |
| 소형 모델 비교 실험   | `gemma3:1b`, `qwen2.5:1.5b`, `llama3.2:1b` |

### 다운로드가 오래 걸리는 이유

모델은 일반 프로그램보다 용량이 큰 편이므로 네트워크 속도와 저장 장치 성능의 영향을 많이 받음. 또한 다운로드 후 모델을 메모리에 로드하는 시간도 필요함.

### 자주 만나는 문제

| 문제 | 원인 가능성 | 해결 방법 |
| --- | --- | --- |
| 명령을 찾을 수 없음 | PATH 반영 전 | PowerShell 재실행 |
| 모델 다운로드 실패 | 네트워크 문제 | 다시 실행 |
| 실행이 너무 느림 | 모델이 PC 사양보다 큼 | 더 작은 모델 사용 |
| 저장 공간 부족 | 모델 파일 용량 큼 | 다른 모델 삭제 또는 저장 위치 변경 |

## 4. LLM과 채팅하기

### 기본 채팅 시작

가장 기본적인 채팅은 다음 명령으로 시작함.

```powershell
ollama run gemma3:1b
```

실행 후 프롬프트에 질문을 입력하면 모델이 응답함.

예:

```text
안녕하세요. 너는 어떤 일을 할 수 있어?
```

### 첫 질문 예시

처음에는 다음과 같은 질문으로 테스트하면 좋음.

- "자기소개를 3문장으로 해줘."
- "Python이 무엇인지 초보자 눈높이로 설명해줘."
- "내가 오늘 할 일을 체크리스트로 정리해줘."
- "로컬 LLM과 클라우드 AI의 차이를 설명해줘."

### 좋은 질문을 만드는 방법

LLM은 질문이 구체적일수록 답변 품질이 좋아지는 경우가 많음.

| 나쁜 질문 | 더 좋은 질문 |
| --- | --- |
| AI 설명해줘 | 로컬 AI와 클라우드 AI의 차이를 표로 설명해줘 |
| Python 알려줘 | Python 입문자가 1주일 동안 공부할 내용을 단계별로 정리해줘 |
| 요약해줘 | 아래 문장을 5줄로 요약해줘 |

### 답변 품질을 높이는 프롬프트 예시

```text
너는 친절한 AI 튜터야.
초보자도 이해할 수 있게 설명하고,
어려운 용어는 쉬운 말로 다시 풀어서 설명해줘.
Ollama가 무엇인지 5문장 이내로 정리해줘.
```

### 여러 줄 입력하기

Ollama CLI는 여러 줄 입력도 가능함. 문단 단위로 길게 질문하거나 문서 일부를 넣고 요약을 요청할 수 있음.

```text
"""
다음 문장을 요약해줘.
Ollama는 로컬 환경에서 대규모 언어 모델을 실행할 수 있도록 돕는 도구이다.
사용자는 다양한 공개 모델을 설치하고 API 형태로 활용할 수 있다.
"""
```

### 채팅 실습 예시 1. 개념 설명

```text
LLM과 일반 프로그램의 차이를 예시와 함께 설명해줘.
```

### 채팅 실습 예시 2. 요약

```text
아래 내용을 3줄로 요약해줘.
파이썬은 다양한 분야에서 사용되는 범용 프로그래밍 언어이다.
웹 개발, 데이터 분석, 인공지능, 자동화 등에 널리 활용된다.
문법이 비교적 쉬워 입문자도 빠르게 시작할 수 있다.
```

### 채팅 실습 예시 3. 코드 도움받기

```text
Python에서 리스트와 튜플의 차이를 표로 정리해줘.
```

### 실행 중 모델 확인 및 종료

채팅을 여러 번 하다 보면 어떤 모델이 메모리에 올라와 있는지 확인하고 싶을 수 있음.

```powershell
ollama ps
```

필요 시 실행 중인 모델을 중지할 수 있음.

```powershell
ollama stop gemma3:1b
```

### 로컬 LLM 사용 시 주의점

| 항목 | 설명 |
| --- | --- |
| **정확성 한계** | 그럴듯하지만 틀린 답을 할 수 있음 |
| **모델 크기 한계** | 작은 모델은 복잡한 추론이나 긴 문서 처리에 약할 수 있음 |
| **최신 정보 부족** | 인터넷 검색 기능 없이 최신 정보를 모를 수 있음 |
| **속도 차이** | CPU만 사용할 때 응답 속도가 느릴 수 있음 |

즉, LLM은 "항상 정답을 말하는 계산기"가 아니라, **확률적으로 적절한 문장을 생성하는 도구**라는 점을 기억해야 함.

## 5. Python으로 Ollama 연동하기

### 왜 Python과 연동할까?

Ollama를 Python과 연결하면 단순 채팅을 넘어서 다음과 같은 작업이 가능해짐.

- 프로그램 안에서 자동으로 질문 보내기
- 응답을 가공해서 저장하기
- 문서 요약 자동화
- 질의응답 프로그램 만들기
- 로그 분석, 보고서 초안 작성, 데이터 설명 생성

즉, Ollama를 단순 채팅 도구가 아니라 **내 코드에서 호출 가능한 AI 엔진**으로 활용할 수 있게 됨.

### 준비 사항

| 항목 | 설명 |
| --- | --- |
| Python 설치 | Python 3 환경 권장 |
| Ollama 실행 가능 | `ollama` 명령 사용 가능 |
| 사용할 모델 다운로드 | 예: `gemma3:1b` |
| 패키지 설치 | Python용 `ollama` 라이브러리 설치 |

### Python 라이브러리 설치

공식 Python 라이브러리는 다음과 같이 설치할 수 있음.

```powershell
pip install ollama
```

가상환경을 사용하는 경우에는 먼저 가상환경을 활성화한 뒤 설치하면 됨.

### 가장 간단한 Python 채팅 예제

```python
from ollama import chat

response = chat(
    model='gemma3:1b',
    messages=[
        {'role': 'user', 'content': 'Ollama가 무엇인지 3문장으로 설명해줘.'}
    ]
)

print(response.message.content)
```

### 코드 설명

| 코드 요소 | 의미 |
| --- | --- |
| `from ollama import chat` | Ollama Python 라이브러리의 채팅 함수 가져오기 |
| `model='gemma3:1b'` | 어떤 모델을 사용할지 지정 |
| `messages=[...]` | 대화 메시지 목록 전달 |
| `role='user'` | 사용자가 보낸 질문임을 의미 |
| `response.message.content` | 모델이 생성한 최종 답변 텍스트 |

### 실행 결과 예시

실행하면 대략 다음과 같은 흐름의 답변을 얻을 수 있음.

```text
Ollama는 로컬 컴퓨터에서 LLM을 실행할 수 있게 도와주는 도구입니다.
다양한 오픈소스 모델을 쉽게 다운로드하고 채팅할 수 있습니다.
또한 API를 제공하여 Python 프로그램과도 연동할 수 있습니다.
```

### 정보 얻기 예제 1. 특정 주제 설명 받기

```python
from ollama import chat

question = 'Python의 장점을 5가지로 정리해줘.'

response = chat(
    model='gemma3:1b',
    messages=[
        {'role': 'user', 'content': question}
    ]
)

print('질문:', question)
print('답변:')
print(response.message.content)
```

### 정보 얻기 예제 2. 역할을 주고 더 정확하게 요청하기

```python
from ollama import chat

response = chat(
    model='gemma3:1b',
    messages=[
        {
            'role': 'system',
            'content': '너는 초보자를 위한 친절한 IT 강사다. 어려운 용어는 쉽게 풀어서 설명한다.'
        },
        {
            'role': 'user',
            'content': '로컬 LLM의 장점과 단점을 표 형태로 정리해줘.'
        }
    ]
)

print(response.message.content)
```

여기서 `system` 메시지는 모델의 말투나 역할, 응답 방식의 기준을 설정하는 데 유용함.

### 정보 얻기 예제 3. 연속 대화 만들기

대화형 프로그램처럼 이어서 질문하려면 이전 대화 내역을 함께 넘겨야 함.

```python
from ollama import chat

messages = [
    {'role': 'system', 'content': '너는 Python 학습 도우미다.'},
    {'role': 'user', 'content': '리스트가 무엇인지 설명해줘.'}
]

response1 = chat(model='gemma3:1b', messages=messages)
print('AI 1:', response1.message.content)

messages.append({'role': 'assistant', 'content': response1.message.content})
messages.append({'role': 'user', 'content': '그럼 튜플과의 차이도 알려줘.'})

response2 = chat(model='gemma3:1b', messages=messages)
print('AI 2:', response2.message.content)
```

이 방식은 "이전 문맥을 기억하는 대화"를 코드로 구현할 때 가장 기본이 되는 패턴임.

### 사용자 입력을 받아 채팅하는 프로그램

```python
from ollama import chat

messages = [
    {'role': 'system', 'content': '너는 사용자의 질문에 친절하게 답하는 AI 도우미다.'}
]

while True:
    user_input = input('질문 입력(종료: exit): ').strip()

    if user_input.lower() == 'exit':
        print('프로그램을 종료합니다.')
        break

    messages.append({'role': 'user', 'content': user_input})
    response = chat(model='gemma3:1b', messages=messages)
    answer = response.message.content

    print('\nAI 답변:')
    print(answer)
    print()

    messages.append({'role': 'assistant', 'content': answer})
```

### 위 프로그램이 하는 일

| 단계 | 설명 |
| --- | --- |
| 1 | 사용자에게 질문 입력받기 |
| 2 | 질문을 메시지 목록에 추가 |
| 3 | Ollama 모델에게 전달 |
| 4 | 응답 출력 |
| 5 | 응답을 다시 메시지 목록에 저장 |
| 6 | 다음 질문에서 이전 대화 맥락 유지 |

### 로컬 API 직접 호출하기

Python 라이브러리를 사용하지 않고, Ollama의 로컬 API를 직접 호출할 수도 있음.

기본 API 주소:

```text
http://localhost:11434/api
```

예를 들어 PowerShell에서는 다음처럼 테스트 가능함.

```powershell
(Invoke-WebRequest -Method POST -Body '{"model":"gemma3:1b","prompt":"파이썬이 무엇인지 설명해줘.","stream":false}' -Uri http://localhost:11434/api/generate).Content
```

이 점이 중요한 이유는, Ollama가 단지 채팅 프로그램이 아니라 **프로그램에서 호출 가능한 로컬 AI 서버**라는 뜻이기 때문임.

### Python에서 정보 얻기 실습 아이디어

| 실습 주제 | 설명 |
| --- | --- |
| 문장 요약기 | 긴 텍스트를 입력받아 짧게 요약 |
| 공부 도우미 | 개념 질문을 하면 설명 반환 |
| 보고서 초안 생성기 | 주제를 입력하면 개요 작성 |
| 코드 설명기 | 짧은 코드를 넣으면 설명 생성 |
| 질의응답 봇 | 특정 주제에 대해 반복 대화 |

## 6. 정리와 추천 학습 순서

### 이번 실습에서 배운 내용

| 주제 | 핵심 내용 |
| --- | --- |
| Ollama 소개 | 로컬 PC에서 LLM을 실행할 수 있는 도구 |
| 모델 탐색 | 라이브러리 모델과 설치된 모델을 구분해서 봐야 함 |
| 모델 다운로드 | `ollama pull`, `ollama run` 으로 간단히 실행 가능 |
| 채팅 | CLI에서 직접 질문하고 답변받을 수 있음 |
| Python 연동 | 코드에서 AI에게 질문하고 응답을 받아 활용 가능 |

### 추천 실습 순서

```text
1. Ollama 설치
2. gemma3:1b 다운로드
3. CLI에서 질문 3~5개 해보기
4. Python에서 단일 질문 보내기
5. 연속 대화 프로그램 만들기
6. 요약기/공부 도우미 같은 작은 프로젝트로 확장하기
```

> 처음부터 큰 모델에 욕심내기보다, **작고 빠른 모델로 흐름을 이해한 뒤 점진적으로 확장하는 것**이 가장 효율적임.

### 직접 해볼 과제

| 과제 | 내용 |
| --- | --- |
| 과제 1 | `gemma3:1b` 또는 `llama3.2:1b` 설치 후 자기소개 질문하기 |

### 마무리

이제 우리는 클라우드 AI만 사용하는 것이 아니라, **내 PC 안에 직접 AI를 설치하고 활용하는 첫 단계**를 익힌 셈임. Ollama를 통해 작은 모델부터 실습해 보면, 이후에는 문서 요약기, 개인용 챗봇, 코딩 보조 도구, 자동화 프로그램 같은 다양한 프로젝트로 확장할 수 있음.
