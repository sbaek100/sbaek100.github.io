## 시작 전: 실습 폴더와 Jekyll 폴더의 관계

앞서 `2-1`과 `2-2` 실습에서 만든 폴더 구조를 기억할 것.

```
C:\work\20240001_project\
  ├── _posts\
  ├── assets\img\posts\
  └── README.md
```

**이것이 바로 Jekyll 블로그의 뼈대 구조임.**  
이번 실습에서는 여기에 Ruby, Jekyll을 설치하고 GitHub에 연결해서  
방금까지 VSCode에서 작성하던 `.md` 파일이 **실제 웹사이트**로 올라가는 것을 확인함.

> 💡 **핵심 메시지:**  
> 2-1, 2-2에서 익힌 폴더 구조(`_posts/`, `assets/img/posts/`)와  
> Markdown 작성 방법이 Jekyll에서도 **100% 동일하게 적용됨.**  
> 새로 배울 것은 Ruby/Jekyll 설치와 `git push` 두 가지뿐임.

---

## 1단계: 필수 도구 설치 (Windows 11 세팅)

Windows에서 Jekyll을 구동하려면 **Ruby**와 **Git**이 필수임.

1. **Ruby 설치 (가장 중요)**

    - [RubyInstaller for Windows](https://rubyinstaller.org/downloads/)에 접속함.

        ![](/assets/img/posts/2026-03-06-portfolio-1-1772772568141.png)


    - **Ruby+Devkit 3.3.X (x64)** 버전을 다운로드하여 설치함.

      ![](/assets/img/posts/2026-03-06-portfolio-1-1772772577072.png)

      ![](/assets/img/posts/2026-03-06-portfolio-1-1772772585835.png)


    - 설치 마지막 단계에서 `ridk install` 체크박스를 유지하고, 검은색 터미널 창이 뜨면 **3번(MSYS2 and MINGW development toolchain)**을 선택하여 개발 도구를 모두 설치함.


2. **Git 설치**

    - [Git for Windows](https://git-scm.com/download/win)를 설치함. (기본 옵션으로 'Next'만 눌러도 충분함.)

      ![](/assets/img/posts/2026-03-06-portfolio-1-1772772616392.png)


3. **Visual Studio Code (VS Code) 설치**

    - 코드 편집을 위해 [VS Code](https://code.visualstudio.com/)를 설치함.

![](/assets/img/posts/2026-03-06-portfolio-1-1772772630741.png)

## 2단계: 테마 복사 및 로컬 환경 구축

가장 인기 있는 **Chirpy** 테마를 기준으로 설명함.

1. [Chirpy Starter](https://github.com/cotes2020/chirpy-starter) 페이지에 접속함.

2. **Use this template** → **Create a new repository**를 클릭함.

  ![](/assets/img/posts/2026-03-06-portfolio-1-1772772646661.png)

3. 이름을 `[본인아이디].github.io`로 정하고 생성함.

![](/assets/img/posts/2026-03-06-portfolio-1-1772772677602.png)


4. 이제 내 컴퓨터(Windows 11)로 가져옴. 터미널(PowerShell)을 열고 다음을 입력함.

   > 📁 **연결 포인트 — 앞에서 만든 폴더와 비교:**  
   > `git clone`으로 가져오면 `[아이디].github.io` 폴더가 생성됨.  
   > 이 폴더 안에 `_posts/`, `assets/` 폴더가 이미 있음 — 우리가 2-1에서 만든 구조와 **완전히 동일함.**

    ```bash
    git clone https://github.com/[본인아이디]/[본인아이디].github.io.git
    cd [본인아이디].github.io
    ```


![](/assets/img/posts/2026-03-06-portfolio-1-1772772697032.png)

## 3단계: Jekyll 패키지 설치 및 로컬 서버 실행

이제 내 컴퓨터에서 블로그가 돌아가게 만듦.

1. **Jekyll 및 Bundler 설치:**

    ```bash
    gem install jekyll bundler
    ```

    ![](/assets/img/posts/2026-03-06-portfolio-1-1772772745286.png)


2. **의존성 패키지 설치:** (해당 폴더 안에서 실행)

    ```bash
    bundle install
    ```
    ![](/assets/img/posts/2026-03-06-portfolio-1-1772772764364.png)


3. **로컬 서버 실행:**

    ```bash
    bundle exec jekyll serve
    ```

    - 잠시 기다리면 `http://127.0.0.1:4000` 주소가 뜸. 브라우저로 접속해서 블로그가 보이면 성공임.

![](/assets/img/posts/2026-03-06-portfolio-1-1772772773365.png)

> 💡 **비교 포인트:**  
> VSCode 미리보기는 파일 1개만 확인할 수 있음.  
> `bundle exec jekyll serve`는 전체 사이트를 실제 브라우저에서 확인할 수 있음.  
> 2-2에서 VSCode 미리보기로 연습했던 것과 결과가 동일하게 보이면 정상임.

## 4단계: 첫 번째 포스트 작성하기

> 💡 **핵심:**  
> 2-2 실습에서 `_posts/practice.md`에 작성했던 방식 그대로 사용함.  
> 파일명 규칙과 Front Matter만 추가하면 됨.

1. **VS Code**로 해당 폴더를 엶.

2. `_posts` 폴더로 들어감. (기본 샘플 글이 있을 것임.)

3. **새 파일**을 만듦. 이름은 반드시 `2026-03-08-my-first-til.md` 형식을 지켜야 함.
   (앞의 형식 YYYY-MM-DD 는 지켜주세요. 그래야 인식과 정렬이 됩니다.)

4. 파일 최상단에 아래 내용을 복사해서 넣음:

    ```yaml
    date: 2026-03-08 12:00:00 +0900
    categories: [TIL, Blog]
    tags: [jekyll, github-pages]
    ---

    ## 오늘 배운 내용
    - Windows 11에서 Ruby 환경을 설정했다.
    - GitHub Pages와 Jekyll을 연동했다.
    ```

## 5단계: GitHub에 배포하기 (전 세계 공개)

수정한 내용을 내 GitHub 저장소로 보냄.

1. 터미널에서 다음 명령어를 차례로 입력함.

    ```bash
    # 1. Git 사용자 정보 설정
    # * GitHub 가입 시 사용한 이메일을 사용함. *
    git config --global user.email "[본인아이디]@github.com에 등록된 이메일"
    git config --global user.name "[본인아이디]"

    # 2. 저장소 루트로 이동
    cd "[본인 폴더 경로]"

    # 3. commit & push
    git add .
    git commit -m "feat: 첫 번째 TIL 작성"
    git push origin main
    ```


![](/assets/img/posts/2026-03-06-portfolio-1-1772772842619.png)

2. **GitHub 웹사이트**의 레포지토리 설정(`Settings` → `Pages`)으로 이동함.

![](/assets/img/posts/2026-03-06-portfolio-1-1772772870840.png)


3. **Build and deployment** 항목의 Source를 **GitHub Actions**로 변경함.

   ![](/assets/img/posts/2026-03-06-portfolio-1-1772772932969.png)


4. 약 1~2분 뒤에 `https://[본인아이디].github.io`로 접속하면 내 블로그가 살아있는 것을 확인할 수 있음.

## 6단계: 나만의 내용으로 변경하기

**전체 순서:**

**1단계 - `_config.yml` 수정** `[내 아이디].github.io/` 루트에 아래 파일 생성:
(기존 양식이 있으면 컬러 부분만 수정함)

```yaml
theme: jekyll-theme-chirpy

lang: ko
timezone: Asia/Seoul

title: "브레인 버퍼"
tagline: "백승수의 학습과 생각 기록"
description: "정보보안, AI, 음악, 그리고 일상의 기록"

url: "https://sbaek100.github.io"

author:
  name: "백승수 (Seungsoo Baek)"

avatar: "/assets/img/avatar.jpg"

github:
  username: sbaek100

toc: true
```

---

**2단계 - 프로필 사진 넣기**

```
[아이디].github.io/
└── assets/
    └── img/
        └── avatar.jpg   ← 여기에 사진 파일 복사
```

> 💡 **폴더 구조 연결:**  
> 2-1에서 만든 `assets/img/` 폴더 구조와 동일함.  
> 2-2에서 이미지 저장 연습을 했던 `assets/img/posts/`의 상위 폴더임.

사진 파일명을 `avatar.jpg`로 저장하거나, `_config.yml`의 경로를 파일명에 맞게 수정하면 됨.

---

**3단계 - push**

```powershell
cd "[해당하는 폴더로 이동]"
git add .
git commit -m "config: 블로그 설정 및 프로필 사진 추가"
git push origin main
```

---

> ⚠️ **주의사항**

- `_config.yml`은 들여쓰기(YAML 형식)가 틀리면 빌드 자체가 실패함. 스페이스 2칸 정확히 맞출 것
- 사진은 **정사각형, 최소 200×200px** 권장
