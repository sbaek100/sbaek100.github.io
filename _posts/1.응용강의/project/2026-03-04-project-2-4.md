## 시작 전: 이 가이드의 전제 조건

2-1 ~ 2-3 실습을 완료했다면 아래 환경이 이미 갖춰져 있어야 함.

```
[아이디].github.io/          ← Jekyll 사이트 루트
  ├── _posts/                ← .md 파일 저장 (2-1, 2-2에서 연습한 바로 그 폴더)
  ├── assets/
  │     └── img/posts/       ← 이미지 저장 (2-2에서 Paste Image로 저장하던 경로)
  └── _config.yml
```

> 💡 **핵심 메시지:**  
> 2-1에서 폴더를 만들고, 2-2에서 VSCode로 파일을 작성하고, 2-3에서 GitHub에 올렸음.  
> 이번 2-4는 **같은 폴더, 같은 방식으로** Chirpy 전용 고급 기능만 추가하는 것임.  
> 새로운 환경이 아니라 지금까지 쓰던 것에 기능을 덧붙이는 것임.

| 실습 | 한 일 | 사용 폴더/파일 |
|:---|:---|:---|
| 2-1 | Markdown 문법 + 폴더 구조 | `_posts/`, `assets/img/posts/` 생성 |
| 2-2 | VSCode 편집 + 미리보기 | `_posts/practice.md` 작성 |
| 2-3 | Jekyll 설치 + GitHub 배포 | 동일 폴더를 그대로 블로그로 사용 |
| **2-4 (지금)** | **Chirpy 고급 기능 추가** | **동일 폴더에 기능만 더함** |

---

### 10-1. Paste Image 플러그인 설정 (사전 준비) ⭐

> ⚠️ 이 설정을 먼저 완료해야 이미지 경로가 Jekyll과 맞게 저장됨.
{: .prompt-warning }

#### 플러그인 설치 확인

VSCode 확장(Extension) 탭(`Ctrl+Shift+X`)에서 **Paste Image** (`mushan.vscode-paste-image`)가 설치되어 있는지 확인함.

#### settings.json 설정

> ⚠️ **전제 조건:** VSCode에서 반드시 `[아이디].github.io` 폴더를 **`File → Open Folder`로 열어야** 함.  
> 단일 `.md` 파일만 열면 `${projectRoot}`가 잘못된 경로를 가리켜 이미지가 엉뚱한 곳에 저장됨.
{: .prompt-danger }

`Ctrl+Shift+P` → **"Preferences: Open User Settings (JSON)"** 선택 후 기존 `settings.json` 안에 아래 항목들을 추가함.

```jsonc
  // ============================================
  // Paste Image 설정 (Jekyll Chirpy 블로그용)
  // ============================================
  "pasteImage.path": "${projectRoot}/assets/img/posts",
  "pasteImage.basePath": "${projectRoot}",
  "pasteImage.prefix": "/",
  "pasteImage.namePrefix": "${currentFileNameWithoutExt}-",
  "pasteImage.encodePath": "urlEncodeSpace",
  "pasteImage.insertPattern": "![](${imageFilePath})\n_캡션_"
```

> ⚠️ 위 내용은 기존 `settings.json`의 `}` 닫는 괄호 **바로 앞**에 붙여넣고, 마지막 항목 뒤에는 쉼표(`,`) 없음.
{: .prompt-warning }

| 설정 키 | 의미 |
|:---|:---|
| `pasteImage.path` | 이미지가 저장될 실제 폴더 경로 |
| `pasteImage.basePath` | Markdown 링크의 기준 경로 (프로젝트 루트) |
| `pasteImage.prefix` | 링크 앞에 붙는 `/` — Jekyll 절대경로용 |
| `pasteImage.namePrefix` | 파일명 앞에 현재 포스트 파일명을 자동으로 붙임 |
| `pasteImage.encodePath` | 경로의 공백을 URL 인코딩 처리 |
| `pasteImage.insertPattern` | 삽입될 Markdown 이미지 문법 + 캡션 자리 |

> 💡 `namePrefix`에 `${currentFileNameWithoutExt}-`를 넣으면  
> `2026-03-08-my-post-` 처럼 포스트명이 접두사로 붙어서 이미지 파일이 **포스트별로 구분**됨.
{: .prompt-tip }

---

#### 이미지를 클립보드에 복사하는 방법

| 상황 | 방법 |
|:---|:---|
| 화면 전체 캡처 | `PrtScn` |
| 현재 창만 캡처 | `Alt + PrtScn` |
| 영역 선택 캡처 | `Win + Shift + S` → 드래그 선택 → 자동으로 클립보드에 저장 |
| 파일 탐색기의 이미지 파일 | 파일 우클릭 → **복사** (또는 선택 후 `Ctrl+C`) |
| 브라우저 이미지 | 이미지 우클릭 → **이미지 복사** |

> 💡 `Win + Shift + S` 로 캡처하면 **알림 클릭 없이** 바로 클립보드에 저장됨.  
> 별도 저장 없이 바로 VSCode에서 `Ctrl+Alt+V` 붙여넣기 가능.
{: .prompt-tip }

---

#### VSCode에서 이미지 붙여넣기

1. `.md` 파일에서 이미지를 넣을 **위치에 커서**를 놓음.
2. 단축키 **`Ctrl + Alt + V`** 를 누름.
3. 아래처럼 자동 삽입되고, 이미지 파일도 `assets/img/posts/`에 저장됨.

```markdown
![](/assets/img/posts/2026-03-08-my-post-1741234567890.png)
_캡션_
```

4. `_캡션_` 부분을 원하는 설명으로 수정하면 Chirpy에서 이미지 아래 캡션으로 렌더링됨.

> ⚠️ **주의:** `Ctrl+V` (일반 붙여넣기)가 아닌 반드시 **`Ctrl+Alt+V`** 를 사용해야 함.  
> `Ctrl+V`는 텍스트만 붙여넣고, 이미지 파일 저장은 하지 않음.
{: .prompt-warning }

---

#### 붙여넣기 후 파일 구조 확인

```
[아이디].github.io/
  ├── _posts/
  │     └── 2026-03-08-my-post.md        ← 현재 작성 중인 포스트
  └── assets/
        └── img/
              └── posts/
                    └── 2026-03-08-my-post-1741234567890.png  ← 자동 저장된 이미지
```
