> 이 글은 **실습** 입니다. 개념은 앞 글(**09-1**)의 2장(포렌식)을 먼저 읽으세요.  
> 이 실습은 **Kali(192.168.0.10)** 에서 진행합니다. 메모리 포렌식(Volatility)은 **데모(🔴)** 로만 다룹니다.
{: .prompt-info }

## 0. 목표

포렌식의 핵심인 **① 무결성 검증(해시)**, **② 메타데이터 추출**, **③ 숨은 문자열 찾기** 를 직접 해 봅니다.

---

## A. 무결성 검증 — 해시로 "안 바뀜" 증명

포렌식 1원칙은 **무결성**(증거가 변경되지 않음)입니다. 이를 **해시값** 으로 증명합니다.

```bash
# === Kali에서 실행 ===
mkdir -p ~/forensic-lab && cd ~/forensic-lab

# 증거 파일 생성
echo "중요 증거 데이터 2026" > evidence.txt

# 원본 해시값 기록 (이 값이 '지문')
sha256sum evidence.txt | tee evidence.sha256
```

이제 파일을 **한 글자라도** 바꾸면 해시가 완전히 달라집니다.

```bash
# === Kali에서 실행 ===
echo "누군가 몰래 추가함" >> evidence.txt

# 다시 해시 → 원본과 다름 = 변조됨!
sha256sum evidence.txt

# 원본 해시와 비교 검증
sha256sum -c evidence.sha256
```

`sha256sum -c` 결과가 **`FAILED`** 로 나오면 → **변조 탐지** 입니다.

> 🟢 **연계보관성(Chain of Custody)**: 증거를 확보한 순간 해시를 기록해 두면, 이후 누군가 손댔는지 **해시 비교만으로** 알 수 있습니다. 이것이 디지털 증거의 신뢰 근거입니다.
{: .prompt-tip }

## B. 메타데이터 추출 — "언제·무엇으로 만들어졌나"

### B.1 파일 시간 정보(timestamps)

```bash
# === Kali에서 실행 ===
stat evidence.txt
```

- **Access(접근)·Modify(수정)·Change(변경)** 시각이 보입니다. 사건 시간대 분석의 기초 자료입니다.

### B.2 사진·문서 메타데이터(exiftool)

사진에는 **촬영 시각·기기·때로는 GPS 위치** 까지 메타데이터로 남습니다.

```bash
# === Kali에서 실행 ===
sudo apt install -y libimage-exiftool-perl     # exiftool (이미 있으면 생략)

# 본인이 가진 사진 파일에 적용 (예: photo.jpg)
exiftool photo.jpg
```

> 사진 파일이 없으면 이 단계는 건너뛰어도 됩니다. 핵심은 **"미디어 파일에는 숨은 정보(시간·기기·위치)가 들어 있다"** 는 점입니다. (개인정보 유출 경로가 되기도 함)
{: .prompt-warning }

## C. 숨은 문자열 찾기 — strings

바이너리 파일 안에 박힌 **읽을 수 있는 문자열**(URL·비밀번호·메시지)을 뽑아냅니다. 악성코드 분석에서 C2 주소·흔적을 찾는 기본 기법입니다.

```bash
# === Kali에서 실행 ===
# 실행파일 안의 문자열 (앞부분만)
strings /bin/ls | head -n 20

# 숨김 데이터 실습: '바이너리처럼 보이는' 파일에 메시지를 숨기고 찾아내기
printf '\x00\x01\x02SECRET-FLAG-2026\x03\x04' > blob.bin
strings blob.bin        # → SECRET-FLAG-2026 가 그대로 보임
```

- 겉보기엔 바이너리라도, **strings 로 숨은 텍스트가 드러납니다.**

## D. 디스크·메모리 포렌식 (🔴 데모/개념)

| 작업 | 도구 | 설명 |
|---|---|---|
| 디스크 **이미지 복제** | `dd`, FTK Imager | 원본을 **그대로 복사** 해 사본으로 분석(원본 보존) |
| 디스크 분석 | **Autopsy**(GUI) | 삭제 파일 복구·타임라인 분석 |
| **메모리 분석** | **Volatility** | RAM 이미지에서 실행 중이던 프로세스·접속·비밀번호 흔적 추출 |

디스크 이미지 복제 예(개념):

```bash
# (데모) 원본 디스크를 이미지 파일로 복제 — 실제로는 쓰기방지 장치 사용
# sudo dd if=/dev/sdX of=evidence.img bs=4M status=progress
```

> 🔴 Volatility 메모리 포렌식은 RAM 덤프 확보·프로파일 설정 등 단계가 많아 1학년 실습엔 과합니다. **"메모리에서 사라지기 전에 흔적을 뜬다"** 는 개념(09-1 휘발성 순서)만 이해합니다.
{: .prompt-info }
