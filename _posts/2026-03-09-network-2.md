# 네트워크 기초 실습 1 — Packet Tracer 설치 & LAN 구성

---

# 1장. Packet Tracer란?

Packet Tracer(패킷 트레이서)는 **Cisco(시스코)에서 무료로 제공하는 네트워크 시뮬레이션 프로그램**임.

실제 라우터, 스위치, 서버, PC 등을 가상으로 배치하고, 케이블로 연결하여 네트워크를 구성하고 테스트할 수 있음.

> **왜 Packet Tracer를 사용하는가?**  
> 실제 네트워크 장비(스위치, 라우터)는 수백만 원을 호가함.  
> Packet Tracer를 사용하면 비용 없이 실제와 동일한 환경에서 실습 가능함.

---

# 2장. Packet Tracer 설치

---

## 2.1 Cisco NetAcad 계정 만들기

Packet Tracer는 **Cisco NetAcad(네트워킹 아카데미) 계정**이 있어야 다운로드 가능함.

### Step 1 — 계정 가입

1. 브라우저에서 아래 주소로 접속함

```
https://www.netacad.com
```

2. 우측 상단 **`Sign up`** 버튼 클릭
3. 아래 정보 입력 후 가입 완료

| 항목 | 입력값 |
|---|---|
| First Name | 영문 이름 |
| Last Name | 영문 성 |
| Email | 본인 이메일 주소 |
| Password | 8자 이상, 영문+숫자 조합 |
| Country | South Korea |

4. 가입한 이메일로 인증 메일이 오면 **`Confirm Account`** 클릭

> **팁**: 학교 계정이 있으면 학교 계정으로 가입하는 것을 권장함.

---

## 2.2 Packet Tracer 다운로드

### Step 2 — Packet Tracer 다운로드 페이지 접속

1. NetAcad에 로그인 후 아래 주소로 이동함

```
https://skillsforall.com/resources/lab-downloads
```

2. **`Cisco Packet Tracer`** 항목을 찾아 클릭

3. 운영체제(OS)에 맞는 버전 선택

| 운영체제 | 선택할 파일 |
|---|---|
| Windows 64비트 | `PacketTracer_x.x.x_Windows_64bit.exe` |
| Windows 32비트 | `PacketTracer_x.x.x_Windows_32bit.exe` |
| macOS | `PacketTracer_x.x.x_MacOS.dmg` |
| Linux | `PacketTracer_x.x.x_amd64.deb` |

> **내 Windows 비트 확인 방법**:  
> `윈도우키` → `설정` → `시스템` → `정보` → **시스템 종류** 확인

---

## 2.3 Packet Tracer 설치

### Step 3 — 설치 진행 (Windows 기준)

1. 다운로드된 `.exe` 파일을 **더블클릭**하여 실행
2. **`I accept the agreement`** 선택 후 `Next` 클릭
3. 설치 경로는 기본값 유지 (`C:\Program Files\Cisco Packet Tracer x.x.x\`) → `Next`
4. 바탕화면 단축키 생성 체크 후 `Next`
5. `Install` 클릭 → 설치 진행 (약 2~3분 소요)
6. 설치 완료 후 `Finish` 클릭

---

## 2.4 Packet Tracer 최초 실행 및 로그인

### Step 4 — 로그인

1. 바탕화면의 **Cisco Packet Tracer** 아이콘 더블클릭
2. 로그인 화면에서 NetAcad 계정 정보 입력

```
Username: 가입한 이메일 주소
Password: 가입 시 설정한 비밀번호
```

3. **`Log in`** 클릭

> **오프라인 모드**: 인터넷이 없을 때는 `Guest Login` 버튼을 클릭하면 일부 기능 제한이 있지만 사용 가능함.

# 3장. Packet Tracer UI 익히기

---

## 3.1 화면 구성

Packet Tracer를 처음 실행하면 아래와 같은 화면이 나타남.

```
┌─────────────────────────────────────────────────────┐
│  메뉴 바 (File, Edit, Options, View, Tools, Help)    │
├─────────────────────────────────────────────────────┤
│  툴바 (새 파일, 저장, 되돌리기 등)                    │
├───────────────────────────┬─────────────────────────┤
│                           │                         │
│   작업 공간 (Workspace)   │   장치 패널             │
│   (네트워크 토폴로지를    │   (Physical, Logical    │
│    구성하는 메인 영역)    │    모드 전환)           │
│                           │                         │
├───────────────────────────┴─────────────────────────┤
│  장비 선택 패널 (하단)                               │
│  [Routers] [Switches] [End Devices] [Connections]   │
└─────────────────────────────────────────────────────┘
```

| 영역 | 설명 |
|---|---|
| **작업 공간** | 장비를 배치하고 케이블로 연결하는 메인 화면 |
| **장비 유형 패널** (하단 좌측) | Routers, Switches, End Devices 등 장비 카테고리 |
| **장비 목록** (하단 우측) | 선택한 카테고리의 세부 장비 목록 |
| **Realtime / Simulation** | 우측 하단, 실시간 모드와 시뮬레이션 모드 전환 |

# 4장. 실습 — PC 2대 + 스위치 LAN 구성

---

## 4.1 목표 토폴로지

이번 실습에서 만들 네트워크 구성도(토폴로지)임.

```
[PC0]                  [PC1]
192.168.1.10           192.168.1.20
    |                      |
    └──────[Switch0]───────┘
            (스위치)
```

두 PC가 스위치를 통해 연결되어 같은 네트워크에서 통신하는 가장 기본적인 LAN 구성임.

---

## 4.2 Step-by-Step 실습

---

### Step 1 — 새 파일 만들기

1. Packet Tracer 실행
2. 상단 메뉴 **`File`** → **`New`** 클릭 (또는 `Ctrl + N`)
3. 빈 작업 공간이 열림

---

### Step 2 — PC 배치하기

1. 하단 장비 유형 패널에서 **`End Devices`** (끝단 장치) 클릭
2. 장비 목록에서 **`PC`** 아이콘 확인
3. PC 아이콘을 **작업 공간으로 드래그** → `PC0` 배치
4. 같은 방법으로 **PC를 하나 더 드래그** → `PC1` 배치
5. 두 PC를 적당히 좌우로 배치함

> **팁**: 이름 변경은 장비를 클릭한 후 `Config` 탭에서 가능함.

---

### Step 3 — 스위치 배치하기

1. 하단 장비 유형 패널에서 **`Switches`** 클릭
2. 장비 목록에서 **`2960`** 스위치 선택 (기본 스위치)
3. 작업 공간의 두 PC 사이 아래쪽에 드래그하여 배치 → `Switch0`

---

### Step 4 — 케이블로 연결하기

1. 하단 패널에서 **`Connections`** (번개 모양 아이콘) 클릭
2. **`Copper Straight-Through`** (직선 케이블, 실선) 선택

> **케이블 종류 설명**  
> - **Straight-Through** (직선): PC ↔ 스위치, PC ↔ 허브 연결 시 사용  
> - **Crossover** (크로스): PC ↔ PC 직접 연결, 스위치 ↔ 스위치 연결 시 사용  
> - **Auto** (자동): 자동으로 케이블 종류 선택 (입문 시 편리함)

3. `PC0` 클릭 → 포트 선택 창에서 **`FastEthernet0`** 클릭
4. `Switch0` 클릭 → 포트 선택 창에서 **`FastEthernet0/1`** 클릭
5. 케이블이 연결되면 포트에 **초록색 점** 표시 → 연결 성공
6. 같은 방법으로 `PC1` ↔ `Switch0` 연결 (Switch의 `FastEthernet0/2` 사용)

> **주황색 점**: 아직 포트가 활성화되지 않은 상태 (잠시 후 초록색으로 변함)  
> **빨간색 점**: 연결 오류

---

### Step 5 — PC0에 IP 주소 설정

1. `PC0` 아이콘을 **더블클릭**
2. 팝업 창에서 **`Desktop`** 탭 클릭
3. **`IP Configuration`** 클릭
4. 아래 정보 입력

| 항목 | 값 |
|---|---|
| **IP Address** | `192.168.1.10` |
| **Subnet Mask** | `255.255.255.0` |
| **Default Gateway** | `192.168.1.1` (라우터가 없으므로 일단 공백 가능) |

5. 입력 후 창 닫기 (`X`)

---

### Step 6 — PC1에 IP 주소 설정

1. `PC1` 아이콘을 **더블클릭**
2. **`Desktop`** 탭 → **`IP Configuration`**
3. 아래 정보 입력

| 항목 | 값 |
|---|---|
| **IP Address** | `192.168.1.20` |
| **Subnet Mask** | `255.255.255.0` |
| **Default Gateway** | `192.168.1.1` |

---

### Step 7 — Ping 테스트로 통신 확인

Ping(핑)은 **목적지 IP 주소로 테스트 패킷을 보내서 통신이 되는지 확인하는 명령어**임.

1. `PC0` 더블클릭
2. **`Desktop`** 탭 → **`Command Prompt`** 클릭
3. 아래 명령어 입력

```
ping 192.168.1.20
```

4. 성공 시 아래와 같은 결과가 나타남

```
Pinging 192.168.1.20 with 32 bytes of data:
Reply from 192.168.1.20: bytes=32 time<1ms TTL=128
Reply from 192.168.1.20: bytes=32 time<1ms TTL=128
Reply from 192.168.1.20: bytes=32 time<1ms TTL=128
Reply from 192.168.1.20: bytes=32 time<1ms TTL=128

Ping statistics for 192.168.1.20:
    Packets: Sent = 4, Received = 4, Lost = 0 (0% loss)
```

> **결과 해석**  
> - `Reply from`: 응답이 왔음 → 통신 성공  
> - `Request timeout`: 응답 없음 → 통신 실패  
> - `Lost = 0 (0% loss)`: 패킷 손실 없음 → 정상

---

### Step 8 — 파일 저장

1. `Ctrl + S` 또는 **`File`** → **`Save`**
2. 파일명: `day1-lan-basic.pkt`
3. 저장 경로: 바탕화면 또는 지정된 폴더

---

## 4.3 전체 구성 확인

완성된 토폴로지는 아래와 같아야 함:

```
[PC0]                    [PC1]
IP: 192.168.1.10         IP: 192.168.1.20
Mask: 255.255.255.0      Mask: 255.255.255.0
    |                         |
 Fa0/1                     Fa0/2
    └──────[Switch0 2960]─────┘
            초록색 점 (연결 확인)
```

> **Ping 성공 = LAN 구성 완료!**
