# 🔬 실습편

## 실습 1. 사용자 및 그룹 관리 종합 실습

```bash
# 실습용 사용자 3명 생성
sudo adduser pig
sudo adduser mango
sudo adduser dog

# 생성된 사용자 정보 확인
grep -E "pig|mango|dog" /etc/passwd
id pig
id mango
id dog

# animals 그룹 생성 및 사용자 추가
sudo addgroup animals
sudo adduser pig animals
sudo adduser mango animals
sudo adduser dog animals

# 그룹 구성원 확인
grep animals /etc/group
```

## 실습 2. 파일 소유권 및 권한 설정

```bash
# 공유 디렉터리 생성
sudo mkdir -p /tmp/shared
sudo chmod 777 /tmp/shared

# dog 사용자로 파일 생성
su dog
echo "dog가 만든 파일" > /tmp/shared/msg_from_dog
ls -l /tmp/shared/msg_from_dog
exit

# mango 사용자로 읽기 시도
su mango
cat /tmp/shared/msg_from_dog    # 성공
exit

# dog 사용자로 읽기 권한 제거
su dog
chmod o-r /tmp/shared/msg_from_dog
exit

# mango 사용자로 읽기 재시도
su mango
cat /tmp/shared/msg_from_dog    # Permission denied
exit
```

## 실습 3. chmod 8진수 표기법

```bash
touch /tmp/chmod_test.txt

chmod 644 /tmp/chmod_test.txt   # -rw-r--r--
ls -l /tmp/chmod_test.txt

chmod 755 /tmp/chmod_test.txt   # -rwxr-xr-x
ls -l /tmp/chmod_test.txt

chmod 600 /tmp/chmod_test.txt   # -rw-------
ls -l /tmp/chmod_test.txt

chmod 000 /tmp/chmod_test.txt   # ----------
cat /tmp/chmod_test.txt          # Permission denied

chmod 644 /tmp/chmod_test.txt   # 복원
```

# 📖 풀이 및 해설

---

### 문제 1 해설 — 사용자 추가 명령어

**정답: ① adduser**

| 명령어 | 특징 |
|---|---|
| `adduser` | 고수준. 홈 디렉터리 자동 생성, 대화형 입력 |
| `useradd` | 저수준. 홈 디렉터리 직접 생성해야 함 |

---

### 문제 2 해설 — /etc/passwd 구분자

**정답: ③ 콜론(`:`)**

```
pig:x:1001:1001:,,,:/home/pig:/bin/bash
```

---

### 문제 3 해설 — /etc/passwd 파일 내용

**정답: ③ 사용자의 암호화된 비밀번호가 저장된다.**

비밀번호 필드는 `x` 로만 표시됨. 실제 암호화된 비밀번호는 `/etc/shadow` 에 저장됨.

### 문제 4 해설 — 사용자 정보 조회

**정답: ③ id**

```bash
id
# uid=1000(user) gid=1000(user) groups=1000(user),4(adm)...
```

---

### 문제 5 해설 — su vs su -

**정답: ③ `su -` 는 대상 사용자의 환경변수를 새로 로드한다.**

| 항목 | `su` | `su -` |
|---|---|---|
| 환경변수 | 현재 사용자 것 유지 | 대상 사용자 환경 새로 로드 |
| 작업 디렉터리 | 현재 위치 유지 | 대상 사용자 홈으로 이동 |

---

### 문제 6 해설 — passwd -l

**정답: ③ pig 사용자 계정을 잠근다.**

| 옵션 | 기능 |
|---|---|
| `-l` | 계정 잠금 |
| `-u` | 계정 잠금 해제 |
| `-d` | 비밀번호 삭제 |
| `-S` | 비밀번호 상태 조회 |

---

### 문제 7 해설 — 기본 그룹 구성원

**정답: ② `/etc/passwd` 에서 GID가 해당 그룹의 GID와 동일한 사용자**

`/etc/group` 4번째 필드는 **보조 그룹** 구성원만 나열됨.  
기본 그룹은 `/etc/passwd` 의 GID 필드로 지정됨.

---

### 문제 8 해설 — 권한 읽기

**정답: ② 읽기, 실행**

```
r w x | r - x | - - -
소유자   소유그룹  기타
```

소유 그룹: `r-x` = 읽기, 실행.

---

### 문제 9 해설 — 권한의 8진수 변환

**정답: ② 644**

```
rw- | r-- | r--
110 | 100 | 100
 6  |  4  |  4   → 644
```

---

### 문제 10 해설 — chmod 755 의미

**정답: ③ 소유자에게는 모든 권한, 그룹과 기타에게는 읽기와 실행 권한을 부여한다.**

```
7 = rwx  → 소유자: 읽기+쓰기+실행
5 = r-x  → 그룹: 읽기+실행
5 = r-x  → 기타: 읽기+실행
```

---

### 문제 11 해설 — 의미 표기법 u+x

**정답: ② script.sh 파일의 소유자에게 실행 권한을 추가한다.**

`u+x` = 소유자(`u`)에게 실행(`x`) 권한 추가(`+`).

---

### 문제 12 해설 — chown으로 소유자+그룹 변경

**정답: ② `chown pig:animals file.txt`**

```bash
chown 소유자:그룹 파일명    # 소유자와 그룹 동시 변경
```

---

### 문제 13 해설 — 디렉터리 x만 있을 때

**정답: ② `cd` 명령으로 디렉터리에 진입할 수 있다.**

`x` 권한 = `cd` 로 진입 가능.  
`r` 권한 없으면 `ls` 불가. `w` 권한 없으면 파일 생성 불가.

---

### 문제 14 해설 — 권한 변경 명령어

**정답: ① chmod**

`chmod o+w` = 기타(other)에게 쓰기(w) 권한 추가.

---

### 문제 15 해설 — 디렉터리 권한 ---

**정답: ④ 아무것도 할 수 없다.**

`drwxr-x---` 에서 기타(other) 권한: `---` (모든 권한 없음) → 아무것도 할 수 없음.
