# Python으로 MySQL 연동하기

이번 글은 2-1-1 수준으로 아주 쉽게 진행한다.

---

## 1. 준비

```bash
python --version
pip --version
pip install mysql-connector-python
```

---

## 2. MySQL에서 DB/테이블 만들기

```sql
CREATE DATABASE python_db;
USE python_db;

CREATE TABLE users (
  id INT,
  name VARCHAR(20)
);
```

---

## 3. Python 파일 작성

파일명: `step1_python_mysql.py`

```python
import mysql.connector

conn = mysql.connector.connect(
    host="localhost",
    user="root",
    password="비밀번호",
    database="python_db"
)

cursor = conn.cursor()

cursor.execute("INSERT INTO users (id, name) VALUES (1, '철수')")
conn.commit()

cursor.execute("SELECT * FROM users")
print(cursor.fetchall())

cursor.close()
conn.close()
```

---

## 4. 실행

```bash
python step1_python_mysql.py
```

예상 결과:

```text
[(1, '철수')]
```

---

## 정리

Python에서 MySQL을 연결하고, 데이터 추가/조회까지 완료했다.
