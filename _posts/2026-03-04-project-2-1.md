## 시작 전: 실습 폴더 구조 만들기

Markdown을 배우기 전에 **작업 폴더를 먼저 만들어야 함.**  
이 폴더 구조는 나중에 Jekyll 블로그에서 사용하는 구조와 **완전히 동일함.**  
지금 익혀두면 Jekyll로 넘어갈 때 추가로 배울 것이 없음.

### 폴더 구조 생성

탐색기를 열고 아래 구조를 그대로 만들 것.  
`학번` 자리에 본인 학번을 넣음.

```
C:\work\
  └── 학번_project\              ← 최상위 폴더 (= Jekyll 사이트 루트)
        ├── assets\              ← 이미지, CSS 등 정적 파일 보관
        │     └── img\
        │           └── posts\  ← 포스트에 쓸 이미지를 여기에 저장
        ├── _posts\              ← Markdown 파일(.md)을 여기에 저장
        └── README.md            ← 첫 번째 연습 파일
```

> 💡 **왜 이 구조인가?**  
> Jekyll Chirpy 테마의 실제 폴더 구조가 이와 동일함.  
> `_posts/` → 게시글, `assets/img/posts/` → 이미지 경로.  
> 지금 만드는 폴더가 곧 블로그 폴더가 됨.

### 폴더 만들기 (PowerShell)

```powershell
# 본인 학번으로 변경할 것 (예: 20240001)
$student = "20240001"

New-Item -ItemType Directory -Path "C:\work\${student}_project\_posts"
New-Item -ItemType Directory -Path "C:\work\${student}_project\assets\img\posts"
New-Item -ItemType File     -Path "C:\work\${student}_project\README.md"
```

### 폴더 구조 확인

```powershell
tree C:\work\20240001_project
```

**출력 결과 예시:**
```
C:\WORK\20240001_PROJECT
├─ _posts
└─ assets
    └─ img
        └─ posts
```

> ✅ 이 구조가 확인되면 Markdown 실습 준비 완료.

## Markdown(마크다운)이란?

Markdown은 **텍스트 기반의 경량 마크업 언어**임.  
HTML을 직접 쓰지 않고도 제목, 표, 이미지, 링크 등을 간단한 기호로 표현할 수 있음.  
GitHub Pages, Notion, Obsidian 등 대부분의 현대 플랫폼에서 지원함.

> 💡 **Jekyll과의 관계:**  
> Jekyll은 `.md` 파일을 읽어서 자동으로 HTML로 변환해 웹사이트를 만들어 줌.  
> 즉, Markdown을 잘 쓸 줄 알면 Jekyll 블로그 작성은 자동으로 해결됨.

## 1. 제목 (Heading)

`#` 기호의 개수로 제목 크기를 결정함.

```markdown
# 제목 1 (가장 큼)
## 제목 2
### 제목 3
#### 제목 4
```

**결과:**

# 제목 1

## 제목 2

### 제목 3

#### 제목 4

> 💡 포트폴리오에서는 `##`(제목 2)를 섹션 구분에, `###`(제목 3)을 소제목에 사용하는 것을 권장함.

## 2. 텍스트 강조

```markdown
**굵게 (Bold)**
*기울임 (Italic)*
~~취소선~~
**_굵게 + 기울임_**
`인라인 코드`
```

**결과:**

**굵게 (Bold)**  
_기울임 (Italic)_  
~~취소선~~  
**_굵게 + 기울임_**  
`인라인 코드`

> 💡 포트폴리오에서 기술명, 도구명은 `` ` `` 백틱으로 강조하면 깔끔하게 보임.  
> 예: `Python`, `Kali Linux`, `Burp Suite`

## 4. 링크 & 이미지

### 링크

```markdown
[보여줄 텍스트](URL)

# 예시
[GitHub](https://github.com)
[내 블로그](https://sbaek100.github.io)
```

**결과:**  
[GitHub](https://github.com/)

### 이미지

```markdown
![대체텍스트](이미지경로)

# 예시 - 방금 만든 폴더 구조 사용
![실습화면](/assets/img/posts/screenshot.png)
```

> 💡 이미지 경로는 반드시 `/`(절대경로)로 시작해야 Jekyll에서 정상 표시됨.  
> 방금 만든 `assets/img/posts/` 폴더가 바로 이 경로임.

**[Jekyll 연결 포인트]**  
VSCode 실습에서 `./images/` 경로로 연습하고,  
Jekyll로 넘어갈 때 `/assets/img/posts/`로 경로만 바꾸면 그대로 사용 가능함.

## 9. Front Matter (Jekyll 전용)

Jekyll 포스트 최상단에 반드시 포함해야 하는 메타데이터임.

```yaml
---
title: "포스트 제목"
date: 2026-03-01 12:00:00 +0900
categories: [상위카테고리, 하위카테고리]
tags: [태그1, 태그2, 태그3]
pin: false        # true면 홈 상단 고정
toc: true         # 목차 자동 생성
---
```

> ⚠️ `---` 사이에 들여쓰기나 탭이 있으면 빌드 오류 발생함. 반드시 스페이스로 맞출 것.

**[폴더 구조 연결]**  
Front Matter가 있는 `.md` 파일을 `_posts/` 폴더에 넣으면 Jekyll이 자동으로 블로그 포스트로 인식함.  
파일명 형식: `YYYY-MM-DD-제목.md`
