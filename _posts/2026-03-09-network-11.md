# LAN-라우터-라우터-LAN 토폴로지 구성 & Static Route 실습

---

# 1장. 실습 목표 및 전체 구성

---

## 1.1 완성 목표

이번 실습이 끝나면 아래 토폴로지가 완성되고, **서로 다른 LAN에 있는 PC0과 PC2가 Ping 통신에 성공**해야 함.

```
[LAN A: 192.168.1.0/24]                         [LAN B: 192.168.2.0/24]

  PC0                    WAN: 10.0.0.0/30                    PC2
192.168.1.10    Router0 ─────────────────── Router1    192.168.2.10
GW: 192.168.1.1  Fa0/0: 192.168.1.1   Fa0/0: 192.168.2.1   GW: 192.168.2.1
      |          Se0/0/0: 10.0.0.1    Se0/0/0: 10.0.0.2          |
   Switch0                                                      Switch1
```

---

## 1.2 필요한 장비 목록

| 장비 | 모델 | 수량 | 역할 |
|---|---|---|---|
| PC | PC-PT | 2대 (PC0, PC2) | 각 LAN의 클라이언트 |
| Switch | 2960 | 2대 (Switch0, Switch1) | LAN 내 연결 |
| Router | 1941 | 2대 (Router0, Router1) | LAN-WAN 연결 + 라우팅 |

> **Router 모델 선택: 1941**  
> Routers 패널에서 **1941** 선택. Serial 포트(WAN 연결)를 기본으로 내장하고 있어 실습에 적합함.

---

# 2장. Step-by-Step 실습 — 토폴로지 구성

---

## Step 1 — 장비 배치

1. Packet Tracer 실행 → 새 파일
2. **End Devices** 패널에서 `PC-PT` 2개를 작업 공간에 배치
   - 좌측: `PC0`
   - 우측: `PC2`
3. **Switches** 패널에서 `2960` 2개 배치
   - 좌측: `Switch0` (PC0 옆)
   - 우측: `Switch1` (PC2 옆)
4. **Routers** 패널에서 `1941` 2개 배치
   - 중앙 좌측: `Router0`
   - 중앙 우측: `Router1`

**배치 권장 위치:**

```
[PC0]    [Switch0]    [Router0]    [Router1]    [Switch1]    [PC2]
  좌측                   중앙 좌                 중앙 우              우측
```

---

## Step 2 — LAN A 케이블 연결 (PC0 ↔ Switch0 ↔ Router0)

1. **Connections** → **`Auto`** 케이블 선택
2. `PC0` 클릭 → `Switch0` 클릭 (포트 자동 선택)
3. `Switch0` 클릭 → `Router0` 의 **`Fa0/0`** 포트 클릭

> **Router0의 포트 확인 방법:**  
> Router0 위에 마우스를 올리면 포트 이름이 표시됨.  
> Fa0/0, Fa0/1, Se0/0/0 중 **Fa0/0** 에 연결함.

---

## Step 3 — LAN B 케이블 연결 (PC2 ↔ Switch1 ↔ Router1)

1. `PC2` 클릭 → `Switch1` 클릭
2. `Switch1` 클릭 → `Router1` 의 **`Fa0/0`** 포트 클릭

---

## Step 4 — WAN 케이블 연결 (Router0 ↔ Router1)

라우터 간 WAN 연결은 **Serial 케이블**을 사용함.

1. **Connections** 패널 → **`Serial DCE`** 케이블 선택  
   (번개 모양 아이콘 중 `Serial DCE`)
2. `Router0` 의 **`Se0/0/0`** 포트 클릭
3. `Router1` 의 **`Se0/0/0`** 포트 클릭

> **DCE 케이블이란?**  
> DCE(Data Circuit-terminating Equipment) 케이블을 먼저 연결한 라우터가 **클럭(clock) 신호**를 제공함.  
> Packet Tracer에서는 Serial DCE 케이블로 WAN 시뮬레이션을 구현함.  
> DCE 쪽 라우터(Router0)에서 `clock rate` 명령어를 추가로 입력해야 함.

---

## Step 5 — 연결 상태 초기 확인

케이블 연결 직후 모든 포트가 **빨간색 불** 임.  
이는 아직 IP 설정과 `no shutdown` 이 되지 않았기 때문임 — 정상 상태.

---

# 3장. Step-by-Step 실습 — PC IP 설정

---

## Step 6 — PC0 IP 설정

1. `PC0` 더블클릭 → **`Desktop`** → **`IP Configuration`**
2. 아래와 같이 입력

| 항목 | 값 |
|---|---|
| IP Address | `192.168.1.10` |
| Subnet Mask | `255.255.255.0` |
| Default Gateway | `192.168.1.1` |

---

## Step 7 — PC2 IP 설정

1. `PC2` 더블클릭 → `Desktop` → `IP Configuration`

| 항목 | 값 |
|---|---|
| IP Address | `192.168.2.10` |
| Subnet Mask | `255.255.255.0` |
| Default Gateway | `192.168.2.1` |

---

# 4장. Step-by-Step 실습 — 라우터 IP 설정

---

## Step 8 — Router0 설정 (LAN A 쪽 라우터)

1. `Router0` 더블클릭 → **`CLI`** 탭 클릭
2. 엔터 키를 눌러 CLI 프롬프트 활성화
3. 아래 명령어를 **한 줄씩 순서대로** 입력

```
Router> enable
Router# configure terminal
Router(config)# hostname Router0
```

**Fa0/0 인터페이스 설정 (LAN A 연결):**

```
Router0(config)# interface fa0/0
Router0(config-if)# ip address 192.168.1.1 255.255.255.0
Router0(config-if)# no shutdown
Router0(config-if)# exit
```

**Se0/0/0 인터페이스 설정 (WAN 연결 — DCE 쪽이므로 clock rate 입력):**

```
Router0(config)# interface se0/0/0
Router0(config-if)# ip address 10.0.0.1 255.255.255.252
Router0(config-if)# clock rate 64000
Router0(config-if)# no shutdown
Router0(config-if)# exit
```

> **clock rate 명령어**  
> DCE 케이블을 연결한 라우터에서만 입력함.  
> WAN 링크의 동기화 신호 속도를 설정함. 64000 = 64Kbps.

---

## Step 9 — Router1 설정 (LAN B 쪽 라우터)

1. `Router1` 더블클릭 → `CLI` 탭
2. 아래 명령어 순서대로 입력

```
Router> enable
Router# configure terminal
Router(config)# hostname Router1
```

**Se0/0/0 인터페이스 설정 (WAN 연결 — DTE 쪽이므로 clock rate 없음):**

```
Router1(config)# interface se0/0/0
Router1(config-if)# ip address 10.0.0.2 255.255.255.252
Router1(config-if)# no shutdown
Router1(config-if)# exit
```

**Fa0/0 인터페이스 설정 (LAN B 연결):**

```
Router1(config)# interface fa0/0
Router1(config-if)# ip address 192.168.2.1 255.255.255.0
Router1(config-if)# no shutdown
Router1(config-if)# exit
```

---

## Step 10 — 인터페이스 상태 확인

두 라우터 CLI에서 아래 명령어로 IP 설정과 인터페이스 상태를 확인함.

```
Router0# show ip interface brief
```

**정상 결과:**

```
Interface       IP-Address       OK?  Method  Status                Protocol
FastEthernet0/0 192.168.1.1      YES  manual  up                    up
Serial0/0/0     10.0.0.1         YES  manual  up                    up
```

> `Status: up` + `Protocol: up` 두 개 모두 up이어야 정상 동작함.  
> `down` 이 보이면 케이블 연결 또는 `no shutdown` 을 다시 확인함.

---

# 5장. Step-by-Step 실습 — Static Route 설정

---

## Step 11 — Router0에 Static Route 추가

Router0은 **192.168.2.0/24 네트워크** 로 가는 경로를 모름.  
Router1 방향(10.0.0.2)으로 보내도록 정적 경로를 추가함.

```
Router0# configure terminal
Router0(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2
Router0(config)# end
```

---

## Step 12 — Router1에 Static Route 추가

Router1은 **192.168.1.0/24 네트워크** 로 가는 경로를 모름.  
Router0 방향(10.0.0.1)으로 보내도록 정적 경로를 추가함.

```
Router1# configure terminal
Router1(config)# ip route 192.168.1.0 255.255.255.0 10.0.0.1
Router1(config)# end
```

---

## Step 13 — 라우팅 테이블 확인

두 라우터에서 라우팅 테이블을 확인하여 경로가 등록되었는지 검증함.

```
Router0# show ip route
```

**정상 결과:**

```
Codes: C - connected, S - static, ...

C    192.168.1.0/24 is directly connected, FastEthernet0/0
C    10.0.0.0/30 is directly connected, Serial0/0/0
S    192.168.2.0/24 [1/0] via 10.0.0.2          ← Static Route 등록 확인!
```

| 코드 | 의미 |
|---|---|
| **C** | Connected — 직접 연결된 네트워크 |
| **S** | Static — 관리자가 입력한 정적 경로 |
| **O** | OSPF — OSPF 동적 라우팅으로 학습된 경로 |

---

# 6장. Step-by-Step 실습 — 통신 테스트

---

## Step 14 — PC0에서 PC2로 Ping 테스트

1. `PC0` 더블클릭 → `Desktop` → `Command Prompt`
2. 아래 명령어 입력

```
ping 192.168.2.10
```

**성공 결과:**

```
Pinging 192.168.2.10 with 32 bytes of data:
Reply from 192.168.2.10: bytes=32 time=2ms TTL=126
Reply from 192.168.2.10: bytes=32 time=1ms TTL=126
Reply from 192.168.2.10: bytes=32 time=1ms TTL=126
Reply from 192.168.2.10: bytes=32 time=1ms TTL=126

Ping statistics for 192.168.2.10:
    Packets: Sent = 4, Received = 4, Lost = 0 (0% loss)
```

> **TTL=126 의 의미:**  
> Windows 기본 TTL=128, 라우터 2개를 거쳤으므로 128 - 2 = 126  
> 라우터를 몇 개 거쳤는지 TTL 감소량으로 파악 가능함.

---

## Step 15 — 단계별 Ping 테스트 (트러블슈팅 기준)

통신이 안 될 경우 아래 순서로 범위를 좁혀가며 확인함.

```
[테스트 순서 — 가까운 곳부터 확인]

① PC0에서 자기 자신에게 Ping
   ping 192.168.1.10  →  성공 필수

② PC0에서 Router0 LAN 포트로 Ping
   ping 192.168.1.1   →  성공 필수 (게이트웨이 연결 확인)

③ Router0에서 Router1 WAN 포트로 Ping
   ping 10.0.0.2      →  성공 필수 (WAN 링크 확인)

④ Router0에서 PC2로 Ping
   ping 192.168.2.10  →  성공 필수 (Router1 LAN 확인)

⑤ PC0에서 PC2로 Ping
   ping 192.168.2.10  →  최종 목표!
```

---

# 7장. 트러블슈팅 체크리스트

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| 인터페이스 Status: down | `no shutdown` 미입력 | `interface fa0/0` → `no shutdown` |
| 인터페이스 Protocol: down | WAN 케이블 문제 또는 clock rate 미설정 | DCE 쪽 라우터에 `clock rate 64000` 입력 |
| 게이트웨이 Ping 실패 | PC IP 또는 라우터 IP 오입력 | PC `IP Configuration`, 라우터 `show ip interface brief` 재확인 |
| WAN Ping 실패 | Serial IP 오입력 또는 인터페이스 down | `show ip interface brief` 로 Se0/0/0 상태 확인 |
| 라우팅 테이블에 S 경로 없음 | `ip route` 명령어 오입력 | `show ip route` 확인 후 재입력 |
| PC0 → PC2 Ping 실패 | Static Route 한쪽만 설정 | 양쪽 라우터 모두 설정되었는지 확인 |

# 정리

| 작업 | 명령어 / 설정 |
|---|---|
| **라우터 hostname 설정** | `hostname Router0` |
| **인터페이스 IP 설정** | `ip address 192.168.1.1 255.255.255.0` |
| **인터페이스 활성화** | `no shutdown` |
| **WAN 클럭 설정 (DCE)** | `clock rate 64000` |
| **Static Route 추가** | `ip route 192.168.2.0 255.255.255.0 10.0.0.2` |
| **라우팅 테이블 확인** | `show ip route` |
| **인터페이스 상태 확인** | `show ip interface brief` |

> **다음 강의 예고**  
> 12강에서는 오늘 구성한 토폴로지에서 WAN 구간 IP를 변경하거나  
> 라우터를 추가하는 응용 과제를 수행하고, Static Route 설정을 직접 완성함.
