# LAN-라우터-라우터-LAN 토폴로지 구성 & Static Route 실습

---

# 1장. 오늘 실습에서 꼭 성공할 것

---

오늘 실습의 목표는 딱 3가지임.

1. PC0가 자기 옆 라우터(`192.168.1.1`)와 통신하기
2. Router0와 Router1이 WAN으로 연결되기
3. 마지막에 PC0가 반대편 PC2(`192.168.2.10`)까지 Ping 성공하기

> **오늘은 숫자를 외우는 날이 아니라 흐름을 익히는 날임**  
> 연결하고, IP를 넣고, 라우터에 길을 알려주고, Ping으로 확인하면 끝임.

---

# 2장. 먼저 완성 그림 보기

---

```
[PC0] -- [Switch0] -- [Router0] ==== [Router1] -- [Switch1] -- [PC2]

LAN A: 192.168.1.0/24
WAN : 10.0.0.0/30
LAN B: 192.168.2.0/24
```

| 장비 | 넣을 값 |
|---|---|
| PC0 | `192.168.1.10 / 255.255.255.0 / GW 192.168.1.1` |
| Router0 LAN | `192.168.1.1 / 255.255.255.0` |
| Router0 WAN | `10.0.0.1 / 255.255.255.252` |
| Router1 WAN | `10.0.0.2 / 255.255.255.252` |
| Router1 LAN | `192.168.2.1 / 255.255.255.0` |
| PC2 | `192.168.2.10 / 255.255.255.0 / GW 192.168.2.1` |

---

# 3장. 장비 배치

---

## Step 1 — 장비 6개 놓기

아래 장비만 먼저 배치함.

1. `End Devices` → `PC` 2개
2. `Switches` → `2960` 2개
3. `Routers` → 라우터 2개

> **라우터 모델 안내**  
> 수업 자료에서는 `1941` 기준으로 설명함.  
> 다만 Packet Tracer 버전에 따라 시리얼 포트가 바로 안 보일 수 있음.  
> 그럴 때는 아래 두 방법 중 하나를 사용함.
>
> 1. 그대로 `1941`을 쓰고 `Physical` 탭에서 `HWIC-2T` 모듈을 꽂기  
> 2. 학교 PC에 이미 시리얼 포트가 보이는 라우터 모델이 있다면 그 모델 사용

## Step 2 — 라우터 시리얼 포트가 안 보이면 먼저 모듈 꽂기

`1941`에 `Se0/0/0` 포트가 안 보이는 경우에만 이 단계를 함.

1. `Router0` 더블클릭
2. `Physical` 탭 클릭
3. 전원 스위치를 눌러 끔
4. `HWIC-2T` 모듈을 빈 슬롯에 드래그
5. 다시 전원 켬
6. `Router1`도 같은 방법으로 반복

> 이 작업이 끝나면 `Se0/0/0` 포트가 보이기 시작함.

---

# 4장. 케이블 연결

---

## Step 3 — PC0와 Switch0 연결

1. `Connections` → `Copper Straight-Through`
2. `PC0` → `FastEthernet0`
3. `Switch0` → `FastEthernet0/1`

## Step 4 — Switch0와 Router0 연결

1. 다시 `Copper Straight-Through`
2. `Switch0` → 아무 빈 포트 하나 선택
3. `Router0` → `GigabitEthernet0/0`

> 만약 화면에 `GigabitEthernet0/0` 대신 `FastEthernet0/0` 이 보이면 그 포트를 사용하면 됨.  
> 즉, **스위치와 연결된 첫 번째 LAN 포트**를 쓰면 됨.

## Step 5 — PC2와 Switch1 연결

1. `Copper Straight-Through`
2. `PC2` → `FastEthernet0`
3. `Switch1` → `FastEthernet0/1`

## Step 6 — Switch1와 Router1 연결

1. `Copper Straight-Through`
2. `Switch1` → 아무 빈 포트 하나 선택
3. `Router1` → `GigabitEthernet0/0`

## Step 7 — Router0와 Router1 WAN 연결

1. `Connections` → `Serial DCE`
2. 먼저 `Router0` 클릭 → `Se0/0/0`
3. 그다음 `Router1` 클릭 → `Se0/0/0`

> **왜 Router0를 먼저 누르나?**  
> 먼저 누른 쪽이 DCE 쪽이 되기 쉬워서, 나중에 `clock rate 64000` 을 Router0에 넣기 편함.

## Step 8 — 불 색깔 확인

지금은 빨간색이나 주황색이어도 괜찮음.  
라우터는 아직 `no shutdown` 을 하지 않았기 때문임.

# 5장. PC부터 먼저 설정

---

## Step 9 — PC0 설정

`PC0` 더블클릭 → `Desktop` → `IP Configuration`

| 항목 | 값 |
|---|---|
| IP Address | `192.168.1.10` |
| Subnet Mask | `255.255.255.0` |
| Default Gateway | `192.168.1.1` |

## Step 10 — PC2 설정

`PC2` 더블클릭 → `Desktop` → `IP Configuration`

| 항목 | 값 |
|---|---|
| IP Address | `192.168.2.10` |
| Subnet Mask | `255.255.255.0` |
| Default Gateway | `192.168.2.1` |

---

# 6장. Router0 설정

---

`Router0` 더블클릭 → `CLI` 탭에서 아래를 천천히 입력함.

> **중요**  
> 라우터 화면에 `Continue with configuration dialog? [yes/no]:` 가 나오면 `no` 입력 후 Enter.

## Step 11 — Router0 명령어 입력

```
enable
configure terminal
hostname Router0
interface g0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit
interface s0/0/0
ip address 10.0.0.1 255.255.255.252
clock rate 64000
no shutdown
exit
ip route 192.168.2.0 255.255.255.0 10.0.0.2
end
```

> 만약 `g0/0` 명령이 안 먹으면 `fa0/0` 으로 바꿔서 다시 입력하면 됨.

---

# 7장. Router1 설정

---

## Step 12 — Router1 명령어 입력

```
enable
configure terminal
hostname Router1
interface s0/0/0
ip address 10.0.0.2 255.255.255.252
no shutdown
exit
interface g0/0
ip address 192.168.2.1 255.255.255.0
no shutdown
exit
ip route 192.168.1.0 255.255.255.0 10.0.0.1
end
```

> Router1에는 `clock rate` 를 넣지 않음.  
> `g0/0` 가 없으면 역시 `fa0/0` 으로 바꾸면 됨.

# 8장. 이제 중간 확인

---

## Step 13 — 인터페이스 상태 보기

각 라우터에서 아래 명령어를 입력함.

```
show ip interface brief
```

### 초보자 기준으로 이렇게만 보면 됨

1. LAN 포트에 IP가 들어갔는지
2. Serial 포트에 IP가 들어갔는지
3. `Status` 와 `Protocol` 이 둘 다 `up` 인지

> 하나라도 `down` 이면 아직 연결이나 설정이 덜 된 것임.

## Step 14 — 라우팅 테이블 보기

각 라우터에서 아래 명령어를 입력함.

```
show ip route
```

### 여기서 찾을 것

Router0에서는 아래 줄이 보여야 함.

```
S    192.168.2.0/24 [1/0] via 10.0.0.2
```

Router1에서는 아래 줄이 보여야 함.

```
S    192.168.1.0/24 [1/0] via 10.0.0.1
```

# 9장. Ping은 이렇게 순서대로

---

## Step 15 — 가까운 곳부터 확인

`PC0` → `Desktop` → `Command Prompt`

1. 먼저 자기 라우터 확인

```
ping 192.168.1.1
```

2. 그다음 WAN 건너편 라우터 확인

```
ping 10.0.0.2
```

3. 마지막으로 반대편 PC 확인

```
ping 192.168.2.10
```

> **가까운 곳부터 확인하는 이유**  
> 첫 번째가 안 되면 LAN 문제,  
> 두 번째가 안 되면 WAN 문제,  
> 세 번째만 안 되면 Static Route나 반대편 LAN 문제로 좁혀짐.

## Step 16 — 성공 기준

가장 중요한 성공 기준은 이것임.

1. `ping 192.168.1.1` 이 됨
2. `ping 10.0.0.2` 가 됨
3. `ping 192.168.2.10` 에서 `Reply from` 이 보임

> `TTL=126` 이 보일 수도 있지만, 오늘은 숫자보다 **최종 통신 성공**이 더 중요함.

# 10장. 막힐 때 바로 보는 체크리스트

---

| 증상 | 먼저 확인할 것 |
|---|---|
| Router에 `Se0/0/0` 이 안 보임 | `Physical` 탭에서 `HWIC-2T` 모듈 추가 |
| 포트 불이 계속 빨간색 | 해당 인터페이스에 `no shutdown` 했는지 확인 |
| WAN이 안 됨 | Router0에 `clock rate 64000` 넣었는지 확인 |
| PC0가 192.168.1.1에 Ping 실패 | PC0 IP, 게이트웨이, Router0 LAN 포트 IP 확인 |
| PC0가 10.0.0.2에 Ping 실패 | 시리얼 IP와 케이블 연결 확인 |
| 마지막 Ping만 실패 | `ip route` 두 줄이 양쪽 라우터에 모두 들어갔는지 확인 |

---

# 정리

오늘 실습은 고등학생 초보자 기준으로 보면 이렇게 기억하면 됨.  
PC에 IP를 넣고, 라우터에 IP를 넣고, 라우터에게 반대편 길을 알려주면 다른 네트워크까지 통신할 수 있음.

> **다음 강의 예고**  
> 12강에서는 WAN IP를 바꿔 보고, 바뀐 주소에 맞게 Static Route도 다시 고쳐 보는 연습을 함.
