# 실습 전 준비

## 0-1. 실습 폴더 만들기

```bash
cd ~
mkdir -p ~/textlab
cd ~/textlab
```

## 0-2. 실습용 파일 만들기

아래 명령을 그대로 입력한다.

```bash
cat > fruits.txt << 'EOF'
apple 100 red
banana 50 yellow
cherry 200 red
grape 80 purple
apple 150 green
banana 90 yellow
kiwi 30 green
mango 120 orange
EOF
```

## 0-3. 파일 내용 확인

```bash
cat fruits.txt
```

### 설명

- `fruits.txt` 는 이번 실습에서 계속 사용할 연습용 파일이다.
- 각 줄은 `과일이름 가격 색상` 순서로 되어 있다.

# 실습 1. grep - 원하는 줄 찾기

## 1-1. 특정 단어 찾기

```bash
grep "red" fruits.txt
```

### 설명

- `red` 가 들어간 줄만 찾는다.
- 즉, 빨간색 과일 줄만 출력된다.

## 1-2. 줄 번호와 함께 보기

```bash
grep -n "banana" fruits.txt
```

### 설명

- `banana` 가 들어간 줄을 찾고
- 몇 번째 줄인지도 함께 보여준다.

## 1-3. 특정 단어 제외하기

```bash
grep -v "yellow" fruits.txt
```

### 설명

- `yellow` 가 없는 줄만 보여준다.

## 1-4. 개수 세기

```bash
grep -c "apple" fruits.txt
```

### 설명

- `apple` 이 들어간 줄이 몇 개인지 숫자로 보여준다.

## 1-5. 정규표현식으로 찾기

```bash
grep "^a" fruits.txt
```

### 설명

- `a` 로 시작하는 줄 찾기

```bash
grep "red$" fruits.txt
```

### 설명

- `red` 로 끝나는 줄 찾기

## 1-6. 파이프와 함께 사용하기

```bash
grep "red" fruits.txt | wc -l
```

### 설명

- 빨간색 과일 줄을 찾고
- 그 줄 수를 센다

# 실습 2. sed - 글자 바꾸기와 줄 삭제

## 2-1. 단어 바꾸기

```bash
sed 's/red/RED/' fruits.txt
```

### 설명

- `red` 를 `RED` 로 바꿔서 화면에 보여준다.
- 원본 파일은 바뀌지 않는다.

## 2-2. 모든 해당 단어 바꾸기

```bash
echo "red red red" | sed 's/red/RED/g'
```

### 설명

- `g` 는 한 줄 안의 모든 대상을 바꾸라는 뜻이다.

## 2-3. 특정 줄 삭제해서 보기

```bash
sed '/yellow/d' fruits.txt
```

### 설명

- `yellow` 가 들어간 줄을 빼고 보여준다.

## 2-4. 빈 줄 삭제 이해하기

먼저 빈 줄이 있는 파일을 하나 만든다.

```bash
cat > lines.txt << 'EOF'
one

two

three
EOF
```

```bash
sed '/^$/d' lines.txt
```

### 설명

- `^$` 는 빈 줄을 뜻한다.
- 빈 줄을 지우고 출력한다.

## 2-5. 특정 줄만 출력

```bash
sed -n '2p' fruits.txt
```

### 설명

- 2번째 줄만 출력한다.

# 실습 3. awk - 칸으로 나누어 보기

## 3-1. 첫 번째 칸만 보기

```bash
awk '{print $1}' fruits.txt
```

### 설명

- 과일 이름만 출력한다.

## 3-2. 첫 번째와 두 번째 칸 보기

```bash
awk '{print $1, $2}' fruits.txt
```

### 설명

- 과일 이름과 가격만 출력한다.

## 3-3. 조건에 맞는 줄만 보기

```bash
awk '$2 >= 100 {print $1, $2}' fruits.txt
```

### 설명

- 가격이 100 이상인 과일만 출력한다.

## 3-4. 특정 색상만 보기

```bash
awk '$3 == "green" {print $1}' fruits.txt
```

### 설명

- 초록색 과일 이름만 출력한다.

## 3-5. 합계 구하기

```bash
awk '{sum += $2} END {print sum}' fruits.txt
```

### 설명

- 가격을 모두 더한 결과를 보여준다.

## 3-6. 줄 번호 붙이기

```bash
awk '{print NR, $0}' fruits.txt
```

### 설명

- `NR` 은 현재 줄 번호이다.

# 실습 4. cut - 필요한 칸만 자르기

## 4-1. 구분자가 있는 파일 만들기

```bash
cat > users.txt << 'EOF'
kim:20:seoul
lee:21:busan
park:19:incheon
EOF
```

## 4-2. 첫 번째 칸만 자르기

```bash
cut -d: -f1 users.txt
```

### 설명

- `:` 를 기준으로 나누고
- 첫 번째 칸만 출력한다.

## 4-3. 첫 번째와 세 번째 칸 자르기

```bash
cut -d: -f1,3 users.txt
```

### 설명

- 이름과 지역만 출력한다.

## 4-4. 글자 위치로 자르기

```bash
cut -c1-3 users.txt
```

### 설명

- 각 줄의 앞 3글자만 출력한다.

---

# 실습 5. sort와 uniq - 정렬하고 중복 정리하기

## 5-1. 중복이 있는 파일 만들기

```bash
cat > names.txt << 'EOF'
banana
apple
banana
kiwi
apple
apple
EOF
```

## 5-2. 정렬하기

```bash
sort names.txt
```

## 5-3. 중복 제거하기

```bash
sort names.txt | uniq
```

### 설명

- 먼저 정렬하고
- 같은 줄은 하나만 남긴다.

## 5-4. 개수까지 보기

```bash
sort names.txt | uniq -c
```

### 설명

- 각 단어가 몇 번 나왔는지 함께 보여준다.

## 5-5. 역순 정렬

```bash
sort -r names.txt
```

# 실습 6. wc - 줄 수와 단어 수 세기

## 6-1. 줄 수 세기

```bash
wc -l fruits.txt
```

## 6-2. 단어 수 세기

```bash
wc -w fruits.txt
```

## 6-3. 글자 수 세기

```bash
wc -c fruits.txt
```

## 6-4. grep와 함께 사용하기

```bash
grep "yellow" fruits.txt | wc -l
```

### 설명

- 노란색 과일 줄이 몇 개인지 센다.

# 실습 7. tr - 글자 바꾸기

## 7-1. 소문자를 대문자로 바꾸기

```bash
echo "hello linux" | tr 'a-z' 'A-Z'
```

## 7-2. 공백 지우기

```bash
echo "h e l l o" | tr -d ' '
```

## 7-3. 여러 공백을 하나로 줄이기

```bash
echo "a    b    c" | tr -s ' '
```

### 설명

- `-d`: 지우기
- `-s`: 반복된 문자를 줄이기

# 실습 8. /etc/passwd로 가볍게 연습하기

실습 파일로 감을 잡았다면, 실제 시스템 파일에서도 같은 방식으로 볼 수 있다.

## 8-1. bash 사용자 찾기

```bash
grep "bash" /etc/passwd
```

## 8-2. 사용자명만 보기

```bash
cut -d: -f1 /etc/passwd | head
```

## 8-3. 사용자명과 UID 보기

```bash
awk -F: '{print $1, $3}' /etc/passwd | head
```

## 8-4. bash 사용자 수 세기

```bash
grep "bash" /etc/passwd | wc -l
```

### 설명

- 연습 파일에서 하던 방식이 실제 시스템 파일에도 그대로 적용된다는 것을 느끼는 것이 중요하다.

# 실습 9. 파이프 종합 연습

이제 짧은 조합을 직접 해 본다.

## 9-1. 빨간색 과일 개수 세기

```bash
grep "red" fruits.txt | wc -l
```

## 9-2. 과일 이름만 뽑아 정렬하기

```bash
awk '{print $1}' fruits.txt | sort
```

## 9-3. 과일 이름 중복 제거하기

```bash
awk '{print $1}' fruits.txt | sort | uniq
```

## 9-4. 색상별 개수 세기

```bash
awk '{print $3}' fruits.txt | sort | uniq -c
```

## 9-5. 가격이 100 이상인 과일만 보기

```bash
awk '$2 >= 100 {print $1, $2}' fruits.txt | sort
```

# 실습 10. 따라하기 미션

아래를 스스로 해 보면 좋다.

1. `fruits.txt` 에서 `green` 인 줄만 찾기
2. `fruits.txt` 의 3번째 줄만 출력하기
3. `users.txt` 에서 이름만 출력하기
4. `names.txt` 를 정렬한 뒤 중복 개수 세기
5. `/etc/passwd` 에서 사용자명만 5개 보기
6. `fruits.txt` 에서 과일 이름만 뽑아 중복 없이 보기

예시로 사용할 수 있는 명령:

```bash
grep "green" fruits.txt
sed -n '3p' fruits.txt
cut -d: -f1 users.txt
sort names.txt | uniq -c
cut -d: -f1 /etc/passwd | head -5
awk '{print $1}' fruits.txt | sort | uniq
```

# 마무리 정리



- `grep`: 원하는 줄 찾기
- `sed`: 줄을 바꾸거나 골라 보기
- `awk`: 칸을 나누어 필요한 값 꺼내기
- `cut`: 특정 부분만 자르기
- `sort`, `uniq`: 정렬과 중복 정리
- `wc`: 개수 세기
- `tr`: 글자 바꾸기
- `|`: 명령어를 연결하기

한 번에 다 외우는 것이 목표는 아니다.  
직접 몇 번 입력해 보고, 결과를 눈으로 확인하면서 "이 명령은 이런 상황에서 쓰는구나" 를 익히면 된다.
