# 텍스트 처리 명령어와 정규표현식


---

# 1장. 왜 텍스트 처리 명령어를 배우는가?

리눅스에서는 설정 파일, 로그 파일, 사용자 목록처럼 **글자로 된 정보**를 자주 다룬다.  
이때 필요한 줄만 찾고, 특정 단어를 바꾸고, 정렬하고, 개수를 세는 작업을 빠르게 해 주는 명령어들이 있다.

예를 들어 이런 상황에서 사용한다.

- `/etc/passwd` 에서 특정 사용자 찾기
- 로그 파일에서 `error` 가 들어간 줄 찾기
- 중복된 내용 정리하기
- 여러 명령을 이어 붙여 원하는 결과만 보기

---

# 2장. 파이프(|) 먼저 이해하기

## 2.1 파이프란?

파이프(`|`)는 **앞 명령의 결과를 뒤 명령으로 넘겨주는 기호**이다.

```mermaid
flowchart LR
    A["명령 1 결과"] -->|"|"| B["명령 2 입력"]
```

예를 들어:

```bash
cat /etc/passwd | wc -l
```

이 명령은 다음 뜻이다.

1. `cat /etc/passwd` 로 파일 내용을 화면에 보여준다.
2. 그 결과를 `wc -l` 에 넘긴다.
3. `wc -l` 은 줄 수를 세서 보여준다.

즉, **파일 줄 수 세기**가 된다.

## 2.2 왜 중요한가?

리눅스 명령어는 하나하나는 단순해 보이지만, 파이프로 연결하면 강력해진다.

```bash
grep "bash" /etc/passwd | wc -l
```

이 명령은 `/etc/passwd` 에서 `bash` 가 들어간 줄만 찾고, 그 줄 수를 센다.

# 3장. 정규표현식(Regex) 아주 쉽게 보기

## 3.1 정규표현식이란?

정규표현식은 **문자열의 모양을 패턴으로 표현하는 방법**이다.

쉽게 말해:

- "이 단어가 들어간 줄"
- "숫자로 시작하는 줄"
- "bash 로 끝나는 줄"

같은 조건을 짧은 기호로 표현하는 것이다.

## 3.2 자주 보는 기호

| 기호 | 의미 | 쉬운 예 |
|---|---|---|
| `.` | 아무 문자 1개 | `a.c` → `abc`, `a1c` |
| `*` | 앞 글자가 0번 이상 반복 | `ab*c` → `ac`, `abc`, `abbc` |
| `^` | 줄의 시작 | `^root` |
| `$` | 줄의 끝 | `bash$` |
| `[]` | 여러 문자 중 하나 | `[ab]` |

## 3.3 가장 자주 쓰는 패턴 예

```bash
^root
```

- `root` 로 시작하는 줄

```bash
bash$
```

- `bash` 로 끝나는 줄

```bash
^[0-9]
```

- 숫자로 시작하는 줄

## 3.4 처음에는 이렇게 기억하면 충분하다

- `^` : 시작
- `$` : 끝
- `.` : 아무 글자 하나
- `*` : 여러 번 반복 가능

처음부터 복잡하게 외우기보다, `grep` 예제와 함께 익히는 것이 좋다.

# 4장. grep - 원하는 줄 찾기

## 4.1 grep이란?

`grep` 은 **파일이나 명령 결과에서 원하는 줄만 찾는 명령어**이다.

가장 기본 형태:

```bash
grep "찾을단어" 파일이름
```

예:

```bash
grep "bash" /etc/passwd
```

뜻:

- `/etc/passwd` 파일에서
- `bash` 가 들어간 줄만 출력

## 4.2 자주 쓰는 옵션

| 옵션 | 뜻 | 쉬운 설명 |
|---|---|---|
| `-i` | 대소문자 무시 | `ROOT`, `root` 를 같은 것으로 봄 |
| `-v` | 제외 | 해당 단어가 없는 줄만 보여줌 |
| `-n` | 줄 번호 표시 | 몇 번째 줄인지 함께 봄 |
| `-c` | 개수만 표시 | 몇 줄인지 숫자만 봄 |
| `-r` | 폴더 안까지 검색 | 디렉터리 전체 검색 |
| `-E` | 확장 정규표현식 | `|`, `+`, `{}` 같은 패턴 쓰기 쉬움 |

## 4.3 쉬운 예제

```bash
grep "root" /etc/passwd
```

- `root` 가 들어간 줄 찾기

```bash
grep -n "bash" /etc/passwd
```

- `bash` 가 들어간 줄과 줄 번호 보기

```bash
grep -v "nologin" /etc/passwd
```

- `nologin` 이 없는 줄만 보기

```bash
grep -c "bash" /etc/passwd
```

- `bash` 가 들어간 줄 개수 세기

```bash
grep -E "root|ubuntu" /etc/passwd
```

- `root` 또는 `ubuntu` 가 들어간 줄 찾기

### 따라하기 한 번

```bash
grep "root" /etc/passwd
```

`root` 라는 글자가 들어간 줄이 보이면 성공이다.

# 5장. sed - 글자를 바꾸거나 줄을 지우기

## 5.1 sed란?

`sed` 는 **입력된 글을 한 줄씩 보면서 바꾸거나 지우는 명령어**이다.

처음에는 아래 두 가지만 익히면 된다.

- 글자 바꾸기
- 특정 줄 지우기

## 5.2 가장 많이 쓰는 형태

```bash
sed 's/old/new/' 파일이름
```

뜻:

- `old` 를 `new` 로 바꿔서 화면에 보여준다.
- 원본 파일은 그대로인 경우가 많다.

## 5.3 쉬운 예제

```bash
echo "hello world" | sed 's/world/linux/'
```

- `world` 를 `linux` 로 바꿈

```bash
sed '/^#/d' /etc/ssh/sshd_config
```

- `#` 로 시작하는 주석 줄 삭제해서 보기

```bash
sed '/^$/d' file.txt
```

- 빈 줄 삭제해서 보기

```bash
sed -n '3p' /etc/passwd
```

- 3번째 줄만 출력

## 5.4 `-i` 옵션은 조심

```bash
sed -i 's/hello/HELLO/' file.txt
```

이 명령은 파일을 **직접 수정**한다.  
처음 배우는 단계에서는 `-i` 없이 먼저 연습하는 것이 안전하다.

### 따라하기 한 번

```bash
echo "hello world" | sed 's/world/linux/'
```

화면에 `hello linux` 가 보이면 성공이다.

# 6장. awk - 칸(필드)으로 나누어 보기

## 6.1 awk란?

`awk` 는 **한 줄을 여러 칸으로 나누어 필요한 칸만 꺼내는 명령어**이다.

예를 들어 한 줄이 이런 식이면:

```text
apple 100 red
```

공백 기준으로 나누면:

- `$1` = `apple`
- `$2` = `100`
- `$3` = `red`

## 6.2 가장 기본 예제

```bash
echo "apple 100 red" | awk '{print $1}'
```

- 첫 번째 칸만 출력

```bash
echo "apple 100 red" | awk '{print $1, $2}'
```

- 첫 번째와 두 번째 칸 출력

## 6.3 `/etc/passwd` 에서는 구분자가 다르다

`/etc/passwd` 는 공백이 아니라 `:` 로 나뉜다.

그래서 이렇게 쓴다.

```bash
awk -F: '{print $1, $3}' /etc/passwd
```

뜻:

- `:` 기준으로 나누고
- 1번째 칸(사용자명)과 3번째 칸(UID)을 출력

## 6.4 쉬운 예제

```bash
awk -F: '{print $1}' /etc/passwd
```

- 사용자명만 출력

```bash
awk -F: '$3 >= 1000 {print $1, $3}' /etc/passwd
```

- UID가 1000 이상인 사용자만 출력

```bash
awk 'END {print NR}' /etc/passwd
```

- 전체 줄 수 출력

### 따라하기 한 번

```bash
echo "apple 100 red" | awk '{print $1}'
```

화면에 `apple` 이 출력되면 성공이다.

# 7장. cut - 필요한 부분만 잘라내기

## 7.1 cut이란?

`cut` 은 **각 줄에서 특정 칸이나 특정 위치만 잘라내는 명령어**이다.

## 7.2 쉬운 예제

```bash
cut -d: -f1 /etc/passwd
```

- `:` 를 기준으로 잘라서 1번째 칸만 출력
- 즉, 사용자명만 출력

```bash
cut -d: -f1,7 /etc/passwd
```

- 사용자명과 로그인 셸 출력

```bash
cut -c1-5 /etc/passwd
```

- 각 줄의 앞 5글자만 출력

### 따라하기 한 번

```bash
cut -d: -f1 /etc/passwd | head -5
```

사용자 이름 5개 정도가 보이면 성공이다.

# 8장. sort, uniq - 정렬과 중복 정리

## 8.1 sort란?

`sort` 는 **줄을 정렬하는 명령어**이다.

```bash
sort fruits.txt
```

- 알파벳 순으로 정렬

```bash
sort -r fruits.txt
```

- 역순 정렬

```bash
sort -n numbers.txt
```

- 숫자로 정렬

### 따라하기 한 번

```bash
printf "banana\napple\nkiwi\n" | sort
```

알파벳 순서로 `apple`, `banana`, `kiwi` 가 보이면 성공이다.

## 8.2 uniq란?

`uniq` 는 **중복된 줄을 정리하는 명령어**이다.

단, 중요한 점이 있다.

> `uniq` 는 바로 옆에 붙어 있는 중복만 처리하므로 보통 `sort` 와 함께 사용한다.
{: .prompt-warning }

예:

```bash
sort names.txt | uniq
```

```bash
sort names.txt | uniq -c
```

- 중복 횟수까지 함께 보기

### 따라하기 한 번

```bash
printf "apple\napple\nbanana\n" | sort | uniq -c
```

`apple` 이 2번, `banana` 가 1번으로 보이면 성공이다.

# 9장. wc - 몇 개인지 세기

## 9.1 wc란?

`wc` 는 **줄 수, 단어 수, 글자 수를 세는 명령어**이다.

## 9.2 자주 쓰는 옵션

| 옵션 | 뜻 |
|---|---|
| `-l` | 줄 수 |
| `-w` | 단어 수 |
| `-c` | 바이트 수 |

## 9.3 쉬운 예제

```bash
wc -l /etc/passwd
```

- 줄 수 세기

```bash
grep "bash" /etc/passwd | wc -l
```

- `bash` 가 들어간 줄이 몇 개인지 세기

### 따라하기 한 번

```bash
wc -l /etc/passwd
```

숫자 하나와 파일 이름이 보이면 성공이다.

# 10장. tr - 글자 바꾸기

## 10.1 tr이란?

`tr` 은 **입력된 글자 하나하나를 바꾸거나 지우는 명령어**이다.

## 10.2 쉬운 예제

```bash
echo "hello" | tr 'a-z' 'A-Z'
```

- 소문자를 대문자로 바꾸기

```bash
echo "h e l l o" | tr -d ' '
```

- 공백 삭제

```bash
echo "a    b    c" | tr -s ' '
```

- 여러 개의 공백을 하나로 줄이기

### 따라하기 한 번

```bash
echo "hello" | tr 'a-z' 'A-Z'
```

화면에 `HELLO` 가 보이면 성공이다.

# 11장. 명령어를 함께 쓰는 간단한 예

이제 명령어를 하나씩만 보지 말고, 간단히 연결해서 생각해 보자.

```bash
grep "bash" /etc/passwd | cut -d: -f1
```

- `bash` 가 들어간 줄 찾기
- 그 줄에서 사용자명만 추출하기

```bash
cut -d: -f7 /etc/passwd | sort | uniq -c
```

- 로그인 셸 목록 추출
- 정렬
- 중복 개수 세기

```bash
cat /etc/passwd | wc -l
```

- 사용자 줄 수 세기

# 12장. 핵심만 다시 정리

| 명령어 | 한 줄 설명 |
|---|---|
| `grep` | 원하는 줄 찾기 |
| `sed` | 글자 바꾸기, 줄 삭제하기 |
| `awk` | 칸으로 나누어 필요한 값 꺼내기 |
| `cut` | 특정 칸이나 글자만 자르기 |
| `sort` | 정렬하기 |
| `uniq` | 중복 정리하기 |
| `wc` | 개수 세기 |
| `tr` | 글자 바꾸기, 삭제하기 |
| `|` | 명령어 결과를 다음 명령으로 넘기기 |
