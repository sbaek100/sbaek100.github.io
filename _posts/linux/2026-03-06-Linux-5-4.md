# 시스템 관리 필수 커맨드 라인 자격증 문제형 30문제 실습


실습 시나리오는 아래와 같다.

> 여러분은 Ubuntu 실습 서버에 접속한 초급 관리자이다.  
> 필요한 패키지를 설치하고, 서비스 상태를 점검하고, 실습 파일을 찾고, 디스크 사용량을 확인하고, 마지막에는 작업 폴더를 압축해 보관해야 한다.

이번 문제에서는 아래 명령어를 반복해서 익힌다.

- `sudo apt update`
- `sudo apt install`
- `sudo apt remove`
- `systemctl status`
- `sudo systemctl restart`
- `find`
- `stat`
- `df -h`
- `du -sh`
- `tar -czvf`
- `tar -xzvf`

---

## 실습 방법

1. 문제를 먼저 읽고, 답을 가리지 않은 상태에서 스스로 명령어를 떠올린다.
2. 바로 아래 정답 명령을 확인한 뒤 터미널에 직접 입력한다.
3. 출력 결과까지 확인하면서 "왜 이 명령이 정답인지" 한 번 더 연결한다.

---

# 1단계. 패키지 준비하기

## 문제 1

관리자가 새 패키지를 설치하기 전, 저장소의 패키지 목록을 최신 정보로 동기화하려고 한다. 이때 입력할 명령은 무엇인가?

### 답

```bash
sudo apt update
```

---

## 문제 2

실습 중 디렉터리 구조를 트리 형태로 확인해야 한다. 아직 `tree` 명령을 사용할 수 없다면 어떤 명령으로 패키지를 설치해야 하는가?

### 답

```bash
sudo apt install tree
```

---

## 문제 3

패키지 설치가 끝난 뒤, 사용자 홈 디렉터리의 전체 구조를 한 번 점검하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
tree ~
```

---

## 문제 4

이번에는 현재 작업 중인 디렉터리만 기준으로 트리 구조를 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
tree .
```

---

## 문제 5

사용을 마친 `tree` 패키지를 시스템에서 제거하려고 한다. 이 작업에 알맞은 명령은 무엇인가?

### 답

```bash
sudo apt remove tree
```

---

## 문제 6

다음 단계에서 다시 `tree` 명령이 필요해졌다. 제거했던 패키지를 재설치하려면 어떤 명령을 입력해야 하는가?

### 답

```bash
sudo apt install tree
```

---

# 2단계. 서비스 상태 점검하기

## 문제 7

서버 시간이 자동 동기화되고 있는지 확인하기 위해 `systemd-timesyncd` 서비스 상태를 점검하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
systemctl status systemd-timesyncd
```

---

## 문제 8

상태 점검 후 시간 동기화 서비스를 한 번 재시작해 보라는 지시를 받았다. 어떤 명령을 사용해야 하는가?

### 답

```bash
sudo systemctl restart systemd-timesyncd
```

---

## 문제 9

서비스 재시작 직후, 실제로 정상 동작 중인지 다시 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
systemctl status systemd-timesyncd
```

---

## 문제 10

일부 환경에서는 시간 동기화 서비스 대신 원격 접속 서비스 점검이 먼저 필요할 수 있다. `ssh` 서비스 상태를 확인하는 명령은 무엇인가?

### 답

```bash
systemctl status ssh
```

---

## 문제 11

`ssh` 서비스가 비정상이라고 가정하자. 서비스 재시작에 사용할 명령을 입력하시오.

### 답

```bash
sudo systemctl restart ssh
```

---

## 문제 12

조치가 끝난 뒤 결과 확인까지 하는 것이 실무 절차다. `ssh` 서비스 상태를 다시 점검하는 명령은 무엇인가?

### 답

```bash
systemctl status ssh
```

# 3단계. 파일 찾기와 상태 확인하기

이제 파일 검색과 상태 확인 실습을 위해 연습용 폴더와 파일을 만든다.

먼저 아래 명령을 순서대로 입력해 실습 환경을 준비한다.

```bash
mkdir -p ~/linux5-quest/docs
touch ~/linux5-quest/docs/sample.txt
touch ~/linux5-quest/docs/report.txt
touch ~/linux5-quest/docs/error.log
```

## 문제 13

실습 폴더 전체에서 텍스트 문서만 골라 찾아야 한다. `linux5-quest` 아래의 `.txt` 파일만 검색하는 명령은 무엇인가?

### 답

```bash
find ~/linux5-quest -name "*.txt"
```

---

## 문제 14

이번에는 점검 대상을 로그 파일로 바꾸었다. 같은 폴더 아래에서 `.log` 파일만 찾는 명령은 무엇인가?

### 답

```bash
find ~/linux5-quest -name "*.log"
```

---

## 문제 15

파일의 존재 여부만이 아니라 크기, 수정 시간, 권한까지 함께 확인해야 한다. `sample.txt`의 상세 정보를 확인하는 명령은 무엇인가?

### 답

```bash
stat ~/linux5-quest/docs/sample.txt
```

---

## 문제 16

이번에는 다른 문서 파일인 `report.txt`의 메타데이터를 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
stat ~/linux5-quest/docs/report.txt
```

---

## 문제 17

압축 전 최종 점검 단계다. `linux5-quest` 폴더 안의 `.txt` 파일 위치를 다시 확인하는 명령은 무엇인가?

### 답

```bash
find ~/linux5-quest -name "*.txt"
```

---

## 문제 18

오류 로그 파일이 실제로 만들어졌는지, 그리고 파일 정보까지 함께 확인하려고 한다. 어떤 명령을 입력해야 하는가?

```bash

```

# 4단계. 디스크 사용량 확인하기

## 문제 19

시스템 관리자는 먼저 전체 파일 시스템 사용량을 확인할 수 있어야 한다. 현재 디스크 사용 상태를 사람이 읽기 쉬운 형식으로 출력하는 명령은 무엇인가?

### 답

```bash

```

---

## 문제 20

실습 폴더 하나가 얼마나 용량을 차지하는지 확인하라는 요청을 받았다. `linux5-quest`의 총 사용량을 확인하는 명령은 무엇인가?

### 답

```bash

```

---

## 문제 21

하위 폴더별 용량도 볼 수 있어야 한다. `docs` 디렉터리만 따로 사용량을 확인하려면 어떤 명령을 입력해야 하는가?

### 답

```bash

```

압축 작업 전, 시스템 전체 여유 공간을 다시 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
df -h
```

## 문제 23

방금 전과 같은 폴더를 다시 점검해 사용량 변화를 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

# 5단계. 압축하고 복원하기

## 문제 25

백업용 보관 파일을 만들기 위해 `linux5-quest` 폴더를 `linux5-quest.tar.gz` 형식으로 압축하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
tar -czvf linux5-quest.tar.gz ~/linux5-quest
```

---

## 문제 26

압축 작업이 끝난 뒤 결과 파일이 현재 작업 위치에 생성되었는지 화면에서 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
tree .
```

---

## 문제 27

압축 해제 결과를 따로 확인하기 위해 복원용 디렉터리를 새로 만들려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
mkdir -p ~/linux5-restore
```

---

## 문제 28

생성한 압축 파일을 `~/linux5-restore` 디렉터리에 해제하려고 한다. 이때 사용할 명령은 무엇인가?

### 답

```bash
tar -xzvf linux5-quest.tar.gz -C ~/linux5-restore
```

---

## 문제 29

복원 후 파일 누락이 없는지 확인해야 한다. `linux5-restore` 아래의 `.txt` 파일을 찾는 명령은 무엇인가?

### 답

```bash
find ~/linux5-restore -name "*.txt"
```

---

## 문제 30

마지막 검증 단계로, 복원된 `sample.txt` 파일의 상태 정보를 다시 확인하려고 한다. 어떤 명령을 입력해야 하는가?

### 답

```bash
stat ~/linux5-restore/linux5-quest/docs/sample.txt
```
