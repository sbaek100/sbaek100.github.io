## 문제 1

현재 로그인 사용자와 셸을 확인하라.

정답/실습:
```bash
whoami           # 현재 사용자 확인
echo $SHELL      # 로그인 셸 확인
```

## 문제 8

링크 inode를 비교하고 원본 삭제 후 차이를 확인하라.

정답/실습:
```bash
ls -i ~/linux-journey/docs/original.txt
ls -i ~/linux-journey/docs/soft_link.txt
ls -i ~/linux-journey/docs/hard_link.txt

rm ~/linux-journey/docs/original.txt
cat ~/linux-journey/docs/soft_link.txt
cat ~/linux-journey/docs/hard_link.txt
```

정답 포인트:
- soft link는 보통 깨진다.
- hard link는 내용이 남아있다.

## 문제 14

정답/실습:
```bash

ls -l /tmp/lab-perm/from_dog.txt
```

## 문제 15

`mango`는 읽고, `outsider`는 읽지 못하게 확인하라.

정답/실습:
```bash
su - mango
cat /tmp/lab-perm/from_dog.txt
exit

sudo adduser outsider
su - outsider
cat /tmp/lab-perm/from_dog.txt
exit
```

정답 포인트:
- `mango`는 성공
- `outsider`는 `Permission denied`

## 문제 17

Sticky bit를 적용하고 삭제 차단을 확인하라.

정답/실습:
```bash
su - pig
echo "pig file 2" > /tmp/sticky-lab/pig.txt
exit

sudo chmod 1777 /tmp/sticky-lab

su - mango
rm /tmp/sticky-lab/pig.txt
exit

ls -ld /tmp/sticky-lab
ls -l /tmp/sticky-lab
```

정답 포인트:
- `drwxrwxrwt` 표시
- mango 삭제 실패

## 문제 18

SGID 디렉터리를 만들고 그룹 상속을 확인하라.

정답/실습:
```bash
sudo mkdir /tmp/team-share
sudo chown root:animals /tmp/team-share
sudo chmod 2775 /tmp/team-share

su - pig
echo "pig note" > /tmp/team-share/pig_note.txt
exit

su - mango
echo "mango note" > /tmp/team-share/mango_note.txt
exit

ls -ld /tmp/team-share
ls -l /tmp/team-share
```

정답 포인트:
- `drwxrwsr-x` 형태
- 파일 그룹이 `animals`

## 문제 20

최종 점검을 실행하라.

정답/실습:
```bash
id pig
id mango
id dog

ls -ld /tmp/lab-perm
ls -ld /tmp/sticky-lab
ls -ld /tmp/team-share

ls -l /tmp/lab-perm
ls -l /tmp/sticky-lab
ls -l /tmp/team-share
```

최종 정답 상태 요약:
- `lab-perm`는 팀 읽기 정책(`640`)이 적용되어야 함
- `sticky-lab`는 `t`가 보이고 삭제 보호가 작동해야 함
- `team-share`는 `s`가 보이고 그룹 상속이 되어야 함
