## 1과목: grep 관련

### 문제 1

다음 중 `grep` 명령어에 대한 설명으로 틀린 것은?

① `-i` 옵션을 사용하면 대소문자를 구분하지 않고 검색한다.  
② `-v` 옵션을 사용하면 패턴과 일치하지 않는 줄을 출력한다.  
③ `-n` 옵션을 사용하면 일치하는 파일의 이름만 출력한다.  
④ `-r` 옵션을 사용하면 하위 디렉터리까지 재귀적으로 검색한다.

# 📖 풀이 및 해설

---

### 문제 1 해설 — grep 옵션

**정답: ③ `-n` 옵션을 사용하면 일치하는 파일의 이름만 출력한다.**

`-n` 은 **줄 번호(line number)** 를 함께 출력하는 옵션임.  
파일 이름만 출력하는 옵션은 `-l`.

| 옵션 | 기능 |
|---|---|
| `-i` | 대소문자 무시 |
| `-v` | 불일치 줄 출력 |
| `-n` | **줄 번호** 출력 |
| `-l` | **파일명** 출력 |
| `-c` | 일치 줄 수 출력 |
| `-r` | 재귀 검색 |

---

### 문제 2 해설 — grep -c

**정답: ② /etc/passwd 파일에서 bash가 포함된 줄의 수를 출력한다.**

`-c`(count) 옵션은 일치하는 **줄의 수**만 출력함.

---

### 문제 3 해설 — 줄의 시작 앵커

**정답: ③ `grep "^root" /etc/passwd`**

- `^` = 줄의 **시작**을 의미하는 앵커
- `$` = 줄의 **끝**을 의미하는 앵커
- `^root` = root로 **시작**하는 줄

---

### 문제 4 해설 — 확장 정규표현식 OR

**정답: ② `grep -E "cat|dog" /etc/passwd`**

기본 grep에서는 `|`가 일반 문자로 처리됨.  
`-E` (Extended) 또는 `egrep`을 사용해야 `|`가 OR 조건으로 동작함.

---

### 문제 5 해설 — grep -o

**정답: ④ 2024**

`-o` 옵션은 패턴과 **일치하는 부분만** 출력함.  
`[0-9]+` 는 ERE이므로 `-E`와 함께 써야 하지만, 문제 조건상 `2024`가 출력됨.

> 실제 실행 시: `echo "Hello Linux 2024" | grep -oE "[0-9]+"` 로 써야 정확히 동작함.
{: .prompt-info }

---

### 문제 6 해설 — sed s///g

**정답: ② /etc/passwd 파일에서 모든 root를 ROOT로 치환하여 출력한다.**

- `s/old/new/` = 각 줄의 **첫 번째** old를 new로 치환
- `s/old/new/g` = 각 줄의 **모든** old를 new로 치환 (`g` = global)
- 파일 직접 수정: `-i` 옵션이 있어야 함

---

### 문제 7 해설 — sed 줄 삭제

**정답: ② `sed '/^#/d' file.txt`**

- `d` = delete(삭제)
- `/^#/d` = `#`으로 시작하는 줄 삭제
- `-n '/^#/p'` = `#`으로 시작하는 줄만 출력 (삭제가 아님)

---

### 문제 8 해설 — sed -n '5,10p'

**정답: ② file.txt 파일의 5번째 줄부터 10번째 줄만 출력한다.**

- `-n` = 기본 출력 억제
- `p` = 명시적 print
- `5,10p` = 5~10번째 줄만 출력

---

### 문제 9 해설 — sed 문자 삭제

**정답: ② aacc**

`s/b//g` = 모든 `b` 를 빈 문자열로 치환 (= 삭제)

```
aabbcc  →  b를 모두 삭제  →  aacc
```

### 문제 10 해설 — awk 필드 추출

**정답: ③ root**

- `-F:` = 콜론을 구분자로 지정
- `$1` = 첫 번째 필드

### 문제 11 해설 — awk 특수 변수

### 문제 12 해설 — awk 조건 필터

- `$3 >= 1000` = UID가 1000 이상인 조건

### 문제 13 해설 — awk NF

**정답: ③ 5**

### 문제 14 해설 — cut 옵션

**정답: ② `cut -d: -f1 /etc/passwd`**

- `-f1` = 첫 번째 필드 추출

`-d` 없이 `-f1`만 사용하면 기본 구분자(탭)가 적용되어 원하는 결과가 안 나옴.

### 문제 15 해설 — sort 옵션

- `-t:` = 콜론을 구분자로 지정
- `-k3` = 세 번째 필드 기준 정렬
- `-n` = 숫자로 정렬 (없으면 문자열 정렬: 10 < 2)

### 문제 16 해설 — uniq + sort

**정답: ② `sort`**

`uniq`는 **인접한 중복만** 제거함. 따라서 정렬되지 않은 데이터에서는 중복이 모두 제거되지 않음.  
반드시 `sort | uniq` 순으로 사용해야 함.

### 문제 22 해설 — grep -E 와 egrep

**정답: ③ `egrep "bash|sh" /etc/passwd`**

`egrep`은 `grep -E`와 동일한 명령으로, 확장 정규표현식을 사용함.  
`grep "bash|sh"` (①번 제외)에서 `|`는 일반 문자로 처리됨.  
`grep "bash\|sh"` 는 BRE에서 OR 조건으로 동작하므로 ①도 같은 기능을 수행하긴 하지만, `egrep`이 더 명확한 동일 표현임.
