# 실습 준비

이번 실습은 **두 개의 테이블**을 사용함. 아래 코드를 먼저 실행해 둘 것.

## students 테이블 (1장 실습용)

```sql
CREATE DATABASE university_db;
USE university_db;

CREATE TABLE students (
    id          INT         NOT NULL AUTO_INCREMENT,
    name        VARCHAR(20) NOT NULL,
    programming INT         NOT NULL,
    db_score    INT         NOT NULL,
    network     INT         NOT NULL,
    PRIMARY KEY (id)
);

INSERT INTO students (name, programming, db_score, network) VALUES
    ('김민준',  95, 88, 92),
    ('이서연',  70, 82, 65),
    ('박지호',  88, 91, 79),
    ('최수아',  60, 55, 72),
    ('정우진',  76, 80, 90),
    ('한예은',  92, 95, 88),
    ('오승현',  45, 60, 58),
    ('윤채원',  83, 77, 85),
    ('임도현',  68, 73, 70),
    ('강하린',  90, 88, 95);
```

## transactions 테이블 (2장 실습용)


# 1장 실습 — 데이터 필터링

---

## 문제 1. 프로그래밍 점수가 90점 이상인 학생의 이름과 프로그래밍 점수를 조회하시오.

```sql
SELECT name, programming
FROM students
WHERE programming >= 90;
```

**결과:**

| name | programming |
|------|-------------|
| 김민준 | 95 |
| 한예은 | 92 |
| 강하린 | 90 |

> 비교 연산자 `>=` 를 사용해 90 이상인 행만 필터링함.
> `SELECT *` 대신 필요한 칼럼만 지정하면 결과가 더 보기 좋음.

---

## 문제 2. 데이터베이스 점수(db_score)가 80점 미만인 학생을 모두 조회하시오.

```sql
SELECT *
FROM students
WHERE db_score < 80;
```

**결과:**

| id | name | programming | db_score | network |
|----|------|-------------|----------|---------|
| 4 | 최수아 | 60 | 55 | 72 |
| 7 | 오승현 | 45 | 60 | 58 |
| 8 | 윤채원 | 83 | 77 | 85 |
| 9 | 임도현 | 68 | 73 | 70 |

> 비교 연산자 `<` 를 사용해 80 미만인 행만 필터링함.

---

## 문제 3. 프로그래밍 점수와 네트워크 점수가 **모두** 80점 이상인 학생의 이름을 조회하시오.

```sql
SELECT name
FROM students
WHERE programming >= 80
  AND network >= 80;
```

**결과:**

| name |
|------|
| 김민준 |
| 정우진 |
| 한예은 |
| 윤채원 |
| 강하린 |

> 두 조건을 **모두** 만족해야 하므로 `AND` 를 사용함.
> `OR` 로 바꾸면 둘 중 하나만 80점 이상이어도 포함되어 결과가 달라짐.

---

## 문제 4. 세 과목 중 **하나라도** 75점 미만인 학생을 모두 조회하시오.

```sql
SELECT *
FROM students
WHERE programming < 75
   OR db_score < 75
   OR network < 75;
```

**결과:**

| id | name | programming | db_score | network |
|----|------|-------------|----------|---------|
| 2 | 이서연 | 70 | 82 | 65 |
| 4 | 최수아 | 60 | 55 | 72 |
| 7 | 오승현 | 45 | 60 | 58 |
| 9 | 임도현 | 68 | 73 | 70 |

> **하나라도** 해당하면 되므로 `OR` 를 사용함.
> 정우진(programming 76, db_score 80, network 90)은 세 과목 모두 75 이상이므로 포함되지 않음.

---

## 문제 5. 모든 학생의 이름과 세 과목 **총점**을 조회하시오. 칼럼명은 `총점` 으로 표시할 것.

```sql
SELECT name,
       programming + db_score + network AS 총점
FROM students;
```

**결과:**

| name | 총점 |
|------|------|
| 김민준 | 275 |
| 이서연 | 217 |
| 박지호 | 258 |
| 최수아 | 187 |
| 정우진 | 246 |
| 한예은 | 275 |
| 오승현 | 163 |
| 윤채원 | 245 |
| 임도현 | 211 |
| 강하린 | 273 |

> `+` 연산자로 세 칼럼을 더하고 `AS 총점` 으로 결과 칼럼명을 지정함.

---

## 문제 6. 모든 학생의 이름과 세 과목 **평균**을 조회하시오. 칼럼명은 `평균` 으로 표시할 것.

```sql
SELECT name,
       (programming + db_score + network) / 3 AS 평균
FROM students;
```

**결과:**

| name | 평균 |
|------|------|
| 김민준 | 91.6667 |
| 이서연 | 72.3333 |
| 박지호 | 86.0000 |
| 최수아 | 62.3333 |
| 정우진 | 82.0000 |
| 한예은 | 91.6667 |
| 오승현 | 54.3333 |
| 윤채원 | 81.6667 |
| 임도현 | 70.3333 |
| 강하린 | 91.0000 |

> 괄호로 더하기를 먼저 수행한 뒤 3으로 나눔.
> 괄호 없이 쓰면 `network / 3` 이 먼저 계산되어 잘못된 결과가 나옴 — 연산자 우선순위 주의.

---

## 문제 7. 총점이 250점 이상인 학생의 이름, 총점, 평균을 조회하시오.

```sql
SELECT name AS 이름,
       programming + db_score + network AS 총점,
       (programming + db_score + network) / 3 AS 평균
FROM students
WHERE programming + db_score + network >= 250;
```

**결과:**

| 이름 | 총점 | 평균 |
|------|------|------|
| 김민준 | 275 | 91.6667 |
| 박지호 | 258 | 86.0000 |
| 한예은 | 275 | 91.6667 |
| 강하린 | 273 | 91.0000 |

> `WHERE` 절에 `AS` 별칭(`총점`)을 쓰면 오류 발생.
> `WHERE` 절에는 반드시 계산식을 직접 써야 함.

# 2장 실습 — 집계 함수

---

## 문제 8. transactions 테이블의 전체 거래 건수를 조회하시오.

```sql
USE bank_db;

SELECT COUNT(*) AS 전체거래건수
FROM transactions;
```

**결과:**

| 전체거래건수 |
|-------------|
| 15 |

> `COUNT(*)` 는 NULL 포함 전체 행 수를 셈. 15건의 거래 내역이 모두 카운트됨.

---

## 문제 9. Amazon 과의 거래 중 가장 큰 금액과 가장 작은 금액을 조회하시오. 칼럼명은 `최대금액`, `최소금액` 으로 표시할 것.

```sql
SELECT MAX(amount) AS 최대금액,
       MIN(amount) AS 최소금액
FROM transactions
WHERE company = 'Amazon';
```

**결과:**

| 최대금액 | 최소금액 |
|----------|----------|
| 620000.00 | 180000.00 |

> `MAX()` 와 `MIN()` 을 한 SELECT 문에 함께 사용할 수 있음.
> `WHERE company = 'Amazon'` 으로 Amazon 거래만 필터링한 뒤 집계함.

---

## 문제 10. Google, PayPal, Amazon 세 거래처와의 총 거래 건수를 조회하시오. IN 연산자를 사용할 것.

```sql
SELECT COUNT(*) AS 거래건수
FROM transactions
WHERE company IN ('Google', 'PayPal', 'Amazon');
```

**결과:**

| 거래건수 |
|----------|
| 11 |

> `IN ('Google', 'PayPal', 'Amazon')` 은 OR 를 세 번 쓰는 것과 동일한 결과임.
> 비교할 값이 3개 이상이면 `IN` 이 훨씬 간결함.

---

## 문제 11. Coupang 과의 거래 금액 합계를 조회하시오.

```sql
SELECT SUM(amount) AS 합계금액
FROM transactions
WHERE company = 'Coupang';
```

**결과:**

| 합계금액 |
|----------|
| 675000.00 |

> Coupang 거래 3건(200000 + 175000 + 300000)의 합계가 반환됨.

---

## 문제 12. 입금 거래의 평균 금액을 조회하시오. 칼럼명은 `입금평균` 으로 표시할 것.

```sql
SELECT AVG(amount) AS 입금평균
FROM transactions
WHERE ttype = '입금';
```

**결과:**

| 입금평균 |
|----------|
| 453750.00 |

> `WHERE ttype = '입금'` 으로 입금 거래만 필터링한 뒤 평균을 구함.
> 입금 건수 8건, 합계 3630000, 평균 453750.

---

## 문제 13. 거래처 목록을 중복 없이 조회하시오.

```sql
SELECT DISTINCT company
FROM transactions;
```

**결과:**

| company |
|---------|
| Google |
| PayPal |
| Coupang |
| Amazon |

> `DISTINCT` 는 `SELECT` 바로 뒤에 붙여 쓰며, 중복된 값을 제거하고 고유한 값만 반환함.
> 15건의 거래 내역에서 4개의 거래처 이름만 추출됨.
