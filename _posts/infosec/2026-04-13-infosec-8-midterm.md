### 문제 1.
CPU(Central Processing Unit)에 대한 설명으로 올바르지 않은 것은?

- (a) 컴퓨터의 모든 연산과 제어를 담당하는 핵심 장치이다
- (b) GPU보다 대규모 병렬 연산에 더 적합하다
- (c) 프로그램의 명령어를 해석하고 실행한다
- (d) 산술논리장치(ALU)와 제어장치(CU)로 구성된다

> **풀이:** CPU는 범용 연산과 제어를 담당하는 장치로, ALU와 CU로 구성된다. 대규모 병렬 연산(그래픽, AI 학습 등)에는 수천 개의 코어를 갖춘 GPU가 더 적합하다.
>
> **정답: (b)**
{: .prompt-tip }

### 문제 2.
시스템 소프트웨어와 응용 소프트웨어에 대한 설명으로 올바른 것은?

- (a) 웹 브라우저는 시스템 소프트웨어에 해당한다
- (b) 운영체제는 응용 소프트웨어에 해당한다
- (c) 시스템 소프트웨어는 하드웨어를 관리하고 응용 소프트웨어의 실행 환경을 제공한다
- (d) 응용 소프트웨어는 하드웨어를 직접 제어한다

> **풀이:** 시스템 소프트웨어(운영체제, 디바이스 드라이버 등)는 하드웨어를 관리하고 응용 소프트웨어의 실행 환경을 제공한다. 웹 브라우저는 응용 소프트웨어이며, 응용 소프트웨어는 시스템 소프트웨어를 통해 간접적으로 하드웨어에 접근한다.
>
> **정답: (c)**
{: .prompt-tip }

### 문제 3.
운영체제의 커널(Kernel)에 대한 설명으로 올바르지 않은 것은?

- (a) 프로세스 관리, 메모리 관리, 파일 시스템 관리를 담당한다
- (b) 하드웨어와 응용 프로그램 사이의 중재자 역할을 한다
- (c) 응용 프로그램은 시스템 콜(System Call)을 통해 커널 기능을 요청한다
- (d) 사용자가 직접 커널 메모리에 접근하여 수정할 수 있다

> **풀이:** 커널은 운영체제의 핵심으로 프로세스, 메모리, 파일 시스템을 관리하며 하드웨어와 응용 프로그램을 중재한다. 보안상 사용자가 직접 커널 메모리에 접근하는 것은 금지되며, 반드시 시스템 콜을 통해 커널 기능을 요청해야 한다.
>
> **정답: (d)**
{: .prompt-tip }

### 문제 4.
가상 메모리(Virtual Memory)에 대한 설명으로 올바른 것은?

- (a) 물리 메모리(RAM)를 직접 확장하는 하드웨어이다
- (b) 프로세스마다 독립된 주소 공간을 제공하여 메모리 보호를 실현한다
- (c) 가상 메모리를 사용하면 스왑(Swap)이 발생하지 않는다
- (d) 가상 메모리는 멀티태스킹과 관련이 없다

> **풀이:** 가상 메모리는 각 프로세스에 독립된 가상 주소 공간을 제공하여, 프로세스 간 메모리 침범을 방지하고 메모리 보호를 실현한다. 물리 메모리가 부족할 때 디스크의 일부를 메모리처럼 사용하는 스왑(Swap)이 발생할 수 있다.
>
> **정답: (b)**
{: .prompt-tip }

### 문제 5.
파일 시스템 FAT32와 NTFS의 비교로 올바르지 않은 것은?

- (a) FAT32는 최대 4GB 파일 크기 제한이 있다
- (b) NTFS는 파일/폴더별 접근 권한 설정이 가능하다
- (c) FAT32는 NTFS보다 보안 기능이 더 강력하다
- (d) NTFS는 저널링(Journaling) 기능을 지원하여 데이터 무결성이 높다

> **풀이:** FAT32는 구조가 단순하여 호환성이 높지만, 파일 크기 4GB 제한이 있고 접근 권한 설정이나 암호화 기능이 없다. NTFS는 접근 권한, 저널링, 암호화 등 보안 기능이 FAT32보다 훨씬 강력하다.
>
> **정답: (c)**
{: .prompt-tip }

### 문제 6.
정보보안의 3대 핵심 특성(CIA Triad)에 해당하지 않는 것은?

- (a) 기밀성(Confidentiality)
- (b) 무결성(Integrity)
- (c) 가용성(Availability)
- (d) 확장성(Scalability)

> **풀이:** 정보보안의 3대 핵심 특성은 기밀성(Confidentiality), 무결성(Integrity), 가용성(Availability)이다. 확장성(Scalability)은 시스템 설계의 특성이지 보안의 핵심 특성은 아니다.
>
> **정답: (d)**
{: .prompt-tip }

- (a) UNIX
- (b) Windows NT
- (c) CTSS(Compatible Time-Sharing System)
- (d) MS-DOS

> **정답: (c)**
{: .prompt-tip }

### 문제 8.
1988년 모리스 웜(Morris Worm)에 대한 설명으로 올바르지 않은 것은?

- (a) 인터넷 역사상 최초로 널리 확산된 컴퓨터 웜이다
- (b) 당시 인터넷의 약 10%를 마비시켰다
- (c) 이 사건을 계기로 CERT/CC가 설립되었다
- (d) 주로 USB를 통해 폐쇄망에 침투하였다

> **풀이:** 모리스 웜은 1988년 인터넷을 통해 확산된 최초의 대규모 웜으로, 인터넷의 약 10%를 마비시켰다. 이 사건을 계기로 카네기 멜런 대학교에 CERT/CC가 설립되었다. USB를 통한 폐쇄망 침투는 Stuxnet(2010)의 특징이다.

### 문제 9.
스턱스넷(Stuxnet)에 대한 설명으로 올바른 것은?

- (a) 데이터 탈취를 목적으로 한 랜섬웨어이다
- (b) USB를 통해 폐쇄망에 침투하여 이란의 원심분리기를 물리적으로 파괴한 사이버 무기이다

미국의 컴퓨터 사기 및 남용 방지법(CFAA, Computer Fraud and Abuse Act)의 주요 목적으로 올바른 것은?

### 문제 11.
ARPANET에서 처음 채택한 핵심 통신 기술은 무엇인가?

- (a) 회선 교환(Circuit Switching)
- (b) 패킷 교환(Packet Switching)
- (c) 셀 릴레이(Cell Relay)
- (d) 메시지 교환(Message Switching)

>
> **정답: (b)**
{: .prompt-tip }

### 문제 12.
패킷(Packet)의 구성요소로 올바른 것은?

- (a) 프레임(Frame)과 세그먼트(Segment)

>
> **정답: (b)**

### 문제 13.
TCP/IP 표준화 이후 발생한 보안적 변화로 가장 적절한 것은?

- (a) 암호화가 의무화되었다
- (b) 공격 표면(Attack Surface)이 크게 증가하였다
- (c) 물리적 보안만 중요해졌다
- (d) 네트워크 속도가 감소하였다

> **풀이:** TCP/IP 표준화로 서로 다른 제조사 장비도 연결 가능해졌다. 연결성이 폭발적으로 증가한 만큼 공격자가 침투할 수 있는 공격 표면(Attack Surface)도 함께 크게 증가하였다.
>
> **정답: (b)**
{: .prompt-tip }

### 문제 14.
LAN(Local Area Network)에 대한 설명으로 올바르지 않은 것은?

- (a) 건물이나 사무실 같은 근거리 네트워크이다
- (b) 스위치(Switch) 중심으로 연결된다
- (c) 라우터(Router)와 통신사업자망을 경유한다
- (d) 내부 사용자 간 통신 비율이 높다

> **풀이:** (c)는 WAN(Wide Area Network)의 특징이다. LAN은 근거리 네트워크로 스위치 중심 연결이며, WAN은 라우터와 통신사업자망을 경유하는 장거리 연결망이다.
>
> **정답: (c)**
{: .prompt-tip }

### 문제 17.
ARP(Address Resolution Protocol)의 역할로 올바른 것은?

- (a) 도메인 이름을 IP 주소로 변환
- (b) IP 주소를 MAC 주소로 변환
- (c) MAC 주소를 IP 주소로 변환
- (d) 포트 번호를 IP 주소로 변환

> **풀이:** ARP는 IP 주소를 MAC 주소로 변환하는 프로토콜이다. PC가 통신하려면 목적지의 MAC 주소를 알아야 하므로 ARP 요청을 브로드캐스트하여 해당 IP 주소를 가진 장비의 MAC 주소를 알아낸다.
>
> **정답: (b)**
{: .prompt-tip }

### 문제 18.
TCP 3-Way Handshake의 올바른 순서는?

- (a) ACK → SYN → SYN/ACK
- (b) SYN → ACK → SYN/ACK
- (c) SYN → SYN/ACK → ACK
- (d) SYN/ACK → SYN → ACK

> **풀이:** TCP 연결 수립은 클라이언트가 SYN을 보내고, 서버가 SYN/ACK로 응답하며, 클라이언트가 ACK를 보내 완료된다. 이 3단계가 완료되어야 데이터 전송이 시작된다.
>
> **정답: (c)**
{: .prompt-tip }

### 문제 19.
SYN Flooding 공격의 원리로 올바른 것은?

- (a) UDP 패킷을 대량 전송하여 대역폭을 고갈시킨다
- (b) SYN 요청만 대량 전송하고 ACK를 완료하지 않아 서버 자원을 고갈시킨다
- (c) ARP 응답을 위조하여 트래픽을 가로챈다
- (d) DNS 응답을 변조하여 악성 사이트로 유도한다

> **풀이:** SYN Flooding은 공격자가 SYN 요청만 대량 전송하고 ACK를 보내지 않아 서버가 반쯤 열린 연결(Half-open Connection)을 유지하느라 자원이 고갈되는 서비스 거부 공격(DoS)이다.
>
> **정답: (b)**
{: .prompt-tip }

### 문제 20.
HTTP와 HTTPS의 차이점으로 올바른 것은?

- (a) HTTP는 암호화를 사용하고 HTTPS는 평문 전송이다
- (b) HTTPS는 TLS 암호화를 사용하여 기밀성, 무결성, 인증을 제공한다
- (c) HTTP와 HTTPS는 동일한 보안 수준을 가진다
- (d) HTTPS는 UDP를 사용한다

> **풀이:** HTTP는 평문(Plaintext) 전송으로 중간에서 내용이 노출될 수 있다. HTTPS는 TLS(Transport Layer Security) 암호화를 사용하여 기밀성(Confidentiality), 무결성(Integrity), 인증(Authentication)을 제공한다.
>
> **정답: (b)**
{: .prompt-tip }

### 문제 21.

- (b) 치환 암호는 문자를 다른 문자로 바꾸고, 전치 암호는 문자의 위치를 바꾼다
- (c) 두 방식 모두 문자의 빈도가 변경된다
- (d) 두 방식 모두 키 없이 동작한다

> **풀이:** 치환 암호(Substitution Cipher)는 문자를 다른 문자로 대체하는 방식(예: A→D)이고, 전치 암호(Transposition Cipher)는 문자 자체는 유지하되 위치를 재배열하는 방식이다.

{: .prompt-tip }
