# 실습 1. 첫 Bash 스크립트 만들기

## 1-1. 파일 만들기

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 입력한다.

```bash
nano hello.sh
```

열린 편집기 안에 아래 내용을 입력한다.

```bash
#!/bin/bash
echo "안녕하세요"
echo "첫 번째 Bash 스크립트입니다."
```

## 1-2. 실행 권한 주기

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 입력한다.

```bash
chmod +x hello.sh
```

## 1-3. 실행하기

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 입력한다.

```bash
./hello.sh
```

### 설명

- `#!/bin/bash` : 이 파일을 Bash로 실행하겠다는 뜻
- `chmod +x` : 실행 가능한 파일로 만들기
- `./hello.sh` : 현재 폴더의 스크립트 실행

# 실습 3. 숫자 계산하기

## 3-1. 계산 스크립트 만들기

# 실습 4. 조건문 만들기

## 4-1. 점수 판정 스크립트

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 입력한다.

```bash
nano score.sh
```

열린 편집기 안에 아래 내용을 입력한다.

```bash
#!/bin/bash

score=85

if [ $score -ge 80 ]; then
    echo "합격입니다."
else
    echo "불합격입니다."
fi
```

## 4-2. 실행하기

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 입력한다.

```bash
chmod +x score.sh
./score.sh
```

## 4-3. 값 바꿔 보기

`score=85` 를 `score=60` 으로 바꾼 뒤 다시 실행해 본다.

### 확인할 점

- 조건이 맞으면 `then` 아래가 실행된다.
- 조건이 틀리면 `else` 아래가 실행된다.

# 실습 7. while 반복문

## 7-1. 1부터 5까지 출력

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 입력한다.

```bash
nano while_demo.sh
```

열린 편집기 안에 아래 내용을 입력한다.

```bash
#!/bin/bash

num=1
while [ $num -le 5 ]; do
    echo "$num"
    num=$((num + 1))
done
```

## 7-2. 실행하기

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 입력한다.

```bash
chmod +x while_demo.sh
./while_demo.sh
```

### 확인할 점

- `num=1` 에서 시작
- 한 번 실행할 때마다 `num` 이 1씩 증가
- `5` 까지 출력하면 종료
