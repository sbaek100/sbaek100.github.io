# Bash 스크립팅 기초

이번 주차부터는 명령어를 한 줄씩 치는 것에서 한 단계 더 나아가, **명령어를 파일에 모아서 자동으로 실행하는 방법**을 배운다.  
이것이 바로 Bash 스크립트이다.

쉽게 말해 Bash 스크립트는:

- 여러 명령을 한 파일에 적어두고
- 한 번에 실행할 수 있게 만든 것

이다.

---

# 1장. Bash 스크립트가 무엇인가?

예를 들어 아래처럼 명령이 여러 개 있다고 하자.

```bash
echo "안녕하세요"
date
pwd
```

이 명령들을 매번 하나씩 치는 대신, 파일에 저장해 두고 실행할 수 있다.

```bash
#!/bin/bash
echo "안녕하세요"
date
pwd
```

위처럼 `#!/bin/bash` 로 시작하는 파일을 스크립트라고 부른다.

### 따라하기 한 번

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 그대로 입력한다.

```bash
cat > ~/hello.sh << 'EOF'
#!/bin/bash
echo "안녕하세요"
echo "여기는 Bash 스크립트입니다."
EOF

chmod +x ~/hello.sh
~/hello.sh
```

# 2장. 변수

## 2.1 변수란?

변수는 **값을 저장하는 이름표**라고 생각하면 쉽다.

```bash
name="kim"
age=20
```

이제 `name`, `age` 라는 이름으로 값을 꺼낼 수 있다.

```bash
echo "$name"
echo "$age"
```

## 2.2 변수 사용할 때 주의할 점

변수를 만들 때는 `=` 양쪽에 공백을 넣지 않는다.

```bash
name="kim"   # 올바름
```

```bash
name = "kim"   # 틀림
```

## 2.3 쉬운 예

```bash
name="kim"
major="security"
echo "이름은 $name 입니다."
echo "전공은 $major 입니다."
```

### 따라하기 한 번

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 그대로 입력한다.

```bash
student="hong"
echo "학생 이름: $student"
```

# 3장. 숫자 계산

Bash에서는 숫자 계산을 할 때 보통 `$(( ))` 를 사용한다.

```bash
a=10
b=3
echo $((a + b))
echo $((a - b))
echo $((a * b))
echo $((a / b))
```

## 기억할 점

- `+` : 더하기
- `-` : 빼기
- `*` : 곱하기
- `/` : 나누기
- `%` : 나머지

### 따라하기 한 번

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 그대로 입력한다.

```bash
x=8
y=2
echo "더하기: $((x + y))"
echo "곱하기: $((x * y))"
```

# 4장. 조건문

## 4.1 if 문이란?

조건문은 **"만약 이 조건이 맞으면 이렇게 해라"** 라고 지시할 때 사용한다.

형식은 아래와 같다.

```bash
if [ 조건 ]; then
    명령
else
    명령
fi
```

## 4.2 쉬운 예

```bash
score=85

if [ $score -ge 80 ]; then
    echo "합격입니다."
else
    echo "조금 더 공부합시다."
fi
```

## 4.3 자주 보는 비교

| 표현 | 뜻 |
|---|---|
| `-eq` | 같다 |
| `-ne` | 다르다 |
| `-gt` | 크다 |
| `-ge` | 크거나 같다 |
| `-lt` | 작다 |
| `-le` | 작거나 같다 |

### 따라하기 한 번

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 그대로 입력한다.

```bash
num=5

if [ $num -gt 3 ]; then
    echo "3보다 큽니다."
else
    echo "3보다 크지 않습니다."
fi
```

# 5장. 문자열과 파일 조건

조건문에서는 숫자뿐 아니라 문자열과 파일도 검사할 수 있다.

## 5.1 문자열 검사

```bash
name="linux"

if [ "$name" = "linux" ]; then
    echo "문자열이 같습니다."
fi
```

## 5.2 파일 검사

```bash
if [ -f /etc/passwd ]; then
    echo "파일이 있습니다."
fi
```

| 표현 | 뜻 |
|---|---|
| `-f 파일명` | 일반 파일이다 |
| `-d 폴더명` | 디렉터리이다 |
| `-e 경로` | 존재한다 |

### 따라하기 한 번

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 그대로 입력한다.

```bash
if [ -d ~/Downloads ]; then
    echo "Downloads 폴더가 있습니다."
else
    echo "Downloads 폴더가 없습니다."
fi
```

# 6장. 반복문

반복문은 **같은 일을 여러 번 할 때** 사용한다.

## 6.1 for 문

```bash
for fruit in apple banana grape; do
    echo "$fruit"
done
```

뜻:

- `apple`
- `banana`
- `grape`

를 하나씩 꺼내서 출력한다.

### 따라하기 한 번

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 그대로 입력한다.

```bash
for i in 1 2 3 4 5; do
    echo "번호: $i"
done
```

## 6.2 while 문

```bash
count=1
while [ $count -le 3 ]; do
    echo "count: $count"
    count=$((count + 1))
done
```

뜻:

- 조건이 맞는 동안 계속 반복한다.

### 따라하기 한 번

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 그대로 입력한다.

```bash
num=1
while [ $num -le 5 ]; do
    echo "$num"
    num=$((num + 1))
done
```

# 7장. break 와 continue

반복문 안에서 흐름을 바꾸는 명령이다.

## 7.1 break

`break` 는 반복을 **즉시 끝낸다**.

```bash
for i in 1 2 3 4 5; do
    if [ $i -eq 3 ]; then
        break
    fi
    echo "$i"
done
```

## 7.2 continue

`continue` 는 **이번 한 번만 건너뛴다**.

```bash
for i in 1 2 3 4 5; do
    if [ $i -eq 3 ]; then
        continue
    fi
    echo "$i"
done
```

### 따라하기 한 번

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 그대로 입력한다.

```bash
for i in 1 2 3 4 5; do
    if [ $i -eq 4 ]; then
        break
    fi
    echo "$i"
done
```

# 8장. 함수

함수는 **자주 쓰는 명령 묶음을 이름 붙여 저장한 것**이다.

## 8.1 가장 쉬운 함수

```bash
hello() {
    echo "안녕하세요"
}

hello
```

## 8.2 값을 받는 함수

```bash
greet() {
    echo "안녕하세요, $1 님"
}

greet "kim"
```

여기서 `$1` 은 첫 번째 입력값이다.

### 따라하기 한 번

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 그대로 입력한다.

```bash
say_name() {
    echo "내 이름은 $1 입니다."
}

say_name "hong"
```

# 9장. 스크립트 인자

스크립트를 실행할 때 뒤에 값을 붙일 수 있다.

```bash
./test.sh apple banana
```

이때:

- `$0` : 스크립트 이름
- `$1` : 첫 번째 값
- `$2` : 두 번째 값
- `$#` : 값의 개수

## 쉬운 예

```bash
#!/bin/bash
echo "스크립트 이름: $0"
echo "첫 번째 값: $1"
echo "두 번째 값: $2"
echo "값 개수: $#"
```

### 따라하기 한 번

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 그대로 입력한다.  
`cat > ~/args.sh << 'EOF'` 부터 `EOF` 까지는 **스크립트 파일 내용**이다.

```bash
cat > ~/args.sh << 'EOF'
#!/bin/bash
echo "첫 번째 값: $1"
echo "두 번째 값: $2"
EOF

chmod +x ~/args.sh
~/args.sh apple banana
```

# 10장. 배열

배열은 **값 여러 개를 한 번에 저장하는 방법**이다.

```bash
fruits=("apple" "banana" "grape")
```

## 10.1 배열 값 꺼내기

```bash
echo "${fruits[0]}"
echo "${fruits[1]}"
echo "${fruits[@]}"
```

뜻:

- `${fruits[0]}` : 첫 번째 값
- `${fruits[1]}` : 두 번째 값
- `${fruits[@]}` : 전체 값

### 따라하기 한 번

아래 명령은 **Ubuntu 터미널(Bash 셸)** 에서 그대로 입력한다.

```bash
colors=("red" "green" "blue")
echo "첫 번째 색: ${colors[0]}"
echo "전체 색: ${colors[@]}"
```

# 11장. Bash 스크립트에서 꼭 기억할 것

- 변수 만들 때 `=` 양쪽에 공백을 넣지 않는다.
- 변수는 보통 `"$name"` 처럼 따옴표와 함께 쓰는 습관을 들인다.
- 조건문은 `if`, 반복문은 `for`, `while` 을 많이 쓴다.
- 함수는 명령 묶음을 다시 쓰기 편하게 만든다.
- `$1`, `$2` 는 입력값이다.
- 배열은 여러 값을 한 번에 저장할 때 쓴다.
