# MySQL 기초 2-1-2

이번 복습은 5개 칼럼 테이블로 CRUD를 다시 연습한다.  
자료형은 `INT`, `VARCHAR`만 사용한다.

---

## 1. DB 만들기

```sql
CREATE DATABASE school_review;
USE school_review;
```

---

## 2. 5개 칼럼 테이블 만들기

```sql
CREATE TABLE student_info (
  student_id INT,
  name VARCHAR(20),
  grade INT,
  class_no INT,
  memo VARCHAR(50)
);
```

---

## 3. 데이터 추가

```sql
INSERT INTO student_info (student_id, name, grade, class_no, memo)
VALUES (1, '철수', 1, 3, '전학 예정 없음');

INSERT INTO student_info (student_id, name, grade, class_no, memo)
VALUES (2, '영희', 2, 1, '독서 동아리');

INSERT INTO student_info (student_id, name, grade, class_no, memo)
VALUES (3, '민수', 1, 2, '축구부');
```

---

## 4. 조회

```sql
SELECT * FROM student_info;
```

---

## 5. 수정

```sql
UPDATE student_info
SET memo = '축구부 주장'
WHERE student_id = 3;
```

---

## 6. 삭제

```sql
DELETE FROM student_info
WHERE student_id = 1;
```

---

## 정리

`CREATE TABLE -> INSERT -> SELECT -> UPDATE -> DELETE` 흐름을  
5개 칼럼 테이블로 복습했다.
