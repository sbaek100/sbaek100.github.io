# 네트워크 기초 과제 1 — PC 3대 LAN 구성 및 Ping 테스트

---

# 과제 목표

2강에서 배운 내용을 응용하여 **스스로 네트워크를 구성하고 통신을 확인**함.

이번 과제는 앞으로 이어지는 모든 실습의 기초가 되는 토폴로지임.  
완성된 파일(`.pkt`)과 Ping 성공 캡처 화면을 제출함.

---

# 과제 조건

> **아래 조건을 모두 만족해야 과제 완성으로 인정됨.**

| 번호 | 조건 |
|---|---|
| 1 | PC 3대, 스위치 1대(2960)로 구성할 것 |
| 2 | 모든 장비를 Straight-Through 케이블로 연결할 것 |
| 3 | 아래 IP 주소 표를 참고하여 각 PC에 IP를 정확히 설정할 것 |
| 4 | PC0 → PC1, PC0 → PC2, PC1 → PC2 방향으로 Ping 테스트를 각각 실행할 것 |
| 5 | 모든 Ping이 **`0% loss`** (손실 0%)로 성공해야 함 |
| 6 | 완성된 파일을 `day1-homework.pkt` 로 저장할 것 |

# IP 주소 설정표

아래 표를 보고 각 PC에 IP를 설정함.

| 장비 | IP 주소 | 서브넷 마스크 | 기본 게이트웨이 |
|---|---|---|---|
| **PC0** | `192.168.1.10` | `255.255.255.0` | `192.168.1.1` |
| **PC1** | `192.168.1.20` | `255.255.255.0` | `192.168.1.1` |
| **PC2** | `192.168.1.30` | `255.255.255.0` | `192.168.1.1` |

> **주의**: 세 PC 모두 같은 네트워크 대역(`192.168.1.x`)에 있어야 통신이 가능함.  
> 서브넷 마스크를 `255.255.255.0`으로 설정하면 `192.168.1.1` ~ `192.168.1.254` 범위의 IP들이 같은 네트워크로 인식됨.

    └──────────[Switch0 2960]────────────┘

# Step-by-Step 힌트

2강 실습을 참고하되, 아래 순서대로 진행함.

### Step 1 — 새 파일 만들기
```
File → New (Ctrl + N)
```

### Step 2 — 장비 배치
```
End Devices → PC 3개 배치 (PC0, PC1, PC2)
Switches → 2960 스위치 1개 배치 (Switch0)
```

### Step 3 — 케이블 연결
```
Connections → Copper Straight-Through 선택
PC0 (FastEthernet0) ↔ Switch0 (FastEthernet0/1)
PC1 (FastEthernet0) ↔ Switch0 (FastEthernet0/2)
PC2 (FastEthernet0) ↔ Switch0 (FastEthernet0/3)
```

> **모든 포트에 초록색 점이 표시되어야 정상 연결됨.**

### Step 4 — IP 주소 설정
```
각 PC 더블클릭 → Desktop 탭 → IP Configuration
위 IP 주소 설정표 참고하여 입력
```

### Step 5 — Ping 테스트

**PC0에서 PC1으로 Ping:**
```
PC0 → Desktop → Command Prompt
> ping 192.168.1.20
```

**PC0에서 PC2으로 Ping:**
```
PC0 → Desktop → Command Prompt
> ping 192.168.1.30
```

**PC1에서 PC2으로 Ping:**
```
PC1 → Desktop → Command Prompt
> ping 192.168.1.30
```

### Step 6 — 파일 저장
```
File → Save As → day1-homework.pkt
```

# 트러블슈팅 (문제 해결)

과제 진행 중 문제가 발생하면 아래 체크리스트를 확인함.

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| 포트에 빨간색 점 | 케이블 연결 오류 | 케이블 삭제 후 다시 연결 |
| `Request timeout` | IP 설정 오류 | IP 주소, 서브넷 마스크 재확인 |
| `Request timeout` | 케이블이 연결 안 됨 | 포트 색상(초록) 확인 |
| `Destination host unreachable` | 다른 네트워크 대역 IP 입력 | 세 PC 모두 `192.168.1.x` 확인 |
| Ping 첫 번째만 실패 | ARP 요청 지연 (정상) | 두 번째 ping부터 성공이면 OK |

> **Ping 처음 1~2개 실패는 정상임.**  
> 처음 통신할 때 ARP(Address Resolution Protocol) 과정으로 MAC 주소를 학습하는 시간이 필요함.  
> 4개 중 3~4개가 `Reply from`이면 성공으로 간주함.

# 핵심 개념 정리 (복습)

| 개념 | 설명 |
|---|---|
| **같은 네트워크** | IP 주소의 네트워크 부분(192.168.1.)이 동일해야 직접 통신 가능 |
| **서브넷 마스크** | 네트워크 부분과 호스트 부분을 구분 (`255.255.255.0` = 앞 3자리가 네트워크) |
| **Ping** | ICMP 프로토콜을 사용한 통신 테스트 명령어 |
| **스위치** | MAC 주소를 학습하여 해당 포트로만 데이터 전달 |
| **Straight-Through** | PC ↔ 스위치 연결에 사용하는 케이블 |
