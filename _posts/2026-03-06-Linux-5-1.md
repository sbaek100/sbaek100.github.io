# 시스템 관리 필수 커맨드 라인 이해하기

이번 자료는 설명을 길게 읽는 방식보다, **직접 입력하면서 의미를 이해하는 방식**으로 구성했다.  
각 명령어는 "왜 쓰는가"만 짧게 설명하고, 바로 실습으로 연결한다.

이번 시간에 집중할 명령어는 아래와 같다.

- 패키지 관리: `apt` (`Advanced Package Tool`)
- 서비스 관리: `systemctl` (`systemd control`)
- 검색/확인: `find`, `stat` (`file status`)
- 디스크 확인: `df` (`Disk Free`), `du` (`Disk Usage`)
- 압축: `tar` (`Tape Archive`)
- 쉘 설정: `source`

---

# 1. 패키지 관리 실습으로 시작하기

패키지 관리는 Ubuntu에서 프로그램을 설치하고 제거하는 기본 방법이다.  
여기서 `apt`는 `Advanced Package Tool`의 약자로, Debian/Ubuntu 계열에서 가장 기본이 되는 패키지 관리 도구다.  
이번 실습에서는 `tree` 패키지를 설치해 보고, 확인한 뒤 제거해 본다.

## 1-1. 패키지 목록 최신화

```bash
sudo apt update
```

짧은 이해:

- `apt`는 `Advanced Package Tool`의 약자다.
- `apt update`는 설치 가능한 패키지 목록을 최신 상태로 가져온다.
- 설치 전에 먼저 실행하는 습관이 중요하다.

## 1-2. 패키지 설치

```bash
sudo apt install tree
```

짧은 이해:

- `apt install`은 패키지를 실제로 설치한다.
- `tree`는 디렉터리 구조를 보기 좋게 보여주는 도구라서 실습용으로 적당하다.

## 1-3. 설치 후 확인

```bash
tree ~
```

짧은 이해:

- 패키지는 설치만 하고 끝내지 말고, 실제로 실행해 봐야 한다.
- `tree ~`는 홈 디렉터리 구조를 트리 형태로 보여준다.

## 1-4. 실습 마무리 후 제거

```bash
sudo apt remove tree
```

짧은 이해:

- `apt remove`는 설치한 패키지를 제거한다.
- 실습에서는 설치와 제거를 한 번씩 다 해 보는 것이 중요하다.

---

# 2. 서비스 상태를 확인하고 다시 시작해 보기

리눅스 서버에서는 프로그램이 "서비스" 형태로 동작하는 경우가 많다.  
`systemctl`은 `systemd control` 명령으로, systemd가 관리하는 서비스를 다룰 때 사용하는 대표 명령어다.  
이번에는 서비스가 살아 있는지 확인하고, 필요하면 다시 시작하는 흐름을 익힌다.

## 2-1. 서비스 상태 확인

```bash
systemctl status systemd-timesyncd
```

짧은 이해:

- `systemctl`은 systemd가 관리하는 서비스 상태를 확인하고 제어하는 명령어다.
- `status`는 서비스가 현재 실행 중인지, 오류는 없는지 확인할 때 가장 먼저 쓰는 동작이다.
- 예시는 `systemd-timesyncd`를 사용했지만, 환경에 따라 다른 서비스로 바꿔도 된다.

## 2-2. 서비스 다시 시작

```bash
sudo systemctl restart systemd-timesyncd
systemctl status systemd-timesyncd
```

짧은 이해:

- `restart`는 서비스를 껐다가 다시 시작한다.
- 설정 변경 후 적용하거나, 일시적인 문제를 정리할 때 자주 쓴다.
- 다시 시작한 뒤에는 `status`로 결과를 바로 확인해야 한다.

> 만약 `systemd-timesyncd`가 없으면 `ssh`, `cron`, `NetworkManager`처럼 현재 시스템에 존재하는 서비스 이름으로 바꿔서 실습해도 된다.

# 3. 파일을 찾고, 파일 정보를 확인하기

시스템 관리에서 필요한 파일을 빨리 찾고, 그 파일의 상태를 확인하는 능력은 매우 중요하다.  
`find`는 조건에 맞는 파일을 찾는 명령이고, `stat`는 파일의 상태 정보를 확인하는 명령이다.  
이번 실습에서는 먼저 연습용 파일을 만들고 `find`, `stat`를 사용해 본다.

## 3-1. 연습용 파일 준비

```bash
mkdir -p ~/linux5-basic/docs
touch ~/linux5-basic/docs/sample.txt
touch ~/linux5-basic/docs/test.log
```

## 3-2. 파일 찾기

```bash
find ~/linux5-basic -name "*.txt"
```

짧은 이해:

- `find`는 파일 이름, 위치, 조건을 기준으로 원하는 파일을 찾을 때 사용한다.
- `-name "*.txt"`는 이름이 `.txt`로 끝나는 파일을 찾는 조건이다.

## 3-3. 파일 정보 확인

```bash
stat ~/linux5-basic/docs/sample.txt
```

짧은 이해:

- `stat`는 `status`에서 온 이름으로, 파일의 상태 정보를 자세히 보여준다.
- 파일 크기, 수정 시간, 권한 같은 상세 정보를 보여준다.
- 관리자는 "파일이 있는가"뿐 아니라 "언제 바뀌었는가"도 자주 확인해야 한다.

---

# 4. 디스크 사용량 확인하기

디스크 관련 명령어는 "전체가 얼마나 찼는지"와 "어느 폴더가 많이 쓰는지"를 나눠서 봐야 한다.  
이때 `df`는 `Disk Free`, `du`는 `Disk Usage`의 약자다.  
여기서 `df`와 `du`의 역할 차이를 실습으로 익힌다.

## 4-1. 시스템 전체 디스크 상태 보기

```bash
df -h
```

짧은 이해:

- `df`는 `Disk Free`의 약자로, 파일시스템 전체 기준의 남은 공간과 사용량을 본다.
- `df -h`는 파일시스템 전체 사용량을 확인한다.
- `-h`는 KB, MB, GB처럼 읽기 쉬운 단위로 보여준다.

## 4-2. 특정 디렉터리 사용량 보기

```bash
du -sh ~/linux5-basic
```

짧은 이해:

- `du`는 `Disk Usage`의 약자로, 특정 파일이나 디렉터리가 차지하는 용량을 본다.
- `du -sh`는 특정 경로가 실제로 얼마나 공간을 차지하는지 보여준다.
- `df`는 전체 관점, `du`는 특정 폴더 관점이라고 생각하면 된다.

---

# 5. 압축과 해제 실습

여러 파일을 묶어서 보관하거나 옮길 때 `tar`를 많이 사용한다.  
`tar`는 `Tape Archive`의 약자로, 여러 파일과 디렉터리를 하나로 묶고 풀 때 사용하는 전통적인 리눅스 명령어다.  
이번에는 만든 실습 폴더를 압축하고, 다시 다른 위치에 풀어 본다.

## 5-1. 압축 파일 만들기

```bash
tar -czvf linux5-basic.tar.gz ~/linux5-basic
```

짧은 이해:

- `tar`는 여러 파일을 하나의 아카이브로 묶는 명령어다.
- `-c`: 새 압축 파일 생성
- `-z`: gzip 방식 사용
- `-v`: 처리 과정을 화면에 표시
- `-f`: 압축 파일 이름 지정

## 5-2. 압축 해제하기

```bash
mkdir -p ~/linux5-restore
tar -xzvf linux5-basic.tar.gz -C ~/linux5-restore
```

짧은 이해:

- `-x`는 압축 해제를 뜻한다.
- `-C`는 지정한 디렉터리로 풀겠다는 의미다.

## 5-3. 해제 결과 확인

```bash
find ~/linux5-restore -name "*.txt"
```

짧은 이해:

- 압축을 풀었으면 실제로 파일이 잘 복원되었는지 확인하는 습관이 필요하다.

# 6. 쉘 설정을 즉시 반영하기

`.bashrc`는 Bash 셸이 시작될 때 읽는 개인 설정 파일이다.  
`source`는 파일의 내용을 현재 셸에서 바로 실행해 반영하는 Bash 내장 명령이다.  
설정을 수정한 뒤 새 터미널을 열지 않고 바로 반영하려면 `source ~/.bashrc`를 사용한다.

## 6-1. `.bashrc`에 별칭 추가

```bash
nano ~/.bashrc
```

아래 한 줄을 파일 끝에 추가한다.

```bash
alias ll='ls -alF'
```

## 6-2. 즉시 반영

```bash
source ~/.bashrc
ll
```

짧은 이해:

- `source`는 파일 내용을 현재 셸 세션에 다시 불러와 즉시 반영한다.
- `source ~/.bashrc`는 설정 파일을 현재 셸에 다시 읽어 온다.
- 새 터미널을 열지 않아도 변경 사항을 바로 시험할 수 있다.

# 7. 오늘 실습으로 이해해야 할 핵심

오늘 배운 내용은 개념을 따로 외우기보다, **어떤 상황에서 어떤 명령을 먼저 쓰는지**를 익히는 것이 목적이다.

정리하면 다음 흐름이다.

1. 프로그램이 필요하면 `apt`로 설치하고 제거한다.
2. 서비스가 문제 있으면 `systemctl status`로 상태를 본다.
3. 필요한 파일은 `find`로 찾고 `stat`로 자세히 확인한다.
4. 저장 공간은 `df -h`로 전체를 보고 `du -sh`로 특정 폴더를 본다.
5. 파일 묶음은 `tar`로 압축하고 다시 풀어 본다.
6. 쉘 설정을 바꿨으면 `source ~/.bashrc`로 즉시 반영한다.

# 8. 짧은 종합 실습

아래 순서대로 직접 입력해 보자.

```bash
sudo apt update
sudo apt install tree
systemctl status systemd-timesyncd
mkdir -p ~/linux5-basic/docs
touch ~/linux5-basic/docs/sample.txt
find ~/linux5-basic -name "*.txt"
stat ~/linux5-basic/docs/sample.txt
df -h
du -sh ~/linux5-basic
tar -czvf linux5-basic.tar.gz ~/linux5-basic
mkdir -p ~/linux5-restore
tar -xzvf linux5-basic.tar.gz -C ~/linux5-restore
source ~/.bashrc
sudo apt remove tree
```

이 정도 흐름을 자연스럽게 따라갈 수 있으면, 시스템 관리 기본 명령어는 잘 잡힌 것이다.
