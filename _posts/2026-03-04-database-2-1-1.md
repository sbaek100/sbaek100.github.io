# MySQL 기초 2-1-1: 설치 다시하기부터 첫 테이블까지

안녕! 오늘은 **중학교 1학년이 처음 MySQL을 만난다**고 생각하고, 아주 쉽고 자세하게 설명할게.

## 1. MySQL 설치가 안 된 사람들을 위한 삭제 + 재설치 주의점

> 목표: **컴퓨터에 남아 있는 MySQL 흔적을 지우고** 다시 설치할 수 있게 만들기

### 1-1. 제어판에서 MySQL 삭제하기

1. `제어판`을 연다.
2. `프로그램 제거`를 클릭한다.
3. 목록에서 **MySQL** 관련 프로그램을 찾는다. (예: `MySQL Server`, `MySQL Workbench` 등)
4. 하나씩 선택해서 **제거**한다.

### 1-2. 남은 폴더 지우기 (중요!)

설치를 지웠어도 **폴더가 남아 있을 수 있어**. 꼭 지워야 해.

#### (A) Program Files 폴더

1. 파일 탐색기 열기
2. 아래 폴더로 이동:
   - `C:\Program Files\MySQL`
   - `C:\Program Files (x86)\MySQL`
3. 폴더가 있으면 **통째로 삭제**하기

#### (B) ProgramData 폴더 (숨김 폴더)

`ProgramData`는 숨겨져 있어서 먼저 보이게 해야 해.

1. 파일 탐색기 열기
2. 상단 메뉴에서 `보기` → `숨긴 항목` 체크
3. 아래 경로로 이동:
   - `C:\ProgramData\MySQL`
4. 폴더가 있으면 **삭제**하기

> **왜 지워야 할까?**  
> MySQL은 설치 정보와 데이터 일부를 여기에 저장해.  
> 이게 남아 있으면 재설치할 때 오류가 날 수 있어.

### 1-3. 다시 설치할 때 주의할 점

- **관리자 권한**으로 설치 파일을 실행하기
- 비밀번호는 **쉬운 걸로 만들고, 꼭 기록**하기
- 설치 중 선택 화면에서는 **Developer Default**를 선택하면 편해
- 중간에 방화벽이 뜨면 **허용**하기

## 2. MySQL Workbench 바로가기 찾는 방법

설치를 했는데 **바탕화면에 아이콘이 없을 수 있어**. 그럴 때는 이렇게 찾아.

### 방법 1: 시작 메뉴에서 찾기

1. 윈도우 키(⊞)를 누른다.
2. 검색창에 `MySQL` 또는 `Workbench` 입력
3. **MySQL Workbench** 클릭

### 방법 2: 설치 폴더에서 직접 실행

아래 경로를 찾아가서 실행할 수도 있어.

- `C:\Program Files\MySQL\MySQL Workbench 8.0 CE\MySQLWorkbench.exe`

> 이 파일을 오른쪽 클릭해서 **바탕화면 바로가기 만들기**도 가능해.

## 3. 데이터베이스 실습: 가장 쉬운 예제로 따라하기

이제 본격적으로 **데이터베이스 실습**을 해보자!

### 3-1. 데이터베이스란?

- **데이터를 보관하는 큰 상자**라고 생각하면 돼.
- 예: 학교에서 학생 명부를 저장하는 공간

### 3-2. 테이블이란?

- **데이터베이스 안에 있는 표(엑셀 표)** 같은 것
- 예: `학생` 테이블에는 학생 이름, 나이, 반 같은 정보가 들어감

### 3-3. 열(Column)과 행(Row)

- **열(Column)**: 어떤 정보를 저장할지 정하는 칸
  - 예: `이름`, `나이`
- **행(Row)**: 실제 한 사람의 데이터
  - 예: `철수, 13`

> **왜 열과 행을 먼저 정해야 할까?**  
> 표를 만들려면 칸을 먼저 그려야 하니까!  
> 나중에 바꾸면 불편하니까 처음에 정하는 게 중요해.

---

## 3-4. 가장 쉬운 테이블 만들기

### (1) 데이터베이스 만들기

```sql
-- 왜 이 명령이 필요할까?
-- 데이터베이스는 "큰 상자"야. 실습할 데이터를 담을 새 상자를 만들어야 해.
-- CREATE DATABASE는 새 데이터베이스(상자)를 만드는 명령이야.
CREATE DATABASE school;
```

### (2) 사용할 데이터베이스 선택

```sql
-- 왜 이 명령이 필요할까?
-- 여러 상자(데이터베이스) 중에서 지금 사용할 상자를 선택해야 해.
-- USE는 "앞으로 이 데이터베이스 안에서 작업하겠다"고 알려주는 명령이야.
USE school;
```

### (3) 가장 쉬운 테이블 만들기

```sql
-- 왜 이 명령이 필요할까?
-- 테이블은 엑셀 표처럼 생긴 공간이야. 표의 모양(열)을 먼저 정해야 해.
-- CREATE TABLE은 테이블을 만드는 명령이야.
-- id는 숫자(학생 번호), name은 글자(이름)를 저장한다는 뜻이야.
CREATE TABLE student (
  id INT,
  name VARCHAR(20)
);
```

> 이제 `student`라는 표가 생겼어!

---

## 3-5. 데이터 넣기 (INSERT)

```sql
-- 왜 이 명령이 필요할까?
-- 테이블을 만들었으면 실제 데이터를 넣어야 해.
-- INSERT는 "이 표에 한 줄(행) 추가"라는 뜻이야.
INSERT INTO student (id, name) VALUES (1, '철수');

-- 한 줄 더 넣어보자.
INSERT INTO student (id, name) VALUES (2, '영희');
```

### 확인하기 (SELECT)

```sql
-- 왜 이 명령이 필요할까?
-- 방금 넣은 데이터가 정말 들어갔는지 확인해야 해.
-- SELECT는 "데이터를 보여줘"라는 뜻이야.
-- *는 "모든 열"을 보여달라는 의미야.
SELECT * FROM student;
```

**예상 결과**

```
id | name
1  | 철수
2  | 영희
```

---

## 3-6. 데이터 수정하기 (UPDATE)

```sql
-- 왜 이 명령이 필요할까?
-- 이름을 잘못 입력했거나 바꾸고 싶을 때 수정해야 해.
-- UPDATE는 "기존 데이터를 고쳐라"라는 뜻이야.
-- WHERE는 "어떤 줄을 고칠지" 정하는 조건이야.
UPDATE student
SET name = '민수'
WHERE id = 2;
```

### 확인하기

```sql
-- 수정이 잘 됐는지 다시 확인해보자.
SELECT * FROM student;
```

**예상 결과**

```
id | name
1  | 철수
2  | 민수
```

---

## 3-7. 데이터 삭제하기 (DELETE)

```sql
-- 왜 이 명령이 필요할까?
-- 필요 없는 데이터는 지워야 해.
-- DELETE는 "조건에 맞는 줄을 삭제"하는 명령이야.
DELETE FROM student
WHERE id = 1;
```

### 확인하기

```sql
-- 삭제가 되었는지 확인해보자.
SELECT * FROM student;
```

**예상 결과**

```
id | name
2  | 민수
```
