# MySQL 기초 2-1-1

---

## 1. MySQL이 설치 안 될 때: 제거 후 재설치 요령

설치가 중간에 실패하거나, Workbench는 켜지는데 서버 연결이 안 되는 경우가 있다.  
이럴 때는 **이전 설치 흔적을 정리한 뒤 다시 설치**하면 해결되는 경우가 많다.

### 1-1. 먼저 주의할 점 (중요)

- 기존 DB 데이터가 필요하면 반드시 백업한다.
- 관리자 권한 계정으로 작업한다.
- 설치 파일은 공식 사이트에서 다시 받는다.

### 1-2. 프로그램 제거(제어판)

1. 윈도우 검색에서 `제어판` 실행
2. `프로그램 제거` 클릭
3. `MySQL` 관련 항목 제거  
   예: `MySQL Server`, `MySQL Workbench`

### 1-3. 남은 폴더 수동 삭제

프로그램 제거 후에도 폴더가 남아 있으면 재설치 충돌이 날 수 있다.

#### (A) Program Files 쪽 삭제

아래 폴더가 있으면 삭제한다.

- `C:\Program Files\MySQL`
- `C:\Program Files (x86)\MySQL`

#### (B) ProgramData 쪽 삭제 (가장 중요)

`ProgramData`는 숨김 폴더라서 기본 설정에서는 안 보일 수 있다.

보이게 하는 방법:

1. 파일 탐색기 열기
2. 상단 `보기` 탭 클릭
3. `숨긴 항목` 체크

그 다음 아래 폴더가 있으면 삭제한다.

- `C:\ProgramData\MySQL`

왜 중요하나?

- MySQL 설정 파일과 데이터 흔적이 여기에 남는 경우가 많다.
- 이 폴더가 남아 있으면 재설치 때 같은 오류가 반복될 수 있다.

### 1-4. 다시 설치할 때 체크할 것

- 설치 파일을 **관리자 권한으로 실행**
- root 비밀번호를 너무 어렵게만 만들지 말고, 지금은 기억 가능한 것으로 설정
- 비밀번호를 메모해 두기

## 2. Workbench 바로가기가 없을 때 실행 방법

설치 후 닫고 나면 바탕화면 아이콘이 안 보일 수 있다. 정상이다.

### 방법 1) 시작 메뉴 검색으로 실행

1. 윈도우 키 누르기
2. `MySQL Workbench` 검색
3. 실행
4. 자주 쓸 거면 `작업 표시줄에 고정`

### 방법 2) 설치 경로에서 직접 실행

아래 경로로 이동해서 `MySQLWorkbench.exe` 실행:

- `C:\Program Files\MySQL\MySQL Workbench 8.0 CE\MySQLWorkbench.exe`

실행 파일 우클릭 -> `바로 가기 만들기`를 누르면 바탕화면 아이콘도 만들 수 있다.

## 3. 본격 실습: DB 개념부터 CRUD까지

이제 진짜 데이터베이스 실습을 시작한다.

## 3-1. 개념 먼저 이해하기

### 데이터베이스(Database)란?

- 데이터를 보관하는 큰 저장 공간(창고)
- 예: 학교 전체 학생 정보를 보관하는 공간

### 테이블(Table)이란?

- 데이터베이스 안에 있는 표(엑셀 같은 형태)
- 예: `students`라는 학생 목록 표

### 열(Column)과 행(Row)

- 열(Column): 어떤 정보를 저장할지 정한 항목  
  예: 번호, 이름, 나이
- 행(Row): 실제 데이터 한 줄  
  예: `1, 철수, 14`

왜 먼저 열을 정해야 할까?

- 집을 지을 때 설계도부터 그리는 것처럼,  
  DB도 어떤 정보를 저장할지 먼저 정해야 나중에 수정이 덜 힘들다.

---

## 3-2. 가장 쉬운 테이블 만들기

아래 SQL을 순서대로 실행한다.

```sql
CREATE DATABASE school_db;
USE school_db;
```

설명:

- `CREATE DATABASE`: `school_db`라는 새 데이터베이스 생성
- `USE`: 지금부터 작업할 DB 선택

다음으로 테이블 생성:

```sql
CREATE TABLE students (
  id INT,
  name VARCHAR(20)
);
```

설명:

- `id INT`: 번호(정수)
- `name VARCHAR(20)`: 이름(최대 20글자 문자)

테이블이 잘 만들어졌는지 확인:

```sql
SHOW TABLES;
DESC students;
```

---

## 3-3. 데이터 넣기 (INSERT)

```sql
INSERT INTO students (id, name) VALUES (1, '철수');
INSERT INTO students (id, name) VALUES (2, '영희');
```

바로 눈으로 확인:

```sql
SELECT * FROM students;
```

예상:

```text
id | name
1  | 철수
2  | 영희
```

---

## 3-4. 데이터 수정하기 (UPDATE)

`id=2` 학생 이름을 바꿔보자.

```sql
UPDATE students
SET name = '민수'
WHERE id = 2;
```

다시 확인:

```sql
SELECT * FROM students;
```

예상:

```text
id | name
1  | 철수
2  | 민수
```

---

## 3-5. 데이터 삭제하기 (DELETE)

`id=1` 학생을 삭제해보자.

```sql
DELETE FROM students
WHERE id = 1;
```

다시 확인:

```sql
SELECT * FROM students;
```

예상:

```text
id | name
2  | 민수
```

## 4. 오늘 꼭 기억할 것

1. 설치 오류가 나면 `ProgramData`, `Program Files`의 MySQL 폴더까지 확인
2. Workbench 아이콘이 없어도 시작 메뉴 검색으로 실행 가능
3. CRUD는 아래 순서로 익히면 쉽다

`CREATE -> INSERT -> SELECT -> UPDATE -> DELETE`
