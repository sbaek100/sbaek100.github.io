# 데이터 필터링 업그레이드 (3-2)

---

## 1. 7개 칼럼 테이블 만들기

```sql
CREATE DATABASE filter_db2;
USE filter_db2;

CREATE TABLE students2 (
  id INT,
  name VARCHAR(20),
  grade INT,
  class_no INT,
  city VARCHAR(20),
  score_math INT,
  score_db INT
);
```

```sql
INSERT INTO students2 VALUES (1, '철수', 1, 1, '서울', 85, 90);
INSERT INTO students2 VALUES (2, '영희', 1, 2, '부산', 78, 82);
INSERT INTO students2 VALUES (3, '민수', 2, 1, '서울', 92, 88);
INSERT INTO students2 VALUES (4, '지은', 2, 3, '대전', 64, 70);
INSERT INTO students2 VALUES (5, '준호', 3, 2, '부산', 88, 95);
INSERT INTO students2 VALUES (6, '수진', 3, 1, '서울', 73, 68);
```

---

## 2. AND 실습

```sql
SELECT * FROM students2
WHERE city = '서울' AND score_math >= 80;

SELECT id, name, grade, score_db
FROM students2
WHERE grade = 2 AND score_db >= 85;
```

---

## 3. OR 실습

```sql
SELECT id, name, city
FROM students2
WHERE city = '서울' OR city = '부산';

SELECT id, name, score_math, score_db
FROM students2
WHERE score_math >= 90 OR score_db >= 90;
```

---

## 4. AND + OR 조합

```sql
SELECT id, name, grade, city
FROM students2
WHERE grade = 2 AND (city = '서울' OR city = '부산');

SELECT id, name, grade, score_math, score_db
FROM students2
WHERE (score_math >= 80 AND score_db >= 80)
   OR grade = 3;
```

---

## 5. 추가 연습 문제

아래 문제는 `students2` 데이터를 기준으로 `AND`, `OR`, 괄호를 함께 사용해 풀어보자.

1. 1학년 또는 2학년이면서, 도시가 `서울`인 학생을 조회해 보자.
2. 수학 점수가 80점 이상이고 데이터베이스 점수도 80점 이상이거나, 3학년인 학생을 조회해 보자.
3. 도시가 `부산` 또는 `대전`이면서, 수학 점수가 70점 이상인 학생을 조회해 보자.
4. 2학년이거나 3학년이면서, 데이터베이스 점수가 90점 이상인 학생을 조회해 보자.
5. 반 번호가 1반이면서 도시가 `서울`이거나, 반 번호가 2반이면서 도시가 `부산`인 학생을 조회해 보자.

먼저 직접 작성해 보고, 필요하면 아래 예시 쿼리와 비교해 보자.

```sql
SELECT id, name, grade, city
FROM students2
WHERE (grade = 1 OR grade = 2) AND city = '서울';

SELECT id, name, grade, score_math, score_db
FROM students2
WHERE (score_math >= 80 AND score_db >= 80)
   OR grade = 3;

SELECT id, name, city, score_math
FROM students2
WHERE (city = '부산' OR city = '대전') AND score_math >= 70;

SELECT id, name, grade, score_db
FROM students2
WHERE (grade = 2 OR grade = 3) AND score_db >= 90;

SELECT id, name, class_no, city
FROM students2
WHERE (class_no = 1 AND city = '서울')
   OR (class_no = 2 AND city = '부산');
```
