## 이 실습의 목표

2-1 ~ 2-4에서 배운 Markdown 문법을 **실제로 써먹는 첫 번째 결과물**을 만드는 실습임.  
새로 배울 내용은 없음. 아래 3가지를 하나의 파일에 담아 완성하는 것이 목표임.

| 섹션 | 내용 | 사용 문법 |
|:---|:---|:---|
| 자기소개 | 이름, 학번, 전공, 한 줄 소개 | 제목, 굵게, 인용문 |
| 이력 & 활동 | 학력, 자격증, 프로젝트, 수상 | 표, 체크리스트 |
| 스킬 소개 | 보유 기술과 숙련도 | 표, 인라인 코드 |

---

## STEP 0. 파일 생성

### 파일 위치와 이름

```
_posts/2026-03-08-20240001-about-me.md
```

> 💡 `20240001` 자리에 본인 학번을 넣을 것. 날짜는 오늘 날짜로 맞출 것.
{: .prompt-tip }

### VSCode에서 파일 만들기

```powershell
cd C:\work\[아이디].github.io
code .
```

VSCode 왼쪽 탐색기:
```
_posts 폴더 우클릭 → 새 파일 → 2026-03-08-20240001-about-me.md → Enter
```

미리보기 분할:
```
Ctrl + K → V
```

---

## STEP 1. Front Matter 작성

파일 맨 위에 아래를 붙여넣고 **본인 정보로 수정**함.

```yaml
---
title: "[홍길동] 포트폴리오 소개"
date: 2026-03-08 12:00:00 +0900
categories: [Portfolio, About]
tags: [자기소개, 이력서, 스킬]
toc: true
description: "정보보안학과 홍길동의 포트폴리오 소개 페이지."
---
```

> ⚠️ `title`의 이름과 `description`을 반드시 본인 것으로 바꿀 것.
{: .prompt-warning }

---

## STEP 2. 자기소개 섹션 작성

### 작성 내용

```markdown
## 👋 안녕하세요, 홍길동입니다

> 보안을 공부하는 ICT폴리텍대학교 정보보안과 학생입니다.  
> 네트워크 보안과 웹 취약점 분석에 관심이 있습니다.

---

## 기본 정보

| 항목 | 내용 |
|:---|:---|
| 이름 | 홍길동 |
| 학번 | 20240001 |
| 학교 | ICT폴리텍대학교 |
| 전공 | 정보보안과 |
| 이메일 | hong@example.com |
| GitHub | [github.com/honggildong](https://github.com) |
```

**확인 포인트:** 미리보기에서 인용문이 회색 박스로, 표가 격자 형태로 보이는지 확인.

---

## STEP 3. 이력 & 활동 섹션 작성

### 작성 내용

```markdown
---

## 학력 및 활동

### 학력

| 기간 | 학교 | 전공 |
|:---|:---|:---|
| 2024.03 ~ 재학 중 | ICT폴리텍대학 | 정보보안과 |
| 2021.03 ~ 2024.02 | ○○고등학교 | 졸업 |

---

### 자격증

| 취득년도 | 자격증명 | 발급기관 |
|:---|:---|:---|
| 2024 | 정보처리기능사 | 한국산업인력공단 |
| 2023 | 리눅스마스터 2급 | 한국정보통신진흥협회 |

자격증이 아직 없다면 아래처럼 목표로 바꿔도 됨:

| 목표 시기 | 자격증명 | 준비 현황 |
|:---|:---|:---|
| 2025 하반기 | 정보처리기능사 | 준비 중 |
| 2026 상반기 | 네트워크관리사 2급 | 미시작 |

---

### 프로젝트 & 활동

- [x] Markdown 포트폴리오 블로그 구축 (2026.03)
- [x] DVWA 환경 구성 및 웹 취약점 실습 (2026.02)
- [ ] 개인 CTF(Capture The Flag) 문제 풀이 정리 (진행 중)
- [ ] 네트워크 패킷 분석 보고서 작성 (예정)

---

### 수상 & 기타

| 연도 | 내용 | 주관 |
|:---|:---|:---|
| 2025 | 교내 해킹방어대회 장려상 | ICT폴리텍대학교 |
| 2024 | 정보보안 우수학생 표창 | 정보보안과 |

수상 내역이 없다면 이 섹션을 삭제하거나 **"준비 중인 대회"** 로 대체해도 됨.
```

## STEP 4. 스킬 소개 섹션 작성

### 숙련도 기준 (본인 기준으로 자유롭게 설정)

| 표시 | 의미 |
|:---:|:---|
| ⭐⭐⭐ | 실습 경험 있음, 혼자 할 수 있음 |
| ⭐⭐ | 배웠고 기초 수준으로 사용 가능 |
| ⭐ | 개념은 알지만 아직 실습 경험 부족 |

### 작성 내용

```markdown
---

## 🛠️ 보유 스킬

### 운영체제 & 네트워크

| 기술 | 숙련도 | 설명 |
|:---|:---:|:---|
| `Kali Linux` | ⭐⭐⭐ | 모의해킹 실습 환경으로 활용 |
| `Ubuntu` | ⭐⭐ | 서버 기본 명령어 사용 가능 |
| `Windows Server` | ⭐⭐ | 수업 실습 수준 |
| `Wireshark` | ⭐⭐ | 패킷 캡처 및 기초 분석 |

---

### 보안 도구

| 기술 | 숙련도 | 설명 |
|:---|:---:|:---|
| `Burp Suite` | ⭐⭐⭐ | 웹 취약점 프록시 실습 |
| `Nmap` | ⭐⭐⭐ | 포트 스캔 및 서비스 탐지 |
| `DVWA` | ⭐⭐⭐ | SQL Injection, XSS 등 실습 |
| `Metasploit` | ⭐ | 개념 학습 단계 |

---

### 프로그래밍 & 기타

| 기술 | 숙련도 | 설명 |
|:---|:---:|:---|
| `Python` | ⭐⭐ | 기초 문법 및 간단한 스크립트 작성 |
| `SQL` | ⭐⭐ | SELECT, INSERT 등 기본 쿼리 사용 |
| `HTML/CSS` | ⭐⭐ | 기본 웹 구조 이해 |
| `Git` | ⭐⭐ | add, commit, push 사용 가능 |
| `Markdown` | ⭐⭐⭐ | 이 페이지를 직접 작성함 |
```

> 💡 스킬은 **솔직하게** 적는 것이 좋음. 없는 능력을 과장하면 면접에서 역효과가 남.
{: .prompt-tip }

---

## STEP 5. 마무리 섹션 작성 (선택)

포트폴리오 페이지의 마지막에 한 마디를 덧붙이면 인상이 좋아짐.

```markdown
---

## 한 마디

> 아직 배우는 단계지만, 매일 조금씩 성장하고 있습니다.  
> 이 블로그가 그 기록이 됩니다.
```

---

## STEP 6. 이미지 추가 (선택)

증명사진이나 프로필 사진을 넣고 싶다면 아래처럼 작성함.

```
1. Win + Shift + S → 사진 캡처 또는 사진 파일 클립보드에 복사
2. 편집창에서 이미지 위치에 커서 이동
3. Ctrl + Alt + V → Enter
```

자동 삽입된 후 아래처럼 크기와 위치를 조정함:

```markdown
![프로필 사진](/assets/img/my.png){: w="200" .left }

안녕하세요, 홍길동입니다. (텍스트가 이미지 옆에 배치됨)
```

> ⚠️ `.left` 또는 `.right` 정렬 옵션 사용 시 이미지 아래 캡션(`_캡션_`)은 사용 불가.
{: .prompt-warning }

## STEP 7. 로컬 서버 확인 후 배포

### 로컬 확인

```powershell
bundle exec jekyll serve
```

`http://127.0.0.1:4000` 에서 아래 항목 확인함:

| 확인 항목 | 확인 |
|:---|:---:|
| 홈에 포스트가 나타남 | ☐ |
| 목차(TOC)가 오른쪽에 생성됨 | ☐ |
| 표가 모두 정상 표시됨 | ☐ |
| 체크리스트 박스가 보임 | ☐ |
| 인용문 박스가 표시됨 | ☐ |
| 인라인 코드(백틱)가 강조됨 | ☐ |

### 배포

```powershell
git add .
git commit -m "feat: [학번] 자기소개 포트폴리오 페이지 추가"
git push origin main
```

약 1~2분 후 `https://[아이디].github.io` 에서 최종 확인함.

## 완성본 전체 구조 미리보기

아래가 이번 실습에서 만든 파일의 최종 모습임.

```
## 👋 안녕하세요, 홍길동입니다
  → 한 줄 인용문 자기소개

## 기본 정보
  → 이름/학번/학교/이메일/GitHub 표

## 학력 및 활동
  ### 학력         → 표
  ### 자격증        → 표
  ### 프로젝트 & 활동 → 체크리스트
  ### 수상 & 기타    → 표

## 🛠️ 보유 스킬
  ### 운영체제 & 네트워크 → 표 + 인라인 코드
  ### 보안 도구          → 표 + 인라인 코드
  ### 프로그래밍 & 기타   → 표 + 인라인 코드

## 한 마디
  → 마무리 인용문
```

## 최종 완료 체크리스트

| 항목 | 확인 |
|:---|:---:|
| 파일명에 학번 포함, 날짜 오늘 날짜로 설정 | ☐ |
| Front Matter에 본인 이름과 설명 입력 | ☐ |
| 자기소개 섹션 — 인용문 + 기본정보 표 | ☐ |
| 이력 섹션 — 학력, 자격증(또는 목표), 활동 체크리스트 | ☐ |
| 스킬 섹션 — 3개 분야 이상, 인라인 코드로 기술명 표시 | ☐ |
| 로컬 서버(`4000`)에서 전체 레이아웃 확인 | ☐ |
| `git push` 후 실제 사이트에서 포스트 확인 | ☐ |

## 참고: 자주 하는 실수

| 증상 | 원인 | 해결 |
|:---|:---|:---|
| 표 열이 어긋나 보임 | 파이프(`\|`) 개수 불일치 | `Alt+Shift+F` 로 자동 정렬 |
| 체크박스가 텍스트로 보임 | `- [x]` 앞에 공백 없음 | `- [x] 내용` 형식 확인 |
| 인용문이 한 줄로 합쳐짐 | 줄 끝에 공백 2칸 없음 | 줄 끝에 스페이스 2칸 추가 |
| 포스트가 홈에 안 나타남 | 파일명 날짜가 미래 | 오늘 날짜로 수정 |
