# 4-3 파이썬으로 연결하기

4-2의 `products` 조회를 파이썬에서 실행해본다.

---

## 1. 준비

```bash
pip install mysql-connector-python
```

---

## 2. 파일 만들기

파일명: `step4_3_products.py`

```python
import mysql.connector

conn = mysql.connector.connect(
    host="localhost",
    user="root",
    password="비밀번호",
    database="datatype_db",
    charset="utf8mb4"
)

cursor = conn.cursor()

print("[1] 전체 조회")
cursor.execute("SELECT id, name, price FROM products")
for row in cursor.fetchall():
    print(row)

print("\\n[2] LIKE 조회")
cursor.execute("SELECT id, name, price FROM products WHERE name LIKE %s", ("%갤럭시%",))
for row in cursor.fetchall():
    print(row)

print("\\n[3] BETWEEN 조회")
cursor.execute("SELECT id, name, price FROM products WHERE price BETWEEN %s AND %s", (10000, 200000))
for row in cursor.fetchall():
    print(row)

cursor.close()
conn.close()
```

---

## 3. 실행

```bash
python step4_3_products.py
```
