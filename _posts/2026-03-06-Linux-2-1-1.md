# (2주차 실습과제) 리눅스 입문 - Shell과 File System

## 1. 실습 목표

- 터미널과 쉘의 역할을 구분하고 설명할 수 있다.
- 기본 명령어(`man`, `ls`, `cd`, `pwd`, `cat`, `mkdir`, `cp`, `mv`, `rm`, `touch`)를 직접 사용한다.
- 리눅스 파일 계층 구조(FHS)와 가상 파일 시스템(`/proc`, `/sys`, `/dev`)을 확인한다.
- 소프트 링크와 하드 링크의 차이를 실습으로 검증한다.
- 간단한 쉘 스크립트를 작성하고 실행한다.

---

## 2. 실습 환경

- OS: Ubuntu 24.xx (또는 동등한 Linux 환경)
- Shell: Bash
- 터미널: GNOME Terminal 또는 동등한 터미널

확인 명령:

```bash
echo $SHELL
uname -a
```

---

## 3. 사전 준비

아래 명령으로 실습용 작업 디렉터리를 만든다.

```bash
mkdir -p ~/linux-week2-lab
cd ~/linux-week2-lab
pwd
```

---

## 4. 실습 과제

### 과제 1) 터미널과 쉘 이해

1. 현재 사용 중인 쉘을 확인한다.
2. `man bash`를 실행해 Bash 매뉴얼의 첫 화면을 확인한다.
3. 아래 질문에 한 줄씩 답을 작성한다.

- 터미널과 쉘의 차이는 무엇인가?
- 사용자가 명령을 입력했을 때, 쉘과 커널은 각각 어떤 역할을 하는가?

실행 예시:

```bash
echo $SHELL
man bash
```

---

### 과제 2) 기본 명령어 실습

다음 순서대로 실행하고, 각 명령의 결과를 기록한다.

```bash
mkdir -p practice/docs practice/tmp
touch practice/docs/file1.txt practice/docs/file2.txt
echo "Linux Week2" > practice/docs/file1.txt
cat practice/docs/file1.txt
ls -la practice/docs
cp practice/docs/file1.txt practice/docs/file1_copy.txt
mv practice/docs/file2.txt practice/docs/file2_renamed.txt
pwd
cd practice
cd -
```

추가 과제:

- `man ls`에서 `-l`, `-a`, `-h`, `-t` 옵션 의미를 찾아 정리한다.
- `rm -r practice/tmp`를 실행하고 삭제 결과를 확인한다.

주의:

- `rm -rf /` 같은 파괴적 명령은 절대 실행하지 않는다.

---

### 과제 3) 파일 시스템 관찰

아래 경로의 성격을 직접 확인하고 요약한다.

```bash
ls /proc | head
ls /sys | head
ls /dev | head
```

작성 항목:

- `/proc`는 어떤 정보를 보여주는가?
- `/sys`는 어떤 장치/커널 정보를 다루는가?
- `/dev`는 무엇을 파일처럼 제공하는가?

---

### 과제 4) FHS 구조 탐색

루트 디렉터리 기준 주요 경로를 조사한다.

```bash
ls -l /
```

아래 디렉터리의 용도를 한 줄씩 작성한다.

- `/bin`
- `/etc`
- `/home`
- `/tmp`
- `/usr`
- `/var`

---

### 과제 5) 소프트 링크 vs 하드 링크

다음 실습을 수행하고 결과를 비교한다.

```bash
cd ~/linux-week2-lab
echo "link-test" > original.txt
ln -s original.txt soft_link.txt
ln original.txt hard_link.txt
ls -l
ls -i original.txt soft_link.txt hard_link.txt
```

원본 삭제 후 확인:

```bash
rm original.txt
ls -l
cat soft_link.txt
cat hard_link.txt
```

분석 항목:

- 어떤 링크가 깨졌는가?
- 어떤 링크가 데이터를 유지했는가?
- inode 번호 관점에서 차이는 무엇인가?

---

### 과제 6) 쉘 스크립트 작성

`week2_summary.sh` 파일을 작성하고 실행한다.

```bash
nano week2_summary.sh
```

스크립트 내용:

```bash
#!/bin/bash
echo "=== Week2 Linux Lab Summary ==="
echo "User: $(whoami)"
echo "Shell: $SHELL"
echo "Date: $(date)"
echo "Current Directory: $(pwd)"
echo "Files:"
ls -la
```

실행:

```bash
chmod +x week2_summary.sh
./week2_summary.sh
```

## 5. 실습 중점 확인 사항

아래 항목은 점수 평가용이 아니라, 실습 이해도를 스스로 점검하기 위한 확인 기준이다.

- 명령어를 단순 실행하는 데서 끝내지 않고, 출력 결과의 의미를 설명할 수 있는가?
- 절대 경로와 상대 경로를 상황에 맞게 구분해 사용할 수 있는가?
- `ls -l` 결과에서 파일 종류 문자(`-`, `d`, `l`)를 읽고 해석할 수 있는가?
- `/proc`, `/sys`, `/dev`가 일반 디렉터리와 어떻게 다른지 말할 수 있는가?
- 소프트 링크/하드 링크 생성 후 inode 번호 차이를 확인했는가?
- 원본 파일 삭제 후 두 링크의 동작 차이를 실제로 확인했는가?
- 쉘 스크립트 실행 권한(`chmod +x`)의 필요성을 설명할 수 있는가?
- 실습 중 위험 명령(`rm -rf`) 사용 시 대상 경로를 재확인하는 습관을 지켰는가?

## 6. 확장 과제 (선택)

- `alias`를 2개 이상 정의하고 동작을 확인한다.
- `history`와 `!번호`를 사용해 이전 명령 재실행을 시도한다.
- `find`, `grep`를 이용해 특정 문자열이 포함된 파일을 검색한다.
