# 📖 풀이 및 해설

---

### 문제 1, 2 해설 — fork와 exec

**정답: 문제1=③, 문제2=②**

프로세스 생성 2단계:

```mermaid
flowchart LR
    A["부모 프로세스"] -->|"fork() = 복사"| B["자식 프로세스\n(부모와 동일한 복사본)"]
    B -->|"exec() = 교체"| C["자식 프로세스\n(새 프로그램 실행)"]
```

- **fork()**: 부모를 그대로 복사해 자식 생성. 부모에는 자식 PID 반환, 자식에는 0 반환
- **exec()**: 현재 프로세스를 새 프로그램 이미지로 교체. 기존 메모리 내용 덮어씀

예시: 셸에서 `ls` 입력 → bash가 fork() → 자식 bash가 exec(ls) → ls 실행

### 문제 3 해설 — init/systemd PID

**정답: ④ init(systemd), PID 1**

- 커널이 부팅 완료 후 최초로 생성하는 프로세스 = **init 또는 systemd**
- 항상 **PID 1** 할당
- 모든 프로세스의 조상. 고아 프로세스의 자동 입양 주체

```bash
ps -p 1           # PID 1 확인
readlink /proc/1/exe  # systemd 경로 출력
```

### 문제 4, 5 해설 — 좀비 프로세스 STAT

**정답: ④ Z**

| STAT 코드 | 의미 |
|---|---|
| R | 실행 중 또는 실행 대기 |
| S | 인터럽트 가능한 수면 |
| D | 인터럽트 불가 수면 (I/O 대기) |
| **Z** | **좀비 프로세스 ← 정답** |
| T | SIGSTOP으로 중단된 상태 |
| X | 완전 종료 (거의 안 보임) |

좀비 프로세스: 실행은 끝났지만 부모가 `wait()` 로 회수하지 않아 프로세스 테이블에 남은 상태. PID는 여전히 점유 중.

```bash
ps aux | awk '$8 == "Z"'     # 좀비 확인
ps -eo stat,pid,cmd | grep Z
```

### 문제 6 해설 — 데몬 확인 방법

**정답: ④ ps 명령어**

- `jobs`: 현재 셸 세션의 포/백그라운드 **작업** 목록 (세션 종속적)
- `ps`: 시스템 전체 프로세스 확인 (세션과 무관)

데몬(daemon)은 시스템 백그라운드에서 돌아가는 서비스 프로세스로, 특정 셸 세션에 속하지 않음. 따라서 `jobs`로는 보이지 않고 `ps aux` 또는 `ps -ef`로 확인해야 함.

### 문제 9, 10 해설 — 키 조합 구분

**정답: 문제9=① Ctrl+C, 문제10=③ Ctrl+Z**

| 키 조합 | 동작 | 전송 시그널 |
|---|---|---|
| `Ctrl+C` | **포어그라운드 프로세스 종료** | SIGINT (2) |
| `Ctrl+Z` | **포어그라운드 프로세스 중단** (백그라운드 전환 전 단계) | SIGTSTP (20) |

| `Ctrl+\` | 강제 종료 + 코어 덤프 | SIGQUIT (3) |

> `Ctrl+Z`는 종료가 아니라 **일시 중단**임. `bg %번호`로 백그라운드 재개 가능.

### 문제 11 해설 — 작업번호로 kill

**정답: ② kill %2**

```bash
jobs       # 작업 목록 확인
# [1] Running ...
# [2] Running ...

kill %2    # 2번 작업에 SIGTERM 전송
kill %1    # 1번 작업에 SIGTERM 전송
```

- `kill 2` 는 **PID가 2인 프로세스**에 시그널을 보내는 것 (PID 2 = kthreadd, 시스템 프로세스)
- `kill %2` 는 **jobs 목록의 2번 작업**에 시그널을 보내는 것

### 문제 13, 14 해설 — NI 값 범위

**정답: ③ -20 ~ 19**

- NI(Nice) 값 범위: **-20 이상 19 이하**
- **-20**: 최고 우선순위 (root만 설정 가능)
- **19**: 최저 우선순위
- **0**: 기본값

> `-20 ~ 20`이 아님. 최솟값은 -20, 최댓값은 **19**임. 시험에서 20과 19를 혼동하도록 출제하므로 주의.
{: .prompt-danger }

### 문제 15, 16 해설 — renice 명령어

**정답: 문제15=② 우선순위를 낮춘다, 문제16=① renice 10 1222**

NI 값과 우선순위의 관계:
- **NI 값을 올림(양수)** → CPU 할당 비율 감소 → **우선순위 낮아짐**
- **NI 값을 내림(음수)** → CPU 할당 비율 증가 → **우선순위 높아짐**

`renice 10 1222` 는 PID 1222의 NI를 10으로 **올리는 것** → 우선순위 낮아짐.

```bash
renice 값 PID           # PID로 변경
renice 값 -u 사용자명   # 사용자의 모든 프로세스 변경
renice 값 -g 그룹명     # 그룹의 모든 프로세스 변경
```

### 문제 17 해설 — 프로세스명 인자 명령어

**정답: ③ killall, nice**

| 명령어 | 인자 | 설명 |
|---|---|---|
| `kill` | PID | PID로 시그널 전송 |
| `killall` | **프로세스 이름** | 이름으로 시그널 전송 |
| `nice` | **명령어(프로세스명)** | 명령어를 지정한 NI로 실행 |
| `renice` | PID | PID로 NI 변경 |

`nice -n 10 ./backup.sh` → backup.sh 라는 프로세스 이름으로 사용
`killall nginx` → nginx 라는 프로세스 이름으로 종료

### 문제 18 해설 — kill 기본 시그널

**정답: ④ SIGTERM, 15**

```bash
kill 1234       # = kill -TERM 1234 = kill -15 1234
```

`kill` 명령의 기본 시그널은 **SIGTERM(15)**임. 프로세스에게 "종료 요청"을 보내며, 프로세스가 받아들여 정상 종료하거나 무시할 수 있음.

SIGKILL(9)는 강제 종료이며 무시 불가. 반드시 `-9` 또는 `-KILL` 옵션을 명시해야 함.

### 문제 20, 21 해설 — 시그널 번호

**정답: 문제20=② 9, 문제21=① 1**

주요 시그널 번호 암기표:

| 번호 | 이름 | 기억법 |
|---|---|---|
| **1** | SIGHUP | 1번 = 전화 끊김(Hang Up) |
| **2** | SIGINT | 2번 = Ctrl+C 인터럽트 |
| **9** | SIGKILL | 9번 = 무조건 Kill (가장 강력) |
| **15** | SIGTERM | 15번 = 기본 kill 값 |
| **18** | SIGCONT | 중단된 프로세스 재개 |
| **19** | SIGSTOP | 19번 = 강제 중단 |
| **20** | SIGTSTP | 20번 = Ctrl+Z |

### 문제 23, 24 해설 — kill vs killall

**정답: 문제23=② killall, 문제24=① kill**

```bash
kill 513 514 515      # PID 여러 개를 직접 나열
killall vsftpd        # 프로세스 이름으로 모두 종료
```

- `kill`: PID를 인자로 받음. 여러 PID를 공백으로 구분해 나열 가능
- `killall`: 프로세스 이름을 인자로 받음. 해당 이름의 모든 프로세스에 시그널 전송

### 문제 25 해설 — cron 설정

**정답: ③ `1 1 * * 1`**

crontab 형식:
```
분(0-59) 시(0-23) 일(1-31) 월(1-12) 요일(0-7, 0=일, 1=월, ..., 6=토, 7=일)
```

"매주 월요일 오전 1시 1분":
- 분: 1
- 시: 1
- 일: `*` (매일)
- 월: `*` (매월)
- 요일: 1 (월요일)

→ `1 1 * * 1`
