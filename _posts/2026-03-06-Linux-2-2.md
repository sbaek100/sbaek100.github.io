# 📖 풀이 및 해설

---

### 문제 1 해설 — 셸의 등장 시기

**정답: ④ bourne shell**

셸(Shell)의 등장 순서는 아래와 같음.

| 셸 이름 | 개발 연도 | 특징 |
|---|---|---|
| Bourne Shell (sh) | 1979년 | 가장 오래된 유닉스 셸. Stephen Bourne 개발 |
| csh (C Shell) | 1979년 | C 언어 문법과 유사. BSD 유닉스에서 사용 |
| bash (Bourne Again Shell) | 1989년 | Bourne Shell 개선판. 리눅스 기본 셸 |
| dash | 2002년 | Debian 경량 셸. POSIX 호환 |

Bourne Shell이 1979년에 등장한 가장 오래된 셸임.  
bash는 Bourne Shell을 개선한 것으로, 이름 자체에 "Again"이 포함되어 있음.

---

### 문제 2 해설 — 로그인 셸 기록 파일

**정답: ② /etc/passwd**

`/etc/passwd` 파일의 각 줄 형식:

```
사용자명:암호:UID:GID:코멘트:홈디렉터리:로그인셸
```

**예시:**
```
user:x:1000:1000:User Name:/home/user:/bin/bash
```

- 마지막 필드가 해당 사용자의 **로그인 셸 경로**임.
- `/etc/shells`는 시스템에서 사용 가능한 셸 목록이 기록된 파일 (문제 5와 연관).
- 두 파일의 역할 구분이 핵심 포인트임.

---

### 문제 3 해설 — 이용 가능한 셸 목록 확인

**정답: ④ chsh -l**

`chsh` 명령어 옵션:

| 옵션 | 의미 |
|---|---|
| `-l` | 사용 가능한 셸 목록 출력 (`/etc/shells` 내용) |
| `-s /bin/zsh` | 로그인 셸을 지정한 셸로 변경 |
| `-u` | 특정 사용자의 셸 변경 |

`echo $SHELL`로도 현재 셸을 확인할 수 있지만, 이는 현재 사용 중인 셸만 보여줌.  
**이용 가능한 전체 셸 목록**을 보려면 `chsh -l` 또는 `cat /etc/shells`를 사용함.

---

### 문제 4 해설 — 로그인 셸 환경변수

**정답: ③ SHELL**

주요 환경변수 정리:

| 환경변수 | 의미 | 확인 방법 |
|---|---|---|
| `$SHELL` | 현재 사용자의 로그인 셸 경로 | `echo $SHELL` |
| `$USER` | 현재 로그인한 사용자명 | `echo $USER` |
| `$HOME` | 홈 디렉터리 경로 | `echo $HOME` |
| `$PATH` | 명령어 검색 경로 목록 | `echo $PATH` |
| `$PWD` | 현재 작업 디렉터리 | `echo $PWD` |

수업에서 다룬 `echo $SHELL` 명령이 바로 이 환경변수를 출력하는 것임.

---

### 문제 5 해설 — 이용 가능한 셸 목록 파일

**정답: ① /etc/shells**

- `/etc/shells`: 시스템에서 사용 **가능한** 셸들의 경로 목록
- `/etc/passwd`: 각 사용자별 **로그인 셸** 경로 포함

```bash
cat /etc/shells
# 출력 예시:
# /bin/sh
# /bin/bash
# /bin/zsh
# /bin/dash
```

문제 2와 함께 자주 출제되는 페어(pair) 개념임.  
- **사용 가능한 셸 목록** → `/etc/shells`  
- **사용자별 로그인 셸** → `/etc/passwd`

---

### 문제 6 해설 — echo $SHELL 출력 결과

**정답: ① 사용자가 로그인 시에 부여받은 셸 정보가 출력된다.**

`$SHELL` 환경변수는 **로그인 시에 설정된 셸 경로**를 저장함.  
현재 실행 중인 셸과 다를 수 있음.

```bash
echo $SHELL
# 출력: /bin/bash   ← 로그인 셸 (변경해도 $SHELL은 로그인 셸 유지)
```

**중요 구분:**
- `$SHELL` → 로그인 시 부여받은 셸
- `ps` 명령으로 현재 실행 중인 셸 확인 가능

---

### 문제 7 해설 — alias 우회 실행

**정답: ③ ls 명령어 앞에 `\` 기호를 덧붙여서 실행한다.**

`alias`로 설정된 명령어를 우회하고 원래 명령어를 실행하려면 **백슬래시(`\`)** 를 앞에 붙임.

```bash
alias ls='ls --color=auto -la'
ls          # alias 적용 실행
\ls         # 원래 ls 명령어 실행 (alias 우회)
```

### 문제 11 해설 — 홈 디렉터리 용량 확인

**정답: ③ du**

```bash
du -sh ~ihduser
```

- `du` (disk usage): **디렉터리나 파일이 차지하는 디스크 용량** 확인
- `df` (disk free): **파일 시스템(마운트된 장치) 전체 사용량** 확인

| 명령어 | 의미 | 용도 |
|---|---|---|
| `du -sh ~ihduser` | 홈 디렉터리 용량 | **특정 디렉터리 크기** |
| `df -h` | 전체 디스크 사용량 | **파티션/마운트 포인트별 여유 공간** |

**옵션 의미:**
- `-s`: 요약(summary) — 하위 디렉터리 합산한 총합만 출력
- `-h`: human-readable — KB/MB/GB 단위로 보기 쉽게 출력
