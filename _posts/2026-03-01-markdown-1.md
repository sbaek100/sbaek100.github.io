## Markdown(마크다운)이란?

Markdown은 **텍스트 기반의 경량 마크업 언어**임.  
HTML을 직접 쓰지 않고도 제목, 표, 이미지, 링크 등을 간단한 기호로 표현할 수 있음.  
GitHub Pages, Notion, Obsidian 등 대부분의 현대 플랫폼에서 지원함.

---

## 1. 제목 (Heading)

`#` 기호의 개수로 제목 크기를 결정함.

```markdown
# 제목 1 (가장 큼)
## 제목 2
### 제목 3
#### 제목 4
```

**결과:**

# 제목 1

## 제목 2

### 제목 3

#### 제목 4

> 💡 포트폴리오에서는 `##`(제목 2)를 섹션 구분에, `###`(제목 3)을 소제목에 사용하는 것을 권장함.

---

## 2. 텍스트 강조

```markdown
**굵게 (Bold)**
*기울임 (Italic)*
~~취소선~~
**_굵게 + 기울임_**
`인라인 코드`
```

**결과:**

**굵게 (Bold)**  
_기울임 (Italic)_  
~~취소선~~  
**_굵게 + 기울임_**  
`인라인 코드`

> 💡 포트폴리오에서 기술명, 도구명은 `백틱`으로 강조하면 깔끔하게 보임.  
> 예: `Python`, `Kali Linux`, `Burp Suite`

## 3. 목록 (List)

### 순서 없는 목록

```markdown
- 항목 1
- 항목 2
  - 하위 항목 (스페이스 2칸)
  - 하위 항목
- 항목 3
```

**결과:**

- 항목 1
- 항목 2
    - 하위 항목
    - 하위 항목
- 항목 3

### 순서 있는 목록

```markdown
1. 첫 번째
2. 두 번째
3. 세 번째
```

**결과:**

1. 첫 번째
2. 두 번째
3. 세 번째

### 체크리스트

```markdown
- [x] 완료된 항목
- [ ] 미완료 항목
- [x] GitHub Pages 설정
- [ ] 포트폴리오 작성
```

**결과:**

- [x] 완료된 항목
- [ ] 미완료 항목
- [x] GitHub Pages 설정
- [ ] 포트폴리오 작성

## 4. 링크 & 이미지

### 링크

```markdown
[보여줄 텍스트](URL)

# 예시
[GitHub](https://github.com)
[내 블로그](https://sbaek100.github.io)
```

**결과:**  
[GitHub](https://github.com/)

### 이미지

```markdown
![대체텍스트](이미지경로)

# 예시
![프로필사진](/assets/img/my.jpg)
![실습화면](/assets/img/posts/screenshot.png)
```

> 💡 이미지 경로는 반드시 `/`(절대경로)로 시작해야 Jekyll에서 정상 표시됨.

## 5. 표 (Table)

```markdown
| 항목 | 내용 | 비고 |
|------|------|------|
| 이름 | 홍길동 | |
| 학번 | 2024001 | |
| 전공 | 정보보안 | |
```

**결과:**

|항목|내용|비고|
|---|---|---|
|이름|홍길동||
|학번|2024001||
|전공|정보보안||

### 정렬 옵션

```markdown
| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
|:----------|:-----------:|------------:|
| 내용 | 내용 | 내용 |
```

**결과:**

|왼쪽 정렬|가운데 정렬|오른쪽 정렬|
|:--|:-:|--:|
|내용|내용|내용|

## 6. 코드 블록 (Code Block)

### 인라인 코드

```markdown
`코드` 이렇게 쓰면 인라인으로 표시됨.
```

### 블록 코드 (언어 지정)

````markdown
```python
# 파이썬 예시
def hello():
    print("Hello, World!")
```

```bash
# 리눅스 명령어 예시
nmap -sV 192.168.1.1
```

```sql
-- SQL 예시
SELECT * FROM users WHERE id = 1;
```
````

**결과:**

```python
def hello():
    print("Hello, World!")
```

```bash
nmap -sV 192.168.1.1
```

> 💡 언어명을 지정하면 **문법 강조(Syntax Highlighting)**가 자동 적용됨.  
> 지원 언어: `python`, `bash`, `sql`, `javascript`, `java`, `c`, `html` 등

## 9. Front Matter (Jekyll 전용)

Jekyll 포스트 최상단에 반드시 포함해야 하는 메타데이터임.

```yaml
---
title: "포스트 제목"
date: 2026-03-01 12:00:00 +0900
categories: [상위카테고리, 하위카테고리]
tags: [태그1, 태그2, 태그3]
pin: false        # true면 홈 상단 고정
toc: true         # 목차 자동 생성
---
```

> ⚠️ `---` 사이에 들여쓰기나 탭이 있으면 빌드 오류 발생함. 반드시 스페이스로 맞출 것.
