# 프로그래밍일반 빈출 주제 정리

프로그래밍일반은 깊은 코딩 능력을 요구하기보다는, 프로그래밍 언어와 번역 과정, 운영체제, 기본 문법 개념을 정확히 구분하는 문제가 자주 나온다.  
특히 `운영체제`, `로더`, `링커`, `토큰`, `후위표기`, `Java`, `C 언어` 기본 개념이 반복된다.

---

## 1. 운영체제

운영체제는 컴퓨터 시스템의 자원을 효율적으로 관리하고 사용자에게 편리한 환경을 제공하는 시스템 소프트웨어이다.  
처리 능력 향상, 신뢰도 향상, 사용 가능도 향상 같은 목적을 자주 묻는다.

시험 포인트:

- 자원 관리
- 사용자와 하드웨어 사이의 인터페이스
- 처리 능력, 신뢰도, 사용 가능도

---

## 2. 링커

링커는 여러 개의 목적 프로그램과 라이브러리를 하나로 묶어 실행 가능한 프로그램으로 만드는 프로그램이다.  
소스코드를 바로 실행하는 것이 아니라, 번역이 끝난 목적 코드들을 연결하는 역할을 한다.

핵심은 다음과 같다.

- 목적 프로그램 연결
- 내장 함수 및 라이브러리 결합
- 실행 가능한 파일 생성

---

## 3. 로더

로더는 실행 프로그램을 주기억장치에 적재하고 실행 준비를 하는 프로그램이다.  
특히 메모리 공간 할당, 적재, 재배치 기능을 문제로 자주 낸다.

링커와의 차이는 이렇게 보면 된다.

- `링커` : 프로그램을 하나로 연결
- `로더` : 연결된 프로그램을 메모리에 올려 실행 준비

---

## 4. 토큰

토큰은 프로그램을 구성하는 최소 의미 단위이다.  
예를 들어 식별자, 상수, 연산자, 구분자 등이 토큰에 해당한다.

시험에서는 주어진 코드 한 줄에서 토큰 수를 세게 하는 문제가 자주 나온다.

---

## 5. 후위표기법

후위표기법은 연산자를 피연산자 뒤에 적는 방식이다.  
예를 들어 일반 수식 `A+B*C`를 후위표기로 바꾸면 `A B C * +`처럼 표현된다.

핵심 포인트:

- 괄호 없이 계산 순서를 표현할 수 있다.
- 스택 구조와 함께 자주 설명된다.

---

## 6. Java 기본 개념

Java 영역에서는 `super`, `extends`, 접근 제어자, 클래스 상속 같은 기본 문법이 자주 나온다.  
깊은 문법보다는 “어떤 키워드가 어떤 역할을 하는가”를 구분하는 문제가 많다.

예:

- `extends` : 상속
- `super` : 상위 클래스 참조
- `public`, `private` : 접근 제어

---

## 7. C 언어 기본 개념

C 언어에서는 기억 클래스, 비트 연산자, 반복문, 포인터, 기계어와의 관계 같은 기본 특징을 묻는다.  
특히 C 언어가 시스템 프로그래밍 언어로 적합하다는 점과, 이식성과 효율성을 자주 다룬다.

---

## 8. 디버거와 바인딩

`디버거(Debugger)`는 프로그램 실행 중 오류를 찾고 수정하는 데 사용하는 도구이다.  
`바인딩(Binding)`은 이름과 속성이 실제 값이나 메모리와 연결되는 시점을 뜻한다.

이 둘은 정의형 문제로 자주 출제된다.

---

## 정리

프로그래밍일반은 개념을 정확히 구분하는 것이 중요하다.

- 운영체제 : 자원 관리
- 링커 : 목적 코드 연결
- 로더 : 메모리 적재
- 토큰 : 문법 최소 단위
- 후위표기 : 연산자 뒤 배치
- Java/C : 기본 문법과 특징

복잡한 코드를 푸는 것보다, 용어의 기능을 한 줄로 설명할 수 있는 상태를 만드는 것이 더 중요하다.
