## 이 실습의 목표

VSCode를 설치하고, 앞서 만든 **학번_project 폴더** 안에서 Markdown을 직접 작성하며 미리보기로 결과를 확인함.  
이 실습 환경은 Jekyll 블로그 환경과 **폴더 구조가 동일**하므로, 여기서 익힌 내용이 그대로 Jekyll에서 사용됨.

---

## STEP 0. 실습 폴더 구조 확인 (가장 먼저)

> ⚠️ VSCode 설치 전에 **폴더 구조가 이미 만들어져 있어야 함.**  
> 아직 안 만들었다면 `2-1 Markdown 완벽 가이드`의 첫 섹션을 먼저 진행할 것.

### 확인할 폴더 구조

```
C:\work\
  └── 20240001_project\          ← 본인 학번으로 생성되어 있어야 함
        ├── assets\
        │     └── img\
        │           └── posts\   ← 이미지 저장 위치
        ├── _posts\              ← Markdown 파일 저장 위치
        └── README.md
```

### 폴더 존재 확인 (PowerShell)

```powershell
tree C:\work\20240001_project
```

폴더가 없다면 아래 명령어로 한 번에 생성함:

```powershell
$student = "20240001"   # ← 본인 학번으로 변경
New-Item -ItemType Directory -Path "C:\work\${student}_project\_posts"
New-Item -ItemType Directory -Path "C:\work\${student}_project\assets\img\posts"
New-Item -ItemType File     -Path "C:\work\${student}_project\README.md"
```

> 💡 **이 구조가 Jekyll과 동일한 이유:**  
> Jekyll Chirpy 블로그도 `_posts/`에 `.md` 파일을 넣고, 이미지는 `assets/img/posts/`에 저장함.  
> 지금 만드는 폴더가 곧 나중에 사용할 블로그 폴더임.

## STEP 1. VSCode 설치

### 1-1. 다운로드 및 설치

1. [https://code.visualstudio.com](https://code.visualstudio.com) 접속
2. **Download for Windows (Stable)** 클릭
3. 설치 파일 실행 → 다음 항목 반드시 체크

```
✅ "PATH에 추가 (Add to PATH)"
✅ "바탕화면에 바로가기 만들기"
```

> ⚠️ "PATH에 추가"를 체크해야 PowerShell에서 `code .` 명령어로 VSCode를 바로 열 수 있음.

### 1-2. 설치 확인

```powershell
code --version
```

버전 번호가 출력되면 설치 성공임.

---

## STEP 2. 필수 플러그인 설치

### 플러그인 설치 방법

```
Ctrl + Shift + X  →  검색창에 플러그인명 입력  →  Install 클릭
```

### 설치 목록 (순서대로 설치할 것)

| 순서 | 플러그인명 | 주요 기능 |
|:---:|:---|:---|
| 1 | `Markdown All in One` | 단축키, 목차 자동생성, 미리보기 |
| 2 | `Markdown Preview Enhanced` | 이미지 포함 미리보기 (**핵심**) |
| 3 | `Paste Image` | 클립보드 이미지 → Markdown 자동 삽입 |
| 4 | `markdownlint` | 문법 오류 실시간 검사 |

> 💡 검색 시 플러그인명을 **정확히** 입력할 것. 비슷한 이름의 유사 플러그인이 존재함.

### 설치 확인

```
Ctrl + Shift + X  →  "설치됨(Installed)" 탭 클릭  →  4개 모두 있는지 확인
```

## STEP 3. VSCode로 실습 폴더 열기

> ⚠️ **반드시 폴더째로 열어야 함.** 파일만 열면 이미지 경로를 찾지 못함.

### 폴더 열기

```powershell
# PowerShell에서
cd C:\work\20240001_project
code .
```

또는 VSCode 메뉴:
```
파일(File) → 폴더 열기(Open Folder) → C:\work\20240001_project 선택 → 확인
```

### 열린 후 화면 확인

VSCode 왼쪽 탐색기에 아래 구조가 보여야 정상임:

```
📁 20240001_PROJECT
  📁 _posts
  📁 assets
    📁 img
      📁 posts
  📄 README.md
```

> 💡 **Jekyll과의 연결:**  
> 나중에 Jekyll 블로그 폴더를 VSCode로 열면 이와 동일한 구조가 보임.  
> `_posts/` 안에 `.md` 파일을 만들고 저장하는 방식도 완전히 동일함.

## STEP 4. 실습 파일 생성 및 미리보기 분할

### 4-1. _posts 폴더에 실습 파일 생성

VSCode 왼쪽 탐색기에서:

```
_posts 폴더 우클릭 → 새 파일(New File) → 파일명: practice.md → Enter
```

> 💡 파일명을 `YYYY-MM-DD-제목.md` 형식으로 만드는 것이 Jekyll 규칙임.  
> 지금은 연습이므로 `practice.md`로 해도 되지만, 실제 포스트는 `2026-03-08-my-first-post.md` 형식으로 만들 것.

### 4-2. 미리보기 패널 열기

```
Ctrl + K  →  V    (순서대로 누를 것, 동시 아님)
```

결과적으로 아래처럼 화면이 분할됨:

```
┌──────────────────────┬──────────────────────┐
│   편집 영역           │   미리보기 영역        │
│   (_posts/           │   실시간 렌더링        │
│    practice.md)      │                      │
│                      │                      │
│  ## 제목              │  제목                 │
│  **굵게**             │  굵게                 │
│  ![img](...)         │  [이미지 표시됨]       │
└──────────────────────┴──────────────────────┘
```

> 💡 편집창에서 입력하면 미리보기가 **실시간으로 반영됨.**

## STEP 5. Paste Image 설정 (이미지 경로를 폴더 구조에 맞게)

이미지 붙여넣기 전에 저장 경로를 우리 폴더 구조에 맞게 설정해야 함.

```
Ctrl + Shift + P  →  "Open User Settings JSON" 검색 → Enter
```

아래 내용을 추가함:

```json
{
  "pasteImage.path": "${projectRoot}/assets/img/posts",
  "pasteImage.basePath": "${projectRoot}",
  "pasteImage.prefix": "/assets/img/posts/"
}
```

> 💡 **왜 이 경로인가?**  
> `assets/img/posts/`는 Jekyll에서 이미지를 저장하는 표준 경로임.  
> 지금부터 이 경로에 이미지를 저장하는 습관을 들이면, Jekyll로 그대로 이어짐.

> ⚠️ 기존 내용이 있으면 맨 마지막 `}` 앞에 `,` 붙이고 위 내용 추가할 것.

## STEP 6. Markdown 문법 실습

아래 내용을 `_posts/practice.md`에 직접 입력하면서 미리보기로 확인할 것.

### 실습 1 — 제목과 텍스트 강조

```markdown
# 내 이름: 홍길동
## 학번: 20240001
### 전공: 정보보안

**굵게 표시** 와 *기울임* 과 ~~취소선~~ 을 연습함.

`인라인 코드`는 이렇게 표시됨.
```

**확인 포인트:** 미리보기에서 제목 크기가 다른지, 굵게/기울임이 적용됐는지 확인.

---

### 실습 2 — 목록과 체크리스트

```markdown
## 오늘 실습 목록

- VSCode 설치
- 플러그인 설치
  - Markdown All in One
  - Markdown Preview Enhanced
- 실습 폴더 생성

## 진행 현황

- [x] VSCode 설치 완료
- [x] 플러그인 설치 완료
- [ ] 이미지 붙여넣기 실습
- [ ] 표 작성 실습
```

**확인 포인트:** 들여쓰기된 하위 목록, 체크박스 확인.

---

### 실습 3 — 표 작성

```markdown
## 내 정보

| 항목 | 내용 |
|:---|:---|
| 이름 | 홍길동 |
| 학번 | 20240001 |
| 전공 | 정보보안학과 |
| 관심 분야 | 네트워크 보안 |
```

> 💡 `Alt + Shift + F` 를 누르면 표의 열 너비가 자동 정렬됨.

---

### 실습 4 — 코드 블록

````markdown
## 내가 배운 명령어

```bash
# 네트워크 스캔
nmap -sV 192.168.1.1
```

```python
# Hello World
print("Hello, Security!")
```
````

**확인 포인트:** 언어별로 색이 다르게(문법 강조) 표시되는지 확인.

---

### 실습 5 — 이미지 붙여넣기

```
1. Win + Shift + S  →  화면 일부 캡처 (클립보드에 저장됨)
2. _posts/practice.md 편집창에서 이미지를 넣을 위치에 커서 이동
3. Ctrl + Alt + V  →  파일명 입력창 나옴 → Enter
```

**자동 삽입 결과:**

```markdown
![screenshot](/assets/img/posts/2026-03-04-screenshot.png)
```

> 💡 **Jekyll 연결 포인트:**  
> 이 경로(`/assets/img/posts/...`)가 Jekyll에서 이미지를 표시하는 경로와 **완전히 동일함.**  
> 즉, 지금 연습한 방식이 그대로 블로그 포스트 작성 방법이 됨.

**확인 포인트:** 미리보기에서 이미지가 실제로 보이는지 확인.

---

### 실습 6 — Front Matter 추가

이제 연습 파일에 Jekyll용 Front Matter를 추가해봄.

```markdown
---
title: "홍길동의 첫 번째 포스트"
date: 2026-03-08 12:00:00 +0900
categories: [실습, Markdown]
tags: [vscode, markdown]
---

# 홍길동 (20240001) - Markdown 실습
```

> 💡 **이것이 Jekyll 포스트의 완성된 형태임.**  
> Front Matter + Markdown 내용 = Jekyll 블로그 포스트.  
> 이 파일을 나중에 `_posts/` 폴더에 넣고 `git push`하면 블로그에 바로 올라감.

## Jekyll과의 비교 정리

| 항목 | 지금 실습 | Jekyll 블로그 |
|:---|:---|:---|
| Markdown 파일 위치 | `_posts/practice.md` | `_posts/YYYY-MM-DD-제목.md` |
| 이미지 저장 위치 | `assets/img/posts/` | `assets/img/posts/` ← **동일** |
| 이미지 경로 | `/assets/img/posts/파일명` | `/assets/img/posts/파일명` ← **동일** |
| Front Matter | 실습 6에서 작성 | 포스트 최상단에 필수 |
| 미리보기 | VSCode 플러그인 | `bundle exec jekyll serve` |

> 💡 **결론:**  
> 지금 실습한 환경이 Jekyll 블로그 환경임.  
> `git push`만 추가하면 전 세계에 공개되는 포트폴리오 사이트가 됨.

## 자주 발생하는 오류

| 증상 | 원인 | 해결 방법 |
|:---|:---|:---|
| 이미지가 미리보기에서 안 보임 | 폴더가 아닌 파일만 열었음 | `File → Open Folder`로 다시 열기 |
| `Ctrl+Alt+V`가 반응 없음 | Paste Image 설정 누락 | settings.json 설정 확인 |
| 표가 한 줄로 붙어 보임 | 파이프(`\|`) 앞뒤 공백 없음 | `Alt+Shift+F`로 자동 정렬 |
| 코드 색상이 안 나옴 | 언어명 미지정 | ` ```bash `, ` ```python ` 처럼 언어명 추가 |
