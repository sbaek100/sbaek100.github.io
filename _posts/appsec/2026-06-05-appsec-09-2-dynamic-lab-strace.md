> 이 글은 **실습** 입니다. 개념은 앞 글(**09-1**)의 1장(동적분석)을 먼저 읽으세요.  
> 이 실습은 **Kali(192.168.0.10)** 에서 진행합니다. (HTTP 연결 관찰엔 06장의 Ubuntu Apache가 있으면 좋습니다.)
{: .prompt-info }

## 0. 목표

**동적분석(DAST)** 의 기본인 **시스템콜 추적** 을 `strace` 로 직접 해 봅니다. 프로그램이 **어떤 파일을 열고, 어디로 접속하는지** 를 소스코드 없이도 관찰합니다.

> **시스템콜(system call)** = 프로그램이 운영체제에 하는 요청(파일 열기, 네트워크 연결 등). 이걸 보면 프로그램의 **진짜 행동** 을 알 수 있습니다.
{: .prompt-tip }

---

## 1. (Kali) strace 설치

```bash
# === Kali에서 실행 ===
sudo apt update
sudo apt install -y strace
```

---

## 2. (Kali) 어떤 파일을 여는지 관찰

`cat` 이 파일을 읽을 때 일어나는 **파일 열기(openat)** 시스템콜만 추려서 봅니다.

```bash
# === Kali에서 실행 ===
strace -e trace=openat cat /etc/hostname
```

출력에서 다음과 같은 줄을 찾습니다.

```
openat(AT_FDCWD, "/etc/hostname", O_RDONLY) = 3
```

- 프로그램이 **정확히 어떤 파일을 열었는지** 가 보입니다.
- 악성코드 분석에서, 프로그램이 **`/etc/passwd` 같은 민감 파일** 을 몰래 여는지 이렇게 잡아냅니다.

---

## 3. (Kali) 어디로 접속하는지 관찰

이번엔 **네트워크 연결(connect)** 시스템콜을 봅니다. 06장에서 만든 Ubuntu 웹서버(192.168.0.30)로 접속해 봅니다.

```bash
# === Kali에서 실행 ===
strace -e trace=connect curl -s http://192.168.0.30 -o /dev/null
```

출력에서 접속 대상을 확인합니다.

```
connect(5, {sa_family=AF_INET, sin_port=htons(80),
        sin_addr=inet_addr("192.168.0.30")}, 16) = ...
```

- 프로그램이 **192.168.0.30 의 80번 포트** 로 접속하는 것이 그대로 드러납니다.
- 악성코드가 **외부 명령제어(C2) 서버** 로 몰래 접속하는지도 이렇게 탐지합니다.

> Ubuntu Apache가 없으면 `curl -s http://example.com` 처럼 외부 주소로 바꿔도 됩니다.
{: .prompt-tip }

---

## 4. (Kali) 전체 동작 요약 보기

특정 시스템콜이 **몇 번** 호출됐는지 통계로 보면, 프로그램의 성격을 빠르게 파악할 수 있습니다.

```bash
# === Kali에서 실행 ===
strace -c curl -s http://192.168.0.30 -o /dev/null
```

- `-c` 는 시스템콜 **횟수·시간 요약표** 를 출력합니다. (파일을 많이 여는지, 네트워크가 많은지 등)

> 참고: 라이브러리 함수 호출을 보려면 `ltrace` 를 씁니다. (`sudo apt install -y ltrace` 후 `ltrace ls`)
{: .prompt-tip }

## 5. 정적분석과 비교 (08장과 연결)

| | 08-3 정적분석(semgrep) | 09-2 동적분석(strace) |
|---|---|---|
| 방법 | 코드를 **안 돌리고** 패턴 검사 | **실행하며** 시스템콜 관찰 |
| 본 것 | `os.system`·하드코딩 등 코드 위험 | 실제로 연 파일·접속한 주소 |
| 한계 | 실행 시 행동은 못 봄 | 실행된 경로만 봄 |

> 🟢 **결론**: 둘을 **함께** 써야 한다. 정적분석으로 코드 위험을 잡고, 동적분석으로 실제 행동을 확인한다.
{: .prompt-tip }

## 6. 체크리스트

- [ ] `strace -c` 로 시스템콜 통계 확인
