# 5-2 집계 함수 실습 — 성적 DB


---

## 이번 실습에서 쓸 함수 목록

| 함수 | 한마디 설명 |
|---|---|
| `COUNT(*)` | 몇 개야? (행 개수) |
| `SUM(칼럼)` | 다 더하면 얼마야? (합계) |
| `AVG(칼럼)` | 평균이 얼마야? |
| `MAX(칼럼)` | 제일 큰 값이 뭐야? |
| `MIN(칼럼)` | 제일 작은 값이 뭐야? |

---

## STEP 1. 데이터베이스 만들기

> MySQL 워크벤치를 열고, 아래 SQL을 **위에서부터 한 줄씩** 실행한다.
{: .prompt-tip }

```sql
-- 새 데이터베이스를 만든다
CREATE DATABASE score_db;

-- 만든 데이터베이스로 들어간다
USE score_db;
```

실행 후 왼쪽 Navigator에 `score_db`가 생기면 성공이다. ✅

---

## STEP 2. 테이블 만들기

학생들의 국어, 수학, 영어 점수를 저장하는 테이블을 만든다.

```sql
CREATE TABLE scores (
  id      INT,
  name    VARCHAR(20),
  subject VARCHAR(20),
  score   INT,
  grade   INT
);
```

칼럼이 뭔지 먼저 확인해두자.

| 칼럼명 | 의미 | 예시 값 |
|---|---|---|
| `id` | 번호 | 1, 2, 3 … |
| `name` | 학생 이름 | 민준, 서연 … |
| `subject` | 과목 이름 | 국어, 수학, 영어 |
| `score` | 점수 | 85, 92, 70 … |
| `grade` | 학년 | 1, 2, 3 |

## STEP 5. COUNT — 개수 세기

### 실습 5-1. 전체 데이터가 몇 줄인지 세어보기

```sql
SELECT COUNT(*) AS 총데이터수
FROM scores;
```

> 결과: **15**  
> 아까 넣은 데이터가 15줄이었으니까 맞다.
{: .prompt-info }

### 실습 5-2. 수학 점수만 몇 개인지 세기

```sql
SELECT COUNT(*) AS 수학데이터수
FROM scores
WHERE subject = '수학';
```

> 결과: **5**  
> 학생 5명의 수학 점수가 있으니까 맞다.

### 실습 5-3. 80점 이상인 점수가 몇 개인지 세기

```sql
SELECT COUNT(*) AS 고득점수
```

## STEP 6. SUM — 합계 구하기

### 실습 6-1. 전체 점수 합계

```sql
SELECT SUM(score) AS 전체점수합계
FROM scores;
```

---

### 실습 6-2. 민준이의 점수 합계

```sql
SELECT SUM(score) AS 민준점수합계
FROM scores
WHERE name = '민준';
```

> 민준이의 점수는 85 + 92 + 78 = **255**가 나와야 한다.
{: .prompt-info }

---

### 실습 6-3. 영어 과목 전체 합계

```sql
SELECT SUM(score) AS 영어점수합계
FROM scores
WHERE subject = '영어';
```

---

## STEP 7. AVG — 평균 구하기

### 실습 7-1. 전체 점수 평균

```sql
SELECT AVG(score) AS 전체평균
FROM scores;
```

---

### 실습 7-2. 국어 과목 평균 점수

```sql
SELECT AVG(score) AS 국어평균
FROM scores
WHERE subject = '국어';
```

---

### 실습 7-3. 1학년 학생들의 평균 점수

```sql
SELECT AVG(score) AS 일학년평균
FROM scores
WHERE grade = 1;
```

> 1학년은 민준, 서연 — 총 6개 점수의 평균이 나온다.
{: .prompt-info }

---

## STEP 8. MAX / MIN — 최고점·최저점 찾기

### 실습 8-1. 전체에서 가장 높은 점수와 가장 낮은 점수

```sql
SELECT MAX(score) AS 최고점수,
       MIN(score) AS 최저점수
FROM scores;
```

---

### 실습 8-2. 수학 과목에서 최고점과 최저점

```sql
SELECT MAX(score) AS 수학최고,
       MIN(score) AS 수학최저
FROM scores
WHERE subject = '수학';
```

---

### 실습 8-3. 하은이의 최고점과 최저점

```sql
SELECT MAX(score) AS 하은최고,
       MIN(score) AS 하은최저
FROM scores
WHERE name = '하은';
```

---

## STEP 9. 여러 함수 한꺼번에 쓰기

지금까지 배운 함수를 모두 한 번에 쓸 수 있다.

### 실습 9-1. 전체 성적 통계 한눈에 보기

```sql
SELECT
    COUNT(*)      AS 총데이터수,
    SUM(score)    AS 점수합계,
    AVG(score)    AS 점수평균,
    MAX(score)    AS 최고점,
    MIN(score)    AS 최저점
FROM scores;
```

결과 예시:

```
총데이터수 | 점수합계 | 점수평균 | 최고점 | 최저점
   15    |  1212  |  80.8  |  95  |  55
```

---

### 실습 9-2. 수학 과목만 통계 내기

```sql
SELECT
    COUNT(*)      AS 수학응시수,
    SUM(score)    AS 수학합계,
    AVG(score)    AS 수학평균,
    MAX(score)    AS 수학최고,
    MIN(score)    AS 수학최저
FROM scores
WHERE subject = '수학';
```

## STEP 10. DISTINCT — 중복 없이 목록 보기

### 실습 10-1. 어떤 학생이 있는지 목록 보기 (중복 없이)

```sql
SELECT DISTINCT name
FROM scores;
```

> 15줄의 데이터가 있어도, 학생 이름은 5명만 나온다.
{: .prompt-info }

---

### 실습 10-2. 학생이 총 몇 명인지 세기

```sql
SELECT COUNT(DISTINCT name) AS 학생수
FROM scores;
```

> 결과: **5** (민준, 서연, 지호, 하은, 준서)
{: .prompt-info }
